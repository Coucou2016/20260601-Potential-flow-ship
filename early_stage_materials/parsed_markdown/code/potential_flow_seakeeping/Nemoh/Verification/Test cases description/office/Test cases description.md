# Test cases description

These test cases allow verification of Nemoh results against Aquaplus results.

Cylinder :

-	One body
-	Uses symmetry about (xOz) 
-	Deep water
-	Wave direction 0°
-	Direct (Gauss) solver
-	Tecplot file Cylinder/results/cylinder.lay shows comparisons of Aquaplus and Nemoh results for hydrodynamic coefficients.

Nonsymmetrical

-	One body
-	Non symmetrical body
-	Deep water
-	Wave direction 0°
-	Direct (Gauss) solver
-	Tecplot files Non-Symmetrical-1.lay and Non-Symmetrical-2.lay show comparisons

2Bodies

-	2 different bodies
-	Uses symmetry about (xOz) 
-	Finite water depth (20m)
-	Wave direction 45°
-	Direct (Gauss) solver
-	Tecplot file 2Bodies.lay shows comparisons of Aquaplus and Nemoh results for hydrodynamic coefficients

Postprocessing

-	One body
-	Uses symmetry about (xOz) 
-	Finite water depth (10m)
-	Wave direction 45°, wave frequency 0.8 rad/s
-	Direct (Gauss) solver
-	Tecplot file Postprocessing.lay shows comparisons of Aquaplus and Nemoh results for free surface elevation and far field coefficients.
