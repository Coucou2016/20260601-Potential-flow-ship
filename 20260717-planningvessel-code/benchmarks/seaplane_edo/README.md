# EDO 106-K 真实浮筒型值数据

## 来源和身份

- Robert B. Liddell，1942，The Aerodynamic Tests of Three Edo Floats for the SB2U-3, OS2U-2, and XSB2C-2 Seaplanes，NACA-WR-L-722。
- NASA 原始来源：https://ntrs.nasa.gov/citations/19930092989 。页面声明美国政府作品，允许公众使用。
- 原始 PDF：`source/naca_wr_l_722.pdf`；表 I 位于 PDF 第6页，原表截图 `source/table106.png`。
- `106k_offsets_inches.csv` 为逐行人工对照扫描图转录，24条记录。112站折角半宽为 **22.30**，不是文本识别的22.10。原表335站半宽确实为6.32，未为使形状平滑而擅自修改。
- 表内空白表示原文未提供，不是零。原表单位为实尺度英寸，1英寸=0.0254米。
- 下载字节保留不变。pypdf提示文件头异常并恢复读取；PyMuPDF可读取20页并渲染表格。该情况不应被描述为原PDF无缺陷，来源字节哈希记录在输出manifest中。

## 重建范围

对应SB2U-3飞机浮筒的106-K改型，不是整个飞机。原报告明确存在浅槽与底部外飘；目前仅连接龙骨、折角和已知内纵骨点，不声称解析这些点之间的完整曲率。

坐标：x从首向后，y横向，z从原文基准面向上；不是求解器机体坐标，也不是从静水面向下的剖面坐标。接入求解必须显式转换，并提供姿态、浸深、重心位置。

179F/179A和325F/325A为断阶前后两侧，保留相同纵向坐标及不同高度，禁止排序去重或跨断阶平滑。网格是**开口底面**，不含舷侧、甲板、尾封板和断阶立面，不可用于封闭体积积分，也不是水动力程序已计算出的湿表面。

浮筒全长8.509米，最大折角宽1.143米。甲板高度虽然记录在表中，但甲板横向轮廓不足，故暂不构造甲板。

## 复现

在项目根目录运行 `python scripts/build_edo_geometry.py`。

输出 `outputs/edo106k_geometry_20260916/`：OBJ与NPZ底面网格、PNG/PDF/SVG图、源文件哈希和自包含HTML报告。该目录只包含几何核查，没有编造起降时间历程或压力场。

双/三浮体装配接受调用者显式提供的位置，保留各体编号并保守拒绝包围盒相交；用户定义布局不等于任何真实飞机/三体船。该接口不计算水动力干扰。
