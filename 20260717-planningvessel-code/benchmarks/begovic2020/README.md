# Begovic Monohedral Regular-Head-Wave Benchmark

This directory provides a reproducible independent motion benchmark for the
linear planing-craft Gate 2 peak-frequency check.

## Sources and scope

- The frozen PDF is Kahramanoglu, Cakici and Dogrul (2020), *Numerical
  Prediction of the Vertical Responses of Planing Hulls in Regular Head
  Waves*, Journal of Marine Science and Engineering 8, 455,
  DOI `10.3390/jmse8060455`.
- Table 1 supplies the monohedral hull particulars.
- Table 4 supplies the eight regular-wave conditions used at each of three
  beam Froude numbers.
- Figures 6--8 republish experimental fluid dynamics (EFD) results from
  Begovic, Bertorello and Pennino (2014), *Experimental seakeeping assessment
  of a warped planing hull model series*, Ocean Engineering 83, 1--15.
- Begovic et al. (2014), Table 3, supplies the measured calm-water running
  trim and sinkage at the three seakeeping speeds.
- Javaherian (2021), Virginia Tech PhD dissertation, printed page 158,
  Table 5.2, transcribes the corresponding experimental wetted lengths from
  Begovic and Bertorello (2012). The dissertation PDF is frozen in `source/`;
  this is explicitly a secondary transcription, not a new measurement.
- Only the red-triangle monohedral EFD heave and pitch response-amplitude
  operators are digitized here. The 2020 computational curves are not used as
  acceptance references.

The pitch ordinate is `eta_5 / (A k)`, not `eta_5 / A`. The heave ordinate is
`eta_3 / A`. The wave frequencies, wave numbers, wavelengths and amplitudes
come directly from Table 4 rather than from graph coordinates.

The Gate 2 comparison prescribes the measured running trim and keel wetted
length from `begovic2014_mono_calm_water_running_state.csv`. This is necessary
because the towing arrangement and its moment are part of the experiment;
re-solving a force-and-moment equilibrium with a model that omits that towing
moment changes the measured operating point. The measured sinkage is retained
for provenance but is not converted into the package vertical coordinate,
because the source datum and sign convention are not sufficiently explicit.

## Reproduction

From the project root:

```powershell
python scripts/digitize_begovic2020_regular_wave.py
```

The script verifies the source PDF SHA-256, extracts the six embedded graph
rasters, verifies each raster SHA-256, locates the red EFD markers at the eight
tabulated wavelength ratios, and writes:

- `begovic2020_mono_hull.csv`
- `begovic2020_regular_wave_conditions.csv`
- `begovic2020_mono_efd_motion_digitized.csv`
- `begovic2020_digitization_audit.csv`

The calm-water running-state table is a frozen hand transcription and is not
regenerated by the graph digitizer.

The audit file records every selected pixel, alternative marker candidate and
the assigned graph-reading uncertainty. A legend marker overlaps the C7 search
window in some embedded plots; the script resolves it using continuity between
the adjacent tabulated EFD points and retains all candidates in the audit file.

## Validation boundary

The data provide 24 motion conditions (three speeds by eight wavelengths), so
the response peak can be bracketed at multiple speeds. They do not provide an
independent experimental phase series in the 2020 figures. Bow-acceleration
graphs are trough-to-peak quantities and may include nonlinear impact effects;
they remain diagnostic rather than a small-amplitude linear hard gate. Fridsma
data continue to provide the Gate 2 phase and acceleration checks.

No response value in this directory may be used to fit, scale or invert a
hydrodynamic input. The EFD values are acceptance evidence only.
