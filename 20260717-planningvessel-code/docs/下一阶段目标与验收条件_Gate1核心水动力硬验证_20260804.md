# 下一阶段目标与验收条件：Gate 1 核心水动力硬验证

日期：2026-08-04

## 1. 与总体目标的关系

本阶段服务于《高速船型运动预报系统总体目标》。

总体目标是形成从排水船型、半排水船型到高速滑行艇，并可继续扩展至多体船、三体船和水翼船的统一运动预报系统。当前最关键的基础不是继续扩大船型范围，而是先把高速船型运动预报系统的线性 2.5D 水动力核心做实。

因此，下一阶段只聚焦一个核心问题：让默认 `matched_bie_station_sweep` 路线下的 Ma--Duan--Song 型线性高速 2.5D 求解器，通过可追溯的文献硬验证。

## 2. 当前进展

## 3. 下一阶段目标

完成 Ma 2005 Wigley III Gate 1 核心水动力硬验证，使默认 `LinearFrequencyProvider(source="linear_2p5d", formulation="matched_bie")` 路线能够在不使用经验拟合补偿的前提下，复现 Ma--Duan--Song 型线性高速 2.5D 方法的升沉/纵摇八个频域水动力系数。

若八个系数仍不能全部通过，则本阶段必须交付可复查的失败封口结果：明确每个失败系数对应的公式位置、数值分量、已排除候选、剩余理论缺口或数据缺口，并说明为什么不能把当前模型作为已验证完整 2.5D 模型使用。

## 4. 阶段范围

本阶段必须完成：

1. 固定 Ma 2005 Wigley III 参考数据、频率、几何、无量纲化和误差门槛。
2. 修正或封口 `Eq.30` 压力恢复、`Eq.31/Eq.32` 前进速度项、端部项、广义力行、局部时间推进和整船积分装配。
3. 保持默认模型路线为 `matched_bie_station_sweep`，所有候选路线只作为诊断输出。
4. 保持示例运动预报链路可运行，输出文件结构不破坏。
5. 同步更新验证报告和阶段文档。

本阶段暂不展开：

1. 强非线性 2D+t 生产级自由面边界元。
2. Delft 372 双体船硬验收。
3. C1 三体船硬验收。
4. SL-7 硬验收。
5. 水翼船控制模型硬验收。

这些内容保留为后续阶段；在当前 Gate 1 未通过前，不作为核心验收目标。

## 5. 可验收条件

| 类别 | 验收条件 | 判定方式 |
|---|---|---|
| 默认路线 | 默认求解器仍为 `linear_2p5d/matched_bie`，输出元数据 `provider_route == matched_bie_station_sweep`。 | 检查验证 CSV 和运行报告。 |
| 八系数硬验证 | `A33/B33/A55/B55` 误差不超过 15%；`A35/B35/A53/B53` 误差不超过 30%。 | `ma2005_wigley_iii_coefficients_comparison.csv` 八项全部 `PASS`。 |
| 非拟合原则 | 不允许通过最终系数倍率、单项经验补偿或针对 Ma 2005 的硬编码来通过。 | 代码审查和诊断 CSV 中无 `candidate_default_gate_eligible=false` 候选进入默认主线。 |
| 公式可追溯 | 每处默认修正必须能对应到 Ma 2005/A1 公式、边界条件、坐标定义、积分定义或离散格式。 | 代码、验证报告和阶段文档均记录来源与理由。 |
| 失败封口 | 若未全部通过，每个失败系数必须给出主要误差来源排序和下一步所需证据。 | `gate1_remaining_blocker_summary.csv` 与失败报告可读、可复查。 |
| 数值稳定 | 验证输出不得出现 `NaN`、`Inf` 或不可解释的矩阵奇异失败。 | 验证结果扫描和测试结果通过。 |
| 示例链路 | `configs/example_planing.yml` 可生成 `summary.csv`、`rao.csv`、时域 CSV、图片和报告。 | 命令行运行成功，输出文件齐全。 |
| 回归测试 | 全量测试通过。 | `python -m pytest -q` 通过。 |
| 文档同步 | 当前进展、修正依据、失败项、排除候选和剩余缺口写入 `docs`。 | 新阶段报告或当前 Gate 1 报告更新。 |
| 数据边界 | SL-7、C1 三体船在缺真实 machine-readable offsets 前不得作为硬验收基准。 | 验证报告中继续标记为参考缺口或 surrogate。 |

## 6. 固定验收命令

Gate 1 验收命令：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

示例运动链路命令：

```powershell
python -m planing_seakeeping run configs\example_planing.yml --out outputs\gate1_linear_2p5d_hard_pass_motion_demo
```

回归测试命令：

```powershell
python -m pytest -q
```

## 7. 本阶段完成判据

本阶段有两种可接受结局。

第一种是硬通过：Ma 2005 Wigley III 八个系数全部达到 Gate 1 误差门槛，默认 2.5D matched BIE 主线保持不变，示例运动链路和全量回归测试全部通过，文档同步完成。

第二种是失败封口：如果八个系数仍未全部通过，必须把失败压缩为明确的理论或数据缺口；所有已排除候选要有 CSV 证据，所有剩余阻塞要说明所需文献、公式、独立截面参考或真实 offsets。此时不能宣布完整 2.5D 已通过，但可以验收为“Gate 1 失败源已清楚界定，可进入定向补证阶段”。
