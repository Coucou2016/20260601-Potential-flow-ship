# 下一阶段阶段目标与验收条件：线性高速 2.5D 核心可信闭环

日期：2026-08-09  
对应总体目标：高速船型运动预报系统总体目标  
阶段定位：总体目标下的第二轮核心模型实化阶段

## 1. 当前进展核定

当前项目已经完成第一轮可扩展框架建设，但尚未完成核心 2.5D 水动力模型的硬验证闭环。

已经完成：

1. 已建立 `planing_seakeeping` Python 包和命令行入口。
2. 已支持船型、质量惯性、航速、规则波、不规则波、海流、风和数值参数的配置读取。
3. 已形成示例滑行艇计算流程，可输出运动响应、响应幅值算子、时间序列、加速度、图像和报告。
4. 已预留 `linear_2p5d`、`nonlinear_2dt`、`multihull`、`hydrofoil` 等内核目录，框架具备后续扩展位置。
5. 已建立文献索引、理论公式整理、阶段报告和验证输出体系。
6. 已围绕 Ma 2005 Wigley III 线性 2.5D 算例建立固定验证入口和大量诊断表。

当前未完成的关键问题：

1. Ma 2005 Wigley III 八个核心频域水动力系数尚未通过 Gate 1。
2. 当前默认 `matched_bie_station_sweep` 路径仍不能作为可信默认线性 2.5D 内核。
3. `A33/A53` 的 body potential 到时间压力尺度链仍未闭合。
4. `B33/A35/B35` 的前进速度梯度项、站位输运项和零 `m3` 几何输运链仍未闭合。
5. `A55/B55` 的 pitch row moment、Stokes 项、端部项和固定控制面矩链仍未闭合。
6. 现有候选修正均只能作为诊断证据，不能作为默认模型替换。

当前 Ma 2005 Wigley III 固定验证结果如下：

| 系数 | 参考值 | 当前计算值 | Gate error ratio | 状态 |
|---|---:|---:|---:|---|
| A33 | 1.000 | 10.186 | 61.243 | FAIL |
| B33 | 2.100 | 9.180 | 22.478 | FAIL |
| A35 | -0.200 | -2.701 | 41.680 | FAIL |
| B35 | 0.130 | 6.541 | 164.377 | FAIL |
| A53 | 0.150 | 1.418 | 28.176 | FAIL |
| B53 | -0.100 | -0.252 | 5.069 | FAIL |
| A55 | 0.063 | 0.160 | 10.249 | FAIL |
| B55 | 0.090 | 1.859 | 131.016 | FAIL |

因此，当前结论是：系统框架可运行、可扩展、可诊断，但线性高速 2.5D 核心水动力模型尚未达到可验证可信状态。

## 2. 下一阶段唯一主目标

下一阶段唯一主目标是：

完成线性高速 2.5D 核心水动力模型的 Gate 1 闭环，使 Ma 2005 Wigley III 的八个核心频域水动力系数 `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 在默认 `matched_bie_station_sweep` 路径下全部通过固定验证，并形成可追溯的公式链、实现链、诊断链、测试链和报告链。

本阶段的实质目标不是继续扩展功能数量，而是把“能运行的框架”推进为“核心 2.5D 水动力计算可信”的研究型计算内核。

## 3. 本阶段工作范围

必须完成：

1. 固定 Ma 2005 Wigley III 为首要硬验证对象。
2. 以 A1/Ma 2005 的线性高速 2.5D 方程链为主要理论依据。
3. 修正默认 `matched_bie_station_sweep` 中的方程、符号、相位、归一化、站位积分、压力梯度项、Stokes 项、端部项和整船装配问题。
4. 按三条问题链闭合八个系数：
   - `A33/A53`：body potential 与时间压力尺度链。
   - `B33/A35/B35`：前进速度梯度项、几何输运项和站位积分链。
   - `A55/B55`：pitch row moment、Stokes body moment、端部项和控制面矩链。
5. 保留所有诊断输出，用于解释每次默认路径修改的理论来源、数值影响和失败排除理由。
6. Gate 1 通过后，重新运行滑行艇规则波与不规则波示例，证明核心修正没有破坏上层运动预报流程。

暂不作为本阶段主线验收：

1. SL-7 真实 offsets 的完整闭环。
2. C1 三体船真实 offsets 的完整闭环。
3. Delft 372 双体船完整斜浪六自由度验证。
4. Sun-Faltinsen 强非线性 2D+t 自由面边界元生产内核。
5. 水翼、压浪板、控制器和真实水翼自由面耦合模型。

上述内容可以继续整理资料和预留接口，但不能替代本阶段 Gate 1 主验收。

## 4. 可验收条件

### 4.1 固定验证入口可复现

必须稳定运行以下命令：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

验收要求：

1. 命令可重复运行。
2. 输出文件路径固定。
3. 参考数据来源固定。
4. 判定规则固定。
5. 不得通过手动改 CSV、后处理缩放或单项拟合制造通过结果。

### 4.2 八个核心系数全部通过

`ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 必须满足：

1. `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 全部为 `PASS`。
2. 每个系数的 `gate_error_ratio <= 1.0`。
3. 计算值不得出现 `NaN`、`Inf`、空值或明显数值发散。
4. 通过结果必须来自默认 `matched_bie_station_sweep` 路径。
5. 诊断候选路径不得混入默认验收结果。

### 4.3 公式链可追溯

每个通过的系数必须能追溯到以下环节：

1. 二维剖面边界条件。
2. 自由面 marching。
3. 压力公式。
4. 前进速度压力梯度项。
5. 几何输运项。
6. Stokes body 项。
7. 端部控制面项。
8. 站位积分。
9. 整船水动力矩阵装配。
10. Ma 2005 归一化公式。

每个默认路径修改必须说明属于文献公式修正、坐标符号修正、离散实现修正、相位修正、归一化修正还是装配修正。

### 4.4 诊断证据完整

固定输出目录中至少保留：

1. `ma2005_wigley_iii_coefficients_comparison.csv`
2. `ma2005_wigley_iii_coefficients_status_by_coefficient.csv`
3. `ma2005_wigley_iii_coefficients_eq30_component_contribution_audit.csv`
4. `ma2005_wigley_iii_coefficients_*summary.csv`
5. `validation_summary.csv`
6. `validation_status_by_benchmark.csv`
7. `validation_report.md`

每个候选修正必须标注为：

1. 默认实现。
2. 诊断候选。
3. 已排除候选。
4. 后续待证候选。

不得把未通过硬验证的候选修正提升为默认模型。

### 4.5 测试通过

必须通过：

```powershell
python -m py_compile planing_seakeeping\validation.py tests\test_validation.py
python -m pytest -q
```

验收要求：

1. 全量测试通过。
2. 新增或修改的默认路径必须有对应回归测试。
3. 诊断工具必须有最小可运行测试。
4. 若全量测试因耗时或外部依赖无法完成，必须在阶段报告中记录原因、替代测试命令和结果。

### 4.6 示例运动预报可复现

Gate 1 通过后，必须重新运行：

```powershell
python -m planing_seakeeping run configs\example_planing.yml --out outputs\gate1_linear_2p5d_hard_pass_motion_demo
```

输出目录必须包含：

1. `summary.csv`
2. `rao.csv`
3. `timeseries_regular_speed_*.csv`
4. `timeseries_irregular_speed_*.csv`
5. `figures/rao.png`
6. `figures/rms_by_speed.png`
7. `figures/timeseries_*.png`
8. `run_report.md`

报告必须明确说明迎浪线性模型中横荡、横摇、艏摇为零或近零的物理原因，不能把该结果表述为完整斜浪六自由度模型已经完成。

### 4.7 阶段报告更新

必须更新阶段报告，至少包含：

1. 当前方法说明。
2. 参考数据来源。
3. 八个核心系数修正前后对照。
4. 误差来源和修正原因。
5. 失败候选排除理由。
6. 诊断文件索引。
7. 测试命令和结果。
8. 当前适用范围和剩余边界。

## 5. 阶段完成判定

只有当 Ma 2005 Wigley III 八个核心系数全部通过固定 Gate，且公式链、实现链、诊断链、测试链、示例链和报告链均完整时，本阶段才算完成。

若八个系数中任意一个仍为 `FAIL`，则本阶段状态仍为：线性高速 2.5D 核心水动力模型尚未闭环。此时后续工作应继续围绕失败系数做公式级、站位级和分量级修正，不应转向更复杂船型或更高级非线性模型作为主线。

## 6. 完成后进入下一阶段的条件

本阶段完成后，才进入下一阶段扩展：

1. SL-7 或替代高速单体船公开 offsets 验证。
2. Delft 372 双体船迎浪与斜浪验证。
3. C1 三体船或可替代公开三体船验证。
4. 滑行艇规则波和不规则波运动响应对 Fridsma/Katayama 数据进行对照。
5. 非线性 2D+t 内核从接口预留推进到最小可验证原型。
