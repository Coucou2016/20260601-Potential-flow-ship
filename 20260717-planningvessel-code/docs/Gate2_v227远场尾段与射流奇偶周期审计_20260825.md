# Gate 2 v227 远场尾段与射流奇偶周期审计

日期：2026-08-25  
结论：**两个候选均否决；二维楔形入水先决门仍为 `FAIL`，Gate 2 仍为 `17/20 PASS`。**

## 1. 审计问题

本轮回答两个彼此独立的问题：

1. `R=20` 扩大到 `R=24` 后运动学积分恶化，是否说明有限远场边界条件漏项或误差主要向内域传播？
2. N=240 长时推进中与浅水射流点数变化同步的锯齿周期，是否由射流尖端奇偶闭合方式造成？

所有候选均不读取 Zhao、Iafrati 压力或自由面参考值；参考数据只在求解后评分。

## 2. Iafrati 式（29）--（30）复核

Iafrati（2013）第 8--9 页规定，在有限远场边界 $S_F$ 上取

$$
\phi=C_D\phi_D,\qquad
\phi_D=\frac{\eta}{\xi^2+\eta^2},
$$

并由边界积分方程求 $\phi_\nu$。额外方程令远场总通量等于同一偶极解的总通量：

$$
-\sum_{j\in S_F}\phi_{\nu,j}\Delta s_j
+C_D\sum_{j\in S_F}\phi_{D\nu,j}\Delta s_j=0.
$$

当前常单元和连续线性单元实现均采用“偶极势列 + 未知远场通量 + 一条总通量方程”。代码法向为流体域外法向，原文为指向流体域的法向；两项同时变号后，上式整体只差一个可消去的负号。因此未发现漏掉第二个远场条件或单独的符号错误。

## 3. 固定内域的远场扩展反证

先前 v223/v224 使用重新分布后的 `N=240/R=20` 与 `N=288/R=24` 网格分区，导致新尾段的一部分被计入“中段”。本轮改为严格保留 v212 的全部 241 个旧节点，只在其后追加至 `R=24` 的渐近过渡尾，旧节点最大位移严格为 `0`。

| 区域 | `R=20` 精确积分 | 固定内域 `R=24` 精确积分 | 变化 |
| --- | ---: | ---: | ---: |
| 根部前 16 面板 | 0.0003670 | 0.0003643 | -0.0000027 |
| 旧中段 | 0.0018880 | 0.0019212 | +0.0000332 |
| 旧远端 16 面板 | 0.0001025 | 0.0001298 | +0.0000273 |
| 新追加尾段 | 不存在 | 0.0011233 | +0.0011233 |
| 全部 | 0.0023575 | 0.0035387 | +0.0011812 |

旧 `R=20` 区间自身只增加约 `0.0000578`，而新尾段贡献约 `0.0011233`。因此总增量约 `95%` 来自追加尾段，不能再解释为远场误差主要通过全局边界积分传播到旧中段。

式（51）给出的渐近初始形状为

$$
\eta\simeq\frac{C_D}{3\xi^2}.
$$

v212 在 `R=20` 的端点 `eta=0.03717`，而用 `C_D=8.20172` 计算的渐近值仅为 `0.006835`，两者相差约 `5.44` 倍。直接外接平滑尾段会把这一尚未松弛的差异带入新区域，所以该扩域结果不能作为远域收敛证据。

## 4. 局部面板长度预条件候选

为检验远端是否仅因根部最小面板限制全局伪时间步而松弛过慢，增加默认关闭的正定局部预条件：

$$
\frac{d\boldsymbol{x}_i}{d\tau}
=p_i\nabla S_i,
\qquad
1\le p_i\le p_{\max}.
$$

$p_i$ 按相邻面板长度与全局最小面板长度之比构造。因为 $p_i>0$，目标法向稳态 $S_\nu=0$ 不变；现有面板相对位移 CFL 仍限制每一步。

v225 采用 `p_max=16` 推进 8 步：精确 `K` 从 `0.0023575` 增至 `0.0028515`；远端 `eta` 从 `0.0371707` 增至 `0.0372075`，未向式（51）靠拢；根状态不一致最高约 `2.36%`。该候选否决，默认保持 `uniform`。

## 5. 射流尖端奇偶闭合候选

旧实现中，浅水推进停止于 $|S_\lambda|<\Delta\lambda$ 后：奇数个完整步会继续延伸 $|S_\lambda|$ 到尖端，偶数个完整步则在当前位置直接把自由面压到船体。该差异确实会产生最多一个 $\Delta\lambda$ 的奇偶总长差。

实验模式 `continuous_tip` 改为每次都闭合剩余距离；若完整步数为偶数，则把最后区间拆成两个子步，从而继续满足原文“两步组成一个边界积分面板”的规则。旧模式 `legacy_parity` 保留用于历史检查点逐位重建，模式切换作为显式状态变换记录。

从同一 v212 状态推进 8 步后：

| 指标 | 旧奇偶闭合 | 连续尖端闭合 |
| --- | ---: | ---: |
| 共同累计伪时间附近最终 `K` | 约 0.00258 | 0.002609 |
| 最大单次 `K` 跳变 | 0.000269 | 0.000302 |
| 最终根状态相对不一致 | 约 $10^{-5}$ | 0.00703 |

连续尖端闭合没有减小事件跳变，反而使最大跳变和根状态不一致增大，因此射流点数变化只是周期伴随量，不是当前平台的充分根因。该候选不进入默认算法。
