# 下一阶段目标与验收条件：线性 2.5D 核心可信化

日期：2026-08-08

## 1. 当前进展

本项目总体目标是建立从排水船型、半排水船型到高速滑行艇，并可继续扩展至多体船、三体船和水翼船的高速船型运动预报系统。当前阶段已经完成第一轮可扩展、可测试、边界清楚的工程框架，但尚未完成核心 2.5D 水动力模型的硬验证。

已完成内容如下：

1. 已建立 `planing_seakeeping` Python 包、命令行入口、配置读取、规则波/不规则波、频域响应、时域响应、六自由度统一输出、可视化和报告输出链路。
2. 已形成面向后续扩展的统一架构，包括线性 `linear_2p5d` 主线、简化滑行载荷接口、非线性 2D+t 预留接口、多体船和水翼船预留接口。
3. 示例滑行艇算例可运行，能够输出不同航速下的规则波、不规则波时历、响应幅值算子、汇总表和图表。
4. 自动验证体系已建立，覆盖数值稳定性、物理趋势、截面边界元基础检查、Faltinsen、Fridsma、Katayama、Ma 2005 Wigley III、SL-7 和完整 2.5D 求解器缺口审计。
5. 最新回归测试通过，软件层面保持稳定；最新汇总为 `64 PASS / 16 FAIL / 8 NOT_EVALUATED / 90 INFO`。

当前主要缺口如下：

1. Ma 2005 Wigley III 八个升沉/纵摇水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 在默认 `matched_bie_station_sweep` 路径下仍全部为 `FAIL`。
2. 失败源已从“结果不合理”压缩到三条具体方程链：`A33/A53` 的时间压力与体势尺度链，`B33/A35/B35` 的固定控制面几何输运链，`A55/B55` 的纵摇矩、力臂、端部项和相位拆分链。
3. 简单经验倍率、最终 `A/B` 符号翻转、相位旋转、实虚部交换、单独端部项修正和单独网格加密均不能使八系数通过，不能进入默认生产路径。

## 2. 下一阶段目标

下一阶段目标是：

在保持默认 `matched_bie_station_sweep` 路线不变、不引入经验拟合和事后补偿的前提下，完成 Ma--Duan--Song 型线性高速 2.5D 核心水动力方程链的硬验证闭环，使 Ma 2005 Wigley III 八个升沉/纵摇水动力系数全部通过 Gate 1；若仍不能全部通过，则必须把每个剩余失败项压缩到明确、可复查、可继续执行的公式项、坐标项、边界积分项、历史卷积项、端部项或参考数据缺口。

本阶段只主攻“线性高速 2.5D 核心是否可信”这一件事。非线性 2D+t、多体船、三体船、水翼船和完整斜浪六自由度模型只保留接口、资料和验证数据准备，不作为本阶段主验收目标。

## 3. 硬验收条件

| 类别 | 验收条件 |
|---|---|
| 总体方向 | 所有工作必须服务于《高速船型运动预报系统总体目标》，不得为了局部拟合偏离可验证 2.5D 主线。 |
| 默认路线 | `ma2005_wigley_iii_coefficients_comparison.csv` 中八项均使用 `matched_bie_station_sweep`，不得切换到 legacy、reduced-order、经验倍率或后处理拟合路线。 |
| 八系数 Gate 1 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部满足 `status == PASS` 且 `gate_error_ratio <= 1.0`。 |
| 公式来源 | 所有进入默认模型的修改必须能追溯到 Ma--Duan--Song、Faltinsen 或已登记文献中的方程、边界条件、归一化、坐标约定或力矩定义。 |
| 候选纪律 | 所有新修正必须先作为 `diagnostic-only` 候选输出审计表；只有八系数同时通过且有公式依据时，才允许进入默认路径。 |
| 方程闭合 | 必须分别闭合或明确封口 `Eq.30` 时间压力、`Eq.31` 前进速度压力梯度、`Eq.32` Stokes/端部项、固定控制面几何输运、`N5/m5` 纵摇力矩链和 `A/B` 复力拆分。 |
| 可复现输出 | 固定验证命令必须生成 `ma2005_wigley_iii_coefficients_comparison.csv`、失败源审计表、候选影响汇总表和 `validation_report.md`。 |
| 运动链路 | 示例运动预报仍能输出 `summary.csv`、`rao.csv`、规则波/不规则波时域 CSV、图表和运行报告。 |
| 六自由度输出 | 所有时序结果保留 `surge/sway/heave/roll/pitch/yaw` 六自由度列；迎浪主验收聚焦 heave、pitch、重心垂向加速度和艏部垂向加速度。 |
| 数值质量 | 验证结果和示例结果不得包含 `NaN`、`Infinity`、空表或不可解释异常值。 |
| 回归测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 更新阶段报告，说明修改内容、理论依据、改善项、失败项、已排除候选和下一步阻塞点。 |

## 4. 固定验收命令

核心验证命令：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

示例运动命令：

```powershell
python -m planing_seakeeping run configs\example_planing.yml --out outputs\gate1_linear_2p5d_hard_pass_motion_demo
```

回归测试命令：

```powershell
python -m pytest -q
```

## 5. 肯定需要的条件

1. 需要保持 Ma 2005 Wigley III 作为本阶段唯一硬水动力系数验收基准，避免同时追多个未闭合 benchmark。
2. 需要继续使用高质量 Markdown/PDF 文献核对 A1、A3、A4_2、A4_3、Faltinsen、Fridsma、Katayama 和 ITTC 中的公式、符号、坐标和归一化。
3. 需要记录所有数字化数据的图号、页码、坐标轴、单位和归一化，不能把曲线读数当作无来源真值。
4. 需要把 SL-7、C1 三体船和 Delft 372 保留为后续验证对象；若缺真实 offsets，可寻找公开替代船型，但本阶段不把它们作为硬通过条件。
5. 需要坚持“先诊断、再入默认路径”的开发纪律，禁止用未解释的比例因子、符号翻转或经验补偿制造表面通过。

## 6. 阶段完成判据

本阶段有两种合格出口：

1. 理想出口：Ma 2005 Wigley III 八系数全部 `PASS`，默认线性 2.5D 水动力核心进入可信验证状态，并保持示例运动链和测试全部通过。
2. 阻塞封口出口：八系数仍未全部 `PASS`，但每个失败项都有明确失败来源、已排除候选、待补文献或待补数据清单，并能说明下一步应补哪条公式、哪组 offsets 或哪项实验数据。

若只得到平滑曲线、局部改善或单个系数通过，但不能满足上述条件，则不得宣布本阶段完成。
