# 隐式自由面耦合候选验证

## 结论

**总体阶段仍未完成。** 本轮实现了隔离的隐式梯形耦合候选，通过解析振子测试，并完成含原有历史卷积的实际边界元固定剖面配对试验。它在原大步长下没有出现显式格式的异常爆发，但宽频扰动末状态尚未收敛，不能接替生产默认路线。

没有修改波浪响应倍率、试验误差门槛或生产入口。新的核文件仅由诊断脚本和测试使用。

## 一、不是旧速度子步

边界元离散写为 M*u=R*phi+h。M 是实际边界元矩阵，u 包含船体势、自由面法向速度和控制面未知量，R 把自由面已知势映射到方程右端，h 包含新时刻的已知外源与由过去控制面状态产生的历史项。q 是 u 中的自由面法向速度分块。

隐式候选将新时刻的势、波高及法向速度共同求解：

$$\eta_{n+1}=\eta_n+\frac{\Delta t}{2}(q_n+q_{n+1}),$$
$$\phi_{n+1}=\phi_n-\frac{g\Delta t}{2}(\eta_n+\eta_{n+1}).$$

eta 为波高，phi 为势，g 为重力加速度，Delta t 为实际时间步。消去新波高和新势后，若 S 从 u 中提取 q，令 alpha=g*Delta t²/4，可得：

$$(M+\alpha RS)u_{n+1}=R(\phi_n-g\Delta t\eta_n-\alpha q_n)+h_{n+1}.$$

这是真正包含新法向速度的耦合线性系统，不是在多个子步中重复使用旧速度。求解后重新检查原边界元方程 M*u=R*phi+h，而不是只检查变换后方程。输入维数、非有限值和重构残差不合格时拒绝返回有效结果。

当前实现只处理冻结几何；变化剖面的状态迁移、完整整船压力装配和生产配置接线尚未实现。

## 二、解析验证

采用 q=4*phi、g=1 的已知振子问题，检查三个方面：

1. 时间步 0.1、0.05、0.025 下与解析解比较，误差按二阶要求降低。
2. 时间步 2、总时长 200 的大步长试验中，振子二次不变量误差小于 10⁻¹²，说明该测试没有依靠额外阻尼压平振幅。大步长仍有相位误差，不能称为准确。
3. 对带复数外源的两未知量系统，原边界元方程、运动学更新和动力学更新同时成立。

这些是算法和代数验证，不是船舶试验对照。

## 三、实际边界元与历史配对

采用 Kang 船中剖面、三倍船宽控制半径、64 船体面元、128 自由面面元、192 控制面面元。对两种推进格式使用相同随机种子 24 的归一化复数初始势，同一时刻初始波高均为零。显式格式的半步波高按已求初始速度一致转换，不直接把半步值零与整步值零当成相同初始条件。

所有算例测试时长 2.21238 秒、历史时长 4.42476 秒。每一步保留原历史卷积规则，并更新实际控制面势和法向导数。初始、第二步及末步额外重组原边界元方程核查。
