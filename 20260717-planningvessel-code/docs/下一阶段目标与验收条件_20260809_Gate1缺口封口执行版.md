# 下一阶段目标与验收条件：线性 2.5D Gate 1 缺口封口执行版

日期：2026-08-09

## 1. 总体目标对齐

本阶段继续服务于《高速船型运动预报系统总体目标》：以高速滑行艇为核心，建立可扩展到排水船型、半排水船型、多体船、三体船和未来水翼船的统一运动预报系统，并形成理论、程序、算例、实验验证和报告输出的闭环。

当前不能继续盲目扩大功能面。下一阶段的核心任务是先把线性高速 2.5D 水动力求解链做实，使它成为后续六自由度运动响应、不规则波统计、非线性 2D+t、多体干扰和水翼扩展的可信根基。

## 2. 当前进展

已完成的基础能力：

1. 已建立 `planing_seakeeping` Python 包、命令行、配置读取、规则波/不规则波输入、频域/时域求解、六自由度统一输出、可视化和报告链路。
2. 已预留 `linear_2p5d`、`nonlinear_2dt`、`multihull`、`hydrofoil` 等后续扩展入口。
3. 已纳入 Ma 2005、Journee 1992、Faltinsen、Fridsma、Katayama、Delft 372、SL-7 等验证资料和基准数据。
4. 默认线性 2.5D 验证路径已固定为 `matched_bie_station_sweep`，并能输出频率配对、力项分量、站位、面元、归一化和候选路线诊断。
5. 最新固定验证汇总为 `64 PASS / 16 FAIL / 8 NOT_EVALUATED / 110 INFO`。这说明软件框架已经可运行、可诊断，但核心水动力硬验证尚未通过。

当前主要缺口：

| 项目 | 当前状态 |
|---|---|
| Ma 2005 Wigley III 八系数 | `A33/B33/A35/B35/A53/B53/A55/B55` 仍为 `0/8 PASS`。 |
| 最大 Gate Ratio | `A33=61.243`、`B33=22.478`、`A35=41.680`、`B35=164.377`、`A53=28.176`、`B53=5.069`、`A55=10.249`、`B55=131.016`。 |
| `A33/A53` | `1/pi^2` 能数值改善时间压力尺度，但还没有可追溯方程来源，不能进入默认路径。 |
| `B33/B35/B53/B55` | 阻尼链的 pressure-gradient、end-term 和固定控制面频率传递仍未闭合；Journee 分量频率趋势审计显示，相关主要分量大多近似频率不敏感，不能由统一实倍率、统一相位或简单频率趋势解释。 |
| `A35/A55` | pressure-gradient、Stokes body 和 end-term 已出现部分频率形状，但纵摇矩链中的 `N5/m5`、力臂原点、压力梯度矩、Stokes body moment 和端部项仍未统一。 |

因此，项目距离最终目标仍处在第一层核心模型验收前：系统框架已经成型，但线性 2.5D 核心水动力模型还没有达到“可验证可信”的门槛；非线性、多体船、三体船和水翼生产模型均不应在本阶段作为主攻方向。

## 3. 下一阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 缺口封口，使 `matched_bie_station_sweep` 路径在 Ma 2005 Wigley III 八个核心频域水动力系数上达到以下两种结果之一：

1. **硬通过结果**：`A33/B33/A35/B35/A53/B53/A55/B55` 全部 `PASS`，且所有进入默认路径的修正均能追溯到明确公式、坐标约定、边界条件、自由面 marching、几何输运、力矩装配、端部项或参考数据处理。
2. **封口结果**：若八系数仍不能全部通过，必须把每个失败项压缩到明确的公式缺口、坐标缺口、归一化缺口、固定控制面缺口、端部项缺口、频率配对缺口或参考数据缺口，并列明下一步必须补充的资料或推导条件。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、失败源可封口”的核心模型阶段。

## 4. 本阶段工作范围

纳入本阶段：

1. 固定 Ma 2005 Wigley III / Journee 1992 参考数据链：频率、单位、坐标、无量纲方式、数字化来源和采用理由。
2. 闭合或封口 `A33/A53` 时间压力链：body potential 尺度、局部时间映射、自由面纵向交错和归一化来源。
3. 闭合或封口 `B33/B35/B53/B55` 阻尼链：pressure-gradient、end-term、同频 A/B 配对、频率传递和固定控制面端部处理。
4. 闭合或封口 `A35/A55` 纵摇矩链：`N5/m5`、力臂原点、压力梯度矩、Stokes body moment、end-contour moment 和参考轴。
5. 保持示例滑行艇运动链路可运行，包括六自由度时序、规则波/不规则波响应、响应幅值算子、加速度和图表。
6. 更新阶段报告，保证每个结论都有代码路径、验证命令和输出文件支撑。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元。
2. 不开发双体船、三体船共同边界积分生产模型。
3. 不开发水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验倍率、最终系数拟合、按参考值反推或只对单个系数有效的局部补丁。
