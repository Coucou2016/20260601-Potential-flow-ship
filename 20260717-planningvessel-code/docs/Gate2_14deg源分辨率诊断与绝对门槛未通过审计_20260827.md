## 8. 结论与下一步

14.0°已经证明分支连续、根闭合方向有效、压力和载荷空间稳定，但没有同时满足640和1280面板的绝对运动学积分门槛。三次160面板高模态修正已经饱和；一次320面板原生修正也只获得小幅改善，并使最细网格根失配略超限。因此14.0°不能加入合格冻结同伦源清单，也不能作为13.5°的继续延拓源。

新增多网格归一化目标、根等式/无等式/指定目标约束、16/32模态以及320/640原生源分辨率诊断后，根约束网格不一致问题已经解决，但640面板绝对积分仍停在 `1.013996e-3`。这说明当前阻塞不再是简单的单网格目标、旧雅可比、根符号选择或源节点数量问题。14.0°仍不能加入合格冻结同伦源清单，也不能作为13.5°的继续延拓源。

下一步不得继续追加同类低阶/高阶修正。应转向网格无关的非线性约束离散，至少同时把640和1280面板的精确端点积分与根不等式放入同一个求解问题，并验证离散残差、根状态和自由面变量在网格间的同一物理定义。任何新方法仍必须恢复640和1280面板 `K<=1e-3`、根失配 `<=1e-3` 和三层空间稳定，才能继续向10°推进。

本轮未修改水动力方程或生产求解算法；新增/扩展的是参考隔离诊断脚本及其单元测试。多网格相关定向回归为 `21 passed, 0 failed`。完整回归首次在 NumPy 2.4.4 环境下暴露旧接口 `np.trapz` 已被移除；仓库随后等价迁移到 `np.trapezoid`，并将依赖声明为 `numpy>=2.0`。受影响模块定向回归为 `156 passed, 0 failed`；最终完整回归为 `606 passed, 0 failed, 1247 warnings, 11 subtests passed`，耗时 `156.92 s`。既有警告仍来自验证统计中的空切片，不改变本轮数值或物理判定。
