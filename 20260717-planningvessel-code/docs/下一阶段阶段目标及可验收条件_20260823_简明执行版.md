# 下一阶段阶段目标及可验收条件

日期：2026-08-23  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
阶段名称：**线性高速 2.5D 规则迎浪纵向运动独立验证闭合（Gate 2）**

> 本阶段只做实高速滑行艇线性 2.5D 规则迎浪纵向预报基线。全部硬验收条件同时满足后，才进入不规则波、斜浪六自由度、非线性 2D+t、多体船和水翼扩展。

## 1. 当前基线

1. Ma 2005 Wigley III 水动力系数 Gate 1 已通过：基准网格和加密网格均为 `10/10 PASS`，最大网格变化 `1.1465%`。
2. 规则迎浪响应方程、直接波浪激励、频域与时域求解、线性缩放、点加速度运动学及数据追溯链已经建立。
3. Gate 2 当前为 `17/20 PASS`；未通过项为 Begovic 独立试验的升沉幅值、纵摇幅值和主峰频率。
4. Sun 2007 图 7.13 的五频率八系数 `NUM` 同源数值复现尚未通过；Troesch 可见 `EXP` 标记的独立诊断表明，当前主要物理缺口集中在升沉--纵摇耦合阻尼和纵摇相关载荷。`sigma=1.40` 的 `0.10B` 局部解析补片和来源固定的 `0.5B` 有效龙骨湿长缩短均未同时闭合八系数，后者为 `0/8 PASS`，因此均不进入五频率生产路径。修正增量与文献在 `B35/B55` 上较一致，说明下一步应优先闭合未修正基线的纵向载荷幅值与作用中心，而不是继续调整艉部修正长度。

## 2. 唯一阶段目标

**在保持 Gate 1 不退化的前提下，定位并闭合生产用线性高速 2.5D/线性化 2D+t 未修正基线的纵向载荷幅值、作用中心及升沉--纵摇耦合链；先通过 Sun 2007 `NUM` 五频率八系数数值复现，再使用冻结且可追溯的 Troesch、Begovic 和 Fridsma 试验数据，完成三个航速下升沉、纵摇、相位及重心/艏部垂向加速度的独立验证，使 Gate 2 从 `17/20 PASS` 达到 `20/20 PASS`，形成可诊断、可复现并可直接扩展到不规则波的纵向运动预报基线。**

全过程禁止使用试验响应反演、经验倍率、参考值缩放、逐点拟合、选择性删点或事后改变适用区。

## 3. 硬验收条件

以下九项必须全部满足，缺一项即不判定本阶段完成。

| 编号 | 验收项 | 通过条件 |
| --- | --- | --- |
| 1 | Gate 1 不退化 | Ma 2005 十行基准与双网格收敛继续全部通过；核心内核、符号、单位、坐标和相位约定可追溯。 |
| 2 | 源级水动力闭合 | Sun 2007 `NUM` 的 `5` 个频率、`8` 个系数全部覆盖；各系数中位相对误差 `<=10%`、归一化均方根误差 `<=15%`，趋势及 `A35/A53` 非互易性正确；机器字段明确标记为同源数值复现，不冒充独立试验。 |
| 3 | 数值收敛可靠 | 强迫运动最后两级八系数变化均 `<=5%`，谐波残差 `<=5%`；运动方程复数残差 `<=1e-8`；无 `NaN/Inf`，失效频点、条件数和原因完整输出。 |
| 4 | 工况覆盖完整 | Begovic 覆盖 `Fn_B=1.67、2.26、2.82`，每个航速保留全部试验点并计算不少于 `20` 个致密频点；输出遭遇频率、复响应、幅值、相位和垂向加速度。 |
| 5 | 独立运动精度 | 预先声明的线性适用区内，升沉和纵摇中位相对误差 `<=15%`、归一化均方根误差 `<=20%`，主峰频率偏差 `<=10%`，非近零响应循环相位中位误差 `<=15 deg`；范围外数据保留并单列。 |
| 6 | 独立加速度精度 | Fridsma 重心垂向加速度归一化均方根误差 `<=25%`；艏部加速度完整输出并注明可验证范围，不以缺失试验数据代替通过。 |
| 7 | 方程与运动学自洽 | 至少 `3` 个代表频点的频域--时域幅值差 `<=5%`、循环相位差 `<=5 deg`；波幅加倍后的运动与加速度幅值比为 `2.00 +/- 5%`；点加速度解析值与程序值相对误差 `<=1e-8`。 |
| 8 | 数据和模型可追溯 | Troesch、Begovic、Fridsma 的几何、质量惯性、工况、来源页码、数字化方法、不确定度和源文件 SHA-256 全部冻结；公式--代码--测试--数据一一对应，缺失输入明确标为“待补充”，不得编造。 |
| 9 | 复现、回归和交付 | 一条固定命令从空输出目录生成输入快照、矩阵、响应、对照表、二维图、三维船型/站位图、动态可视化、报告和机器清单；完整 `python -m pytest -q` 无失败，机器结果明确为 `Gate 1 = PASS`、`Gate 2 = 20/20 PASS`。 |

## 4. 必要前提

1. **冻结输入**：Troesch、Begovic、Fridsma 的船型、质量、惯性、航速、姿态、波浪和坐标约定必须齐全；无法从文献确认的量不得靠响应曲线反推。
2. **生产内核**：必须使用真实频率相关的辐射、绕射和波浪激励矩阵；简化经验矩阵只能作为诊断对照，不能用于最终验收。
3. **独立验证分层**：Sun `NUM` 只用于同源算法复现；Troesch、Begovic、Fridsma `EXP` 才用于实验验证，两类证据必须分开报告。
4. **固定验收规则**：误差定义、近零量处理、线性适用区和频点集合均在计算前冻结，不得根据结果修改。
5. **计算与复现资源**：五频率八系数、三航速响应和收敛网格必须由脚本批量完成，并保留输入快照、日志、哈希和中间结果。

## 5. 完成判定与阶段边界

只有九项硬验收全部通过，且机器清单明确记录 `Sun_NUM_reproduction = PASS`、`Gate 1 = PASS`、`Gate 2 = 20/20 PASS`，本阶段才算完成。局部曲线改善、单频点通过或仅完成诊断，均不得替代阶段通过。

本阶段不正式验收不规则波、斜浪完整六自由度、强非线性大幅运动、多体干扰或水翼控制。Gate 2 通过后的下一阶段依次为：不规则波纵向统计响应、斜浪六自由度、非线性 2D+t、多体船和水翼模型。
