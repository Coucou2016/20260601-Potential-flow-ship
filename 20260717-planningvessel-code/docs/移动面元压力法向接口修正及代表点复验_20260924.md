# 移动面元压力法向接口修正及代表点复验

日期：2026-09-24。总体目标及正式实验门槛保持不变。

## 发现与修改

生产匹配边界积分求解器的绕射法向导数采用流体域向外方向；几何数组中的法向则由船体指向流体。两者相反。压力梯度恢复器通过切向势导数与法向导数组合重建速度，要求法向导数和输入几何法向使用相同方向。

`scripts/probe_eulerian_diffraction.py`此前直接传递求解器法向导数，造成诊断接口不一致。现在显式执行：

```text
q_hull = -q_fluid
velocity = tangent * d(phi)/ds + hull_normal * q_hull
partial_x(phi) = d(phi_on_moving_panel)/dx - velocity_y*y_x - velocity_z*z_x
```

其中q表示沿指定单位法向的势导数，等于该方向的流速；phi为速度势；s为剖面弧长。最后一式是链式求导恒等式，将随面元坐标移动的导数转换为伯努利压力所需的固定空间导数。正常的局部时间相位变换仍单独执行，不能用法向取反代替相位转换。

新增解析复数谐势测试验证两个速度分量，错误法向的对照显著失败；测试还检查输入不被修改、非有限数值被拒绝。相关测试14项通过。生产内核未在本轮改动，仅修正候选后处理脚本，并显式保存法向约定与输入/源码摘要。

## 实际重算结果

使用冻结三航速配置，每航速取原第5个遭遇频率；规定平均姿态、原流场求解及艉部0.5船宽积分截断保持不变。采用直面元解析积分、曲面中点积分。先作29站粗筛，再计算原85站中档与113站细档，面元及历史积分配置均沿用既定细化路线。

以下是细档修正复数载荷的模除以原总复数载荷的模。它不是幅值相对误差，更不是与试验的偏差：

| 船宽弗劳德数 | 遭遇角频率/(弧度/秒) | 升沉激励变化 | 纵摇激励变化 |
| --- | --- | --- | --- |
| 1.67 | 8.69660 | 10.66% | 25.10% |
| 2.26 | 10.43540 | 16.56% | 40.77% |
| 2.82 | 12.10175 | 23.57% | 48.77% |

修正量不可忽略，尤其是纵摇。复数分量必须先相加再求模，不能把这些百分比直接加到运动幅值上。当前没有重新计算整船运动，因此不能判断修正一定改善实验吻合。

## 数值检查

用原先冻结的5%相对变化限值；细档无量纲模小于0.02时，改用0.001绝对容差。没有因本次结果修改限值。

| 检查分量 | 中细两档通过数 |
| --- | --- |
| 原总激励 | 6/6 |
| 几何链式修正量 | 6/6 |
| 修正后的总激励 | 6/6 |
| 修正量中的法向贡献 | 6/6 |
| 修正量中的切向贡献 | 6/6 |
| 合计 | 30/30 |

每类6项为三个速度分别检查升沉力与纵摇力矩。部分力矩在近零绝对容差下通过，不应解释为全部相对变化小于5%。独立比较脚本核对每个目录的配置和源码哈希、法向约定、完整代表点清单及既定中细档配置。

旧诊断中法向与切向的抵消关系不能用于当前修正结果。旧资料已加醒目修订说明，历史文件不覆盖。本轮三个代表点通过，不继承成旧全24工况的压力候选通过，也不是独立实验激励验证。

## 下一步

1. 将该修正作为显式可选压力路线接入统一求解入口，默认历史路线保留；记录原梯度、链式项及修正后的激励，不允许静默切换。
2. 求解前冻结新路线的全部24工况和三档配置，逐频率检查修正量及总激励，不仅检查代表点。
3. 与独立复数激励参考、长波极限共同核验；随后重跑原三航速实验门及完整软件回归。禁止响应倍率拟合，不以数值收敛替代实验通过。

**阶段仍未完成。** 本轮实际进展是排除了一处候选诊断接口错误，并取得修正量在三个代表点上的中细档稳定性证据。
