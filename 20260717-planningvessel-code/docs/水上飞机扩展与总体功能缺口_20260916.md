# 水上飞机扩展与总体功能缺口

日期：2026-09-16。上位目标：[高速船型运动预报系统总体目标](高速船型运动预报系统总体目标.md)。

## 1. 本次决定与边界

将船身式和双浮筒式水上飞机正式纳入同一平台，保留高速滑行艇作为共享水动力内核的首个交付对象。按用户语意，将新增应用解释为正常水面起飞和着水降落；“风机”若指独立风机设备，其结构/旋翼动力学不在此次默认扩展中。

**可以共用水动力框架，不等于现有2.5D程序已经能预测完整起降。** 正常着水、应急迫降、恒速规定运动、自由降落、加速起飞是不同问题，不能共用一个未经区分的“飞机案例通过”标签。

Wen等的恒速/变速楔形入水研究明确将其应用背景关联到水上飞机起降的2.5D方法，以及船体砰击的2D+t方法。该研究支持复用二维入水内核的方向，不提供本项目整机有效性的证明；其模型假设也不能无条件搬用于整个起飞航程。[论文摘要与来源](https://arxiv.org/abs/2201.00959)。

## 3. 统一框架如何组织

### 3.1 共享与新增

共享：几何/横剖面、风浪流环境、2.5D/2D+t水动力、载荷分量追踪、刚体惯性、数据快照、验收和可视化。

新增：机翼尾翼气动力、动力装置、舵面/作动器、飞机质量惯性、接触状态与飞行阶段、变速运动和真实飞机几何。双浮筒飞机还依赖多体联合求解；不能用两个独立浮筒相加宣称完成干扰预测。

建议在同一个刚体积分器中装配水动力、气动力、推进与重力，不让每个提供器自行推进整机状态。同一状态下各载荷共享时间、坐标和重心基准，明确总载荷是否已经包含静水力、重力或附加质量，防止重复计算。

### 3.2 坐标与速度

飞机局部采用右手体轴：x向前、y向右舷、z向下。局部力矩也按右手法则。纵向船舶接口若使用升沉向上、纵摇艏抬为正，转换为升沉力=-Fz、纵摇力矩=My，且参考重心必须相同。

对气速度和对水速度分别计算：

```text
v_air_body   = R_body_to_earth.T @ (v_vehicle_earth - v_wind_earth)
v_water_body = R_body_to_earth.T @ (v_vehicle_earth - v_current_earth)
```

这里R是把体轴向量转为地固向量的旋转矩阵，T表示转置。两种速度分别控制空气和水的载荷，不能把迎风增加的空速直接当成对水速度。安装点局部速度还要加入角速度叉乘力臂；本轮基础函数尚不代替该局部速度计算。

### 3.3 载荷与运动

```text
m * dv_earth/dt = R * (F_water_body + F_air_body + F_thrust_body) + m*g_earth
I * domega_body/dt + omega_body × (I*omega_body)
    = M_water_body + M_air_body + M_thrust_body
```

m为质量，I为重心处惯性张量，omega为机体角速度。姿态需同步积分；水动力若含加速度相关附加质量，应进入耦合方程求解，不能用上一步加速度简单外推并认定稳定。

最先做纵向三自由度：前进、垂向、纵摇。起飞不能继续把航速固定；随后扩展六自由度。若尚未做气动滚转/偏航和侧滑载荷，应拒绝斜向着水生产计算。

### 3.4 状态转换

漂浮/滑跑/首次着水/持续湿接触/部分离水/完全离水/再入水均需要可审计事件。转换应依据真实几何与瞬时水面、法向相对速度及载荷历史；添加防抖与时间步独立性检验。仅用升力大于重量、一个傅汝德数或一帧零湿面来判“成功起飞”都不充分。

二维剖面无接触时不继续保留虚假水压力，但空气载荷、重力、推进仍存在。再入水时不能丢失必要的自由面/尾迹历史。低速前进时纵向位置到局部时间的高速映射可能失效，需要另立适用域。

## 4. 本轮实际新增代码

新增 `planing_seakeeping/aerohydro.py`，不是整机求解器：

- 对风、对流的相对速度及正确旋转矩阵检查。
- 安装点力到重心力矩的叉乘转换。
- 用户提供系数的小攻角纵向气动极曲线：升力、阻力、气动俯仰力矩，分别输出分量及来源。
- 飞机体轴到现有升沉/纵摇广义载荷的显式转换。
- 缺来源、非有限数值、反向来流、侧滑或超攻角范围拒绝，不静默外推失速。

基本气动关系为动压乘参考面积及对应系数；升力垂直来流，阻力反向于来流，安装力矩使用力臂叉乘力。这些是隔离的代数基础，不含真实飞机气动数据库、地效/水面效应、推进、六自由度积分器或水空耦合。

对应测试使用明确标注的合成参数，检查速度平方缩放、零空速、风流区分、反射矩阵拒绝、力矩臂、升力正交性和阻力耗能性。测试通过只代表上述代数/接口正确，不能生成“飞机已验证”标签。

本次实际运行：`test_aerohydro.py`与`test_stage_admission.py`共22项通过；`test_unified_architecture.py`与`test_planing_frequency_correction.py`共85项通过，合计107项针对性测试通过。本轮未重新运行全套回归，先前708项全通过是9月15日记录，不作为本轮完整回归声明。

| S2 | 非线性入水及规定运动可信载荷 | 既有楔形合同不变；补变速入水及冲量；Troesch系数通过；时间步/远域/网格独立 |
| S3 | 单体非线性纵向自由运动 | 压力积分载荷驱动运动；规定运动退化一致；无外力能量/动量检查；规则波独立实验 |
| A1 | 飞机气动/推进及安装载荷 | 真实系数表与适用域、推力图谱与安装点齐备；独立气动与推进参考；坐标、功率、力矩验证 |
| A2 | 船身式飞机纵向着水 | 真实几何、质量惯性、初始水平/垂向速度和姿态；先规定运动再自由着水；触水位置、压力、峰值、冲量、轨迹逐项验证 |
| A3 | 船身式飞机变速起飞 | 完成加速滑跑、离水与短段空中运动；推进功率、气水载荷分配、湿长、起飞距离/时间、俯仰稳定性验证 |
| A4 | 双浮筒及斜向六自由度 | 联合水动力、横向气动、侧滑和控制模型齐备；独立验证横向载荷、姿态和浮筒干扰 |

飞机新实验门的数值阈值必须在数据数字化/不确定度审查后、候选求解前冻结。暂未取得参考时标记“未具备验收条件”，不为了表格完整随意制定或承诺通过。各阶段不得用软件单元测试取代物理实验门。

## 6. 必须取得的飞机资料

1. 一种船身式或双浮筒式基准的完整数字型线、断阶、折角和坐标；机翼/尾翼展示几何也要有真实来源。
2. 同一构型的质量、重心和惯性；不能拼用另一架飞机的质量数据。
3. 气动系数随攻角、侧滑、舵角和必要工况的表格及适用域，初期可限纵向。
4. 推力或功率随速度/转速的图谱，推力线与控制时序。
5. 同构型着水或起飞试验，含初始姿态、速度、下沉率、风浪、压力测点、采样率、坐标和不确定度。

缺少这些信息时可以做标为“合成模型”的单元验证，但不能宣称真实机型性能预测。当前尚未选定并冻结完整飞机基准，未生成伪装成实算的起降动画。

## 7. 可视化合同

典型对象优先为已有真实船舶基准、单体滑行艇实测型线、首个资料齐备的船身式飞机，最后才是双浮筒飞机。每个对象建立独立运行包，不能把Delft的几何、Begovic的运动和另一飞机的机翼拼成一个仿真案例。

页面同时显示：真实外形网格、求解面板/剖面、瞬时水面与湿区、航速和空速、六自由度中实际求解项、力/矩分解、压力范围、时间控制、验证状态及当前适用性警告。二维求解自由面沿纵向拼接生成三维表示时必须标明映射方法，不称为三维全流场求解。

首触水、离水、再入水用实际事件时刻标注；显示倍率可调整但物理读数不变。实验幅相重构标“实验重构”，解析入射波标“给定波面”，没有计算自由面扰动或喷溅就不画成预测结果。
