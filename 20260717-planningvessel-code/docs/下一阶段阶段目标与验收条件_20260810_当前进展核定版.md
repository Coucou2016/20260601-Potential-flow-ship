# 下一阶段阶段目标与验收条件：线性高速 2.5D 核心硬验证闭环

日期：2026-08-10  
对应总体目标：高速船型运动预报系统总体目标  
阶段定位：总体目标下的核心模型可信化阶段

## 1. 当前进展核定

当前项目已经完成第一轮框架建设，但尚未完成核心 2.5D 水动力模型的硬验证闭环。

已经完成：

1. 已建立 `planing_seakeeping` Python 包、命令行入口、配置读取、示例算例、输出报告和可视化流程。
2. 已支持船型、质量惯性、航速、规则波、不规则波、海流、风和数值参数的统一配置。
3. 已形成 `linear_2p5d`、`nonlinear_2dt`、`multihull`、`hydrofoil` 等扩展目录和接口雏形。
4. 已整理文献索引、理论公式、阶段报告和验证数据目录。
5. 已建立 Ma 2005 Wigley III、Faltinsen、Fridsma、Katayama、Delft 372 等基准数据入口。
6. 已围绕 Ma 2005 Wigley III 线性 2.5D 算例建立固定验证命令、诊断表和回归测试。

当前关键未完成项：

1. Ma 2005 Wigley III 八个核心频域水动力系数仍为 `0/8 PASS`。
2. 默认 `matched_bie_station_sweep` 路径仍不能作为可信线性 2.5D 生产内核。
3. `A33/A53` 的 body potential 与 time-pressure 尺度链未闭合。
4. `B33/A35/B35` 的 zero-`m3` 固定控制面几何输运链未闭合。
5. `A55/B55` 的 pitch row moment、Stokes body moment、端部项与控制面矩链未闭合。
6. 当前已有候选修正只能作为诊断证据，不能作为默认模型替代。

当前 Ma 2005 Wigley III 固定验证结果如下：

结论：当前系统已经具备“可运行、可扩展、可诊断”的工程框架，但尚未达到“核心 2.5D 水动力计算可信”的科研验收状态。

## 2. 下一阶段主目标

下一阶段唯一主目标是：

完成线性高速 2.5D 核心水动力模型的 Gate 1 硬验证闭环，使 Ma 2005 Wigley III 的八个核心频域水动力系数 `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 在默认 `matched_bie_station_sweep` 路径下全部通过固定验证，并形成可追溯的公式链、实现链、诊断链、测试链和报告链。

本阶段的实质目标不是继续堆叠新功能，而是把已有框架中的线性高速 2.5D 内核从“可运行原型”推进为“可验证基准内核”。

## 3. 工作范围

必须完成：

1. 固定 Ma 2005 Wigley III 为本阶段首要硬验证对象。
2. 核准 Ma 2005 图线数字化数据、Journee 1992 表格数据和当前参考频率之间的对应关系。
3. 以 A1/Ma 线性高速 2.5D 方程链为主要理论依据，修正默认 `matched_bie_station_sweep`。
4. 按三条失败链逐项闭合八个系数：
   - `A33/A53`：body potential、自由面匹配和 time-pressure 尺度链。
   - `B33/A35/B35`：前进速度梯度项、zero-`m3` 几何输运和整船装配链。
   - `A55/B55`：pitch row moment、Stokes body moment、端部项和固定控制面矩链。
5. 每个默认路径改动都必须保留诊断输出，说明理论来源、实现位置、数值影响和候选排除理由。
6. Gate 1 通过后，重新运行示例滑行艇规则波与不规则波运动预报，证明上层运动响应流程仍可复现。

暂不作为本阶段主验收：

1. SL-7 真实 offsets 完整闭环。
2. C1 三体船真实 offsets 完整闭环。
3. Delft 372 双体船斜浪六自由度完整验证。
4. Sun-Faltinsen 强非线性 2D+t 自由面边界元生产内核。
5. 水翼、压浪板、控制器和真实水翼自由面耦合模型。

这些内容可以继续整理资料和预留接口，但不能替代本阶段的 Ma 2005 Wigley III Gate 1 主验收。

## 4. 可验收条件

### 4.1 固定验证命令可复现

必须稳定运行：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

验收要求：

1. 命令可重复运行。
2. 输出目录、参考数据、判定规则固定。
3. 不允许手动修改 CSV、后处理缩放、单项拟合或最终系数重标定来制造通过结果。

### 4.2 八个核心系数全部通过

`ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 必须满足：

1. `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 全部为 `PASS`。
2. 每个系数的 `gate_error_ratio <= 1.0`。
3. 计算值无 `NaN`、`Inf`、空值或明显数值发散。
4. 通过结果必须来自默认 `matched_bie_station_sweep` 路径。
5. 诊断候选路径不得混入默认验收结果。

### 4.3 三条失败链全部闭合

`ma2005_wigley_iii_coefficients_remaining_failure_chain_budget_summary.csv` 或等价诊断表必须证明：

1. `A33_A53_time_pressure_body_potential` 不再存在失败系数。
2. `B33_A35_B35_zero_m3_geometry_transport` 不再存在失败系数。
3. `A55_B55_pitch_row_moment` 不再存在失败系数。
4. 每条链的最终修正必须能追溯到方程、离散实现或参考数据校正，而不是经验尺度拟合。

### 4.4 理论与实现可追溯

每个默认路径修正必须记录：

1. 对应文献、方程或图表来源。
2. 涉及的代码文件、函数和主要变量。
3. 修改前后的系数对照。
4. 影响的诊断表。
5. 为什么该修改可以进入默认路径。
6. 哪些候选方案被排除，以及排除原因。

### 4.5 回归测试通过

必须通过：

```powershell
python -m py_compile planing_seakeeping\validation.py tests\test_validation.py
python -m pytest -q
```

验收要求：

1. 全量测试通过。
2. 新增或修改的默认路径有对应回归测试。
3. 诊断工具有最小可运行测试。
4. 如果某项测试因外部依赖或耗时无法完成，必须在阶段报告中记录原因、替代命令和实际结果。

### 4.6 示例运动预报可复现

Gate 1 通过后必须重新运行：

```powershell
python -m planing_seakeeping run configs\example_planing.yml --out outputs\gate1_linear_2p5d_hard_pass_motion_demo
```

输出目录必须包含：

1. `summary.csv`
2. `rao.csv`
3. `timeseries_regular_speed_*.csv`
4. `timeseries_irregular_speed_*.csv`
5. `figures/rao.png`
6. `figures/rms_by_speed.png`
7. `figures/timeseries_*.png`
8. `run_report.md`

报告必须明确说明迎浪线性模型中 sway、roll、yaw 为零或近零的物理原因，不能把当前结果表述为完整斜浪六自由度高精度模型已经完成。

### 4.7 阶段报告更新

必须更新阶段报告，至少包含：

1. 当前方法说明。
2. 参考数据来源。
3. 八个核心系数修正前后对照。
4. 失败链闭合过程。
5. 候选方案排除理由。
6. 诊断文件索引。
7. 测试命令与测试结果。
8. 当前适用范围和剩余边界。

## 5. 阶段完成判定

只有当 Ma 2005 Wigley III 八个核心系数全部通过固定 Gate，且公式链、实现链、诊断链、测试链、示例链和报告链均完整时，本阶段才算完成。

只要八个系数中任意一个仍为 `FAIL`，本阶段状态仍为：

```text
线性高速 2.5D 核心水动力模型尚未闭环。
```

此时后续工作应继续围绕失败系数做公式级、站位级和分量级修正，不应把多体船、三体船、水翼船或强非线性 2D+t 作为主线验收对象。

## 6. 完成后进入下一阶段的条件

本阶段完成后，才进入下一阶段扩展：

1. 建立 SL-7 或替代公开高速单体船 offsets 二级验证。
2. 推进 Fridsma/Katayama 滑行艇规则波和不规则波运动响应对照。
3. 推进 Delft 372 双体船迎浪与斜浪验证。
4. 搜索或重建 C1 三体船或公开替代三体船验证对象。
5. 将非线性 2D+t 内核从接口预留推进到最小可验证原型。
