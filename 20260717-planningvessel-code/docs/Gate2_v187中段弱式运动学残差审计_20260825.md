# Gate 2 v187 中段弱式运动学残差审计

日期：2026-08-25  
结论：**连续低频运动学误差本身仍超过门槛；二维先决门保持 FAIL，Gate 2 保持 17/20 PASS。**

## 1. 目的与定义

线性面板法向在节点处不连续，面板端点强式残差可能包含几何法向跳变和高频离散分量。为判断约 `K=0.005` 的平台是否只是强式端点伪差，本轮将面板端点残差 `r` 投影到整条外自由面的全局连续一次函数空间。

对连续一次试函数 `N_i`，装配

```text
b_i = integral(N_i r ds),
M_ij = integral(N_i N_j ds),
M c = b.
```

其中 `c` 是连续弱投影后的节点残差。定义

```text
K_weak = c^T M c = b^T M^(-1)b,
K_unresolved = K_strong - K_weak.
```

`K_weak` 表示连续试函数仍能检测到的低频运动学误差；`K_unresolved` 表示不能由该连续空间表示的面板法向跳变和高频分量。弱式量只用于诊断，Iafrati 方程（52）的面板精确强式 `K` 仍是正式停止与验收量。

## 2. 数学正确性测试

1. 对全局连续的一次残差，投影节点值、积分和解析值在约 `1e-14` 内一致，`K_unresolved=0`。
2. 对相邻面板正负交替的常值残差，`K_unresolved>0` 且 `K_weak<K_strong`。
3. 面板强式贡献、弱式贡献与汇总值逐项重构一致。

新增定向测试为 `4 passed, 0 failed`；最终完整回归为 `547 passed, 0 failed`，耗时 `745.33 s`。

网格加密后，弱式占比上升到约 `93%`，说明细网格平台主要是连续、低频的形状/运动学误差，而不是端点交替伪差。双节点把 `N=240` 的弱式值降低约 `3.88%`，但 `K_weak=0.004673` 仍约为正式门槛的 4.7 倍。

`N=240` 双节点弱式分区为：根部前 `16` 面板 `0.002856`，中段 `0.001639`，远端 `0.000178`。即使完全消除根部弱式误差，中段仍单独超过 `0.001`。

## 5. 物理判读

1. 根部双节点是正确的尖角离散修正，但不是长期平台的充分修正。
2. 细网格强式误差的约 `93%` 能被连续弱空间检测到，不能用事后平滑或只换积分口径消除。
3. 长时状态的强弱差较大，说明 `N=80` 仍有显著面板法向/高频误差；但其连续弱式值仍为门槛的 2.1--2.3 倍。
4. 中段弱式误差单独超标，下一主线必须检查外自由面形状推进、相似势材料导数和浅水--外域匹配条件，而不是继续只处理喷射根部。

## 6. 下一项可证伪工作

1. 在每一步分别输出 `q`、`x.n`、强式残差和弱式投影，按归一化弧长跟踪中段低频模态。
2. 对相同冻结状态比较直接几何法向、连续曲线法向和控制体积分形式，判断误差来自折线法向还是自由面形状。
3. 复核外自由面势 `phi=0.5(|x|^2-tau^2)` 中 `tau=tau_star+s` 的弧长原点、方向及重网格继承是否与浅水射流根状态一致。
4. 任何候选修正必须同时降低 `K_strong` 和 `K_weak`，并通过网格、远域和时间步收敛；只降低其中一个量不得晋级。
