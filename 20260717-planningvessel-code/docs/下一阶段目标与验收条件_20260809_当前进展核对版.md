# 下一阶段目标与验收条件：当前进展核对版

日期：2026-08-09

## 1. 与总体目标的关系

本阶段继续围绕《高速船型运动预报系统总体目标》展开。总体目标是建立以高速滑行艇为核心、可扩展至排水船型、半排水船型、多体船、三体船和未来水翼船型的统一运动预报系统，并形成从理论、程序、算例到实验验证的闭环。

当前最关键的事情不是继续扩大功能面，而是先把线性高速 2.5D 核心水动力模型做成可信基础。只有核心 2.5D 水动力系数可以被公开算例验证，后续六自由度运动响应、不规则波统计、非线性 2D+t、多体干扰和水翼控制扩展才有可靠根基。

6. `B33/A35/B35` 的 Eq.31 产品法则端点要求均为 `open`；当前端部项所需中位倍率约 `2.124`，边界代理所需中位倍率约 `1.108`，纵向双端状态量所需中位倍率约 `2.383`。conservative Eq.31 候选可把这三项最大 Gate Ratio 从 `164.377` 降到 `139.321`，mapping conservative 最佳候选 `mapped_normalized_y_central` 可进一步降到 `138.599`，但仍为 `0/3 PASS`。
8. shared body-potential scale 审计显示，`1/pi^2` 能让 `A33/A53` 通过，也能让 `A35` 落入门槛，但 `B33` 和 `B35` 仍失败；该尺度下 zero-`m3` 最大 Gate Ratio 约 `11.047`，结论为 `shared_body_potential_scale_matches_time_pressure_but_excludes_zero_m3`。说明下一步不应继续追单一全局尺度，而应转向 `B33/B35` 的压力梯度、端部项、同频复数配对和参考频率链。
9. Journee complex scale/phase 审计显示，同频 A/B pair 共 `8` 组，没有任何一组可由统一实尺度解释，所需复数相位跨度约 `174.609 deg`，复数尺度模最大/最小比约 `6.078`，结论为 `journee_complex_scale_phase_varies_across_pairs`。说明下一步应避免继续寻找全局常数或全局相位，而要分解 `B33/B35` 压力梯度、端部项、频率趋势和 pitch moment chain。
10. Journee coefficient frequency-trend 审计显示，8 个系数均有多频率点，其中 `A33/A53/B35/B53/B55` 计算值近似频率不敏感，`B33` 计算敏感性也接近零但参考变化较小，`A35/A55` 则表现为 required scale 随频率显著变化；结论为 `journee_frequency_trend_contains_invariant_computed_rows`。说明后续应检查 damping 类系数的 pressure-gradient/end-term 频率传递，以及 pitch-coupled 项的 moment chain。
11. Journee component frequency-trend 审计显示，32 个系数-分量组合中 `23` 个分量近似频率不敏感，只有 `5` 个分量明显随频率变化；`A33/A53/B35/B53/B55` 的主要分量均几乎不随频率变化，`A35/A55` 的 pressure-gradient、Stokes body 和 end-term 有频率形状但 Gate 仍开。结论为 `journee_component_frequency_trend_contains_invariant_components`。说明下一步应分别处理 `A33/A53` 时间压力链、`B35/B53/B55` 阻尼链和 `A35/A55` pitch moment chain。

## 3. 下一阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 硬验证闭环，使 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 上全部通过，并保证每一项修正都能追溯到明确的理论方程、坐标约定、边界条件、力项装配或参考数据处理。

若八个系数仍无法全部通过，则阶段目标退化为“失败源封口”：必须把剩余误差明确定位到公式缺口、坐标缺口、归一化缺口、固定控制面缺口、端部项缺口、频率传递缺口或参考数据缺口，并给出下一步所需资料或推导条件。不得用经验调参、最终系数拟合或按参考值反推的方式制造通过。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、可作为后续扩展根基”的核心模型。

## 4. 本阶段范围

纳入本阶段：

1. Ma 2005 Wigley III / Journee 1992 参考数据审计：频率、单位、坐标、无量纲方式、数字化来源和取舍理由。
2. `A33/A53` 链路闭合：时间压力、体势尺度、局部时间相位、自由面 marching、压力恢复和归一化。
3. `B33/A35/B35/B53/B55` 链路闭合：固定控制面几何输运、zero-`m3` 行、同频 `A/B` 配对、Eq.30 pressure-gradient、Eq.31/Eq.32 转换、Eq.31 产品法则端点和 Eq.32 end-contour 频率传递。
4. `A55/B55` 链路闭合：纵摇矩、压力梯度矩、Stokes body moment、端部项、力臂原点和参考轴装配。
5. 保持示例滑行艇运动预报链路、六自由度输出、不规则波统计和可视化不退化。
6. 更新阶段报告，使每个结论都有代码路径、命令和输出文件可追溯。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元。
2. 不开发双体船、三体船共同边界积分生产模型。
3. 不开发水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验补偿、最终系数修正、曲线拟合或只对单个系数有效的局部补丁。
