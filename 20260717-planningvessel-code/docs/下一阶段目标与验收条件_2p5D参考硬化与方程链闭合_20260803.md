# 下一阶段目标与验收条件：2.5D 参考硬化与方程链闭合

日期：2026-08-03

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》，是高速船型运动预报系统进入可信扩展前必须完成的核心验证阶段。

当前系统已经具备配置读取、示例运动预报、六自由度统一输出、可视化、验证审计和回归测试能力，但 Ma 2005 Wigley III 八个线性高速 2.5D 水动力系数尚未通过硬验证。因此，下一阶段不急于扩展非线性 2D+t、多体船、三体船或水翼船生产模型，而是先把线性 2.5D 核心水动力链做到可验证、可解释、可复现。

## 2. 阶段目标

完成 Wigley III Gate 1 参考数据硬化与 Ma--Duan--Song 型线性高速 2.5D 方程链闭合，使默认 `matched_bie_station_sweep` 路径下的升沉/纵摇八个水动力系数通过硬验证，并保持运动预报主链路稳定可用。

本阶段必须解决四类问题：

1. 参考数据硬化：消除当前 Ma 2005 稀疏参考点与 Journee 1992 表格之间的频率配对歧义。
2. `A33/A53`：闭合开放剖面 body potential 到 Eq.30 时间压力的尺度链路。
3. `B33/A35/B35`：闭合 zero-`m3` 行中 Eq.31/Eq.32 固定控制面分布式几何输运。
4. `B53/A55/B55`：闭合 pitch row 的 `N5/m5`、力臂、Stokes moment、pressure-gradient moment 和 end-contour moment 装配链。

## 3. 工作范围

1. 建立最终 Wigley III Gate 1 参考集，明确每个系数的来源、频率、数值、归一化方式和误差边界。
2. 将现有 diagnostic-only 审计结果转化为方程级实现修正，而不是最终系数修正。
3. 修正并验证默认 `LinearFrequencyProvider(source="linear_2p5d", formulation="matched_bie")` 路径。
4. 复跑示例滑行艇在规则波和不规则波中的运动响应，确认水动力修正不会破坏已有应用链路。
5. 更新阶段报告、验证数据表和理论说明，形成可追溯闭环。

## 4. 暂不纳入本阶段

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船、三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制系统生产模型。
4. 不用经验比例、全局缩放、最终系数 delta、按参考值反推或最小二乘拟合替代方程修正。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 参考数据 | 生成最终 `wigley_iii_gate1_reference.csv`，每一行包含系数名、真实频率、参考值、来源、单位/归一化、数字化或表格来源说明。 |
| 频率配对 | `reference_frequency_pairing_ambiguity` 关闭；Ma 2005 图线、Journee 1992 表格和当前 Gate 1 参考集之间的频率和值对应关系可追溯。 |
| 默认路径 | 验证输出中八系数均来自 `matched_bie_station_sweep` 默认路径，不依赖手动候选开关。 |
| 八系数硬通过 | `A33/B33/A35/B35/A53/B53/A55/B55` 在 `ma2005_wigley_iii_coefficients_comparison.csv` 中全部为 `PASS`。 |
| 方程级证据 | 三条链路分别给出可读审计表：时间压力尺度、zero-`m3` 几何输运、pitch row moment chain；审计结论均为 `PASS` 或等价通过状态。 |

| 数值稳定 | 验证输出、运动输出和关键矩阵无 `NaN/Inf`；质量矩阵、附加质量矩阵、阻尼矩阵、恢复矩阵数值有限。 |
| 运动链路 | 示例配置可完成规则波/不规则波计算，输出六自由度时序、RAO、RMS、加速度和图表；迎浪下横荡、横摇、艏摇为零时必须注明对称性假设。 |

| 阶段报告 | 更新阶段报告，包含参考数据来源、方程修正位置、关键公式、验证结果、失败项变化、残余风险和后续扩展建议。 |
