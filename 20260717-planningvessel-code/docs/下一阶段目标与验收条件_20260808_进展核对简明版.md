# 下一阶段目标与验收条件：线性 2.5D 核心可信化

日期：2026-08-08

## 1. 总体目标对齐

后续工作继续围绕《高速船型运动预报系统总体目标》展开：以高速滑行艇为核心，建立可验证、可扩展的 2.5D 运动预报模型及软件框架，并逐步扩展到排水船型、半排水船型、单体、多体、三体和未来水翼船型。

当前阶段不继续扩大船型范围，而是先把线性高速 2.5D 核心水动力模型做实。只有核心 2.5D 模型通过可追溯硬验证，后续非线性 2D+t、多体船、三体船和水翼模块才有可靠基础。

## 3. 下一阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 硬验证闭环，使 `matched_bie_station_sweep` 路径在 Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 上全部通过。

若八系数仍无法全部通过，则必须把每个失败项封口到明确的公式、坐标、归一化、固定控制面、端部项、历史卷积、频率传递或参考数据缺口；不得使用经验倍率、曲线拟合或最终系数补丁制造通过。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、可作为后续扩展根基”的核心模型。

## 4. 本阶段工作范围

纳入本阶段：

1. 闭合 `A33/A53` 的时间压力、体势尺度、局部时间映射和归一化链路。
2. 闭合 `B33/A35/B35` 的固定控制面几何输运、同频 `A/B` 配对和 Eq.31/Eq.32 转换链路。
3. 闭合 `A55/B55` 的纵摇矩、固定控制面边界项、端部项和力矩参考点装配链路。
4. 固定 Ma 2005 Wigley III 参考数据来源、频率、坐标、单位和无量纲方式。
5. 保持示例滑行艇运动预报链路、六自由度输出、不规则波响应和可视化不退化。

暂不纳入本阶段：

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船、三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验补偿、最终系数修正或按参考值反推的方式通过验证。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数均使用 `provider_route == matched_bie_station_sweep`。 |
| 八系数硬门槛 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 方程级修正 | 所有进入默认路径的修正必须位于压力恢复、体势、自由面 marching、几何输运、力矩装配或端部项，不允许只改最终系数。 |
| 参考数据 | 八点参考值的来源、频率、坐标、单位、数字化方式和无量纲方式写入阶段报告。 |
| 三条失败链 | `A33/A53`、`B33/A35/B35`、`A55/B55` 均有独立审计表，说明修正依据、残差来源和是否进入默认路径。 |
| 候选纪律 | 未通过八系数硬门槛的候选均保持 `candidate_default_gate_eligible=false`，并说明排除原因。 |
