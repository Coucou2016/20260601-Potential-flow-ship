# 当前进展与下一阶段阶段目标及验收条件

日期：2026-08-09  
对应总体目标：《高速船型运动预报系统总体目标》

## 1. 当前进展

项目已经完成“高速船型运动预报研究框架 v1”的主体搭建，但尚未完成“完整 2.5D 运动预报模型的可验证闭环”。

已经具备的基础：

1. 已建立 `planing_seakeeping` Python 包、命令行接口、配置读取、规则波和不规则波输入、频域响应、时域响应、六自由度统一输出、图表和报告输出链路。
2. 已整理 Faltinsen、Ma 2005、Fridsma、Katayama、Delft 372、ITTC 等文献来源，并建立理论、公式、算例、代码和验证输出之间的追溯关系。
3. `numerical_sanity`、`physical_trend_sanity`、`section_bem_numerical_sanity` 当前为 `PASS`，说明基础矩阵、物理趋势和二维剖面边界元链路可继续作为诊断基础。
4. 短回归测试已通过：`python -m pytest -q tests\test_core.py tests\test_station_2p5d.py tests\test_unified_architecture.py` 得到 `120 passed in 44.83s`。
5. 已形成 Ma 2005 Wigley III Gate 1 诊断体系，可输出八个核心频域水动力系数的对照、误差、候选路线、失败原因和阶段报告。

当前关键缺口：

1. Ma 2005 Wigley III 八个核心水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 当前为 `0/8 PASS`，线性 2.5D 核心水动力链路还不能宣称可信闭合。
2. `validation_status_by_benchmark.csv` 中 `ma2005_wigley_iii_coefficients` 仍为 `FAIL`；`katayama_regular_wave_qualitative_trends` 也仍有失败项，若不闭合 Gate 1，不宜继续把后续运动预报结果作为可信结论。
3. Eq.23 内域自由面符号映射审计显示：代码与 A1 文献公式符号 `10/10` 对齐；数值上有帮助的符号翻转候选不能直接进入默认路径，下一步应转向法向定义、压力恢复、相位约定、参考频率配对和自由面几何输运的公式级核对。
4. 全量 `python -m pytest -q` 本轮在 5 分钟内未完成，说明测试体系需要拆成“快速回归门”和“长耗时诊断门”。
5. SL-7、C1 三体船等公开可用数字型线仍不足，暂不能作为本阶段硬验收对象。

阶段判断：

> 当前状态是“可运行、可诊断、可继续扩展的研究框架”，不是“已验证完成的完整运动预报系统”。下一阶段必须优先把线性高速 2.5D 核心水动力验证做实。

## 2. 下一阶段阶段目标

**完成线性高速 2.5D 核心水动力模型 Gate 1 验证闭环，使 `matched_bie_station_sweep` 默认路径能够稳定、可追溯、可复现地通过 Ma 2005 Wigley III 八个核心频域水动力系数验证。**

需要通过的八个系数为：

```text
A33, B33, A35, B35, A53, B53, A55, B55
```

目标边界：

1. 本阶段只以 Ma 2005 Wigley III 为硬验收对象。
2. 本阶段只把线性 2.5D `matched_bie_station_sweep` 作为生产主线。
3. 本阶段不扩展生产级非线性 2D+t、多体船共同边界积分、三体船干扰和水翼控制模型。
4. 本阶段不得用经验缩放、最终系数拟合或参考结果反推制造通过。

一句话目标：

> 把线性 2.5D 主线从“能运行、能诊断”推进到“能验证、能解释、能支撑后续扩展”。

## 3. 必要工作条件

为实现该阶段目标，必须具备以下条件：

1. 固定 Ma 2005 Wigley III 的参考数据来源、频率配对、无量纲化方式和验收误差门槛。
2. 固定 `matched_bie_station_sweep` 默认计算路径，不把诊断候选参数混入生产默认值。
3. 逐项闭合船体边界条件、内外域匹配、自由面推进、时间压力项、前进速度压力梯度项、端部项、力矩臂、复数相位和系数无量纲化。
4. 对所有候选修正给出“公式来源、代码位置、数值影响、是否允许进入默认路径”的记录。
5. 将测试体系拆为两个层级：快速回归门用于日常开发，长耗时诊断门用于 Gate 1 验收。
6. 保持示例滑行艇输入、规则波/不规则波响应、六自由度输出、图表和报告链路不被破坏。

## 4. 可验收条件

只有同时满足以下条件，才可判定下一阶段完成。

| 编号 | 验收项 | 通过条件 |
|---|---|---|
| 1 | 默认路径 | 八个核心系数均由 `matched_bie_station_sweep` 默认路径直接计算得到。 |
| 2 | 八系数硬通过 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`。 |
| 3 | 误差门槛 | 每个系数的 `gate_error_ratio <= 1.0`；不得用平均误差替代逐项通过。 |
| 4 | 公式追溯 | 每项修正均能追溯到文献公式、推导说明或明确的数值离散原则。 |
| 5 | 候选纪律 | 经验缩放、符号试探、参考值反推和局部拟合不得进入默认路径。 |
| 6 | 数值稳定 | 验证输出无未解释的 `NaN`、`Inf`、空表、奇异矩阵或非物理跳变。 |
| 7 | 快速回归 | 核心快速测试集通过，并在报告中记录命令和结果。 |
| 8 | 长耗时诊断 | Gate 1 长耗时诊断可复现运行，并生成完整 CSV、图像和 Markdown 报告。 |
| 9 | 示例链路 | `configs/example_planing.yml` 可生成 `summary.csv`、`rao.csv`、时域 CSV、PNG 图像和 `run_report.md`。 |
| 10 | 六自由度输出 | 输出包含 `surge/sway/heave/roll/pitch/yaw`；迎浪主验证为 `heave/pitch` 和垂向加速度，其余自由度明确标注假设。 |
| 11 | 不规则波复现 | 固定随机种子下，不规则波响应的均方根、峰值和统计结果可复现。 |
| 12 | 阶段报告 | 报告包含当前误差、修正依据、通过项、失败项、候选排除、剩余风险和后续建议。 |

## 6. 未通过时的封口条件

如果下一阶段仍无法达到八系数全部 `PASS`，不得宣称完成，只能判定为“Gate 1 缺口封口”。封口必须满足：

1. 每个失败系数都有明确误差来源分类：公式实现、边界条件、几何输入、参考数据、无量纲化、相位约定、数值离散或文献歧义。
2. 每个候选修正都有诊断结果，并明确“保留、排除或待证”。
3. 默认路径未被经验拟合或参考值反推污染。
4. 下一步所需资料、推导或代码改动明确到文件、公式、模块或测试。

## 7. 后续进入条件

只有 Gate 1 通过或严格封口后，才进入下一层扩展：

1. Fridsma 规则波和不规则波滑行艇运动、加速度验证。
2. Katayama 非线性跳跃和峰值移动验证。
3. Sun-Faltinsen 型非线性 2D+t 原型。

6. 水翼、压浪板和控制器接口扩展。
