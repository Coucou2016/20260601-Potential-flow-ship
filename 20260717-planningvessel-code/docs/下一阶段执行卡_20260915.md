## 目标

**以单体高速艇为对象，建立同一入口、同一线性2.5D内核、同一工况的规则迎浪预测闭环：读取来源明确的船型、质量惯性、航速、波浪和平均姿态，输出频率相关水动力、升沉/纵摇幅相、稳态时域及重心/艏部加速度，在冻结的三航速公开试验上完成可追溯验收。不得使用试验响应标定、静默回退或放宽既有误差限值。**

第一版可规定实测平均姿态，但必须注明并非自动预测稳态；规则波时域可由线性复数响应重构，不能称为非线性自由航行。

## 执行顺序

| 步骤 | 具体任务 | 必须交付 |
| --- | --- | --- |
| 1. 准入修正 | 修Delft分组、虚假外部后端标签、缺字段误判通过、版本兼容和未求解自由度标签 | 负向测试、正确数据集、环境锁定、真实能力清单 |
| 2. 工况冻结 | 固定Begovic三速度、几何、平均姿态、牵引条件、单位和频率约定 | 24工况全表，21个线性适用点及3个诊断点原因，参考哈希 |
| 3. 分量诊断 | 比较失败低速与通过高速的恢复力、八系数、复数激励及艉部项 | 可定位到公式/站位/分量的诊断，不做响应倍率拟合 |
| 4. 内核接线 | 同一入口调用已声明内核，频域与时域共享同一水动力结果 | 一次运行产生完整案例包，拒绝未实现后端和无提示回退 |
| 5. 正式验收 | 网格独立性、时频一致性、三速度实验对照、全回归和真实来源图表 | 一键报告、机器验收清单和适用范围；不通过则保留失败 |

## 可验收条件

| 编号 | 条件 |
| --- | --- |
| 1 | 船型、质量惯性、姿态、外力矩条件、波浪及坐标/单位完整可追溯；缺失或矛盾不允许静默默认。 |
| 2 | 旧线性基础门仍10/10且网格变化≤2%；交付频段八系数和复数激励完成三档离散，细两档关键量变化≤5%；近零量用预先冻结的绝对容差。 |
| 3 | 波浪激励路线明确，长波极限、相位和独立参考验证完成；新参考及限值在求解前冻结，不能只验辐射系数。 |
| 4 | Begovic三个速度分别满足：升沉、纵摇中位相对误差≤15%，归一化均方根误差≤20%；保留合并指标，不靠平均掩盖单速度失败。 |
| 5 | 可解析主峰至少4个，覆盖至少2个速度和两种运动；各主峰频率误差≤10%。 |
| 6 | 同一内核时频幅值误差≤5%、相位误差≤5°；Fridsma既有适用区运动仍满足15%/20%，实验相位中位误差≤15°、重心加速度归一化均方根误差≤25%。 |
| 7 | 同一次运行输出几何/计算网格、水动力、激励、响应、时域、加速度、逐工况误差、适用性及验收文件；图形来源明确，无虚构计算压力/自由面。 |
| 8 | 失稳、湿长超船长、大幅运动和未支持输入不能归为有效预测；六自由度分别标注求解、约束或未支持，零值不能冒充已预测。 |
| 9 | 求解不读取实验响应；缺字段、未知状态、错误哈希、缺工况均拒绝通过；锁定环境，从洁净输出复现，全套回归0失败。 |

第4项逐速度验收是拟新增的加强条件；不倒改历史合同或分数。实验数据已经反复用于诊断，后续应另保留未参与方法选择的工况作独立复核，并如实标注已有案例是回归验证集。

## 必要条件与边界

- 当前优先复用Wigley解析几何及已有Begovic/Fridsma资料；具体单体几何重构必须记录来源和假设。
- 规定试验姿态可先隔离耐波误差；要验收自动稳态预测，必须有正确姿态基准及牵引/推进力矩。
- 真实目标艇交付仍需完整型线、质量惯性、推进信息及试验；公共基准通过不能代替实艇验证。
- SL-7、C1真实型线采集不阻塞本阶段；类似形体不得用于通过原船试验门。
- 非线性楔形、规定运动另线推进，原10°/20°/30°门槛不变；它们不阻塞未调用它们的线性交付。
- 本阶段不承诺斜浪六自由度、非线性随机波、多体干扰、水翼控制或全过程自动切换。
