# 艉部截断积分与分轴收敛

上位目标与既有试验门槛不变。本轮针对前次全频段三档离散未通过的问题推进，不宣布整船或阶段完成。

## 已确认的数值问题

旧算法在截断位置以前将站位载荷设为零，再对全部站位作梯形积分。这会在最后一个零值站位和第一个保留站位之间引入线性过渡，并非在指定位置发生硬截断。

例如恒定载荷密度为f，真实截断位置为c，前后两站为x0、x1，旧积分相当于把截断移动至两站中点。误差为f乘以“c减去两站中点”，其量级随网格间距变化。若c恰好落在站位上且该站被置零，仍会损失其后一段的半个梯形。该问题与实验响应无关，可以由解析积分独立验证。

新候选在固定c处插入线性插值载荷，再只积分c之后的湿段。它准确积分原始站位的分段线性插值，不是声称恢复了站位之间未知的真实压力。截断长度仍为0.5倍船宽，没有更改物理参数。

常量与复数线性载荷、15/29/57站的6项解析测试全部通过，绝对误差限1e-12，在运行前冻结。

## 显式候选接线

统一入口可显式配置：

```json

  "head_sea_excitation_formulation": "matched_domain_incident_diffraction",
  "cutoff_quadrature": "clipped_linear"
```

## 后续复核：边界含义和子步时间层

源码复核发现，上文“内/外自由面”只是沿用配置字段名，物理含义不够准确。在匹配内核中，`free_surface_inner_panels`离散真实自由面，`free_surface_outer_panels`离散内外域之间的控制边界。因此上文自由面方向实际上是两个边界同时加密，不能单凭此前15/20的结果归咎于真实自由面。

新的分离检查固定57站、48船体面元、128历史缓存，分别改变：真实自由面24/36/48面元；控制边界48/72/96面元；自由面更新1/2/4子步。仍只检验最低航速两个端点频率，不代替全频段验收。

### 已修正的子步错误

独立常速度测试给出了确定错误：取重力为1、垂向速度为2、步长为1，势函数起始时间1，水面高度起始时间0.5且高度为0，则在势函数时间1至2之间，高度从1线性增加至3。由动态边界条件“势的时间导数等于负重力乘水面高度”，势增量应为负面积，即-2。

旧算法的1/2/4子步分别得到-2/-1.5/-1.25，根因是水面高度采用半步交错存储，细分时间步时没有把它移到新的半步时间层。修正后在子步前按当前恒定垂向速度移动高度时间层，子步结束再移回外层半步时间；势函数和水面高度的实际时间均保持一致。初始状态为空时也执行统一的最终时间层转换。

新增12项解析测试，覆盖正反时间方向、1/2/4/8子步及初始状态；全部通过。默认单步结果保持不变。该修正不是实验响应标定。

本方法在站位内仍冻结同一次边界元给出的垂向速度；即使多子步一致，也不证明每子步重新求解边界元的耦合时间收敛。对于恒定速度和线性自由面更新，子步数改变不应制造不同的物理积分结果。

最初的分离运行已因确认上述错误而主动停止，保留于 `outputs/surface_control_split_20260921`，不得作通过证据。修正后的重跑位于 `outputs/surface_control_split_stagger_fixed_20260921`，以完整 `results.json` 和回归报告为准。
