# Gate 2：19.5°同伦与受约束信赖域审计

日期：2026-08-26  
结论状态：**19.5°空间数值收敛通过；19.0°诊断仍失败；二维先决门保持 FAIL**

## 1. 审计目的

本审计检验从20°已收敛源状态向低斜升角推进时，运动学残差能否在不读取参考曲线的条件下持续下降，并区分三种完全不同的结论：算法可推进、空间网格稳定和物理验证通过。三者不能相互替代。

## 2. 19.5°残差来源

80面板状态的线性端点精确运动学积分为 `0.0185306544`，中点积分仅为 `0.0021446383`。两者之差 `0.0163860161` 来自面板内线性斜率项，占精确积分的 `88.43%`；其中 `98.99%` 集中在外自由面前10%弧长。左右端点跳变相关系数为 `-0.95269`。因此残差底限来自根区不连续 Neumann 迹的面板内变化，不是简单的中点采样误差。

## 3. 受约束信赖域与细网格结果

新增的曲率门限制候选自由面的弧长积分曲率能量不得超过源状态的1.10倍；根部保持条件只作为数值信赖约束，不构成新的物理方程。64个离散余弦变换模态把160面板状态的精确积分从 `0.00797757` 降至 `0.00408148`，同时曲率能量比为 `0.950836`、根部失配为 `6.34e-5`，矩阵条件数改善。

对同一冻结几何进行320、640、1280面板重构后，精确运动学积分分别为：

| 外自由面面板数 | 精确运动学积分 K | 根部相对失配 |
| ---: | ---: | ---: |
| 320 | `1.605905e-3` | `2.586e-4` |
| 640 | `1.032766e-3` | `3.361e-4` |
| 1280 | `9.266963e-4` | `3.705e-4` |

640到1280面板之间，偶极系数、积分垂向力、压力峰值、自由面曲线和压力曲线变化均小于 `0.263%`。由此只能判定19.5°冻结状态具备三层空间稳定趋势，并满足数值 `K<=1e-3`；由于没有冻结的19.5°自由面和压力基准，该状态的物理验证仍为 `FAIL`。

## 4. 19.0°局部旋转同伦

旧同伦只缩放根区纵坐标，导致匹配面移动5.0625个面板且初始 `K=0.216515`。新同伦以楔顶 `(0,-1)` 为中心，在根区施加随弧长向远场衰减的 `-0.5°` 局部旋转，使自由面局部方向跟随目标斜升角；远场端点不动。该变换把初始 `K` 降至 `0.0623191`，匹配面位移降为0，根部失配为 `0.002017`，条件数比为 `0.999093`。

固定匹配分支的32和64模态信赖域随后把 `K` 降至 `0.0475037`。冻结64模态方向继续复用12个接受步后，`K` 降至 `0.00444519`；条件数从约 `9.93e4` 降至 `9.88e4`，曲率能量持续下降。第13步的步长因子 `1.0/0.5/0.25` 均使目标增大，因此旧方向明确饱和。最终根部相对失配为 `0.00203324`，仍高于 `1e-3` 门槛。

检查点曾错误继承父状态的外形偶极系数，导致重载相对误差 `8.80727e-5`。现已记录每个接受几何实际使用的源偶极系数；修复后重载最大相对误差为 `2.43e-17`，没有放宽 `1e-6` 检查点复现门槛。

## 5. 结论与下一步

19.5°提供了稳定的数值同伦源，但没有物理参考，不能代替10°验证。19.0°证明局部旋转映射和冻结方向复用有效，但旧方向已在 `K=0.00444519` 饱和，且根部失配未通过。

下一步只能采用可审计的更新：在19.0°最终检查点重新计算低模态 Jacobian，或减小斜升角同伦步长；新候选仍须通过精确 `K`、根部、条件数和曲率门。即使19.0°数值门通过，也必须继续到冻结基准所要求的10°和30°并完成自由面、压力、载荷及网格/时间步/远域对照，二维先决门才可转为 `PASS`。

后续更新已完成19.0°和18.5°的根闭合及三层空间收敛，最细网格 `K` 分别为 `1.965879e-4` 和 `4.439977e-4`。详细证据见 [Gate2_19deg_18p5deg根闭合与空间收敛审计_20260826.md](./Gate2_19deg_18p5deg根闭合与空间收敛审计_20260826.md)。这些结果仍是无物理参考的数值同伦源，不改变二维先决门状态。

本轮修改后的扩大定向回归为 `98 passed, 0 failed`；完整软件回归为 `600 passed, 0 failed, 1247 warnings`，耗时 `836.76 s`。这些测试证明软件基线可复现，不改变二维先决门和 Gate 2 的物理失败判定。
