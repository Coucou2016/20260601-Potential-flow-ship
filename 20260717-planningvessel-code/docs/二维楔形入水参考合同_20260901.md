## 1. 合同目的

本合同冻结10°、20°和30°二维恒速、无重力楔形入水物理验证的工况、坐标、参考对象、来源层级、验收指标和冲突处理规则。所有参考数据只能在求解完成后评分，不得进入残差、搜索方向、停止条件或参数标定。

## 2. 问题与坐标

- 物理问题：二维无限对称楔形以恒定竖直速度入水，理想不可压无旋流体，忽略重力和表面张力。
- 求解器水平相似坐标：`xi = y/(Vt)`。
- 求解器竖直向上相似坐标：`eta = z/(Vt)`。
- Sun 2007自由面横轴`y/(Vt)`对应`xi`，纵轴`z/(Vt)`对应`eta`。
- Sun 2007压力横轴`z/(Vt)`对应`eta`，纵轴为`p/(0.5 rho V^2)`。
- 求解器静水面为`eta=0`，楔尖为`(xi,eta)=(0,-1)`。
