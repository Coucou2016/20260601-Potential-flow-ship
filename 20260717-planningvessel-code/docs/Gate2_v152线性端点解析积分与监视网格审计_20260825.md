## 2. 线性单元解析积分

设一个长度为 `L` 的线性面板两端运动学残差为 `r_0` 和 `r_1`。面板内残差为

```text
r(s) = r_0 + (r_1-r_0)s/L,  0<=s<=L.
```

其平方的精确积分为

```text
integral_0^L r(s)^2 ds = L(r_0^2+r_0 r_1+r_1^2)/3
                         = L r_mid^2 + L(r_1-r_0)^2/12.
```

第二种写法说明，中点积分总是漏掉非负的端点梯度项 `L(r_1-r_0)^2/12`。因此，当线性单元运动学残差在节点间存在强梯度或反号时，中点 `K` 会系统性偏小。本轮保留历史 `kinematic_integral` 的中点语义，同时新增 `kinematic_integral_linear_exact` 和端点梯度贡献；旧检查点与历史曲线不被静默改写。

## 4. 冻结监视网格实现

监视量由四部分构成：声明的双端基础密度、当前 `|S_nu|`、自由面转角以及相邻面板长度对数变化。各物理量按当前曲线弧长加权均方根无量纲化，经过有限次局部平滑后等分累计监视量。最终节点相对基础双端网格的单次移动受 `maximum_node_shift_panels` 限制。

生成后的归一化弧长节点写入配置字段 `coupled_outer_monitor_fractions`，网格模式标记为 `frozen_monitor`。每个 Runge--Kutta 阶段均使用同一组冻结分数，机器审计直接核对最终节点与配置，避免出现“配置声称自适应、实际推进恢复旧网格”的问题。

为避免薄射流自然终止步数对微小浮点扰动敏感，监视网格默认冻结源检查点的实际薄射流边界元面板数。本轮源 `v143` 为每侧 `256` 个面板；后续必须以 `256/384/512` 独立做拓扑收敛，不能把面板数作为调幅参数。

## 6. 结论

1. 线性单元端点解析积分是必要诊断；中点 `K` 对当前端点运动学残差的面板内梯度存在明显低估。后续复核表明节点法向导数总体平滑，残差反号主要来自喷射根部尖角两侧不同面板法向及残差重构，不应误述为通量本身的锯齿振荡。
2. 固定双端网格的远端误差已显著降低，主要问题转移到匹配根和中段法向导数离散。
3. 当前残差/曲率监视网格实现具备参考隔离、持久网格契约和确定性检查点，但尚未形成稳定收敛，因此保持实验模式，不能作为验收结果。
4. 二维楔形入水先决门仍为 `FAIL`，Gate 2 仍为 `17/20 PASS`；Gate 1 结论不变。
