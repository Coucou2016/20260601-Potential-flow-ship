# 从缺参数到可看结果：浮筒研究闭环

## 现在可直接使用的交付

打开 `outputs/edo106k_workflow_release_20260916/report.html`。它包含全部静态图与动态GIF，图片以Base64嵌入，不依赖网络、外部脚本或本地数据路径。对应Markdown、图像PDF/SVG、计算CSV、输入快照和验收JSON位于同一结果目录。trial与final目录保留中间运行证据，release为本轮交付版本。

一键重算，在项目根目录执行：

```powershell
python -m planing_seakeeping run configs/edo106k_workflow.json --out outputs/my_edo106k_run
```

输出目录必须为空，防止覆盖已有研究证据。该模型复用现有CLI、真实型值读取、分部件质量计算与波谱生成；新增静水、封闭几何和纵向降阶计算。不替换已有高速2.5D内核，不改变任何旧实验门。

## 缺参数怎么处理

| 缺口 | 可复算处理 | 不允许的解释 |
| --- | --- | --- |
| 侧面/甲板几何 | 以原折角宽度向上作垂直侧面，至原表甲板高度封平甲板；面标签区分原表底面与假设闭合 | 不称原型实测侧面，不据此保证真实储备浮力 |
| 整机质量惯性 | 前轮1800kg六部件等效长方体，加平行轴定理；重心与惯性同时改变 | 不分别调三个数字以拟合响应 |
| 平均姿态/吃水 | 以假设质量和完整合成几何解力/力矩平衡 | 不把配平失败截断成成功 |
| 附加质量 | 每单位长度 a=πρc²/2，c为平衡水线半宽；作为明确条带近似 | 不称通过自由面边界元求出的水动力 |
| 阻尼 | ζ=0.12的模态阻尼假设；考察ζ的2/3与1.5倍 | 不宣称0.12是实验识别值 |
| 规则波 | H=0.04m、T=3s，深水波数k=ω²/g | 不称真实试验海况 |
| 不规则波 | JONSWAP谱，Hs=0.025m、Tp=3s、48分量、固定种子；保留全部离散分量 | 120s示例不是ITTC长时统计验收 |

零航速和小波高是这个子模型的应用范围，不是为了放宽原高速验收。高航速工况仍须调用并验收高速内核；这个示例不能替代它。

## 理论和坐标

源坐标x向艉、y向右、z向上。令X=xCG−x，Z=z−zCG；艏升角θ为正，地固前向Xw=cosθ X−sinθ Z，地固高度Zw=hCG+sinθ X+cosθ Z，地固左向Yw=−y。静水面Zw=0。

以每个源站区间细分后的中点积分，不跨相同x的断阶前后记录。逐段底线与给定水位截取，得到浸没面积和面积一阶矩。体积V=∫A dx，浮力F=ρgV，艏升矩Q=ρg∫Xw dV。关于CG的浮心高度影响保留在精确姿态旋转中，不只使用水线面二次矩。

解[F−mg,Q]=0得到平衡；以中心差分求C=−∂[F,Q]/∂[hCG,θ]。不偷偷对错误的非对称C做强制对称化。封闭三角面另按p=−ρgZw积分压力和力矩，复核体积积分，两条计算路径互不调用其结果。

动态扰动q=[升沉,艏升纵摇]ᵀ满足：

```text
(M + A) q_ddot + B q_dot + C q = F_wave(t)
Q(omega) = [C - omega^2 (M+A) + i omega B]^-1 F_wave(omega)
```

M为刚体质量/纵摇惯性；A由条带附加质量沿纵向装配；B由广义特征模态与给定阻尼比构造；C来自配平静水载荷。波浪激励仅把局部入射波面变化转为静水增量，使用沿船长的复相位，不包括完整Froude–Krylov压力、绕射、辐射记忆及前进速度效应。

时域采用`scipy.solve_ivp`从零扰动开始积分，不用频域幅值直接冒充独立时域解；随后取最后四分之一规则波时历拟合复幅值，与频域解比较。自由衰减检验E=½q̇ᵀ(M+A)q̇+½qᵀCq是否不增。不规则波完整保存种子、频率、幅值和相位。

标准参考：[WAMIT手册静水与重力恢复系数](https://www.wamit.com/manualv7.4/wamit_v74manualch3.html)。它支撑静水量与重力项的检查框架，不意味着本程序调用了WAMIT。真实底部来源：[NACA-WR-L-722](https://ntrs.nasa.gov/citations/19930092989)。

## 怎么看结果

1. 先看状态表：`numerical_status=PASS`仅表示本示例预设数值检查满足，`physical_validation_status=NOT_VALIDATED`仍保留。`overall_project_status=NOT_COMPLETE`明确总体目标尚未完成。
2. 再看图1：封闭面已补，不再把断阶开口当成真实断裂；棕色是几何假设。红点是整机重心，未画凭空拟造的飞机外壳。
3. 频域图的横轴是波周期，纵轴分别为每米波幅引起的位移或角位移；峰值与质量、恢复力、附加质量和阻尼共同相关，不是已获实测认证的共振。
4. 时域图的升沉和纵摇是平衡附近扰动；绝对姿态应加上配平角。初始时刻从静止扰动启动，因此会先出现过渡，再形成稳态。
5. 自由衰减的波面为零；能量降低说明构造阻尼吸收能量。受迫波浪下有外界输入，能量不要求单调下降。
6. 敏感性9案例分别考察总质量、载荷前后位置、附加质量与阻尼。其RMS来自集合谱积分，不与单条有限长度时历RMS直接相减作为误差。它们不是实验置信区间。
7. 动画播放最后两个规则波周期，读取真实计算位移；没有人为放大纵摇或波高。小波在全艇真实尺度下看起来较平，这是尺度事实，不用放大波面制造效果。
