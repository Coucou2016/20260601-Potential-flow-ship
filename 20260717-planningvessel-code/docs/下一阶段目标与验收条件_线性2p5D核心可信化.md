# 下一阶段目标与验收条件：线性 2.5D 核心可信化

日期：2026-08-02

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》。

当前系统已经具备可运行的软件框架、配置读取、验证输出、诊断 CSV 和回归测试链，但核心线性 2.5D matched BIE 水动力模型尚未通过 Ma 2005 Wigley III 八系数硬验证。

因此，下一阶段不急于扩展非线性 2D+t、多体船或水翼模块，而应优先把高速滑行艇/高速船型线性 2.5D 核心做可信。

## 2. 阶段目标

完成线性高速 2.5D matched BIE 核心水动力链的可信化，使其能够作为后续滑行艇运动预报、规则波/不规则波响应、多体船扩展和非线性模型开发的可靠基础。

具体目标是：

> 在保持 `matched_bie_station_sweep` 默认主线不变、拒绝经验拟合补偿的前提下，闭合 Ma--Duan--Song 型 2.5D 方法中 Eq.31/Eq.32 的几何输运、边界项和整船装配链，使 Ma 2005 Wigley III 八个频域水动力系数通过 Gate 1；若仍不能通过，则必须把剩余失败源精确封口到公式、坐标映射、边界积分、端部项、投影链或参考数据缺口。

## 3. 本阶段工作范围

本阶段只聚焦以下工作：

1. 完善 `linear_2p5d/matched_bie` 主线。
2. 修正或证明 Eq.31/Eq.32 几何输运与边界项的闭合关系。
3. 完成 Ma 2005 Wigley III 八系数硬验证。
4. 将通过验证的水动力系数稳定接入频域运动响应计算。
5. 保持 6 自由度输出框架，但重点验收 heave、pitch 和垂向加速度。
6. 输出可复现的 CSV、图表和阶段报告。

本阶段暂不把以下内容作为硬验收：

1. 强非线性 2D+t 生产级求解器。
2. 多体船/三体船完整耦合求解器。
3. 水翼船控制系统。
4. SL-7 与 C1 trimaran 的硬验证，除非获得真实 machine-readable offsets。

## 4. 可验收条件

| 类别 | 验收条件 | 判定方式 |
|---|---|---|
| 总目标一致 | 阶段工作必须服务于高速船型运动预报系统总体目标 | 文档引用总体目标，且不引入偏离方向的临时模型 |
| 默认主线 | 仍使用 `linear_2p5d/matched_bie` | 输出 `provider_route == "matched_bie_station_sweep"` |
| 八系数验证 | Ma 2005 Wigley III 八个频域水动力系数达到 Gate 1 精度 | `ma2005_wigley_iii_coefficients_comparison.csv` 八项均为 `PASS` |
| 精度阈值 | `A33/B33/A55/B55` 误差不超过 15%；`A35/B35/A53/B53` 误差不超过 30% | comparison CSV 中 gate ratio 均不超过 1 |
| Eq.31/Eq.32 闭合 | 几何输运、Stokes body、端点/水线边界项和整船装配能形成可追溯闭合链 | 诊断 CSV 给出分量闭合残差，目标 `<1e-9` |
| zero-`m3` 问题 | `B33/A35/B35` 的 `d(N3 ds)/dx` 非零输运必须被公式化处理或明确证明为剩余阻塞项 | `row_measure_zero_mi_boundary_audit.csv` 与 summary 来源不为 `unknown` |
| 候选纪律 | 未通过公式依据、数值闭合和八系数验证的候选不得进入默认模型 | 候选表中 `candidate_default_gate_eligible == false` |
| 运动响应链 | 通过验证的水动力系数能接入 heave/pitch 频域响应计算 | 生成 RAO CSV 和响应图，且无 `NaN/Inf` |
| 不规则波响应 | 至少一个示例海况能输出可复现的不规则波 heave/pitch/加速度时域响应 | 固定随机种子下输出 CSV、RMS 和图表一致 |
| 6 自由度输出 | 输出格式保持 `[surge, sway, heave, roll, pitch, yaw]` | head sea 中非主自由度可为零，但必须标注模型假设 |
| 数值稳定 | 不得出现奇异矩阵伪通过、未报告异常、`NaN/Inf` | `validation_summary.csv`、运行日志和测试检查 |
| 回归测试 | 现有功能不退化 | `python -m pytest -q` 全部通过 |
| 文档同步 | 理论依据、验证结果、失败项、排除候选和剩余问题必须记录 | 更新 `docs` 阶段报告和审计文档 |

## 6. 合格交付

本阶段接受两种合格交付：

1. **理想交付**：Ma 2005 Wigley III 八系数全部通过 Gate 1，线性 2.5D 水动力链可信，示例 heave/pitch/加速度响应稳定输出，完整测试通过。
2. **阶段封口交付**：若八系数仍未全部通过，必须明确列出剩余失败源、已排除候选、公式或数据缺口，并证明默认模型未被未经验证候选污染；此时只能称为“线性 2.5D 核心继续验证中”，不得宣称最终总体目标完成。

## 7. 与总体目标的关系

本阶段完成后，系统才具备向以下方向继续扩展的基础：

1. 滑行艇规则波和不规则波运动预报的可信应用。
2. 非线性 2D+t 模型开发。
3. 多体船、三体船和水翼船型扩展。
4. 面向科研汇报的可追溯 HTML/Markdown/PDF 报告生成。

如果本阶段未通过核心验证，后续扩展仍可继续做架构准备，但不得把扩展结果作为已验证运动预报能力。
