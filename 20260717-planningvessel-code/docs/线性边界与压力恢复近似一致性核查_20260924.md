## 可直接推导的几何恒等式

以向下为正的局部垂向坐标写湿表面 `z=f(x,y)`，左右水线为 `y=±b(x)/2`。设 `P(x,y)=phi(x,y,f(x,y))`，并定义 `H(x)=-integral(P dy)`。负号对应本诊断的剖面广义升沉积分权重，不能单独据此重新定义整船坐标。

沿表面求导满足：

```text
P_x = phi_x + phi_z*f_x

-integral(phi_x dy)
  = H'(x) + integral(phi_z*f_x dy)
    + b'(x)/2 * (P_right + P_left)
```

第一式是链式法则，第二式来自变积分限求导。三项分别表示剖面势积分的纵向变化、水下纵向坡度贡献以及水线端点移动贡献。再乘纵摇力臂并沿船长分部积分，还会出现力臂导数和首尾端点项。以上是几何与微积分恒等式，不是额外的水动力闭合条件；它没有证明所用势场适合更高阶模型。

离散计算使用分片线性势与几何及其既有离散导数，所以水线/坡度表示与直接几何/链式表示之间仍有可测的乘积法则残差。数据中将该残差单列，未混作物理载荷。

## 下一步决策

1. 保留原Ma型边界条件及原整船装配作为独立基线，不把本次压力后处理候选升级为生产模型。
2. 对照PDF原页核验式(30)至(32)及其引用推导，明确式(32)中的法向、稳态项和水线处理；尤其不能把剖面法向与三维法向不加区分地替换。
3. 在实现任何新增项前，先写出同一平均湿表面与稳态背景下的边界条件、恢复力和压力线性化。若保留坡度相关高阶项，应同时说明船体边界、稳态势和力矩法向的相应近似，不能只改输出压力。
4. 独立固定船体复数绕射参考仍需补齐。本次几何恒等式、14项相关测试通过均不能替代该参考，也不能替代三速度运动、峰值和相位验收。

结论：已定位到比积分精度更深的模型一致性风险；尚未证明其是所有实验误差的唯一来源，也没有得到可宣布通过的新模型。

## PDF原页核验与压力变换回归

已逐页查看A1原PDF的第4、14、15和24页，对应期刊页940、950、951和960。原文件SHA-256：`75f12aa81b390eed329389768caab59c314e10023bbf13bb598b4d2979a94840`。

核验结果：

1. 第4页确实给出二维剖面法向及忽略稳态扰动势的 `m3=0, m5=Nz`，并定义局部时间和变换势。此前对应关系得到原页确认。
2. 第14页式(30)第二个等号确实印为 `-rho*exp(-i*omega*t)*partial(psi)/partial(x)`，不是Markdown独有的识别错误。这里没有声称找到作者勘误，而是记录原式与其前文定义的代数不一致。
3. 第15页式(32)的末项为负号的艉端轮廓积分，与当前端部实现的结构一致；该页未给出详细推导，引用Dai (1998)。第24页确认其为戴遗山的频域与时域船舶波浪运动势流理论著作。尚未据该引用取得并核对原推导，不能称为完成独立理论复核。

为避免把局部推进时间与真实运动时间混为一谈，令局部时间为 `tau=(x0-x)/U`，变换势为 `psi(tau)=phi(x0-U*tau)*exp(i*omega*tau)`。固定横向和垂向坐标求导，直接得到：

```text
dpsi/dtau = exp(i*omega*tau)*(i*omega*phi-U*phi_x)
p = -rho*exp(-i*omega*tau)*dpsi/dtau
  = -rho*(i*omega*phi-U*phi_x)
```

若一定使用纵向导数，则必须对复合函数 `psi(tau(x))` 求导：

```text
p = +rho*U*exp(-i*omega*tau(x))*d[psi(tau(x))]/dx
```

因此不能原样采用印刷式(30)第二个等号；其缺少速度量纲且与式(7)、(8)不一致。当前 `recover_body_pressure_from_matched_solution` 使用第一个等号，本轮未修改该函数。

新增 `tests/test_pressure_local_time_mapping.py`：以复数二次纵向势、固定横向点、两航速三频率，独立对变换势做局部时间中心差分，再直接比较生产压力函数输出。6项新测试与4项既有移动几何梯度测试合计10项通过。这只核验压力变换、速度因子与相位，不是绕射或整船精度验收，也不消除当前模型背景一致性问题。

## 一致线性化的实施合同

对采用精确平均船体边界的新候选，令平均相对流速为V0，位移为d，刚体小转角为theta，非稳态势为phi，时间约定为exp(i*omega*t)。从瞬时船体不可穿透条件一阶展开，必须同时满足：

```text
V0 dot n = 0                         (零阶平均船体条件)
n dot grad(phi)
 = i*omega*(n dot d)
   - n dot ((d dot grad)V0)
   - (theta cross n) dot V0          (一阶运动边界)

p1 = -rho*(i*omega*phi + V0 dot grad(phi))
```

最后一式是固定空间位置的压力扰动；将载荷转回移动船体时，还须包含平均压力的位移采样、法向/力臂变化及适用的水线变化，不能把该式本身视为完整力矩。以上为刚体边界的直接一阶展开，不冒充已实现的稳态求解器；它也没有取代新候选所需的自由面线性化。

| 必需项 | 当前状态 | 下一步可核验交付 |
|---|---|---|
| 同一平均几何、坐标与姿态 | 参数化湿V形面，姿态规定 | 保持来源及近似标签，不称为实测完整船壳 |
| 平均船体不可穿透 | 均匀基流近似；本轮已量化残差 | 新基流的逐面元边界残差与离散收敛 |
| 稳态自由面与平均压力 | 未求解匹配的稳态势及自由面 | 明确模型阶次；禁止把镜像双体势直接称为滑行稳态 |
| 运动边界与基流梯度 | 当前m项采用忽略稳态扰动的简化 | 同一基流的一阶边界推导及解析构造测试 |
| 非稳态压力与载荷 | 均匀流压力已核验；候选几何项未物理验收 | 与边界、力矩、水线、端部处理配套 |

当前只有第一行的受限输入和第二行的诊断已具备；没有把上述合同写出视为完成模型。新增4项图面解析/输入测试与6项压力时间映射测试合计10项通过，未运行全套回归。

## 配套线性化算子已实现，稳态求解仍未完成

新增 `planing_seakeeping/kernels/linear_2p5d/baseflow_linearization.py`，提供两项底层运算：

- `rigid_motion_boundary_rhs`：用同一平均流速与速度梯度计算运动边界右端，分别返回运动速度、基流采样、法向转动贡献，同时显式返回零阶不可穿透残差。
- `eulerian_pressure`：使用同一平均流速恢复固定空间位置的线性压力。均匀来流时退化到现有压力公式，不含移动面载荷的额外变化项。

所有向量必须位于同一笛卡尔坐标系；平均流速已经包含均匀来流。速度梯度约定为 `J[i,j]=dV[i]/dx[j]`。这些算子没有自行生成稳态势、没有将未知的背景量默认为零，也没有接入默认模型。返回非零基流残差用于诊断，不代表允许该背景通过新的物理验收。

核验采用对称、迹为零的速度梯度构造无旋且不可压缩的非均匀基流。对六个刚体运动方向，实际旋转表面点和法向并施加平移，中心差分原始不可穿透表达式，与算子给出的一阶项比较。这是独立有限几何变换检查，不是将同一展开公式再抄一遍作为参考。该构造未声称是满足船体或自由面边界的水动力解。

新增8项测试，连同前述局部时间和基流残差测试共18项通过。稳态场求解、自由面线性化、移动面载荷、恢复力一致性及独立实验验证仍缺失，不能把本模块称为完成的稳态或耐波求解器。现有整船入口禁止零频，本轮未以小正频率冒充稳态，也未放宽其校验。

## 自由面一阶算子实现

上述“自由面线性化缺失”现已推进到底层残差算子实现，但尚未装配成边界积分求解。新增 `graph_free_surface_residuals`，要求本接口统一使用竖直向上坐标；调用方必须转换现有向下存储的几何、速度及梯度，不可只反转某个压力符号。

设平均自由面为h0，水平梯度为s，平均流速为V，扰动波面为eta，扰动势为phi，D表示平均流速的空间雅可比矩阵；所有基流量均在平均自由面处取值。h下标表示两个水平分量，z下标表示竖直分量。原始运动学条件和恒定大气压下的Bernoulli条件一阶展开为：

```text
K1 = i*omega*eta + V_h dot grad_h(eta)
     + grad_h(phi) dot s - phi_z
     + eta*((partial_z V_h) dot s - partial_z V_z)

D1 = i*omega*phi + V dot grad(phi)
     + eta*(g + V dot partial_z V)
```

接口同时返回零阶残差 `K0=V_h dot s-V_z` 与 `D0=|V|²/2+g*h0-C`，C为调用方显式提供的Bernoulli常数。不将零阶残差自动扣除后声称背景已满足边界，也不把这些表达式作为已求出的自由面。

验证包括：非均匀无旋不可压缩基流上，将原始非线性条件在竖直位移后的自由面直接求值并作中心差分；以及三种均匀来流速度、两种波数下的深水波色散关系。后者使用遭遇频率与本征频率区分，要求两种一阶残差同时为零。新增7项测试，加上基流运动边界、残差与压力变换测试合计25项通过。

尚未完成的求解环节明确保留：平均自由面与稳态势的共同求解、势梯度和二阶导数的数值恢复、新自由面算子进入匹配系统、移动面完整载荷及恢复力、独立复数激励与原整船验收。当前没有新的整船实验分数，不宣称候选优于原路线。
