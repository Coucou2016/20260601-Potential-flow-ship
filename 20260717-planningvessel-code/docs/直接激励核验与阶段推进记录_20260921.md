## 下一步具体目标与验收

**目标：在不改动试验门槛和不使用响应拟合的前提下，完成直接绕射激励及纵摇力矩的独立验证和全频段离散收敛，明确三航速失败的物理来源，再进行整船正式复验。**

| 顺序 | 任务 | 验收证据 |
|---|---|---|
| 1 | 核对绕射边界条件、压力符号、纵摇力臂、前进速度与艉部项 | 独立参考、坐标/相位定义、公式到代码定位；阈值及参考哈希在求解前冻结；不得只重复核验入射项 |
| 2 | 分离入射、绕射及整船积分，输出低速失败点与高速对照点的站位分量 | 每点复数载荷分解、积分重构残差；不将幅值直接相加代替复数相加；不按实验响应修改倍率 |
| 3 | 全交付频段三档站位/面元/历史离散 | 八个水动力系数及复数激励细两档变化≤5%；近零项绝对容差预先冻结；不以少数代表点代替全频段 |
| 4 | 原合同整船复验 | 三速度各自升沉、纵摇15%/20%；至少4个主峰、覆盖两速度两运动、频率误差≤10%；旧基础门10/10且≤2% |
| 5 | 补齐剩余交付门 | Fridsma相位≤15度、重心加速度≤25%；同核时频5%/5度；稳定性、适用性、全回归与可重现报告；未完成项明确失败或待验 |
