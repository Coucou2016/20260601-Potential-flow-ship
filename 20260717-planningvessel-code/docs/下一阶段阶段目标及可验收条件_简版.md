| 编号 | 验收项 | 硬性条件 |

| 4 | 三角度数值独立性 | 10°、20°、30°均满足 `K<=1e-3`、根部相对失配 `<=1e-3`，并通过网格、时间步、远域和路径独立性检查，关键量变化均 `<=5%`。 |
