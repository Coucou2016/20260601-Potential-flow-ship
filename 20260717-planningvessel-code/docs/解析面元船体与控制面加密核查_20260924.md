# 解析面元船体与控制面加密核查

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。阶段状态：未通过。

## 结论

沿用有界自由面迁移、直面元解析积分及完整外域历史，在单个Kang工况完成船体、控制面分别加密：

- 船体面元64增至128，复数绕射升沉力及纵摇力矩变化分别0.0326%、0.0277%。
- 控制面面元96增至192，变化分别0.8294%、1.1991%。
- 上述局部比较小于既定5%离散限值，但不构成全频段、三档、八系数及复数激励的完整离散验收。
- 计算总升沉激励仍约10.28至10.30，待准入论文数字化候选约6.875，差异仍约49%至50%。本轮加密不能解释主要参考偏差，也不能据此断言偏差一定来自某一物理公式。

## 一、哪些变量被固定

所有计算采用3米Kang解析船型，船长弗劳德数0.2，无量纲遭遇频率3；321纵向站位，每侧自由面内区20、外区44划分，控制半径0.9米。历史步长、历史时长、波数积分、端部截断、旧速度迁移和压力恢复公式均保持一致。

面元积分为显式 `analytic_straight_midpoint_curved` 路线：符合直面元几何的边界采用解析对数核积分，圆形控制面仍采用原中点积分。求解不读取参考响应，所有结果继续标为未通过阶段验收。

| 计算 | 船体面元 | 控制面面元 | 无量纲总升沉激励幅值 | 最大方程相对残差 |
|---|---:|---:|---:|---:|
| 原解析积分候选 | 64 | 96 | 10.278439 | 8.69×10⁻¹⁶ |
| 仅加密船体 | 128 | 96 | 10.277652 | 9.89×10⁻¹⁶ |
| 仅加密控制面 | 64 | 192 | 10.295039 | 1.39×10⁻¹⁵ |

小残差证明所构造线性系统解得准确，不代表边界模型或压力公式已物理验证。

## 二、按复数分量比较

相对变化以复数差的模除以原64/96档复数载荷的模，包含相位和幅值变化。这里没有用幅值简单相减，也没有仅比较总力。

| 加密方向 | 分量 | 升沉力变化 | 纵摇力矩变化 |
|---|---|---:|---:|
| 船体64至128 | 直接入射 | 0.00708% | 0.00506% |
| 船体64至128 | 绕射 | 0.03259% | 0.02769% |
| 船体64至128 | 总激励 | 0.00936% | 0.00483% |
| 控制面96至192 | 直接入射 | 0 | 0 |
| 控制面96至192 | 绕射 | 0.8294% | 1.1991% |
| 控制面96至192 | 总激励 | 0.1661% | 0.1948% |

控制面加密不改变船体上的直接入射压力积分，因此该分量完全不变。船体加密则同时改变入射积分和绕射离散。两者单独改变有助于定位误差，不等同于所有方向同时加密后的收敛证明。

## 三、接触处势检查

继续使用上一轮的两点端点外推诊断，以单位波幅的水面入射势尺度归一化船体侧与自由面侧的势差：

| 船体面元 | 最大差异 | 中位差异 |
|---|---:|---:|
| 64 | 0.00163635 | 0.00043945 |
| 128 | 0.00071912 | 0.00019557 |

加密船体后两个指标均减小，支持先前“中点积分与近接触离散会影响势一致性”的判断。但这里仍是面元中心值的外推，船体距离用弦长近似，不能替代精确接触点未知量或新暴露状态的物理验证。
