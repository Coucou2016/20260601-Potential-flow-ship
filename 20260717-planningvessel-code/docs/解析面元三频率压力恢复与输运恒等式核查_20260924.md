## 一、为什么要区分两种纵向导数

压力沿用既有线性形式

\[
p=-\rho i\omega\phi+\rho U\phi_x.
\]

这里，p为谐波压力复幅值，rho为水密度，i为虚数单位，omega为遭遇角频率，phi为物理谐波势，U为航速；phi_x要求在横向坐标y、向下深度z固定时求纵向导数。

沿船体相同面元索引，y、z会随纵向x变化，因此实际直接差分包含几何项：

\[
D_x\phi=\phi_x+y_x\phi_y+z_x\phi_z.
\]

本轮保留原相位域差分路线，仅从保存的导数扣除后两项。横向梯度由船体切向差分与已知法向边界值联合恢复，左右两侧分别计算，不跨龙骨折角求导。尖端及接触附近仍存在单边差分和常数面元误差，故此处理仍是候选诊断。

## 二、积分输运恒等式及端部项

对从右水线沿船体走向左水线的截面轮廓，以固定轮廓参数lambda描述位置。定义

\[
I(x)=\int\phi\,dy,\qquad
E(x)=[\phi y_x]_{\rm start}^{\rm end},\qquad
H(x)=\int\phi_z(z_x\,dy-y_x\,dz).
\]

I是势在垂向压力投影上的截面积分，E是两侧水线端点随船型变化产生的边界项，H是轮廓形状变化项。对I求导，并对含有y的参数导数作分部积分，可得

\[
I_x=\int\phi_x\,dy+E+H.
\]

因此整船的前进速度压力项无需直接对phi作纵向差分：

\[
J_3=I(x_b)-I(x_a)-\int_{x_a}^{x_b}(E+H)\,dx.
\]

以l为力矩参考点，保留当前程序的力臂l-x，纵摇对应项为

\[
J_5=[(l-x)I]_{x_a}^{x_b}+\int_{x_a}^{x_b}I\,dx
-\int_{x_a}^{x_b}(l-x)(E+H)\,dx.
\]

其中x_a、x_b是实际截断计算域的纵向两端；端部项没有擅自置零。l在当前Kang诊断中取几何船中1.5米，不代表已经核实的实验重心。

程序采用船体中心点几何导数、恢复的phi_z及水线端点势外推来近似E、H。连续恒等式严格成立，不等于这些离散量已经严格守恒或物理准确。最终力仍使用同一压力约定，将非定常势积分项与rho乘U乘J相加。

## 三、制造解和负向测试

新增制造解采用随x改变宽度和深度的V形截面，给定phi=x²+z。固定空间导数为2x，整船力及力矩可直接解析积分。17、33、65站位的输运公式误差表现为二阶下降。另以常数势检查：仅船形改变不应产生虚假的纵向势梯度载荷。

回放器增加了压力、相位和积分力分别损坏的测试，必须拒绝生成成功摘要；不支持的候选配置在创建输出前拒绝。上述测试验证数学和程序行为，不冒充船舶实验验证。

## 六、下一步

本轮证据不支持“主要幅值偏差只来自移动面元纵向差分”的解释。应继续核对入射/绕射边界条件、局部时间变换、外域历史与控制半径，以及当前低船长弗劳德数下的理论适用性；不能把未经验证的理论适用性推测作为删除失败工况的理由。

若将固定空间压力恢复接入新候选，辐射和绕射必须采用一致约定，重新生成八系数和复数激励；不能只替换激励侧后宣布整船修复。其余频率的完整三档离散、独立复数参考、Begovic三速度及所有既定验收条件继续保留。
