# Gate 2 Aitken 相位一致性与 Eq.52 收敛判据复核

日期：2026-08-25  
状态：**可信普通分支已推进至 v113；二维楔形入水先决门仍为 FAIL；Gate 2 仍为 17/20 PASS。**

## 1. 复核原因

二维自相似楔形入水求解器会周期性重置匹配面。不同循环相位的自由面状态不能直接组成向量 Aitken 外推序列，否则外推量同时包含物理解的慢变化与离散重置造成的锯齿变化。Iafrati 2013 还明确以方程（52）

`K = integral(S_nu^2 ds)`

衡量自由面运动学条件的收敛，其中 `S_nu` 是伪速度在自由面法向的分量，`ds` 是弧长微元。旧的等面板均方根会给短面板过高权重，因此仅保留为诊断量；求解停止、长时分析和外推候选资格统一改用源文献定义的 `K`。

本复核所用主来源为本地 `benchmarks/iafrati2013_self_similar_wedge/iafrati2013_arxiv1212.6699v2.pdf`，方程（52）位于论文第 16 页，网格相关的非零渐近行为见图 6。

## 4. 物理量与双参考审计

`v113` 的 Zhao 自由面归一化均方根误差为 `11.20%`，压力曲线误差为 `2.25%`，精确压力峰值误差为 `0.30%`，峰位误差为 `0.85%`。相同 Zhao 横坐标上，对 Iafrati 自由面误差为 `2.55%`；完整重叠区为 `1.76%`。这说明压力和 Iafrati 外自由面已较接近，但 Zhao 近根参考仍未通过，且两个参考本身存在系统差异，故必须双报告。

从 `v96` 进行的法向伪速度单独诊断 `v111` 使 `K` 增至 `0.729957`，路线被否决；80/120/160 网格的一步探针又显示 120 到 160 的 `K` 基本不变。这些结果用于排除候选原因，不是验收算例。

## 5. 当前结论与下一动作

1. 当前唯一可信普通推进基线是 `v113`，但它没有达到收敛和自由面阈值。
2. 二维楔形入水先决门保持 `FAIL`，Gate 2 保持 `17/20 PASS`。
3. 下一动作必须从 `v113` 对根部和远端空间离散做有理论依据的修正；任何新外推仍须先通过相位与方程（52）资格门。
4. 只有 `10/20/30 deg` 同时满足冻结的二维精度、收敛和网格/时间步条件，才允许恢复 Sun--Troesch 整船强迫运动验证。
