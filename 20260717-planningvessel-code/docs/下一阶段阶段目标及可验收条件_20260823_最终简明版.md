# 下一阶段阶段目标及可验收条件

日期：2026-08-23  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
阶段名称：**线性高速 2.5D 规则迎浪纵向运动验证闭合（Gate 2）**

> 本文件是下一阶段的简明验收口径。所有条件必须同时满足，才可进入不规则波及更高层级模型开发。

## 一、阶段目标

**在保持 Ma 2005 线性高速 2.5D 水动力 Gate 1 不退化的前提下，闭合高速滑行艇规则迎浪中的频率相关辐射、绕射、直接波浪激励、恢复力及升沉--纵摇耦合计算；先通过 Sun 2007 五频率八水动力系数同源数值复现，再以 Troesch、Begovic 和 Fridsma 冻结试验数据完成三个航速下升沉、纵摇、相位及重心/艏部垂向加速度的独立验证，使 Gate 2 由 `17/20 PASS` 达到 `20/20 PASS`，形成可解释、可诊断、可一键复现并可扩展到不规则波的线性高速 2.5D 纵向运动预报基线。**

全过程禁止使用试验响应反演、经验倍率、参考值缩放、逐点拟合、选择性删点或根据计算结果事后改变验收范围。

## 二、可验收条件

| 编号 | 验收项 | 必须满足的条件 |
| --- | --- | --- |
| 1 | Gate 1 不退化 | Ma 2005 十行基准和双网格收敛继续全部通过；单位、符号、坐标、相位及矩阵顺序可追溯。 |
| 2 | 源级水动力闭合 | Sun 2007 的 `5` 个频率、`8` 个系数全部计算；各系数中位相对误差 `<=10%`、归一化均方根误差 `<=15%`，物理趋势及耦合非互易性正确；明确标记为同源数值复现，不冒充独立实验。 |
| 3 | 数值收敛可靠 | 强迫运动最后两级八系数变化均 `<=5%`，谐波残差 `<=5%`；运动方程复数相对残差 `<=1e-8`；无 `NaN/Inf`，并输出条件数、失效频点和原因。 |
| 4 | 工况覆盖完整 | Begovic 覆盖 `Fn_B=1.67、2.26、2.82`；每航速保留全部实验点并计算不少于 `20` 个致密频点；输出遭遇频率、升沉/纵摇复响应、幅值、相位及重心/艏部垂向加速度。 |
| 5 | 独立运动精度 | 预先冻结的线性适用区内，升沉和纵摇中位相对误差 `<=15%`、归一化均方根误差 `<=20%`，主峰频率偏差 `<=10%`，非近零响应相位中位误差 `<=15 deg`；范围外数据保留并单列。 |
| 6 | 独立加速度精度 | Fridsma 重心垂向加速度归一化均方根误差 `<=25%`；艏部加速度完整输出并注明验证边界，不以缺少实验数据代替通过。 |
| 7 | 频时域和运动学自洽 | 至少 `3` 个代表频点的频域--时域幅值差 `<=5%`、循环相位差 `<=5 deg`；波幅加倍后的运动及加速度幅值比为 `2.00 +/- 5%`；点加速度解析值与程序值相对误差 `<=1e-8`。 |
| 8 | 数据与模型可追溯 | 冻结 Troesch、Begovic、Fridsma 的几何、质量惯性、工况、来源页码、数字化方法、不确定度和源文件 SHA-256；建立公式--代码--测试--数据追踪表；缺失输入标记“待补充”，不得编造。 |
| 9 | 一键复现和完整交付 | 一条固定命令从空输出目录生成输入快照、水动力与激励矩阵、响应数据、误差表、二维图、三维船型/站位图、动态可视化、报告及机器验收清单；完整测试无失败，机器结果明确为 `Gate 1 = PASS`、`Gate 2 = 20/20 PASS`。 |

## 三、完成判定与阶段边界

九项条件必须全部通过，任何单频点改善、局部曲线吻合或仅完成诊断均不构成阶段完成。

本阶段只验收**小幅规则迎浪纵向运动**。通过后依次开展：不规则波纵向统计响应、斜浪六自由度、强非线性 2D+t、多体船干扰和水翼控制。未经验证的占位模型不得作为这些后续阶段的正式结果。
