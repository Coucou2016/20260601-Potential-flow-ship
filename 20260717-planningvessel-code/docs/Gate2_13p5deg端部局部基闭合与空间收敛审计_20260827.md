# Gate 2：13.5°端部局部基闭合与空间收敛审计

日期：2026-08-27  
结论状态：**数值门槛与三层空间收敛通过；13.5°冻结为合格数值同伦源；独立物理验证仍为 `FAIL`；二维先决门和 Gate 2 总状态不变。**

## 1. 目的与判定边界

13.5°在128个全局离散余弦变换模态下仍有 `K640=1.42307e-3`、`K1280=1.34376e-3`，未满足绝对运动学积分 `K<=1e-3`。本轮没有放宽门槛，而是先审计根约束可行子空间和残差空间分布，再把全局形状基改为自由面末端局部形状基。

求解过程没有读取自由面、压力、载荷或整船试验参考，所有运行均为 `reference_used_during_solve=false`。本审计只判定数值约束闭合、空间稳定和可复现性；13.5°没有冻结权威物理参考，不能据此宣称自由面、压力或载荷已经通过物理验证，也不能替代10°、20°、30°楔形入水正式基准。

冻结数值门槛为：320、640、1280面板精确运动学积分和根部相对失配均 `<=1e-3`，并通过同源三层空间收敛检查。

## 2. 形状空间诊断

对128模态全局雅可比进行根约束零空间分析后得到：

- 达到细网格绝对门槛最多需要约 `30.18%` 的相对下降；
- 128模态在640/1280根一阶不变子空间内的理论可达下降只有 `0.6319%`；
- 源状态自由面末端10%的残差能量占640/1280面板总量的 `76.24%/83.59%`；
- 64至128全局模态只增加约 `0.207%` 的理论可达下降。

因此继续增加同类全局模态缺少收益依据。机器诊断输出建议 `change_to_endpoint_local_basis_before_more_global_dct_modes`，对应证据为：

`outputs/self_similar_wedge_13p5deg_n320_dct128_feasible_subspace_audit_v598`

该诊断只使用控制方程残差和保存的雅可比，不读取物理参考。

## 3. 方法增量

1. 多网格信赖域新增 `dct`、`root_local` 和 `far_local` 三种形状基选择。
2. 端部局部基由少量全局模态和指定弧长支撑内的局部帽函数构成，并用连续线性弧长质量矩阵正交归一化。
3. 新增归一化后正交性复核；Cholesky分解虽返回但质量矩阵正交误差过大的基函数会被判为数值病态并拒绝。
4. 局部基类型、全局模态数和支撑比例写入检查点及摘要；不同局部模态总数的雅可比不得错误地按前缀复用。
5. 方向复用脚本可从摘要重建局部基，并严格解析CSV布尔状态；每一步仍重新检查多网格目标、三层非线性根、条件数、曲率和绝对门槛。
6. 新增根约束可行子空间和弧长分段残差能量诊断脚本，明确区分“形状空间不足”和“根约束不足”。

这些修改不改变控制方程、物理参考或任何冻结验收阈值。

## 7. 结论

13.5°现已同时满足320/640/1280三层绝对运动学积分、三层根部失配和空间稳定性要求，因此可冻结为**合格数值同伦源**，并可用于13.0°的参考隔离延拓。此前全局高模态未闭合审计保留为形状空间诊断历史，不再代表当前状态。
