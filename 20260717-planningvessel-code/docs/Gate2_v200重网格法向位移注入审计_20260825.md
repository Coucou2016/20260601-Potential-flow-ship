# Gate 2 v200 重网格法向位移注入审计

日期：2026-08-25  
状态：**诊断完成；求解器物理行为未改变；二维楔形入水先决门仍为 FAIL**

软件回归：`551 passed, 0 failed`，耗时 `780.03 s`；既有 `1247` 条空切片统计告警保留。

## 1. 目的

此前的弱式残差、连续几何法向和节点伪速度审计表明，二维楔形入水解在长时推进后仍停留于 `K≈0.005`。本审计检验一个独立候选原因：每个二阶 Runge--Kutta 阶段后的重采样、样条重网格、根部转移或匹配面调整，是否持续向自由面注入非物理法向位移，从而制造残差平台。

## 2. 方法

在不修改求解器更新规律的前提下，新增只读诊断：

1. 保存显式 Runge--Kutta 更新后的原始自由面；
2. 将最终接受曲线采样到原始曲线的归一化弧长坐标；
3. 消去沿同一曲线的纯切向节点重分布；
4. 将剩余几何修正分解到连续节点切向和法向；
5. 计算法向修正速度平方积分、切向修正速度平方积分、最大局部法向位移比、与原始法向速度的相关系数及抵消率。

解析单元测试证明：直线上的纯切向节点重分布给出零法向注入；整条直线作单位法向速度平移时，数值积分与解析积分一致。

- 方法：双节点角点、element 梯度、connected-average 根部速度、固定 `256` 个喷射边界元面板

## 5. 判定

重网格不是 `K≈0.005` 平台的主因。它在该冻结状态下确实引入同向法向修正，因此属于应继续约束的次要放大项；但其法向积分只有正式平台值的 `4.77%`，即使完全消除也不足以达到 `K<=0.001`。

结合此前结果，已排除或降级的主因候选包括：端点线性积分误差、共享角点、根部速度平均、相似势切向恒等式违背、远域偶极系数滞后、面板法向不连续和重网格法向注入。下一项应直接研究保持切向重参数化时的连续法向自由面边界更新及其时间离散闭合。

## 6. 边界

本审计只说明重网格不是当前平台的主导来源，不证明现有重网格在全部角度、网格和长时工况下均可忽略，也不改变二维楔形入水先决门的 `FAIL` 判定。只有三角度、三类收敛及全部冻结误差阈值同时满足，才能转为 `PASS`。
