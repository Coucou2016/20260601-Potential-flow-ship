# 自由面暴露状态迁移制造解失败定位

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。**总体阶段未通过；有界邻近值迁移不满足已有制造解误差限。**

## 1. 先核对自由面方程

本地A1原文式(4)、式(10)对辐射和绕射势都采用齐次自由面动力学、运动学条件，绕射入射作用通过船体法向导数输入。按本阶段采用的A1模型，不能为追近参考曲线额外添加自由面源项。本轮没有进行这种修改。

A1第3.3节说明固定横向网格及水线处截断面元，但该段没有给出当前候选所用的邻近值保持暴露状态。该算法不能仅因采用固定网格就被称为原论文算法。

## 2. 发现的验证缺口

已有移动网格制造解在新暴露点使用精确的旧时刻状态，而实际Kang候选使用同侧最近自由面点的状态。这是两种不同边界处理；前者通过不能覆盖后者。

本轮保留同一个解析傅里叶自由面振子，将半宽按0.097+0.031sin(2πt)米变化，比较：

1. 精确暴露状态：在刚释放的自由面位置使用解析旧时刻势、升高量及法向速度；其他位置沿用已有插值。
2. 当前实际有界迁移：支持区内插值，支持区外取同侧最近点状态，保持原暴露距离限制。

计算时间1秒。四档同时加密时间和横向网格，时间步数40、80、160、320。新暴露访问次数10、22、52、104；两种策略在同一档使用完全相同的网格与动力学推进。

解析状态满足自由面动力学和运动学方程，但采用对角算子“法向速度等于波数乘势”，不是移动船体边界积分求解。这是状态迁移一致性检验，不是船舶接触物理或整船载荷验证。

## 3. 结果

最大加权误差是全过程势和自由面升高量分别归一化后、按面元长度加权的相对二范数；最大点误差采用解析振幅尺度，而非局部接近零的瞬时参考值。两项都检查全过程，不只检查终点。

| 加密档 | 精确暴露最大加权误差 | 邻近值保持最大加权误差 | 邻近值保持最大点误差 |
|---:|---:|---:|---:|
| 1 | 0.8121% | 1.6578% | 5.1717% |
| 2 | 0.2019% | 1.5416% | 5.0540% |
| 4 | 0.0503% | 1.5333% | 5.1617% |
| 8 | 0.0126% | 1.4808% | 5.0323% |

精确暴露状态呈明显二阶趋势；当前有界迁移在这四档中出现误差平台。不能仅据有限四档严格证明其数学极限不收敛，但它已无法满足此前制造解冻结的最大加权误差1%要求，也没有表现出与精确暴露路线相当的收敛行为。

两种策略的推进方程残差均约机器精度。这进一步说明“方程解得准”不能证明提供给方程的暴露状态准确。

首轮结果在`bounded_contact_manufactured_20260924`，随后显式记录继承的1%制造解限值并在新目录`bounded_contact_manufactured_contract_20260924`重跑，未覆盖首轮。该限值原用于精确暴露制造解，不是新设的整船实验门槛。机器结果分别记录精确暴露通过、有界迁移失败；整体始终不通过。

## 4. 原因与实际影响

邻近值保持是凸组合或直接复制，能避免线性外推的负权重放大；但在新释放的区域，它不能产生源点范围以外的空间变化。连续多次释放会把边缘状态向新区域传播，保留局部偏差。本例的误差平台与这种机制一致，但不是对真实船舶误差来源的最终定量归因。

不能用本表5%的点误差直接解释Begovic几十个百分点的运动误差，因为本例没有真实船体边界积分、压力恢复或耦合运动方程。此前Kang候选的控制半径和历史积分变化较小，也不能弥补该状态初始化缺口。

## 5. 对下一步实现的约束

- 不将有界邻近迁移接入整船默认或宣布其已验证；此前候选场解保留为诊断。
- 新接触处理需说明新暴露点的势和升高量从哪里来，如何满足连续性及自由面演化；不能通过设定试验响应来初始化。
- 首先在同一制造解、同一误差限和全局/局部误差记录下检验，再进入实际移动船体边界积分及网格收敛。
- 单纯恢复未经限制的线性外推并不构成修复：历史计算已出现放大与不稳定，必须同时检验一致性和稳定性。
- 仍需独立复数激励参考及原三航速整船验收，不能把制造解通过等同于物理验证。
