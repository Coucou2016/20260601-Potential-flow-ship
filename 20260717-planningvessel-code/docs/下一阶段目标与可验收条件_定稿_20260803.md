# 下一阶段阶段目标及可验收条件

日期：2026-08-03

适用范围：本文件服务于《高速船型运动预报系统总体目标》。后续开发、验证、文档和报告均应以本阶段目标为近期执行边界。

## 一、阶段名称

线性 2.5D 核心硬验证与运动预报闭环。

## 二、阶段目标

在现有 `planning_motion / planing_seakeeping` 基础上，以高速单体滑行艇和高速细长船型纵向运动为核心，完成 Ma-Duan-Song / Faltinsen 型线性 2.5D 求解器的方程级闭合、基准算例验证和工程化输出，使其从“可运行、可诊断的原型”推进为“可验证、可复现、可作为后续非线性 2D+t、多体船、三体船和水翼船扩展基础的默认核心模型”。

一句话目标：

> 先把线性 2.5D 纵向耐波核心做实、验硬、说清楚，再扩展非线性、多体和水翼。

## 三、本阶段范围

1. 以 Ma 2005 Wigley III 八个升沉/纵摇水动力系数为第一硬验证对象。
2. 固定 `matched_bie_station_sweep` 为默认 2.5D 主路径。
3. 闭合升沉、纵摇及二者耦合项的水动力系数计算链。
4. 保持示例滑行艇可输出规则波、不规则波和不同航速下的六自由度统一时序结果。
5. 对暂未高精度验证的横向自由度、斜浪、多体船、三体船、水翼船仅保留接口、诊断和资料储备，不作为本阶段硬通过条件。

## 四、本阶段不做

1. 不把经验缩放、曲线拟合或最终系数修正作为通过 Gate 1 的手段。
2. 不把未验证的 `diagnostic-only` 候选路径接入默认模型。
3. 不把 SL-7、C1 三体船或替代几何作为本阶段硬通过依据；它们只作为后续验证数据储备。
4. 不宣称完成生产级强非线性 2D+t 自由面边界元、多体船共同边界积分或水翼控制模型。

## 五、必须完成的工作

1. 固定 Ma 2005 Wigley III 参考数据表，包含系数名称、频率、参考值、归一化方式、来源位置和误差门限。
2. 审计并修正线性 2.5D 方程链，包括内域边界积分、外域控制面、自由面历史项、压力恢复、前进速度梯度项、端部项和整船装配。
3. 输出八个水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 的逐项对照、误差来源和通过状态。
4. 运行示例滑行艇配置，生成不同航速下的响应幅值算子、规则波时域、不规则波时域、垂向加速度和统计结果。
5. 更新阶段报告，说明公式来源、代码位置、验证命令、结果表格、失败项解释、候选路径排除原因和剩余缺口。

## 六、可验收条件

| 类别 | 验收条件 |
|---|---|
| 理论追溯 | 默认模型中每个实质性修正均能追溯到 Ma-Duan-Song、Faltinsen 或等价 2.5D 理论中的具体方程、边界条件、积分项或归一化定义。 |
| 参考数据 | `wigley_iii_gate1_reference.csv` 或等价参考表固定可读，包含八个系数的来源、频率、参考值、无量纲方式和误差门限。 |
| 默认路径 | 验证结果必须来自 `matched_bie_station_sweep` 默认路径，不能依赖人工开关、后处理修正或候选模型。 |
| 八系数验证 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部达到 Gate 1 误差门限；若未全部通过，必须把每个失败项压缩到明确的方程、数据、坐标、积分或归一化缺口。 |
| 候选隔离 | 所有未通过硬验证的候选修正均标注 `candidate_default_gate_eligible=false`，并写明不进入默认路径的原因。 |
| 运动预报 | `configs/example_planing.yml` 可运行，输出 `summary.csv`、`rao.csv`、各航速时序 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时序结果包含 `surge/sway/heave/roll/pitch/yaw`；迎浪场景重点验证 `heave`、`pitch` 和垂向加速度，其他自由度必须注明对称性或线性扩展假设。 |
| 不规则波 | 固定随机种子下，不规则波输入谱、时域响应、均方根值、峰值和统计结果可复现。 |
| 数值稳定 | 验证结果、运动结果和关键矩阵不得出现 `NaN`、`Inf` 或非物理发散。 |
| 自动测试 | `python -m pytest -q` 全部通过。 |
| 报告交付 | 阶段报告清楚列出目标、方法、公式来源、代码修改点、验证结果、失败项、剩余风险和下一步建议。 |

## 八、完成判定

本阶段的理想完成标准是：Ma 2005 Wigley III 八个水动力系数全部通过 Gate 1，示例运动预报链路稳定运行，完整测试集通过，阶段报告能够解释每个关键结果的理论来源和验证证据。

若八个系数尚未全部通过，本阶段不能标记为完全完成；只能标记为“有限完成”。有限完成必须满足：所有失败项均已压缩到明确、可追溯、当前资料无法直接消除的理论或数据缺口，且没有未经验证的经验修正进入默认路径。
