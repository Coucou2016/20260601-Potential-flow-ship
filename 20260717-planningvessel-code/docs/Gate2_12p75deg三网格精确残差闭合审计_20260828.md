# Gate 2：12.75°三网格精确残差闭合审计

日期：2026-08-28  
状态：**12.75°三网格数值门 `PASS`；二维入水物理门 `FAIL`；整船 Gate 2 `17/20 PASS`**

## 1. 目的与边界

本审计只判定12.75°恒速楔形入水同伦源的320/640/1280面板数值门。它不读取自由面或压力参考参与求解，不判定10°、20°、30°物理精度，也不增加整船Gate 2通过项。

正式接受量为Iafrati式（52）的分片线性精确积分：

```text
K = sum[ds * (r_left^2 + r_left*r_right + r_right^2) / 3].
```

每层必须满足`K<=1e-3`、根部相对失配`<=1e-3`且无非有限值；640到1280面板的`K`和积分垂向力变化均须`<=5%`。相对变化固定为`abs(fine-coarse)/max(abs(fine),1e-12)`。

## 2. 问题定位与修正

v836直接重网格后的三层`K`为`9.53012e-4/7.26067e-4/8.18152e-4`，绝对门通过，但最后两级变化为`11.255%`。分量定位显示，网格差异主要集中在射流匹配根首面板：其精确贡献随320/640/1280面板加密由`1.80289e-4`增至`3.36545e-4/4.99770e-4`，说明普通几何插值不能替代细网格根区再求解。

代码据此增加冻结Newton法向方向的归一化弧长映射。该映射只把物理位移场插值到细网格；每个候选仍重新闭合根状态、重建完整边界积分方程，并用本层正式`K`、位移、曲率、条件数和根失配验收。640面板由v837推进到v840；1280面板先映射方向，再以根起前5%弧段的16维局部余弦基重新线性化并复用两步，得到v844。
