# 下一阶段目标与验收条件：线性高速 2.5D 核心闭环

日期：2026-08-09  
对应总体目标：高速船型运动预报系统总体目标

## 1. 当前进展判断

项目已经完成第一轮可扩展框架建设，当前状态可以概括为：

1. 已建立 `planing_seakeeping` Python 包和命令行入口，具备配置读取、船型几何、稳态滑行平衡、波浪、求解器、六自由度统一输出、可视化和验证模块。
2. 已形成 `linear_2p5d`、`nonlinear_2dt`、`multihull`、`hydrofoil` 等内核目录，说明总体架构已经具备后续扩展位置。
3. 示例滑行艇算例已经可运行，能够输出 `summary.csv`、`rao.csv`、规则波/不规则波时间序列、图像和 `run_report.md`。
4. 文献和验证体系已经初步建立，覆盖 Faltinsen、Ma 2005、Fridsma、Katayama、Delft 372、ITTC 等来源。
5. 基础数值检查、物理趋势检查和二维截面边界元基础检查已经具备通过记录。

## 2. 下一阶段阶段目标

下一阶段唯一主目标是：

完成线性高速 2.5D 核心水动力模型的 Gate 1 闭环，使 Ma 2005 Wigley III 八个核心频域水动力系数 `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 在固定验证入口下全部通过，并形成可追溯的公式链、实现链、诊断链、测试链和报告链。

本阶段的实质目标不是“让程序跑起来”，而是让默认 `matched_bie_station_sweep` 路径在理论、数值和对照数据上站得住。

## 3. 本阶段范围

必须包含：

1. 以 Ma 2005 Wigley III 为首要硬验证对象。
2. 以 A1/Ma 2005 的线性高速 2.5D 公式链为主要理论依据。
3. 修正默认 `matched_bie_station_sweep` 中的公式、符号、相位、归一化、站位积分、压力梯度项、Stokes 项和端部项问题。
4. 将八个系数按问题链分组闭合：`A33/A53`、`B33/A35/B35`、`A55/B55`。
5. 保留所有诊断 CSV 和阶段报告，使每次默认路径修改都有来源、有原因、有结果。
6. Gate 1 通过后，重新运行滑行艇规则波和不规则波示例算例。

本阶段暂不作为主线验收：

1. SL-7 真实 offsets 闭合。
2. C1 三体船真实 offsets 闭合。
3. Delft 372 双体船完整斜浪六自由度验证。
4. Sun-Faltinsen 强非线性 2D+t 生产级自由面边界元。
5. 水翼船控制系统和真实水翼自由面耦合。

这些内容只保留为资料整理、接口预留和后续验证对象。

## 4. 可验收条件

### 4.1 固定验证入口可重复

必须提供并稳定运行固定 Gate 1 命令：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

如果全量 `all` 验证耗时过长，必须同时提供 Ma 2005 Wigley III 专用命令；两种入口的参考数据、输出文件和判定规则必须一致。

### 4.2 八个核心系数全部通过

`outputs/gate1_linear_2p5d_hard_pass\results\ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 必须满足：

1. `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 全部为 `PASS`。
2. 对角项相对误差不超过 15%。
3. 耦合项相对误差不超过 30%。
4. 所有计算值不得出现 `NaN`、`Inf`、空字段或数值发散。
5. 通过结果必须来自默认模型路径，不得来自诊断候选、经验缩放、后处理拟合或单系数补偿。

### 4.3 公式链可追溯

每个通过的系数必须在报告中追溯到：

1. 截面边界条件。
2. 自由面 marching。
3. 压力公式。
4. 前进速度梯度项。
5. Stokes 或几何输运项。
6. 端部项。
7. 站位积分。
8. 整船矩阵装配。
9. Ma 2005 归一化方式。

每个修正必须说明来自文献公式、坐标/符号修正、数值实现修正，还是归一化/装配修正。

### 4.4 诊断输出完整

至少保留以下文件：

1. `ma2005_wigley_iii_coefficients_comparison.csv`
2. `ma2005_wigley_iii_coefficients_status_by_coefficient.csv`
3. `ma2005_wigley_iii_coefficients_eq30_component_contribution_audit.csv`
4. `ma2005_wigley_iii_coefficients_*summary.csv`
5. `validation_summary.csv`
6. `validation_status_by_benchmark.csv`
7. `validation_report.md`

所有候选路径必须标注为诊断证据，不得混入默认模型验收结果。

### 4.5 测试通过

必须至少通过：

```powershell
python -m py_compile planing_seakeeping\validation.py tests\test_validation.py
python -m pytest -q
```

如全量测试因耗时或外部依赖不能完成，必须在阶段报告中列明未完成原因，并给出已执行的替代测试命令和结果。

### 4.6 示例运动预报可复现

Gate 1 通过后，必须重新运行示例：

```powershell
python -m planing_seakeeping run configs\example_planing.yml --out outputs\gate1_linear_2p5d_hard_pass_motion_demo
```

输出目录必须包含：

1. `summary.csv`
2. `rao.csv`
3. `timeseries_regular_speed_*.csv`
4. `timeseries_irregular_speed_*.csv`
5. `figures/rao.png`
6. `figures/rms_by_speed.png`
7. `figures/timeseries_*.png`
8. `run_report.md`

报告必须明确说明迎浪线性模型中横荡、横摇、艏摇为零或近零的物理原因，不得将其解释为完整斜浪六自由度模型已经完成。

### 4.7 阶段报告更新

必须更新一份阶段报告，内容至少包括：

1. 当前方法说明。
2. 参考数据来源。
3. 八个核心系数修正前后对照。
4. 误差来源和修正原因。
5. 诊断文件索引。
6. 测试命令和结果。
7. 当前模型适用范围和剩余边界。

## 5. 阶段完成判定

只有当 Ma 2005 Wigley III 八个核心系数全部通过固定 Gate，且公式链、诊断链、测试链、示例链和报告链均完整时，本阶段才算完成。

若八个系数仍有任意一个 `FAIL`，则本阶段状态仍为：线性高速 2.5D 核心水动力尚未闭环。此时后续工作应继续围绕剩余失败系数做公式级、站位级和分量级修正，不应转向更复杂船型或更高级非线性模型主线开发。
