# 下一阶段阶段目标及可验收条件

日期：2026-08-24  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
阶段名称：**线性高速 2.5D 规则迎浪纵向运动独立验证闭合（Gate 2）**

> 本文件是下一阶段唯一执行口径。本阶段通过前，不把不规则波、斜浪六自由度、非线性 2D+t、多体船或水翼扩展作为主线任务。

## 一、当前基础

1. Ma 2005 线性高速 2.5D 水动力 Gate 1 已通过，基准网格与加密网格均为 `10/10 PASS`，最大网格变化为 `1.1465%`。
2. Gate 2 当前为 `17/20 PASS`。未通过项为 Begovic 三航速独立试验的升沉幅值、纵摇幅值和已解析主峰频率。
3. 非零直接波浪激励、复数运动方程、三航速频率覆盖、频域--时域一致性、波幅线性、点加速度运动学和 Fridsma 线性适用区验证已经通过。
4. 当前关键缺口是：与滑行基流相容的二维入水压力、频率相关辐射/绕射及其向整船升沉--纵摇方程的物理一致装配。现有楔形入水候选尚未达到基准门槛，不能进入默认生产路径。
5. 最新连续线性增广候选完成 `160` 个耦合伪时间步，运动学残差降至 `0.350`，但分布压力归一化均方根误差仍为 `35.43%`，高于 `10%` 门槛，故二维压力先决门仍为 `FAIL`。
6. 最新二维相关回归为 `74 passed`；最新完整回归为 `493 passed`、`0 failed`，耗时 `836.42 s`。`1247` 条运行时警告仍来自既有验证统计的空切片。这些结果说明软件链稳定，但不等于物理验证通过。

## 二、阶段目标

**在保持 Gate 1 不退化的前提下，完成与稳态滑行基流一致的二维压力、频率相关辐射/绕射、直接波浪激励、恢复力和升沉--纵摇耦合模型；通过 Zhao--Faltinsen、Sun--Troesch、Begovic 与 Fridsma 的分层独立验证，使 Gate 2 从 `17/20 PASS` 达到 `20/20 PASS`，形成具有物理依据、误差可诊断、一键可复现且可作为后续不规则波计算基础的线性高速 2.5D 纵向运动预报基线。**

禁止使用试验响应反演、经验倍率、参考值缩放、逐点拟合、选择性删点或事后改变验收范围。

## 三、可验收条件

以下八项必须全部满足，缺一项即不通过。

| 编号 | 验收项 | 必须满足的条件 |
| --- | --- | --- |
| 1 | Gate 1 不退化 | Ma 2005 十行水动力基准及双网格收敛继续全部通过；单位、符号、坐标、矩阵顺序和相位约定可追溯。修改核心内核后必须重新运行 Gate 1。 |
| 2 | 二维压力先决门 | Zhao--Faltinsen 恒速楔形入水 `10 deg、20 deg、30 deg` 均通过：自由面归一化均方根误差 `<=5%`，压力曲线归一化均方根误差 `<=10%`，压力峰值位置和积分垂向力误差各 `<=5%`；最后两级空间、时间离散结果变化各 `<=5%`。 |
| 3 | 源级水动力闭合 | 完成 Sun--Troesch `5` 个频率、`8` 个升沉--纵摇水动力系数；各系数中位相对误差 `<=10%`、归一化均方根误差 `<=15%`，最后两级网格变化 `<=5%`，谐波拟合残差 `<=5%`，耦合项符号、趋势和非互易性与基准一致。 |
| 4 | 三航速运动验证 | 保留 Begovic `Fn_B=1.67、2.26、2.82` 的全部试验点；预先声明的线性适用区内，升沉和纵摇中位相对误差各 `<=15%`、归一化均方根误差各 `<=20%`，已解析主峰频率偏差各 `<=10%`，非近零响应相位中位循环误差 `<=15 deg`。适用区外数据保留并单列，不参与硬门槛。 |
| 5 | 独立加速度验证 | 使用冻结的 Fridsma 1969 数据；重心垂向加速度归一化均方根误差 `<=25%`；艏部加速度完整输出，并明确区分线性谐波加速度与非线性冲击峰值，不以线性结果冒充砰击预报。 |
| 6 | 数值与物理自洽 | 每个有效频点的复数方程相对残差 `<=1e-8`，无 `NaN/Inf`；至少 `3` 个代表频点的频时域幅值差 `<=5%`、相位差 `<=5 deg`；波幅加倍后的运动和加速度幅值比为 `2.00 +/- 5%`；点加速度解析值与程序值相对误差 `<=1e-8`。 |
| 7 | 数据与结果可追溯 | 冻结几何、质量惯性、航速、波浪、来源页码、数字化方法、不确定度和源文件 SHA-256；提供公式--代码--测试--数据追踪表、失败频点及误差原因。缺失输入标记“待补充”，不得编造。 |
| 8 | 一键复现与完整交付 | 一条固定命令可从空输出目录生成输入快照、水动力/激励矩阵、频域和时域响应、误差统计、二维图、三维船型与站位图、三维动态可视化、阶段报告和机器验收清单；完整 `python -m pytest -q` 无失败，最终明确输出 `Gate 1 = PASS`、`Gate 2 = 20/20 PASS`。 |

## 四、必要交付物

1. 三角度二维楔形入水基准、五频率八系数源级基准及网格/时间步收敛数据。
2. Begovic 三航速升沉、纵摇、相位和主峰对照，以及 Fridsma 重心/艏部垂向加速度对照。
3. 频域与时域原始数据、误差统计、失败工况、条件数和方程残差。
4. 冻结输入、来源清单、SHA-256、公式--代码--测试--数据追踪表。
5. 二维图、三维船型与站位图、三维动态可视化、阶段报告和机器验收清单。

## 五、完成判定与阶段边界

只有八项条件全部满足且机器验收输出 `20/20 PASS`，才能宣布本阶段完成。单个频点改善、单航速吻合、仅完成程序接口或仅获得低代数残差，均不构成通过。

本阶段只验收**小幅规则迎浪下的升沉、纵摇、相位和垂向加速度**。通过后，按总体目标依次进入：不规则波纵向统计响应、斜浪六自由度、强非线性 2D+t、多体船干扰和水翼控制。
