# 下一阶段目标与可验收条件：当前进展对齐版

日期：2026-08-08

## 1. 总体目标锚点

后续工作继续围绕《高速船型运动预报系统总体目标》展开：以高速滑行艇为核心，建立完整、可验证、可扩展、可追溯的 2.5D 运动预报模型及软件框架，并逐步扩展到排水船、半排水船、多体船、三体船和未来水翼船。

当前阶段的优先级不是继续扩展船型范围，而是把线性高速 2.5D 核心水动力模型做实。只有核心 2.5D 模型通过可追溯硬验证后，非线性 2D+t、多体船、三体船和水翼模块才有可靠基础。

## 2. 当前进展判断

项目已经完成第一轮可继续扩展、可测试、边界清楚的升级：

1. `planing_seakeeping` 包、命令行、配置读取、规则波、不规则波、频域响应、时域响应、六自由度统一输出、可视化和报告链路已经建立。
2. 示例滑行艇算例可运行，能够输出响应幅值算子、时域响应、加速度、汇总表和图像。
3. 文献和验证框架已经覆盖 Faltinsen、Ma--Duan--Song、Fridsma、Katayama、Delft 372、SL-7、ITTC 等路线。
4. 线性 2.5D 默认主线已经固定为 `matched_bie_station_sweep`，并生成分量级、站位级和面元级诊断表。
5. 最新 `validation_summary.csv` 汇总为 `64 PASS / 16 FAIL / 8 NOT_EVALUATED / 92 INFO`。

但核心硬验收尚未通过：

1. Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 仍全部为 `FAIL`。
2. 当前失败已不是笼统的“结果不合理”，而是压缩为三条明确链路：`A33/A53` 的时间压力与体势尺度链，`B33/A35/B35` 的固定控制面几何输运链，`A55/B55` 的纵摇矩固定控制面映射与端部项链。
3. 最新 `A55/B55` 面元审计显示：本地 `N5 ds`、`m5 ds` 和 `d(N5 ds)/dx` 构造本身闭合，但 `d(N5 ds)/dx` 不能直接等同或缩放为 `-m5 ds`，下一步应查固定控制面映射、站位面元对应、边界分配和端部项，而不是继续做简单符号或倍率修正。
4. 所有未通过八系数硬门槛的候选仍必须保持 `diagnostic-only`，不得进入默认生产路径。

## 3. 下一阶段目标

下一阶段目标为：

> 完成线性高速 2.5D 核心水动力模型的 Gate 1 硬验证闭环，使默认 `matched_bie_station_sweep` 路径下 Ma 2005 Wigley III 八个核心频域水动力系数全部通过；若仍不能全部通过，则必须把每个失败项封口到明确的公式、坐标、归一化、边界积分、历史卷积、固定控制面映射、端部项或参考数据缺口。

一句话概括：

> 把当前“可运行、可诊断”的 2.5D 主线推进到“可验证、可信赖”的核心模型，不靠经验拟合，不靠最终系数补丁。

## 4. 本阶段工作范围

1. 闭合 `A33/A53`：核清体势尺度、时间压力项、局部时间映射、内自由面势传递和 Ma 2005 无量纲方式。
2. 闭合 `B33/A35/B35`：推导并实现固定控制面下的几何输运项，明确 Eq.31 与 Eq.32 的差异来源及其边界项。
3. 闭合 `A55/B55`：比较 equal-panel、fixed-y、normalized-y、normalized-arclength 等固定控制面映射，并在同频复力层面检查 direct pressure-gradient、projection transport、Stokes body 和 end-contour 是否闭合。
4. 固定参考数据链：确认 Wigley III 八点参考值的图号、频率、坐标、单位、无量纲方式和数字化来源。
5. 保持工程链路可运行：核心修正不得破坏配置读取、示例运行、六自由度输出、规则波、不规则波、可视化和报告生成。

## 5. 暂不纳入本阶段

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船或三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验倍率、曲线拟合、最终系数修补或按参考值反推的方式制造通过。
