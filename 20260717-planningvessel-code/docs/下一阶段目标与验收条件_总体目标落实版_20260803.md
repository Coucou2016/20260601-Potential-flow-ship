# 下一阶段目标与可验收条件：总体目标落实版

日期：2026-08-03

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》。总体目标是建立从排水船型、半排水船型到高速滑行艇，并可扩展至多体船、三体船和水翼船的统一运动预报系统。

下一阶段不继续扩大功能面，而是优先把“高速单体船线性 2.5D 核心模型”做实。只有该核心模型具备文献方程依据、可追溯基准数据、稳定数值输出和明确误差诊断后，后续非线性 2D+t、多体船、三体船和水翼船扩展才有可信基础。

## 2. 阶段目标

完成高速单体船线性 2.5D matched boundary integral equation 核心求解器的硬验证闭环，使当前原型从“可运行、可诊断”推进到“可验证、可复现、可作为默认基础继续扩展”。

一句话目标：

> 以 Ma 2005 Wigley III 八个升沉/纵摇水动力系数为硬基准，打通线性 2.5D 水动力系数、规则波响应、不规则波时域响应和六自由度统一输出的可验证闭环。

## 3. 本阶段范围

1. 固定 `matched_bie_station_sweep` 为线性 2.5D 默认主路径。
2. 方程级检查并修正 Ma-Duan-Song 型 matched-BIE 求解链，包括内域边界积分、外域控制面、自由面历史项、前进速度压力项、端部项和整船 heave/pitch 装配。
3. 以 `A33/B33/A35/B35/A53/B53/A55/B55` 八个水动力系数作为第一硬验收对象。
4. 保持示例滑行艇配置可运行，输出不同航速下的规则波响应、不规则波时域响应、垂向加速度和六自由度时序结果。
5. 输出阶段报告，说明公式来源、代码位置、验证命令、通过项、失败项、误差来源和剩余缺口。

## 4. 本阶段不做的内容

1. 不把非线性 2D+t、双体船、三体船或水翼船模型作为本阶段硬通过条件。
2. 不使用经验缩放、曲线拟合或后处理修正替代方程级修正。
3. 不把 SL-7、C1 三体船或替代几何作为本阶段硬验证基准；它们只作为后续扩展验证对象。
4. 不将未通过硬验证的 `diagnostic-only` 候选模型接入默认路径。

## 5. 必须满足的条件

| 类别 | 必须条件 |
|---|---|
| 文献依据 | 默认模型中的每个实质修正必须能追溯到 Ma-Duan-Song、Faltinsen 或等价 2.5D 理论中的具体方程、符号或积分项。 |
| 基准数据 | Ma 2005 Wigley III 八系数参考数据必须固定、可追溯、可重复读取；若有数字化误差或频率配对歧义，必须单独标注。 |
| 默认路径 | 验证与示例运行必须使用同一条默认 2.5D 主路径，不能验证一套、示例一套。 |
| 输入配置 | 船型、质量惯性、航速、波浪、海流、风和数值参数必须通过配置文件读取，并具备单位和字段校验。 |
| 诊断输出 | 失败项必须能分解到压力项、输运项、端部项、自由面历史项、pitch 力矩链、投影链或参考数据缺口。 |
| 数值稳定 | 核心水动力矩阵、系数表、响应时序和统计结果不得出现 `NaN` 或 `Inf`。 |
| 结果复现 | 固定命令、固定配置和固定随机种子下，CSV、图像和报告可以重复生成。 |
| 回归安全 | 新增修正不能破坏配置读取、命令行接口、可视化、示例运行和现有测试集。 |

## 6. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 硬基准通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`；对角项误差不超过 15%，耦合项误差不超过 30%，或验证器给出等价通过判定。 |
| 默认路线一致 | 验证输出中的 `provider_route` 全部为 `matched_bie_station_sweep`。 |
| 方程证据完整 | 每项默认修正均在阶段报告中列出文献方程位置、代码位置和对应验证表。 |
| 失败闭环 | 若八系数尚未全部通过，所有失败项必须被压缩到明确的方程缺口、坐标映射缺口、边界积分缺口、端部项缺口或独立参考数据缺口；不得只写“误差较大”。 |
| 候选隔离 | 所有未通过硬验证的候选输出均标注 `candidate_default_gate_eligible=false`，并说明排除原因。 |
| 运动预报可运行 | `configs/example_planing.yml` 可运行，生成 `summary.csv`、`rao.csv`、各航速时序 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 所有时序 CSV 包含 `surge/sway/heave/roll/pitch/yaw` 六自由度列；迎浪场景重点验证 `heave`、`pitch` 和垂向加速度，其他自由度必须标注模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波输入谱、时域响应、均方根值和峰值统计可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 更新或生成阶段报告，包含目标、方法、命令、八系数对照、示例结果、失败项解释、候选排除、剩余风险和下一步建议。 |

## 8. 合格判定

理想合格：Ma 2005 Wigley III 八个水动力系数全部通过 Gate 1，示例运动预报和测试集全部通过，线性 2.5D 可作为后续非线性 2D+t、多体船和水翼船扩展的默认基础。

有限合格：八个系数尚未全部通过，但每个失败项均有明确、可追溯、当前资料无法直接消除的方程或数据缺口；所有候选修正均未违规进入默认路径。

不合格：依赖经验缩放、只改善局部曲线、无法复现固定命令、缺少分量诊断，或把替代几何、占位模型当作真实硬验证结果。
