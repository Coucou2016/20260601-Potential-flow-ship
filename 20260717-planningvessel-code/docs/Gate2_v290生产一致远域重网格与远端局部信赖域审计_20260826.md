# Gate 2 v290 生产一致远域重网格与远端局部信赖域审计

日期：2026-08-26  
状态：**20° 等密度远域候选首次达到 `K<=1e-3`，但远域相对变化和 Zhao 自由面门槛仍未通过；二维先决门保持 `FAIL`，Gate 2 保持 `17/20 PASS`。**

## 1. 审计目的

`v282` 的 `R=20,N=400` 候选达到 `K=0.000760788`。旧 `v283` 把远域扩大到 `R=30` 后，`K` 升至 `0.0166174`，且对同一几何执行生产零步重网格仍移动约 `2.03` 个局部面板。必须先区分检查点变换缺陷、面板密度变化和新增远场尾段未满足运动学条件三种来源，才能进行有效远域验收。

全部形状修正只使用 Iafrati 式（52）运动学残差和数值资格门。Zhao--Faltinsen、Iafrati 压力/自由面及积分力参考只在候选冻结后评分，不进入雅可比、步长或停止条件。

## 2. 实现修复

检查点重采样原先直接重建边界积分解，而生产伪时间推进还会依次执行几何约束、根部修剪、平滑、弧长重采样、根部重构和匹配面分辨率迁移。两条路径不一致，使远域变换态不是生产算法的固定点。

本轮完成以下修复：

1. 显式检查点重采样和远域延拓后，先调用生产 `_regrid_coupled_outer_nodes`，再重建势流解。
2. 输出本次生产维护位移，以及再次零步维护的剩余位移，直接审计幂等性。
3. 几何误差针对最终送入求解器的节点计算。
4. 节点数因根部重构发生变化时，先按归一化弧长对齐两条曲线，再计算位移，保留原配置能力。
5. 低模态信赖域新增 `far_local` 基函数：保留低阶全局模态，并将紧支撑模态限制在远端弧长区。

核心修改定向测试为 `27 passed, 0 failed`；覆盖全部二维自相似检查点、重网格、残差、信赖域及收敛分析的扩大定向回归为 `95 passed, 0 failed`。完整软件回归为 `576 passed, 0 failed, 1247 warnings`，耗时 `785.25 s`。警告仍来自既有验证统计空切片和 `pytest-asyncio` 配置弃用提示。

## 4. 幂等性与等密度要求

固定 `R=30,N=400` 会使外域长度扩大 50% 而面板数不变，首面板变粗并触发匹配面迁移，不是严格远域对照。采用近似等密度的 `R=30,N=600` 后：

- 首次生产维护位移为 `5.67e-5` 个面板；
- 再次零步维护位移为 `9.71e-9` 个面板；
- `v290` 再次零步维护位移为 `9.60e-8` 个面板，最大节点位移为 `4.92e-10`；
- `R=20` 与 `R=30` 的自由面势积分常数 `tau_star` 分别为 `4.25536392/4.25537226`，差约 `8.34e-6`。

因此生产路径一致性、节点密度和修正势积分常数已经闭合。剩余差异属于远场自由面形状求解，不再归因于检查点变换。

## 6. 结论与下一步

1. 远域检查点变换不幂等的实现缺陷已经修复，并有机器位移指标和回归测试证明。
2. 等密度远域对照必须随半径同比增加面板数；固定 `N` 的旧 `v283/v285` 不进入远域验收。
3. 远端局部精确残差信赖域能够在不扰动压力和积分力的前提下，将新增尾段从 `K=0.01658` 降至 `0.0008105`。
4. 20° 远域物理量已高度稳定，但 `K` 相对变化仍为 `6.535%`，Zhao 自由面仍为 `10.84%`，故20°和二维先决门均不得判为通过。
5. 下一顺序是冻结 `v290` 算法后完成20°时间步口径复核，再以同一算法和预先声明参数执行 `10/30 deg`；不得针对参考曲线单独调参。
