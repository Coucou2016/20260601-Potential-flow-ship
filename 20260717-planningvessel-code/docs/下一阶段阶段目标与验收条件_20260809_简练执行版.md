# 下一阶段阶段目标与验收条件：线性 2.5D 核心 Gate 1 闭环

日期：2026-08-09  
对应总体目标：《高速船型运动预报系统总体目标》

## 1. 当前进展判断

项目已经完成第一轮“可运行、可测试、可扩展、边界清楚”的基础建设，但还没有完成核心线性 2.5D 水动力模型的硬验证。

已完成的部分：

1. `planing_seakeeping` 包、命令行接口、配置读取、规则波、不规则波、频域响应、时域响应、六自由度统一输出、图表和报告链路已经形成。
2. 示例滑行艇算例可以运行，并生成 `summary.csv`、`rao.csv`、规则波/不规则波时域 CSV、图像和 `run_report.md`。
3. 验证体系已经接入 Ma 2005、Journee 1992、Faltinsen、Fridsma、Katayama、Delft 372、ITTC 等来源，具备可追溯诊断能力。
4. 当前 `numerical_sanity`、`physical_trend_sanity`、`section_bem_numerical_sanity` 已通过。
5. 完整自动测试最近一次结果为 `234 passed`，说明主程序、测试框架和示例链路保持可用。

尚未完成的核心问题：

1. Ma 2005 Wigley III 八个频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 当前仍为 `0/8 PASS`。
2. 固定验证命令当前仍有 `Hard failures: 16`，其中核心阻塞集中在 `matched_bie_station_sweep` 的力项装配链。
3. 最新审计确认存在 `fixed-control-surface boundary / endpoint allocation` 缺口，涉及 row-measure、端部项、endpoint-forward、纵摇 `m5` 输运和复数力相位闭合。
4. 因此当前系统只能称为“可运行、可诊断、可扩展的研究框架”，还不能称为“线性 2.5D 核心已验证通过”的运动预报系统。

## 2. 下一阶段唯一主目标

完成线性高速 2.5D 核心水动力模型的 Ma 2005 Wigley III Gate 1 验证闭环。

具体说，就是在不使用经验倍率、不按参考结果反推系数、不把诊断候选路线混入默认生产路径的前提下，修复或封口 `matched_bie_station_sweep` 中八个核心频域水动力系数的计算链，使 `A33/B33/A35/B35/A53/B53/A55/B55` 达到可验证、可解释、可复现的状态。

一句话目标：

> 把当前“能运行、能诊断”的线性 2.5D 主线，推进为“能硬验证、能解释误差、能支撑后续非线性 2D+t、多体船和水翼扩展”的核心模型。

## 3. 本阶段范围

本阶段纳入：

1. Ma 2005 Wigley III 八系数硬验证。
2. `matched_bie_station_sweep` 默认路径的公式级修复。
3. 时间压力、前进速度压力梯度、固定控制面输运、端部项、站位推进、纵摇力矩、复数相位和无量纲化链路审计。
4. Journee 1992 同频复数力、相位和力矩链作为辅助核对。
5. Katayama 定性趋势失败项的修复或合理重分类，避免阶段范围内遗留未解释硬失败。
6. 示例滑行艇规则波、不规则波、六自由度输出链保持可运行。
7. 测试、验证输出和阶段报告同步更新。

本阶段不纳入：

1. 不开发生产级强非线性 2D+t 自由面边界元模型。
2. 不开发生产级双体船、三体船共同边界积分模型。
3. 不开发生产级水翼、压浪板和控制器模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过对象。
5. 不用经验拟合、最终系数缩放或参考曲线反推制造通过结果。

## 4. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数必须由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| 八系数硬通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 公式来源 | Ma 2005 / Journee 1992 的频率、坐标、符号、单位、无量纲化、数字化来源和取舍理由必须写入阶段报告。 |
| 缺口封口 | 若八系数未全部通过，每个失败系数必须有明确缺口分类、审计表、关键数值、失败原因和下一步所需资料或推导条件。 |
| 候选隔离 | 未通过八系数硬门槛的候选路线必须保持 `candidate_default_gate_eligible=false`，不得进入默认结果。 |
| 固定控制面 | row-measure、端部项、endpoint-forward、纵摇 `m5` 输运和复数相位必须被统一规则解释；不能只让单个系数局部变好。 |
| 数值质量 | 验证输出、矩阵、响应幅值算子、时域响应和统计结果不得出现 `NaN`、`Inf`、空表或未解释异常值。 |
| 运动链保持 | `configs/example_planing.yml` 必须可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时域结果必须包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度必须标注模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波响应的均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 必须全部通过；若未完整运行，必须记录原因、已运行测试和补跑计划。 |
| 阶段报告 | 阶段报告必须包含代码改动、公式依据、验证命令、八系数对照、失败封口、候选排除、剩余风险和下一步建议。 |
