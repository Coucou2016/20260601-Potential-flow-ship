# Gate 2：12.4°至12.375°同步候选桥接审计

日期：2026-09-01  
上位目标：[下一阶段阶段目标及可验收条件](./下一阶段阶段目标及可验收条件.md)  
审计结论：**12.3875°和12.375°的320面板正式数值门，以及12.425°至12.375°连续桥接审计均`PASS`；12.25°及其三网格门仍未完成。**

## 1. 背景与问题

从12.4°向12.3875°同伦后，冻结候选映射可将正式端点积分误差降至`K=1.0023436e-3`附近，但后续局部和全局方向在最终偶极同步及规范重网格后出现下降预测漂移。这里的正式`K`始终采用Iafrati Eq. (52)对应的分片线性端点精确积分；没有换用中点指标、放宽`1e-3`门槛或读取物理参考参与求解。

诊断表明，旧雅可比在冻结远场形状偶极系数的候选上评价残差，而最终检查点还要按候选求得的偶极系数重新闭合并重网格。两者并非同一个非线性映射，因此候选阶段的下降不一定能完整保留到最终同步态。

## 2. 同步候选映射

`scripts/diagnose_self_similar_newton_krylov.py`新增可选的`--candidate-map-policy synchronize_candidate`。启用后：

1. 先按给定形状位移求解候选状态；
2. 使用候选求得的`dipole_coefficient`更新远场形状偶极系数；
3. 执行规范重网格和根部闭合；
4. 在该同步态上评价正式端点残差、条件数、根部失配和线搜索目标；
5. 用同一同步映射显式计算零位移基准`F(0)`，防止重网格或偶极更新形成隐藏零阶偏差。

默认`freeze_rebased_source`策略保持不变；检查点元数据明确记录候选映射、重网格和`F(0)`策略。正式误差、根部失配、条件数、曲率和信赖域门槛均未修改。

## 3. 数值推进结果

同步候选路径先后使用16和32模态根部余弦局部基，将最终同步后的正式`K`从`1.0018110e-3`降至`1.0001383e-3`。局部方向耗尽后，16模态全局离散余弦基提供了新的长波形状方向，得到最终候选合格点：

正式`K`的通过裕量只有约`0.00405%`。因此该结果只证明冻结320面板检查点满足当前数值门，不证明其已具备网格独立性，更不构成物理验证通过。

## 4. 连续性审计

机器审计重新加载12.425°、12.4125°、12.4°、12.3875°和12.375°五个正式检查点。五点数值门全部通过，四段角度步长均为0.0125°；相邻根厚度、根速度、偶极系数和根位置的最大相对变化均小于5%，条件数最大比值为`1.000162`，无跳支迹象。

审计器同时修正了角度差边界的二进制浮点误判：`0.012500000000001066`现在只在机器舍入容差内视为等于`0.0125`，而真实超限仍会失败。该修正不作用于正式`K`或物理误差门槛。

## 6. 软件回归与边界

目标测试为`29 passed`；完整Python 3.14回归为`689 passed, 0 failed, 1247 warnings, 11 subtests passed`。警告仍来自既有空切片统计路径，本轮未新增测试失败。

本轮把合格320面板前沿从12.4°推进到12.375°，并使候选雅可比与线搜索可以评价同步偶极闭合后的非线性映射。**这不构成12.25°桥接闭合，不构成320/640/1280面板独立性，也不构成10°、20°、30°独立物理验证通过。**

下一步从12.375°正式检查点继续按不大于0.25°、当前实际0.0125°的冻结路径推进12.3625°；每个新角度必须先通过正式`K`、根部失配、重载、参考隔离和连续性审计，方可继续向12.25°推进。
