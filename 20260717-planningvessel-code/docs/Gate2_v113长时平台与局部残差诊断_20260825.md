# Gate 2 v113 长时平台与局部残差诊断

日期：2026-08-25  
状态：**二维楔形入水先决门仍为 FAIL；Gate 2 仍为 17/20 PASS。**

## 1. 目的与证据边界

本轮只回答一个问题：20 度恒速楔形入水的 Iafrati 方程（52）运动学积分量为什么停留在 `K≈0.0043`，而没有达到冻结阈值 `K<=0.001`。所有试验均从未经外推的可信普通检查点延续，参考曲线只在求解结束后评分，不进入边界积分方程、停止条件或参数调整。

主理论来源为 Iafrati 2013：第 13 页给出浅水射流方程（43）--（46）及 `|S_lambda|<delta_lambda` 停止条件；第 14 页规定两个相邻浅水步组成一个边界积分面板；第 16 页以方程（52）`K=integral(S_nu^2 ds)` 衡量运动学收敛，并指出非零平台随网格加密下降。

## 2. 最新可信普通分支 v113

`v113` 从 `v112` 普通续算 `800` 步，全部接受；累计步数为 `2057`，累计伪时间为 `1.96976`。末态 `K=0.00431682`，仍为阈值的 `4.32` 倍。最近 `40` 个相位循环的包络只下降 `2.01%`，对数线性拟合 `R^2=0.0245`，不能证明继续迭代会趋近于零。

| 指标 | v113 结果 | 冻结门槛 | 判定 |
| --- | ---: | ---: | --- |
| 方程（52）`K` | 0.00431682 | `<=0.001` | FAIL |
| Zhao 自由面归一化均方根误差 | 11.20% | `<=5%` | FAIL |
| 压力曲线归一化均方根误差 | 2.25% | `<=10%` | PASS |
| 压力峰值误差 | 0.30% | `<=5%` | PASS |
| 压力峰位误差 | 0.85% | `<=5%` | PASS |

因此 `v113` 是当前最新可信普通研究基线，不是物理通过结果。

## 3. 方程（52）逐面板定位

逐面板严格重构 `K=sum(S_nu^2*Delta s)`，重构相对误差为零。结果显示残差不是均匀分布：

| 区域 | `K` 贡献 | 占总量 |
| --- | ---: | ---: |
| 根部前两面板 | 0.00233887 | 54.18% |
| 去除根部两面板和远端八面板后的中段 | 0.000972293 | 22.52% |
| 远端最后八面板 | 0.00100566 | 23.30% |

第一面板与第二面板的 `S_nu` 分别约为 `-0.3052` 和 `+0.2206`，呈相邻符号交替；最远八面板长度约为 `0.49--0.77`，单面板残差虽小，但弧长权重使其累计贡献不可忽略。中段贡献本身已经低于总门槛，说明后续修正应针对根部和远端，而不是整体经验缩放。

## 4. 四步周期的直接诊断

求解历史新增了预估/校正阶段的匹配面有效移位量、根部位移、触发码、时间步回退次数、射流点数、每侧射流面板数、总边界面板数和射流尖端状态。`v121` 的十二步探针覆盖三个完整周期：

1. 显式兼容性匹配面移位次数为 `0`，时间步回退次数为 `0`，但四步周期仍完整出现，故“浅水射流物理解失败后外移匹配面”被排除。
2. 原始射流点数按 `521/520/522/521` 循环；根部三次跳变均与总边界面板数 `688 -> 690` 的变化同位。
3. 条件数在约 `3.68e4` 和 `7.02e4` 两个平台间切换，说明旧的奇数浅水步末端单面板和边界矩阵维数变化确实造成代数条件数跳变。

Iafrati 第 14 页只允许两个浅水步组成一个边界积分面板。代码现用不超过一个 `delta_lambda` 的尖端闭合子步补齐奇数步，移除了非来源的单步面板。`v122` 中条件数摆幅约降低 `10%`，但 `K` 均值和振幅几乎不变；该修改是来源一致性修复，却不是残差平台的主修复。

## 5. 两个反事实试验

### 5.1 固定射流边界积分拓扑 v123

将浅水密集解连续重采样为固定每侧 `260` 个边界积分面板后，总边界面板始终为 `688`，条件数稳定在 `3.6766e4--3.6940e4`。然而根部仍发生三次同周期跳变，`K` 均值由 `0.00435786` 变为 `0.00435833`，振幅只降低约 `2.5%`。因此矩阵维数切换解释了条件数双平台，但不是 `K` 平台的充分原因。

### 5.2 强制根部相容 v125

在固定拓扑基础上，每个龙格--库塔阶段执行最多八次根部相容迭代。根部相对失配均值由 `1.991%` 降至 `0.0132%`，约降低 `150` 倍；但 `K` 均值只降低约 `0.33%`，振幅由 `2.043e-4` 增至 `5.454e-4`。因此根部标量连续性必须保留为物理一致性条件，但它也不是平台的单一主因。

## 6. 远场反证

`v113` 在半径 `20` 处的自由面高度约为 `0.03662`，而用当前偶极系数代入方程（51）的渐近高度约为 `0.00685`。仅投影最外端点会制造尾部折角，使 `K` 暴增至约 `0.412`；保留原域并直接拼接到半径 `30/40` 的未松弛渐近尾段同样产生约 `0.113/0.122` 的大残差。这些结果否决“硬改端点”或“未经伪时间松弛直接拼尾段”，但支持开展平滑域扩展和远端网格收敛研究。

## 7. 当前结论

1. `v113` 已接近固定网格平台，继续盲目长算不能代替空间离散修正。
2. 显式匹配面兼容性外移不是四步周期原因。
3. 射流拓扑切换是条件数跳变原因，但固定拓扑不能消除 `K` 周期。
4. 根部标量失配不是 `K` 平台主因。
5. 剩余误差集中在根部前两面板和远端八面板；下一主线应是双端自适应空间离散与远场域收敛，而不是经验调幅、参考拟合或继续外推。

## 8. 下一最小闭环

实现不读取参考结果的双端网格：根部按浅水厚度/首面板尺度加密，远端按曲率和 `S_nu^2 Delta s` 指示量加密，并保持中段连续增长率；随后冻结同一物理状态完成至少三档根部尺寸、三档远域半径和两档时间步比较。只有 `K<=0.001`、最后两级变化 `<=5%`，且自由面、压力、峰值、峰位和积分力同时满足阶段门槛，二维 20 度算例才可判为通过。
