# 线性高速 2.5D Gate 1 阶段闭合报告

日期：2026-08-16  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)

## 1. 阶段结论

**线性高速 2.5D 纵向水动力 Gate 1 已完成。**

在未改变 `matched_bie_station_sweep` 势流求解路线、未改变 `eq32_stokes_body_plus_end` 力和力矩装配路线、未采用经验缩放或参考值拟合的条件下，Ma 2005 Wigley III 固定参考集的 10 个水动力系数数据行在基准网格和加密网格上均全部通过。

原唯一失败项 `B55` 并非由缺失公式或比例因子造成，而是原 `8/4` 演示网格分辨率不足。采用预先锁定的论文离散量级基准网格 `30/20` 后，`B55=0.07067637649`；采用加密网格 `40/30` 后，`B55=0.07034910894`，参考值为 `0.0703`。两网格结果均通过，且变化为 `0.4652%`。

## 3. 诊断过程与候选排除

原 `8/4` 演示粗网格给出的 `B55=0.0483319113`，明显低于参考值 `0.0703`。在保持公式和装配路线不变后，`30/20` 与 `40/30` 两组网格均恢复到参考量级，说明失败原因是自由面与船体离散不足，而不是缺少经验比例。

据此排除对最终系数缩放、按参考值反推符号或比例、任意删除 Stokes/端部项以及单频后处理补偿。这些候选既无必要，也会破坏模型对其他频率、船型和运动方程的可扩展性。既有 `A33/A53` 四个理论复现点及 `14/14` 阶段验收保持通过；Ma 曲线仍被明确归类为求解器复现基准，而不是独立试验真值。

## 4. 已冻结接口

已冻结升沉--纵摇顺序为 `(heave, pitch)` 的频率相关 `2 x 2` 水动力矩阵接口：

\[
\mathbf{A}_{hp}=
\begin{bmatrix}
A_{33} & A_{35}\\
A_{53} & A_{55}
\end{bmatrix},\qquad
\mathbf{B}_{hp}=
\begin{bmatrix}
B_{33} & B_{35}\\
B_{53} & B_{55}
\end{bmatrix}.
\]

接口同时固定了单位、六自由度索引 `(2,4)`、坐标与正方向、简谐相位约定和复力重构关系。后续运动方程可直接读取，不允许手工转置、换号或重新缩放。

## 5. 可复现交付

固定复现命令：

```powershell
python -m scripts.run_ma2005_gate1_acceptance --out outputs\gate1_linear_2p5d_acceptance
```

主要产物位于 `outputs/gate1_linear_2p5d_acceptance`，包括十行参考对照、网格收敛、公式追踪、`2 x 2` 矩阵、机器验收清单、运行清单和自动报告。参考数据文件以固定 SHA-256 校验，参考值字段在进入求解器前被剥离，防止计算路径读取答案。

## 6. 结论边界

本阶段证明的是 Ma 2005 Wigley III 线性 matched-BIE 水动力系数的实现复现、公式自洽和网格一致性。它尚不证明规则波整船运动、相位、垂向加速度、不规则波统计、非线性 2D+t、多体船或水翼模型已经通过独立验证。

因此，紧接本阶段的工作必须从“水动力系数正确”推进到“运动响应可独立对照”，不能直接跳到完整六自由度或非线性生产声明。
