# 旧速度重求候选与变化剖面局部谱核查

日期：2026-09-24。总体阶段状态：未通过。本文接续《变化剖面旧法向速度一致性诊断》。

## 本轮问题与结论

上一轮发现，迁移速度和辅助边界值问题求得的速度存在明显差异。但“存在差异”不能证明“替换后就正确”。本轮显式试验了替换路线，结论是：**单独重求旧速度不能修复后半船异常增长，不接入正式内核。**

另对五个实际剖面建立局部势到法向速度的线性映射，冻结外域历史。其隐式时间推进谱半径均为1附近，没有检测到这五个冻结局部问题的指数放大模态。此结果不证明变化剖面、状态迁移、历史反馈组成的完整系统稳定，也不排除非正规算子的瞬态放大。

## 候选如何隔离变量

命令新增显式选项 `--old-velocity-policy refreshed_frozen_geometry_unvalidated`，默认仍为 `transferred`。未知选项拒绝运行。

候选仅将梯形时间推进使用的旧法向速度替换为辅助旧时刻边界积分解。迁移后的势和波面高度不变；新暴露位置仍使用原先明确标记为未验证的有限距离线性外推。实际控制面历史不被辅助解覆盖，仍由新时刻完整解更新。船体几何、入射波、网格、压力公式及积分保持一致。求解不读取试验响应。

原文A1第3.2节式(19)至(22)采用交错时间推进；本候选为同位梯形隐式方法，不称为该论文算法的逐项复现。辅助旧时刻冻结的是新几何，也不是物理旧剖面的真实解。

## 冻结剖面局部谱

在每个剖面构造矩阵 `K`（保持船体速度和外域历史不变时，将自由面势映射为法向速度的离散算子）。通过求解原边界积分矩阵的多个右端获得，不使用拟合。原方程重构残差不超过1.64×10⁻¹⁵，随机复数势的右端重构误差为0。

特征值最大虚部小于2×10⁻¹⁴。在冻结问题中，正实特征值对应振荡而非指数增长，梯形法对这些振荡的放大模为1。靠近1.125米位置的小面元使最高频率明显增大：时间上不放大并不意味着相位精度足够，也不意味着经过迁移和外推后仍稳定。

只检查了五个剖面，不代表全部剖面；仅检查冻结历史，不代表完整记忆系统；特征值也不能单独刻画非正规算子的瞬态放大。不得以此宣称边界积分求解器已经物理正确。

## 下一步的具体方向

停止将“重求旧速度”作为单独修复方案，也不继续只靠细化时间步或更换积分格式期待消除全部误差。下一步应构造带实际状态迁移和控制面历史反馈的组合推进检查，首先区分：

1. 新暴露点势与波面高度的外推是否引入持续增长；
2. 接触点附近小面元和插值是否导致瞬态放大；
3. 与外域卷积历史的反馈是否放大上述扰动。

必须保留相同输入和所有失败候选，以原方程残差、离散收敛和独立物理参考共同验证，不能删掉艉部贡献或降低门槛来宣布成功。独立复数绕射与力矩验证、全频段三档离散、三速度整船复验仍未完成。
