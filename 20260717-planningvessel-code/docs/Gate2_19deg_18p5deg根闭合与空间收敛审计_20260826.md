# Gate 2：19.0°与18.5°根闭合及空间收敛审计

日期：2026-08-26  
结论状态：**19.0°和18.5°空间数值收敛通过；均无冻结物理参考；二维先决门保持 FAIL**

## 1. 审计目的

本审计承接19.5°参考隔离同伦源，检验低斜升角推进中的两个独立问题：主体流与薄射流接口的根状态是否一致，以及线性边界元端点运动学积分能否随空间网格稳定下降。所有候选只使用方程残差、根缺陷、条件数、位移和曲率，不读取参考自由面、压力或载荷数据。

## 2. 主体流--射流根闭合约束

定义有符号根缺陷

$$
d_r=\frac{S_{\lambda,\mathrm{measured}}-S_{\lambda,\mathrm{interface}}}
{|S_{\lambda,\mathrm{interface}}|}.
$$

旧的 `preserve` 约束在线性化内要求 $\nabla d_r^\mathsf T\Delta a=0$，只能保持既有缺陷。新增的 `close` 模式在阻尼 Gauss--Newton 的KKT系统中要求

$$
\nabla d_r^\mathsf T\Delta a=-d_r.
$$

信赖域缩放后，该关系不再被当作精确非线性等式；每个候选仍须完整重建边界积分，并用实际根失配裁决。它是主体流--射流接口方程的一致性条件，不是参考数据惩罚项。

19.0°的64模态根闭合候选把有符号缺陷从 `-2.0358e-3` 降至 `8.844e-6`，条件数和曲率同时改善。18.5°采用32模态根闭合方向并复用至饱和，实际根失配从 `1.978e-3` 降至 `1.696e-5`。

## 3. 19.0°结果

## 5. 证据边界与下一步

19.0°和18.5°均满足数值 `K<=1e-3`、根失配和三层空间稳定要求，可作为后续0.5°同伦的数值源。两者没有冻结的权威自由面、压力和载荷参考，因此 `physical_validation_status` 仍为 `FAIL`，不能代替10°、20°、30°正式验收，也不改变 Gate 2 的 `17/20 PASS`。
