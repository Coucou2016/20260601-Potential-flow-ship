# 变化剖面自由面迁移核查

## 结论与阶段边界

**阶段仍未完成。** 在已经通过固定剖面平滑激励时间收敛检查之后，本轮检查变化剖面的自由面状态迁移，确认存在必须显式处理的新露出区域。完成了真实求解状态重放、分类迁移接口及固定横向节点候选网格，但没有把新露出区域的缺失状态伪装成物理已知量，也没有替换生产路线。

## 一、真实算例重放

输入为此前 Kang 321 站、三倍船宽控制半径、128 自由面面元的三个频率算例，数据目录为 `outputs/kang_boundary_dense_quarter_dt_r3_20260924`。使用已保存的各站自由面推进后势和波高，按原函数重采样到下一站网格，与实际保存的下一站推进前状态比较。势与波高的最大相对重放误差均为 0，说明检查针对的是实际执行路径，不是另造的示意过程。

|---|---:|---:|---:|---:|---:|

新露出点是指下一站自由面采样点位于上一站船体水线以内。它们不属于上一站已求解的自由面，不能直接解释为普通插值。点访问次数占约 0.425%，但涉及约 27.2% 的迁移步骤，且位于水线附近；不能由占比小推断载荷影响小。

另有每频率 233 次迁移涉及旧自由面物理范围内、但超出旧面元中心采样覆盖的边缘区域。它与“上一站实体船体占据、下一站新露出”的区域不同，必须分开处理。

原 `resample_free_surface_state` 使用 `numpy.interp`，在端点以外通常沿用端值，并依据中心间隙启发式决定是否两侧分别插值。对于新露出点，这属于未独立验证的延拓，不是已有自由面状态的精确传递。本次保存其原始结果供比较，没有据此断言这些点已经造成多少整船误差。

## 二、显式分类迁移接口

新增 `free_surface_transfer.py`，仅供后续隐式变化剖面候选使用：

1. 旧自由面内且在采样覆盖中的点，按左右两侧分别插值，不跨船体间隙混合数据。
2. 仍属于旧自由面、但在面元中心覆盖之外的边缘带，使用明确标记的一侧线性外推。
3. 新露出区域必须由调用者提供状态及来源描述；缺失时拒绝迁移，不默认复制端点、置零或跨船体插值。
4. 控制域外点、非法网格、非有限数据和缺失来源均拒绝处理。

返回结果包含边缘外推和新露出区域掩码。该接口传递的是给定状态，不负责发明接触线条件；给定来源标签本身也不构成物理验证。

## 三、固定横向节点候选网格

重新核对用户提供 A1 文献第 3.3 节：其描述沿纵向固定的横向网格线及水线交点调整。当前单区网格会随水线移动全部自由面节点，现有双区辅助函数在小分区退化时也会重新铺均匀网格，不能直接视为严格固定节点实现。

新增 `anchored_free_surface.py`，先定义从中心线到最大半宽、再到控制面的固定节点，剔除当前水线以内节点，只在水线处插入裁切端点。外侧节点不随船体半宽改变；自由面面元数量允许变化，无退化后自动改成均匀网格的回退。

几何测试确认：左右对称、覆盖总长度正确、节点不落入船体、最大半宽处无零长面元、外侧节点保持不变。水线与固定节点近乎重合而生成浮点尺度微小面元时直接报错，不静默移动型线或合并面元。后续仍需明确小裁切面元的数值处理策略。

**该构造器没有接入当前整船求解器。** 自由面面元数可变意味着相关状态、方程维数和输出存储必须同步支持；现有固定尺寸数组不能原样复用。
