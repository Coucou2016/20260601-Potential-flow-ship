## 顺序与限制

主线继续关闭既有单体规则波实验失败；飞机支线先做真实浮筒的规定姿态接触与入水，再做自由着水，最后做加速起飞。双/三体支线先共同剖面流场，再整船；水翼先载荷验证，再控制。不能一次增加多个未经验证载荷并靠整机动画判断对错。

公开报告确实能补到真实几何，但**真实几何、整机参数、气动推进数据和匹配试验是不同数据集，不能保证全部公开可得**。原始NACA报告的试验主题是浮筒气动阻力，不可把它说成浮筒着水载荷或整机起降试验。
