## 阶段目标

**在保持 Gate 1 不退化的前提下，定位并闭合生产用线性高速 2.5D/线性化 2D+t 未修正基线的纵向载荷幅值、作用中心及升沉--纵摇耦合链；先使内核通过 Sun 2007 `NUM` 五频率八系数数值复现门，再以冻结且可追溯的 Troesch、Begovic 和 Fridsma 试验数据完成实验对照及三个航速下升沉、纵摇、相位和重心/艏部垂向加速度独立验证；全过程不使用试验响应反演、经验倍率、逐点拟合或选择性删点，使 Gate 2 从 `17/20 PASS` 达到 `20/20 PASS`，形成可诊断、可复现、可继续扩展到不规则波的纵向运动预报基线。**

## 硬验收条件

1. Sun 2007 `NUM` `5` 频率、`8` 系数数值复现全部通过：各系数中位相对误差 `<=10%`、归一化均方根误差 `<=15%`，趋势和非互易性正确；机器字段明确为 `same_model_NUM_reproduction_not_independent_EFD`。
2. 强迫运动最后两级八系数变化均 `<=5%`，谐波残差 `<=5%`；响应残差 `<=1e-8`，无 `NaN/Inf`。
3. 不使用响应反演、经验倍率、参考缩放、逐点拟合或选择性删点；`response_calibration_used=false`。
4. Begovic 覆盖 `Fn_B=1.67、2.26、2.82`，每航速保留全部试验点并生成不少于 `20` 个频点的致密响应。
5. 升沉/纵摇中位相对误差 `<=15%`、归一化均方根误差 `<=20%`，主峰频率偏差 `<=10%`，相位中位误差 `<=15 deg`。
6. Fridsma 重心垂向加速度归一化均方根误差 `<=25%`，艏部加速度完整输出并单列适用边界。
7. 至少 `3` 个频点的频域--时域幅值差 `<=5%`、相位差 `<=5 deg`；线性缩放与点加速度运动学检查通过。
8. 所有基准输入、数字化过程、不确定度和 SHA-256 可追溯，缺失值不编造，适用区不事后调整。
9. 一键生成全部数据、误差表、二维图、三维船型/站位和动态可视化；Gate 1、完整测试不退化，机器验收为 `Gate 2 = 20/20 PASS`。

## 完成判定

九项条件必须同时满足，并由机器验收明确记录 `Sun_NUM_reproduction = PASS`、`Gate 1 = PASS`、`Gate 2 = 20/20 PASS`，方可进入不规则波纵向统计响应验证。任何仅改善单一响应曲线、但不能同时解释源级系数和独立试验的修改，均不计为阶段完成。

## 边界

本阶段只验收小幅规则迎浪纵向响应。不规则波、斜浪完整六自由度、强非线性大幅运动、多体船和水翼模型待本阶段通过后依次开展。
