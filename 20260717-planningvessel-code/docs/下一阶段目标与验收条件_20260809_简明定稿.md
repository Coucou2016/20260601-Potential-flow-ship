# 下一阶段目标与验收条件：线性 2.5D 核心可信化

日期：2026-08-09

## 1. 总体目标对齐

本阶段服务于《高速船型运动预报系统总体目标》：以高速滑行艇为核心，建立可扩展到排水船型、半排水船型、单体船、多体船、三体船和未来水翼船的统一运动预报系统，并形成理论、程序、算例、实验验证和报告输出的闭环。

当前阶段的合理主攻方向不是继续扩大功能面，而是先把线性高速 2.5D 核心水动力链做实。只有这条链经过公开基准验证，后续六自由度运动响应、不规则波统计、非线性 2D+t、多体干扰和水翼扩展才有可信基础。

## 3. 下一阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 可信化与缺口封口，使 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 八个核心频域水动力系数上达到以下两种结果之一：

1. **硬通过**：`A33/B33/A35/B35/A53/B53/A55/B55` 全部 `PASS`，且每项修正均可追溯到明确公式、坐标约定、边界条件、自由面 marching、几何输运、压力恢复、力矩装配、端部项或参考数据处理。
2. **封口通过**：若八系数仍不能全部 `PASS`，必须把每个失败项定位到明确的理论缺口、坐标缺口、归一化缺口、固定控制面缺口、端部项缺口、频率传递缺口或参考数据缺口，并列出下一步必须补充的资料或推导条件。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、失败源可封口”的核心模型阶段。

## 4. 本阶段工作范围

纳入本阶段：

1. 固定 Ma 2005 Wigley III / Journee 1992 参考数据链，包括频率、单位、坐标、无量纲方式、数字化来源和采用理由。
2. 闭合或封口 `A33/A53` 时间压力链，包括 body potential 尺度、局部时间映射、自由面 marching、压力恢复和归一化。
3. 闭合或封口 `B33/B35/B53/B55` 阻尼链，包括 pressure-gradient、end-term、同频 A/B 配对、频率传递和固定控制面端部处理。
4. 闭合或封口 `A35/A55` 纵摇矩链，包括 `N5/m5`、力臂原点、压力梯度矩、Stokes body moment、end-contour moment 和参考轴约定。
5. 保持示例滑行艇运动链路可运行，包括六自由度时序、规则波/不规则波响应、响应幅值算子、垂向加速度和图表输出。
6. 更新阶段报告，使所有结论均有代码路径、验证命令、CSV 输出和文献依据支撑。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元。
2. 不开发双体船、三体船共同边界积分生产模型。
3. 不开发水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验补偿、最终系数修正、曲线拟合或按参考值反推的方式制造通过。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数均由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| 硬通过条件 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 封口条件 | 若未硬通过，每个失败系数必须对应到明确缺口，并在 blocker summary 中写明 `next_required_evidence`。 |
| 理论可追溯 | 所有进入默认路径的修正必须对应到具体公式、边界条件、坐标约定、自由面 marching、压力恢复、几何输运、力矩装配或端部项。 |
| 参考数据闭环 | Ma 2005 / Journee 1992 的参考值、频率、单位、坐标、无量纲方式、数字化来源和取舍理由写入阶段报告。 |
| 频率传递审计 | `A33/A53` 时间压力链、`B33/B35/B53/B55` 阻尼链、`A35/A55` 纵摇矩链均有独立审计表和结论。 |
| 候选隔离 | 未通过八系数硬门槛的候选必须保持 `candidate_default_gate_eligible=false`，不得污染默认结果。 |
| 数值质量 | 验证输出、矩阵、频域响应、时域响应和统计结果无 `NaN/Inf`、空表或不可解释异常值。 |
| 示例链路 | `configs/example_planing.yml` 可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时序结果包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其他自由度明确模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过；若未运行完整回归，必须记录已运行 targeted tests、未跑原因和补跑计划。 |
| 阶段报告 | 更新 `docs/线性2p5D_Gate1硬验证通过_阶段报告.md`，包含公式依据、代码改动、验证命令、八系数对照、候选排除、剩余风险和下一步。 |
