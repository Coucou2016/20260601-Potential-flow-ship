# 修正法向后高波数截断核查

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。**阶段未通过。**

## 目的与配置

上轮验证了固定波数上限25每米时的求积点数精度，但没有验证被截断的尾部。本轮使用同一Kang参数化船型、无量纲遭遇频率3、321站位、64船体面元、96控制面面元、0.9米控制半径和完整历史，将上限依次设为25、50、100每米，三档统一512个谱积分点。其他计算条件保持不变，三个运行均在新目录中完成，求解不读取实验响应。

谱积分在波数平方根坐标中等距，所以固定512点扩大区间仍会增大步长。本轮另用原波数坐标中的自适应积分检查上限100时的36个历史核条目，以免把求积不足混入截断效应。该抽查不是所有矩阵元素的严格误差界。

## 独立求积检查

| 谱积分点数 | 势核最大绝对误差 | 法向导数核最大绝对误差 |
|---:|---:|---:|
| 64 | 0.011787 | 2.843010 |
| 128 | 0.002707 | 0.026964 |
| 256 | 0.000659 | 0.004736 |
| 512 | 0.000163 | 0.001104 |

两个核具有不同量纲，表中只能分别比较加密趋势，不作跨列大小比较。64点在扩大波数区间后对部分条目明显不足；不能只增大截断而保持很粗的积分，再把计算差异归为物理尾部贡献。

独立有限区间积分也显示尾部确有作用。例如场点0、源点95、滞后512步的法向导数核，从上限25时约-1.973750变为上限100时约-1.701436，绝对差约0.272314。它属于近自由面跨控制面的核条目，不是整船力。必须在实际历史卷积及场解后判断其载荷影响。

## 实际载荷结果

| 波数上限（每米） | 无量纲总升沉激励幅值 |
|---:|---:|
| 25 | 7.703070847 |
| 50 | 7.705065134 |
| 100 | 7.705403329 |

| 截断变化 | 绕射升沉复数变化 | 绕射纵摇复数变化 | 总升沉复数变化 | 总纵摇复数变化 |
|---|---:|---:|---:|---:|
| 25→50 | 0.09937% | 0.13611% | 0.02653% | 0.02637% |
| 50→100 | 0.01977% | 0.02679% | 0.005277% | 0.005191% |

复数变化以较大截断结果的模为分母，直接比较复数而不是幅值差；机器输出同时保留绝对差。纵摇载荷参考点为几何船中。全部场解的最大方程相对残差小于9e-16，但小代数残差不代表独立物理验收通过。

## 判断及下一步

在本单频工况和所检查范围内，高波数截断增加后的载荷变化小，不能解释当前主要参考差异。不能据此宣布无限波数尾部已严格收敛，更不能外推到所有频率、所有船型或全频段八系数。

控制面扩大、谱求积加密与波数上限提高这三项诊断均未改变主要偏差，下一步应优先核查自由面与船体接触处的状态迁移、入射/绕射自由面条件及独立复数参考。当前有界迁移仍是未验证的数值闭合条件，不能仅因它让计算稳定而当作正确物理条件。不得靠试验响应倍率消除剩余差异。
