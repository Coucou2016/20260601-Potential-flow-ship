# 下一阶段阶段目标与验收条件

日期：2026-08-09  
对应总体目标：《高速船型运动预报系统总体目标》

## 1. 当前进展判断

当前项目已经完成第一轮“可继续扩展、可测试、边界清楚”的基础升级，但尚未完成核心 2.5D 模型的硬验证。

已完成内容如下：

1. 已建立 `planing_seakeeping` Python 包、命令行接口、配置读取、规则波与不规则波输入、频域与时域求解、六自由度统一输出、图表和报告输出链路。
2. 示例滑行艇运动预报链可以运行，能够输出 `summary.csv`、`rao.csv`、规则波和不规则波时域结果、图像和 `run_report.md`。
3. 六自由度输出格式已经统一，迎浪工况下重点求解升沉、纵摇和垂向加速度，横荡、横摇、艏摇等自由度按当前模型假设标注为对称或占位输出。
4. 已将 Ma 2005、Journee 1992、Faltinsen、Fridsma、Katayama、Delft 372、ITTC 等资料纳入理论和验证体系。
5. 默认线性 2.5D 路径已固定为 `matched_bie_station_sweep`，并已建立大量公式链、站位链、压力链、端部项、归一化和候选路线审计。
6. 当前固定验证快照为 `64 PASS / 16 FAIL / 8 NOT_EVALUATED / 112 INFO`。
7. 最近完整自动化回归测试记录为 `226 passed`，说明现有代码整体可运行，新增诊断没有破坏主要测试链。

尚未完成内容如下：

1. Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 当前仍为 `0/8 PASS`。
2. 当前八个系数均由 `matched_bie_station_sweep` 生成，但误差仍显著，`gate_error_ratio` 约在 `5.07` 到 `164.38` 之间。
3. `body_potential_frequency_entry` 审计显示：八个系数的体势跟随运动学边界条件，但 `A33/A53/B35/B53/B55` 仍缺少足够的水动力频率过滤效应。
4. `a1_frequency_ladder` 审计显示：当前 Gate 1 八个稀疏图线点与 A1 原文给出的频率序列 `0/8` 匹配，而 Journee 表格数据与该频率序列 `16/16` 匹配；后续必须明确参考数据政策，不能含糊替换硬门槛。
5. `validate --benchmark all` 当前能够刷新输出，但运行耗时和退出行为仍需单独优化，不能作为已完全健康的流水线。

阶段判断：当前系统已经是可运行的研究框架，但还不能宣称核心线性 2.5D 水动力模型已经通过验证。下一阶段应优先把核心 2.5D 验证做实，再进入非线性、多体和水翼扩展。

## 2. 下一阶段目标

完成线性高速 2.5D 核心水动力模型的 Gate 1 硬验证闭环。

具体目标是：在不进行经验拟合、不按参考结果反推系数、不污染默认生产路径的前提下，修复或封口 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 算例中的八个核心频域水动力系数计算链，使 `A33/B33/A35/B35/A53/B53/A55/B55` 达到可验证、可解释、可复现的状态。

优先完成标准是八个系数全部通过 Gate 1。若阶段内仍无法全部通过，则必须把每一个失败系数封口到明确的理论、数据、几何、频率、坐标、归一化、自由面、压力恢复、端部项或力矩装配缺口，形成可继续推进的证据链，而不是留下笼统误差。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进为“可验证、可解释、可作为后续非线性和多船型扩展基础”的核心模型。

## 3. 本阶段范围

本阶段纳入：

1. Ma 2005 Wigley III / Journee 1992 参考数据链闭合。
2. `matched_bie_station_sweep` 默认求解链修复。
3. `A33/A53` 时间压力和体势频率过滤链定位与修复。
4. `B33/B35/B53/B55` 前进速度压力梯度、几何输运、端部项和阻尼链定位与修复。
5. `A35/A55` 纵摇力矩、力臂、坐标原点、端部力矩和归一化链定位与修复。
6. 示例滑行艇运动预报链保持可运行。
7. 自动化测试、验证输出和阶段报告同步更新。

本阶段不纳入：

1. 不开发生产级强非线性 2D+t 自由面边界元模型。
2. 不开发双体船、三体船共同边界积分生产模型。
3. 不开发水翼、压浪板和控制器生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过对象。
5. 不采用经验倍率、最终系数拟合或按参考曲线反推的方式制造通过结果。

## 4. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数必须由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| Gate 1 硬通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 失败封口 | 若未全部 `PASS`，每个失败系数必须对应一个明确缺口类别，并给出审计表、证据文件和下一步所需资料或推导条件。 |
| 参考数据闭环 | Ma 2005 / Journee 1992 的频率、单位、坐标、符号、无量纲化、数字化来源和取舍理由必须写入阶段报告。 |
| 候选隔离 | 所有未通过八系数硬门槛的候选路线必须保持 `candidate_default_gate_eligible=false`，不得进入默认结果。 |
| 公式链审计 | 时间压力链、前进速度压力梯度链、固定控制面几何输运链、端部项链和纵摇力矩链均应有独立审计输出。 |
| 数值质量 | 验证输出、矩阵、响应幅值算子、时域响应和统计结果不得出现 `NaN`、`Inf`、空表或无法解释异常值。 |
| 示例链路 | `configs/example_planing.yml` 可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时序结果必须包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度必须明确模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波响应的均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过；若未完整跑通，必须记录未跑原因、已跑测试和补跑计划。 |
| 验证命令 | 固定验收命令必须可复现运行，输出路径、文件名和关键字段保持稳定。 |
| 阶段报告 | 更新阶段报告，包含公式依据、代码改动、验证命令、八系数对照、失败封口、候选排除、残余风险和下一步建议。 |
