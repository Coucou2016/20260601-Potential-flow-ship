## 本轮实质进展

从加拿大国家图书馆公开地址取得Wei Qiu的2001年博士论文《A Panel-Free Method for Time-Domain Analysis of Floating Bodies in Waves》，完成文件结构、标题页、相关正文及升沉幅相图核查。全文102页，已归档并计算SHA-256，而非只保留搜索摘要。

论文确实提供Wigley船型的升沉和纵摇激励幅相，但正文第4.2.2节（PDF第74页）明确限定零航速；结论（PDF第83页）也将前进速度验证列为后续工作。图4.24与图4.25（PDF第80页、印刷页64）视觉核查确认弗劳德数为0。**这份资料不能替代本阶段前进速度激励参考。**

## Qiu资料的后续用途与限制

该文可支持将来的零速独立边界元模块参考整理，但几何、相位符号、相位原点、力矩原点及幅相配对数字化仍须完成。PDF第75页给出波数乘船长的横坐标和载荷归一化，公式需继续视觉核查，不能只依赖识别文本。纵摇两图目前仅确认文本索引，未完成图像审核。

不得通过给2.5D推进映射输入任意很小速度来“近似通过”零速参考；纵向位置到局部时间的映射含速度分母，零速与当前有速模型不是可静默替代的同一验收工况。也不得把图中其他数值方法的点线改称实验点。
