# 下一阶段目标与可验收条件：线性 2.5D Gate 1 闭环执行版

日期：2026-08-08

## 1. 总体目标锚点

后续所有工作继续围绕《高速船型运动预报系统总体目标》展开：以高速滑行艇为核心，建立完整、可验证、可扩展的 2.5D 运动预报模型及软件框架，并逐步覆盖排水船、半排水船、滑行艇、单体船、多体船、三体船和未来水翼船。

当前阶段的优先级不是继续扩大船型范围，而是先把线性高速 2.5D 核心水动力模型做实。只有核心 2.5D 模型通过可追溯验证，后续非线性 2D+t、多体船、三体船和水翼模块才有可靠基础。

## 3. 下一阶段目标

下一阶段目标：

> 完成线性高速 2.5D 核心水动力模型的 Gate 1 验证闭环，使默认 `matched_bie_station_sweep` 路径在 Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 上全部通过；若因参考资料缺口暂时无法全部通过，则必须把每个失败项封口到明确的公式、坐标、归一化、固定控制面、端部项、历史卷积或参考数据缺口。

一句话概括：

> 把当前“可运行、可诊断”的 2.5D 主线推进到“可验证、可信赖”的核心模型；不靠经验拟合，不靠最终系数补丁。

## 4. 本阶段工作范围

纳入本阶段：

1. 闭合 `A33/A53` 的时间压力、体势尺度、局部时间映射和无量纲化链路。
2. 闭合 `B33/A35/B35` 的固定控制面几何输运链路，并补齐或数字化同频 `A/B` 参考配对。
3. 闭合 `A55/B55` 的纵摇矩、固定控制面边界项、端部项和全局力矩参考点装配。
4. 固定 Ma 2005 Wigley III 参考数据来源、频率、坐标、单位和无量纲化方式。
5. 保持示例滑行艇运动预报链路、六自由度输出、不规则波响应和可视化不退化。

暂不纳入本阶段：

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船、三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不使用经验倍率、曲线拟合、最终系数修补或按参考值反推的方式制造通过。

## 5. 可验收条件

硬通过出口必须同时满足：

| 类别 | 验收条件 |
|---|---|
| 默认路径 | `ma2005_wigley_iii_coefficients_comparison.csv` 中八个核心系数均使用 `provider_route == matched_bie_station_sweep`。 |
| 八系数硬门槛 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_ratio <= 1.0`。 |
| 公式来源 | 进入默认路径的每一项修正均可追溯到 Ma--Duan--Song、Faltinsen 或已登记文献中的方程、边界条件、坐标定义、归一化或力矩定义。 |
| 候选纪律 | 未通过八系数硬门槛的候选全部保持 `diagnostic-only`，并写明排除原因。 |
| 三条链路 | `A33/A53`、`B33/A35/B35`、`A55/B55` 均有独立审计表，说明修正结果、剩余误差和是否进入默认路径。 |
| 参考数据 | Wigley III 八点参考值的来源、频率、坐标、单位、数字化方式和无量纲化方式写入阶段报告。 |
| 数值质量 | 验证输出和示例输出无 `NaN`、`Inf`、空表或不可解释异常值。 |
| 运动链路 | 示例配置仍可生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 输出仍包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度明确标注模型假设。 |
| 不规则波 | 固定随机种子下不规则波响应统计可复现，均方根、峰值和谱响应结果可追溯。 |
| 自动测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 更新阶段报告，记录公式依据、代码改动、验证命令、八系数对照、候选排除、残余风险和下一步阻塞项。 |

| 类别 | 封口条件 |
|---|---|
| 失败定位 | 八个失败系数每一项都有明确失败来源，不再停留在“模型不合理”或“需要调参”的层面。 |
| 缺口清单 | 明确列出仍缺的公式、图表、同频参考值、offsets、坐标定义或实验数据。 |
| 排除证据 | 已测试并排除的候选修正均有 CSV 审计表和阶段报告说明。 |
| 默认路径 | 任何未通过硬门槛的候选不得进入默认生产路径。 |
| 后续动作 | 每个剩余缺口都对应一个可执行动作，例如重新数字化、补充文献页、推导固定控制面边界项或补充验证数据。 |
