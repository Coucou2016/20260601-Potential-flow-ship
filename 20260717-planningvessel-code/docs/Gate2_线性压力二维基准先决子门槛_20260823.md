## 目标

**按 Sun 2007 第 2.3、2.7、2.8 节的连续线性边界元、四阶时间推进和压力辅助边值问题，复现 Zhao--Faltinsen 恒速楔形入水相似解；先证明二维自由面、压力分布和积分载荷正确，再恢复 Sun--Troesch 整船强迫运动计算。**

## 验收条件

以下条件必须全部满足：

1. **来源可追溯**：冻结 A3 图 2.6 的 `beta=10 deg、20 deg、30 deg` 自由面和压力曲线，记录页码、图号、坐标定义、数字化点、不确定度、源文件及 SHA-256；不得补画或编造不可读数据。
2. **方程一致**：势函数与压力辅助函数均采用连续线性单元；实现对应式 (2.6)--(2.11)、(2.16)--(2.20)、(2.27)--(2.29)，并明确接触点法向导数不连续处理、压力积分位置和无重力相似解条件。
3. **二维精度**：三个斜升角中，自由面归一化均方根误差 `<=5%`；压力曲线归一化均方根误差 `<=10%`；压力峰值位置误差 `<=5%`；积分垂向力系数误差 `<=5%`。图像数字化不确定度应单列，不得并入模型误差掩盖失败。
4. **数值收敛**：至少两级空间网格和两级时间步；自由面、压力峰值和积分力的最后一级变化均 `<=5%`；每步势与压力边值问题相对残差 `<=1e-8`，无 `NaN/Inf`、接触点发散或负面板长度。
5. **交叉实现检查**：连续线性单元为目标路线；现有常单元压力只作为对照。两者结果、耗时和条件数完整保留，禁止根据整船参考响应选择性删点或调整压力倍率。
6. **整船晋级条件**：二维门槛通过后，才允许重跑 `sigma=1.4` 单频纯升沉。该候选须在同一冻结网格下同时保持 `B33` 相对 Sun 图 7.13 `NUM` 误差 `<=10%`、使 `B53` 不退化，并使 `A33/A53/B33/B53` 整体误差优于常单元基线，方可计算纵摇列和五频率八系数。
7. **复现与回归**：一条命令从空目录生成数字化数据、二维计算、误差表、收敛表、图和机器判定；相关测试及完整 `python -m pytest -q` 无失败，Gate 1 不退化，`response_calibration_used=false`。

## 2026-08-24 薄射流拓扑审计结论

本轮没有继续按结果扫描射流阈值，而是分别审计两条有来源的拓扑路线。Sun 距离法以自由面节点 `B` 到楔面的法向距离为触发量；新增实现能够在一个四阶 Runge--Kutta 外步内定位首次过阈值时刻，并在切除后完成剩余子步。图 2.6 的完整几何复核表明，边界从喷射尖端开始时会先沿上射流分支向根部行进，首段横坐标减小可能是物理拓扑，不等同于面板反转。旧有“横坐标回折即切除”逻辑应解释为未解析射流的遗留截断近似。关闭该近似后，计算仍会形成未解析长薄射流；较大的固定阈值虽避免发散，却通过高频切除削弱压力，不能满足压力和积分力门槛。因此距离阈值不再作为拟合变量继续扫描。

第二条路线按照公开角度切除定义构造点 `E/B/C/D`：从射流尖端沿自由面寻找切线偏离楔面超过 `4 deg` 的点 `E`，当 `AE > 0.1L` 时令 `EB=0.08L`、`BC=0.01L`，将 `B` 投影到楔面得到 `D`，再用 `CB` 上的势函数插值和外推形成新段 `CD`。代码明确强制尖端 `A` 满足与楔面相切的接触条件，并有几何、弧长比例、投影和势函数继承测试。该候选没有改变默认距离法。

在 `beta=20 deg`、`V=1 m/s`、`dt=1.25e-4 s`、每侧 `16` 个船体面板和 `40` 个自由面面板的冻结对照中，按有限楔体全弧长定义 `L=1.59627 m`，触发长度为 `0.159627 m`。目标时刻 `t=0.0025 s` 前没有一次角度切除；直接压力曲线归一化均方根误差为 `43.3529`，即 `4335%`，平均积分力相对误差为 `26.4737`，即 `2647%`。计算延伸到 `t=0.0030625 s` 时接触位置越过 `1.5 m` 楔体边界。势与压力辅助边值问题残差仍约 `1e-15`，再次证明失败来自自由面/薄射流物理解算，而不是线性方程求解精度。

数字化曲线的 `20 deg` 下自由面最内端约为 `(y/(Vt),z/(Vt))=(4.59,0.37)`，它对应薄射流卷曲后的下分支起点；完整图中的上射流仍沿楔面延伸至约 `y/(Vt)=8` 的喷射尖端。因此，以前将 `4.59` 称为“参考接触点”的文字已经撤销。压力峰值位于 `z/(Vt)≈0.51`，处在射流根部邻域，这与完整拓扑一致。

在此基础上新增了独立的 Iafrati 自相似外域求解模块。模块仅以式 (17)/(24) 的 `S_n=0` 为自由面优化目标，参考曲线不进入优化器；求解结束后才执行误差评分。远场增广方程首次实现时曾误用全边界零通量，导致偶极系数异常增大；现已按原文式 (30) 改为“远场求解通量等于偶极解通量”，偶极系数由约 `119` 降至量级 `4--6`，矩阵条件数由约 `1.24e7` 降至约 `2e3`。这证明方程溯源修正确实改善了数值结构。

外域随后分别测试了两种不混淆的闭合方式。`truncated_control` 在下自由面与船体之间保留控制面，`body_root` 则让边界元外域在射流根部直接接到船体，并为浅水射流预留接口。控制面闭合还加入了一个不依赖参考数据的几何可行性条件：控制面在船体上的投影端不得低于未扰动自由面。该条件排除了优化器此前利用的水下退化解；修正后的运动学、自由面和压力误差分别为 `16.94%`、`20.97%`、`71.43%`。船体根部方式分别为 `37.49%`、`32.49%`、`33.47%`。船体根部方式改善了分布压力，却明显恶化运动学闭合；控制面方式相反。两条路线都表明，缺失的上射流弧长和根部匹配不能靠选择一种几何闭合自动补齐。

压力验证同时拆成两层。Sun 图 2.6 数字化曲线用于公共坐标区间内的分布误差；Iafrati Table 1 的 Zhao--Faltinsen 列则提供不受计算覆盖区裁剪影响的精确峰值 `17.77` 和峰位 `0.5087`。控制面闭合仅覆盖到较低船体位置，其公共区间峰值看似接近，但精确标量检查给出峰值误差 `46.61%`、峰位误差 `94.74%`；船体根部闭合对应 `33.86%` 和 `66.24%`。因此，公共区间内的局部最大值不得冒充真实压力峰值。

式 (38)--(46) 的浅水射流部分也已开始实装。当前空间推进器完整实现式 (43)--(46)，使用论文原图所示的式 (44) 除法形式，并以逐步方程回代测试锁定。它尚未连接外域，是因为根部边界元梯度到局部 `lambda/mu` 坐标的方向转换和初始厚度必须由同一几何严格推导；在该接口闭合前，不采用人为绝对值或参考曲线来决定符号。

因此当前最小剩余缺口已进一步收敛为：必须在自相似自由边界中显式表示“上射流--根部回折--下自由面”拓扑，或接入 Iafrati 式 (38)--(46) 的浅水薄射流匹配；仅优化单调下自由面或继续扫描切除阈值都不够。新路线仍须直接对照 `10/20/30 deg` 自由面、压力峰值和积分力，未经二维门槛不得进入整船生产路径。

## 2026-08-24 伪时间与浅水射流增广边界推进

在前述外域诊断之后，已按 Iafrati 原文补入式 (51) 偶极初始自由面、偶极系数预迭代、式 (31)--(34) 二阶伪时间推进、四分之一面板位移上限、船体根部和远场圆弧约束，以及 `10 deg` 射流接管条件。`20 deg` 算例的偶极初值由 `4.0` 自洽迭代至约 `5.63`，未读取 Zhao--Faltinsen 或 Sun--Troesch 参考曲线。

根部角点审计发现，自由面侧和船体侧的 `grad(S)` 切向分量在混合边界角点不连续。原实现使用自由面首面板速度推进交点，会把根部错误拉向楔尖并越过静水线；现改为使用船体末面板的切向 `grad(S)`，同时保持交点严格位于楔面。该修正有方程和边界归属依据，不是参考结果调节。

按照原文远离根部面板按 `1.05` 增长的规则，将自由面由 `36` 面板提高到 `80` 面板后，最小根部面板由约 `0.174` 降至 `0.0170`，进入论文细网格量级。随后加入 `10 deg` 接管事件的步内二分定位，避免整步从 `12.88 deg` 越过到 `0.14 deg`。在 `pseudo_cfl=0.20、0.10、0.05` 三组计算中，最终角度均为约 `9.999 deg`，根部厚度均约 `0.00299`，`S_lambda` 均约 `1.688`，证明接管状态已基本消除时间步依赖。式 (43)--(46) 随后无参考数据推进到 `378` 个节点，尖端厚度降至约 `5.8e-7`。粗网格同一接口会给出错误符号或不足一步的退化状态，因此明确判为不具备耦合资格，不再用于推断局部方向。

第 3.4 节要求两个相邻浅水步组成一个边界积分面板，并在共享中间节点赋予自由面势。该规则已实现，形成约 `189` 个射流船体面板和 `189` 个射流自由面面板，与外域共同组成 `546` 面板增广系统。根部状态进一步改为从完整增广解的首个射流船体面板回读，并以 `0.5` 数值松弛执行固定外域下的内迭代；`S_lambda` 由 `1.6879` 收敛到 `3.0076`，最后相对变化为 `0.053%`。根部一致解的代数残差为 `4.24e-15`、条件数约 `3.30e4`，外域运动学均方根残差为 `1.746`，偶极系数为 `-4.136`。其自由面误差为 `30.6%`、压力分布误差为 `43.2%`、Iafrati 精确峰值误差为 `39.6%`、峰位误差为 `66.0%`，仍全部未通过。一个带根部内迭代的外域二阶步保持可解，但运动学残差由 `1.748` 升至 `1.840`，因此尚未证明重复耦合收敛。
