# 变化剖面旧法向速度一致性诊断

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。

## 结论与边界

**总体阶段仍未通过。本轮完成了非侵入诊断，没有修复或验收完整绕射模型。**

161、321站位两档计算都表明：从前一剖面迁移过来的自由面法向速度，与在新剖面几何上重新求解的辅助旧时刻边界值问题存在明显差异。差异平方和高度集中在后半船新暴露的自由面点。这将下一步工作聚焦到自由面新暴露初始化、法向速度约束及其与历史控制面的耦合；尚不能认定其中任何一个是唯一根因。

诊断前后所有保存的原始场数组逐元素完全相同。未改变状态更新、控制面历史、压力公式、试验数据和门槛。所有输出继续标记 `stage_acceptance=false`。

## 为什么检查这个量

隐式自由面推进使用旧时刻和新时刻的法向速度。旧速度不能仅因插值连续就认定满足新几何上的边界积分方程。尤其在后半船，剖面收缩会使原来位于船体内的横向位置成为水面；这些位置没有前一剖面的自由面状态，现有候选仅用显式声明的、尚未物理验证的有限距离线性外推补充。

本轮比较的是两种数值构造之间的差异，不是数值解与物理真值之间的误差。

## 辅助问题如何构造

1. 保留当前站位的新船体和自由面网格。
2. 自由面势取迁移后的旧时刻值，不采用推进后的新值。
3. 当前缓冲区首项是上一时刻的控制面解。在辅助旧时刻求解中移去首项，末尾补零，使历史滞后重新对应旧时刻；不修改实际推进使用的历史数组。
4. 在冻结的新几何上，将船体入射边界值乘以 `exp(-i*omega0*dt)`，退回旧时刻。其中 `omega0` 是绝对波频率，`dt` 是时间步长，`i` 是虚数单位。这里使用绝对频率，是因为当前相位域入射沿纵向推进的变化率为遭遇频率减去航速与波数的乘积。
5. 解辅助边界积分系统，提取自由面法向速度，与迁移的旧速度逐点比较。
6. 辅助解不反馈进入推进，只保存诊断。

这是“新几何冻结到旧时刻”的辅助问题，并不是实际前一剖面的重新求解；几何变化本身也会导致差异。因此，不能将辅助速度直接视为正确替代值。

## 两档结果

同一工况：Kang解析船型，长度3米，船长弗劳德数0.2，无量纲遭遇频率3。仅一个频率，不能代替全频段验收。

| 指标 | 161站位 | 321站位 |
|---|---:|---:|
| 原始场数组与原候选完全相同 | 是 | 是 |
| 辅助方程最大相对残差 | 3.82×10⁻¹⁵ | 4.48×10⁻¹⁵ |
| 前半船速度相对差异范数 | 0.9553 | 0.9106 |
| 后半船速度相对差异范数 | 1.0475 | 0.8522 |
| 新暴露点访问数 | 82 | 82 |
| 新暴露点差异平方和占全部差异平方和 | 95.6666% | 96.7229% |
| 有旧自由面支持位置的速度相对差异范数 | 0.3197 | 0.2917 |
| 原候选无量纲总升沉激励幅值 | 509.5038 | 185.7611 |

相对差异范数定义为：辅助速度与迁移速度之差的欧氏范数，除以辅助速度的欧氏范数。统计包含全部站位的点访问，未按面元长度或时间步长加权；不是能量、载荷误差或连续空间积分。前后半船与新暴露/有支持位置是两种交叠分组，不能把四组比例相加。大幅增长的后期状态会主导全程平方和，不能仅凭其比例判定最早失稳起点。

表中的微小方程残差说明线性代数求解满足所构造的方程，不证明所构造的运动自由面问题正确。激励幅值依然不收敛，不能根据细档幅值降低宣称通过。

1. **定位最早异常而非只看最终增长。** 按站位、接触点距离和面元长度分组，比较新暴露前后及网格尺度，保留复数状态和控制面历史，区分小面元效应、迁移误差与接触状态缺失。
2. **建立有依据的接触/新暴露状态处理。** 先核对原文离散和接触边界，再建立可独立求解的变化剖面验证算例。仅用制造解通过，不能替代物理验证；不得用实验响应拟合外推倍率。
3. **若试验重求旧速度，必须作为独立候选。** 保留当前基线，核对历史时刻、入射相位及势/速度一致性；不得静默覆盖。单纯有界不等于正确或收敛。
4. **回归完整阶段合同。** 新候选须先完成变化剖面三档收敛和独立复数绕射/力矩验证，再进入三航速整船复验。原5%离散限值、三航速15%/20%误差门槛以及其余历史条件保持不变。
