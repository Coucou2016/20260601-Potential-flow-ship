# 守恒压力全24工况候选：否定结果

## 结论

将守恒直线迹压力恢复用于全部三航速、八频率的辐射与绕射计算后，六项运动指标全部失败。不得替换生产模型，不得把数值积分守恒写成运动预报验证通过。原生产路线与原验收结果均保留。

本次不是正式精细网格验收：使用29站位、36船体/自由面面元、48控制面面元、64历史步、48谱积分点。范围覆盖全部24工况，但只有一档粗网格。平均姿态仍为规定输入，恢复力仍为原Savitsky静水载荷导数；此前识别的长波背景不一致没有因更换压力积分而消除。

## 实施内容

- `scripts/audit_conservative_fullband_candidate.py`：求解前记录输入、实现哈希和离散参数；同一内域/外域匹配内核计算辐射及绕射，使用候选压力恢复后积分，按既有坐标与相位约定装配两自由度动态方程。
- 保存24份矩阵、复数激励、响应及站位载荷文件；预测阶段不读取实验响应。
- `scripts/evaluate_conservative_candidate.py`：求解完成后单独读取冻结实验参考，校验输入/条件/参考哈希、24工况覆盖、CSV响应与保存动态解一致性，并重构动态方程残差。
- 评价沿用原每航速7个适用点与1个诊断点，阈值仍为中位相对误差15%、归一化均方根误差20%。

## 后续推进：同网格同势场的四组合诊断

本轮已完成上述第1项的四组合计算。每个工况只求一套辐射势和一套绕射势；原装配和候选装配使用完全相同的几何、离散、质量、恢复力与平均姿态。四种组合在求解前写入契约，全部保留，不挑选表现最好者作为最终模型：

- 原辐射 + 原直接激励：同网格基线。
- 候选辐射 + 原直接激励：只更换辐射。
- 原辐射 + 候选直接激励：只更换激励。
- 候选辐射 + 候选直接激励：同时更换。

证据目录：`outputs/conservative_paired_fullband_20260924`。24份保存文件均包含原、新辐射矩阵、原、新复数激励及四组合复数响应。这里的“原直接激励”是原入射加绕射路线，不是更早的等效辐射激励路线。

### 精确复数归因

令原、新动态矩阵分别为 `D0=C-omega^2*M-R0`、`D1=C-omega^2*M-R1`，其中 `R=omega^2*A-i*omega*B`；原响应满足 `D0*q0=F0`。总响应变化严格满足：

```text
q1-q0 = solve(D1, (R1-R0)*q0) + solve(D1, F1-F0)
```

右侧两项分别记录为辐射变化贡献和激励变化贡献。24工况最大相对重构残差1.06e-15；不能将两项模长直接相加解释总变化，也不能据此把某项当作应当减掉的“误差力”。

在低速第5个频率点，候选升沉幅值比为9.0397 m/m；这是单位波幅的线性响应，不是实际船体升沉9米。用船长缩放纵摇坐标后，动态矩阵条件数从21.955升至81.545。该点说明耦合放大增强，但不是密集主峰解析，也不是自由运动失稳证明。相应附加质量与阻尼的改变已经保存在原、新矩阵中，后续可继续定位到八个系数分量。

## 八系数响应变化分解

新增 `scripts/audit_radiation_response_components.py`，只读取上述保存的矩阵和计算响应，不读取实验响应。结果在 `outputs/radiation_response_components_20260924`，包括192条分量记录、24条闭合检查以及输入文件哈希。它是诊断工具，不是新增生产求解后端。

对每个附加质量或阻尼分量，分别构造复数辐射矩阵增量，再用同一个候选动态矩阵求解其响应贡献。八项之和必须等于前述辐射变化贡献；加上激励变化贡献后，必须恢复候选与基线的响应差。24工况最大相对残差分别为1.05e-15和3.59e-15。这里的精确闭合仅验证代数和实现，不代表水动力正确。

B53是升沉速度引起纵摇水动力矩的阻尼系数，A53是升沉加速度引起纵摇水动力矩的附加质量系数；A55是纵摇加速度引起纵摇水动力矩的附加惯性系数。下标第一位代表力或力矩方程，第二位代表被施加的运动，3为升沉、5为纵摇。它们位于耦合运动方程左端，影响两个运动之间的反馈，而不是外部波浪输入。

低速第5个采样频率处，B53从264.562变为95.661 kg·m/s，A53从-4.916变为8.259 kg·m，A55从19.942变为13.834 kg·m²。三者的尺度化响应贡献范数分别为25.815、17.513和16.749。不能将这些数直接相加解释实际响应，也不能根据其大小反向拟合或恢复某个系数。

这项结果将排查范围进一步收敛到纵摇力矩行：优先逐站检查升沉辐射的力矩积分、前进速度与截断边界项，再检查纵摇附加惯性及其与规定姿态恢复力的背景一致性。不得强制令交叉系数相等，也不得仅因为旧系数更接近实验就认定其正确。所有原始失败结果及原误差门槛继续保留。

新增5项单元测试及3项既有相关测试共8项通过；本轮未重跑全套回归。机器状态继续为 `NOT_PASSED`。独立激励参考、物理一致性修复、候选全频段三档离散及原合同实验复验仍是后续必需项。

### 原始资料对修正的限制

- `../20260729-文献收集/md/A4_1.md`第261至267行讨论艉板分离与压力下降。其中第267行说明，0.5倍船宽是用于改善总力关联的经验修正，并明确质疑其对力矩修正的可靠性，因为它不描述实际力分布。
- `../20260729-文献收集/md/A4_2.md`第235行将艉部0.5倍船宽范围的剖面力设为零，作为三维效应修正；该段并没有给出适用于当前线性匹配势求解器的独立艉部复数辐射边界条件。

因此，目前证据支持的结论是：模型间差异主要是艉部载荷修正与力矩装配定义的差异，不能归结为守恒积分精度不足。也不能据此直接删除边界项、改变0.5B或选择对实验最有利的组合。
