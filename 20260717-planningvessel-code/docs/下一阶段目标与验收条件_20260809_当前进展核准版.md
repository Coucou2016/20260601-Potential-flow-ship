# 下一阶段目标与验收条件：线性 2.5D 核心水动力闭环

日期：2026-08-09

## 1. 当前进展核准

本项目的总体目标是：以高速滑行艇为核心，建立从排水船型、半排水船型到滑行艇，并可扩展到单体、多体、三体和水翼船型的高速船型运动预报系统；理论上以 2.5D 为近期核心，逐步扩展至非线性 2D+t；输入覆盖船型、质量惯性、航速、波浪、海流、风等条件；输出不同航速下六自由度运动响应与不规则波统计响应；最终形成可追溯、可验证、可扩展的计算平台。

当前已经完成第一轮基础建设：`planing_seakeeping` 程序框架、配置读取、示例算例、规则波和不规则波输出、可视化输出、文献与基准数据目录、验证框架、阶段报告和大量诊断审计均已建立。现有代码规模约为 70 个程序文件、15 个测试文件、30 个基准数据文件和 72 个文档/报告文件。

当前已经能运行示例滑行艇算例，并输出不同航速下的稳态姿态、响应曲线、规则波/不规则波时历和统计结果。`outputs/linear_2p5d_motion_demo/summary.csv` 显示示例航速约为 9.29、13.93、18.58 m/s，Savitsky 平衡求解链路可运行。

当前验证框架已经具备数值 sanity check、物理趋势 sanity check、二维截面 BEM sanity check、Faltinsen 第 9 章响应对照、Fridsma/Katayama/ Ma 2005 等验证入口。其中数值稳定性、物理趋势和截面 BEM 基础检查已有通过项。

当前最关键缺口是：Ma 2005 Wigley III 线性 2.5D 八个核心水动力系数尚未通过硬验证。固定 Gate 目录 `outputs/gate1_linear_2p5d_hard_pass/results/ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 中，`A33、B33、A35、B35、A53、B53、A55、B55` 目前均为 `FAIL`，即 0/8 通过。因此，当前阶段仍不能宣称完整 2.5D 核心已经可信闭环。

## 2. 下一阶段唯一主目标

下一阶段的目标是：完成线性高速 2.5D 核心水动力模型的 Gate 1 闭环，使 Ma 2005 Wigley III 八个频域水动力系数在固定验证入口下通过硬验收，并形成可追溯的公式链、诊断链、测试链和报告链。

本阶段不以新增船型数量为目标，不以经验缩放拟合为通过标准，不把 SL-7、三体船、水翼船或强非线性 2D+t 作为主线开发对象。只有当 Wigley III 线性 2.5D 核心通过后，才进入多船型和非线性扩展。

## 3. 必须满足的验收条件

1. 固定验证入口可复现：使用同一个固定命令运行 Gate 1 验证，输出目录固定为 `outputs/gate1_linear_2p5d_hard_pass/results/`，所有核心 CSV、图表和报告均可重新生成。

2. 八个核心水动力系数全部通过：`ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 中 `A33、B33、A35、B35、A53、B53、A55、B55` 全部为 `PASS`；直接项建议相对误差不超过 15%，耦合项建议相对误差不超过 30%，且无 `NaN`、`Inf` 或数值发散。

3. 公式链闭合：对 `A33/A53`、`B33/A35/B35`、`A55/B55` 三组问题分别给出明确解释，说明误差来自边界条件、压力公式、前进速度梯度项、端部项、坐标/力矩约定、归一化还是参考数据；每个修正必须能追溯到 Ma 2005、Faltinsen 或已登记文献。

4. 禁止经验硬拟合：不得用只对某个系数有效的经验比例、符号翻转或后处理缩放冒充模型修正。候选比例和敏感性扫描只能作为诊断输出，不能作为最终通过依据。

5. 诊断文件完整：每个失败系数必须有对应的分量级审计 CSV，至少包含参考值、计算值、误差、容差、压力项、自由面项、端部项、站位贡献和候选排除结论。

6. 回归测试通过：核心单元测试、验证测试和 CLI 冒烟测试全部通过；测试结果中不得出现新的失败项；已有示例配置仍能生成 `summary.csv`、`rao.csv`、`timeseries_*.csv`、`figures/*.png` 或等价图表文件。

7. 示例运动预报可解释：在 Gate 1 通过后，重新运行示例滑行艇规则波和不规则波算例，输出不同航速下的六自由度响应；迎浪工况中横荡、横摇、艏摇为零或近零时，必须在报告中明确标注这是对称线性模型假设，不得解释为真实横向运动预测。

8. 验证报告更新：生成一份阶段报告，至少包含当前方法、参考数据来源、核心公式、八个系数对照表、误差图、修正前后对比、仍未解决的边界和下一步扩展建议。

9. 数据缺口明确：SL-7 真实 offsets、C1 三体船数字 offsets、Fridsma/Katayama 加速度和幅值曲线等未完全具备的数据，必须在报告中列为后续验证层级，不作为本阶段通过 Gate 1 的必要条件；若使用替代船型，只能标注为替代验证，不能等同原始试验验证。

10. 阶段出口清晰：若八个系数全部通过，则进入“规则波/不规则波运动响应硬验证”阶段；若仍未通过，则必须输出剩余阻塞项清单，列明缺失证据、已排除路径和下一步最小可执行诊断，而不是继续扩大功能范围。

## 4. 本阶段交付物

1. 可复现的 Gate 1 验证输出目录。
2. 八个 Ma 2005 Wigley III 系数对照 CSV 与误差图。
3. 公式链和分量级诊断 CSV。
4. 更新后的验证报告 Markdown。
5. 通过的测试记录。
6. 重新运行的示例运动预报结果。

## 5. 阶段完成判定

只有当 Ma 2005 Wigley III 八个核心水动力系数全部通过固定 Gate 1，且报告能够解释这些结果为什么合理、如何复现、边界在哪里时，本阶段才算完成。否则，本阶段状态为“核心 2.5D 尚未闭环”，后续工作应继续围绕失败系数收敛，而不是转向更复杂船型或非线性模块。
