## 2. 下一阶段目标

完成线性高速 2.5D 核心水动力模型的 Gate 1 验证闭环。

具体目标是：在不使用经验倍率、不按参考结果反推系数、不污染默认生产路径的前提下，修复或封口 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 算例中的八个核心频域水动力系数计算链，使 `A33/B33/A35/B35/A53/B53/A55/B55` 达到可验证、可解释、可复现的状态。

优先完成目标：八个核心系数全部通过 Gate 1。  
最低阶段目标：若阶段内不能全部通过，则每个失败系数必须被封口到明确的理论、数据、几何、频率、坐标、压力恢复、自由面推进、端部项、固定控制面输运、纵摇力矩装配或无量纲化缺口，并给出证据文件和下一步所需条件。

一句话目标：

> 把当前“能运行、能诊断”的线性 2.5D 主线，推进为“能硬验证、能解释误差、能支撑后续非线性和多船型扩展”的核心模型。

## 3. 本阶段范围

本阶段纳入：

1. Ma 2005 Wigley III 八个核心系数硬验证。
2. Journee 1992 同频复数力、相位和力矩链辅助核对。
3. `matched_bie_station_sweep` 默认路径修复。
4. 时间压力、前进速度压力梯度、固定控制面输运、端部项、站位推进、纵摇力矩和无量纲化链路审计。
5. Katayama 定性趋势硬失败的修复或合理重分类，避免 `validate --benchmark all` 中保留未解释硬失败。
6. 示例滑行艇规则波、不规则波、六自由度输出链保持可运行。
7. 自动化测试、验证输出和阶段报告同步更新。

本阶段不纳入：

1. 不开发生产级强非线性 2D+t 自由面边界元模型。
2. 不开发生产级双体船、三体船共同边界积分模型。
3. 不开发生产级水翼、压浪板和控制器模型。
4. 不把 SL-7、C1 三体船、Delft 372 作为本阶段硬通过对象。
5. 不用最终结果拟合、经验补偿或参考曲线反推制造通过结果。

## 4. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数必须由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| 八系数通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 硬失败清零 | 固定验证命令完成后，阶段范围内不得存在未解释硬失败；若仍有失败，必须有封口分类和证据文件。 |
| 失败封口 | 每个未通过系数必须给出缺口类型、审计表、关键数值、不能通过的原因和下一步所需资料或推导条件。 |
| 候选隔离 | 所有未通过八系数硬门槛的候选路线必须保持 `candidate_default_gate_eligible=false`，不得进入默认结果。 |
| 公式追溯 | Ma 2005 / Journee 1992 的频率、坐标、符号、单位、无量纲化和数字化来源必须写入阶段报告。 |
| 数值质量 | 输出不得出现 `NaN`、`Inf`、空表、未说明异常峰值或不可解释负阻尼。 |
| 运动链保持 | 示例配置必须可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时域结果必须包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度必须标注模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过；若未完整运行，必须记录原因、已运行测试和补跑计划。 |
| 阶段报告 | 阶段报告必须包含：代码改动、公式依据、验证命令、八系数对照、失败封口、候选排除、剩余风险和下一步建议。 |
