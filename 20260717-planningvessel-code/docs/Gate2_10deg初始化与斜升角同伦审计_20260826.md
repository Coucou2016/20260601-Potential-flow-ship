# Gate 2：10° 初始化与斜升角同伦审计

日期：2026-08-26  
结论状态：**10° 正式验证包仍为 FAIL；参考隔离同伦路线已进入可持续下降支**

## 1. 审计目的

10° 恒速楔形入水是 Gate 2 二维先决门的低斜升角端点。该算例不能通过修改参考曲线、经验指定射流根速度或放宽正根条件来启动。本审计记录直接初始化失败、匹配面搜索修正和斜升角同伦初值路线，并明确区分“找到可推进初值”与“10° 已通过验证”。

## 2. 不变的源级条件

Iafrati 2013 式（41）--（46）要求薄射流第一个空间 marching 点由主体流边界积分解提供。由式（42）

$$
\widetilde S_\lambda=-\frac{S_\tau}{\sqrt{1+f_\lambda^2}}
$$

可知，在当前从主体流根部指向喷溅尖端的 $\lambda$ 方向下，物理解必须满足

$$
f>0,\qquad S_\lambda>0,\qquad S_\tau<0,\qquad \Delta\lambda>0.
$$

参考自由面和压力曲线只在求解结束后评分，不进入初值、匹配面位置、停止条件或同伦候选选择。

## 4. 匹配面搜索修正

旧实现只会在“浅水第一步方程无解”时继续向外移动匹配面；若候选更早以 `S_lambda<=0` 失败，则立即退出。现已统一为：

1. 负根候选仍严格拒绝；
2. 将该候选视为当前匹配面不适用，继续向外转移主体自由面首段；
3. 每次转移后重新求主体边界积分和全部根量；
4. 找到最小可行位置才接受，穷尽候选则输出最后一个根错误。

实际 10° 测试证明默认自由面上的全部候选均为负根，因此修正没有伪造一个可行状态，只把“首个失败”升级为“穷尽搜索后的可追溯失败”。

## 5. 参考隔离斜升角同伦

新增 `scripts/continue_self_similar_wedge_deadrise.py`。源检查点为已收敛的 20° 解；对每个候选根区纵向尺度 $s_x$，以外自由面弧长分数 $u\in[0,1]$ 构造

$$
\xi'(u)=\xi(u)\left[1+(s_x-1)(1-u)^p\right],
\qquad \eta'(u)=\eta(u),
$$

其中 $p=2$。该变换只调整根区，远场端点严格不动。每个候选必须重新构建目标斜升角的主体流和增广边界积分，并满足：

- 主体射流根和增广边界积分回读根均为正；
- 射流 marching 到达尖端；
- 条件数不超过源状态的冻结倍数；
- 候选选择只按 Iafrati 式（52）运动学积分及条件数，不读取参考曲线；
- 选中后继续运行直接二阶 Runge--Kutta 伪时间步，以检验其是否位于目标方程吸引域。

## 7. 当前边界与下一步

当前证据证明：10° 直接初始化的失败可复现；参考隔离的半度斜升角同伦能够越过负根初值区并进入目标方程的残差下降支。它尚未证明 10° 结果正确。

后续必须依次完成：

1. 将 19.5° 收敛至绝对 `K<=1e-3`，并验证 128/256 射流面板一致性；
2. 以相同硬门逐级推进至 19°、18.5°，直至 10°；
3. 在 10° 比较至少两条同伦步长/初值路径，证明最终解路径独立；
4. 完成 10° 的网格、时间步、远域和参考误差正式验收。

在以上四项完成前，10° 和二维楔形先决门均保持 `FAIL`。

本轮新增同伦、负根穷尽搜索、检查点时间轴和信赖域相关实现后，扩大定向回归为 `82 passed, 0 failed`；最终代码完整软件回归为 `588 passed, 0 failed, 1247 warnings`，耗时 `798.05 s`。该结果只证明软件基线未退化，不改变 10° 的物理失败判定。

## 8. 19.5°数值源与19.0°方向饱和更新

后续受约束低模态信赖域和三层重网格已把19.5°最细1280面板的精确运动学积分降至 `K=9.266963e-4`。640到1280面板的自由面相对变化为 `0.2629%`，压力曲线相对变化为 `0.00234%`，积分垂向力变化为 `0.000983%`。这建立了空间数值稳定的同伦源，但19.5°没有冻结参考曲线，所以物理验证仍为 `FAIL`。
