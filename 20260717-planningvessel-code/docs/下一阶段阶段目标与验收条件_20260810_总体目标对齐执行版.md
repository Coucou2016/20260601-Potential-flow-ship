# 下一阶段阶段目标与验收条件：线性高速 2.5D 核心硬验证闭环

日期：2026-08-10  
对应总体目标：高速船型运动预报系统总体目标  
阶段定位：总体目标中的第一条主线，即“以高速滑行艇为核心，建立完整、可验证、可扩展的 2.5D 运动预报模型及框架”。

## 1. 当前进展判断

项目已经完成第一轮基础框架建设，具备继续向完整高速船型运动预报系统推进的条件。

已完成内容包括：

1. 已建立 `planing_seakeeping` Python 包和命令行入口，具备配置读取、船型参数读取、波浪输入、航速输入、运动响应计算、六自由度统一输出、可视化和报告输出能力。
2. 已形成线性 2.5D、非线性 2D+t、多体船、水翼船等后续模块的目录与接口预留，软件框架具备扩展基础。
3. 已整理 Faltinsen、Ma 2005、Fridsma、Katayama、Delft 372、ITTC 等验证路线，初步形成理论来源、代码实现和验证数据之间的追踪链。
4. 已能运行示例滑行艇算例，输出响应幅值算子、规则波时域响应、不规则波时域响应、均方根统计、图像和 Markdown/HTML/PDF 报告。
5. 已针对 Ma 2005 Wigley III 线性 2.5D 验证建立固定验证入口，并生成多类诊断表。

当前主要不足是：线性高速 2.5D 核心水动力模型尚未通过 Ma 2005 Wigley III 的硬验证。当前八个核心频域水动力系数仍存在失败项，因此现阶段不能宣称完整 2.5D 模型已经可信闭环。

## 2. 下一阶段总目标

下一阶段的总目标是：

**完成线性高速 2.5D 核心水动力模型的 Gate 1 硬验证闭环，使 Ma 2005 Wigley III 八个核心频域水动力系数在固定验证入口下全部通过，并形成可追溯的公式链、实现链、诊断链、测试链和报告链。**

一句话概括：

> 先把线性 2.5D 核心算准、说清、验实，再进入非线性 2D+t、多体船、三体船和水翼船扩展。

## 3. 阶段工作范围

本阶段必须完成：

1. 以 Ma 2005 Wigley III 为首要硬验证对象。
2. 以 A1/Ma 2005 的线性高速 2.5D 方程链为主要理论依据。
3. 重点闭合八个核心系数：`A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55`。
4. 优先处理当前最明确的阻塞链：`Eq.23 RHS -> body potential -> Eq.30 time pressure -> A33/A53`。
5. 继续排查并闭合 `B33/A35/B35` 的前进速度梯度项、几何输运项和站位积分问题。
6. 继续排查并闭合 `A55/B55` 的纵摇力矩、力臂、端部项和整船装配问题。
7. 保留所有诊断候选路径，但只有具有公式来源、物理解释和测试验证的修正才能进入默认计算路径。
8. 更新阶段报告，说明每一项修正的理论来源、代码位置、修正原因、验证结果和剩余风险。

本阶段暂不作为主线验收：

1. SL-7 真实 offsets 闭合。
2. C1 三体船真实 offsets 闭合。
3. Delft 372 双体船完整斜浪六自由度验证。
4. Sun-Faltinsen 强非线性 2D+t 生产级自由面边界元实现。
5. 水翼船控制系统和真实水翼自由面耦合。

这些内容只作为资料整理、接口预留和下一轮验证对象储备。

## 5. 阶段完成判定

只有同时满足以下条件，本阶段才算完成：

1. Ma 2005 Wigley III 八个核心频域水动力系数全部通过固定 Gate 1。
2. 通过结果来自默认 2.5D matched BIE 路径。
3. 所有进入默认路径的修正都有公式级或物理级依据。
4. 诊断表、验证表、测试结果、示例结果和阶段报告完整可复查。
5. 能说明当前模型适用范围：迎浪线性高速 2.5D 纵向运动可信；斜浪完整六自由度、强非线性 2D+t、多体干扰和水翼控制仍属于后续扩展。

若八个系数仍有任意一个为 `FAIL`，则本阶段状态仍为“线性高速 2.5D 核心水动力尚未闭环”，后续工作应继续围绕失败系数做公式级、站位级和分量级排查，不应转向更复杂船型或更高级非线性模型的主线开发。

## 6. 完成后进入的下一步

本阶段完成后，再进入下一阶段：

1. 将通过 Gate 1 的线性 2.5D 核心接回滑行艇运动预报主流程。
2. 用 Fridsma/Katayama 规则波和不规则波数据验证 heave、pitch、重心加速度、艏部加速度和统计响应。
3. 建立 Delft 372 双体船和可替代三体船几何的第二级验证入口。
4. 在已可信的线性核心上推进非线性 2D+t、湿甲板拍击、多体干扰和水翼控制扩展。
