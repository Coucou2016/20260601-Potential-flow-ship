## 接入顺序

1. 优先取得并检查原始Journée固定船体载荷表；Liu的有航速数值对照作为另一证据层。
2. 确认完整船型、吃水、重心/矩参考点、频率与相位约定，再冻结工况及误差标准。
3. 纯绕射若由总激励扣除入射载荷得到，必须先统一复数约定，并明确这是推导参考，不是直接测得的分量。
4. 对当前站位推进内核，Fn=0不能用极小正速度代替；零速参考只用于适用的独立内核核查。
5. 幅值对照不替代相位对照；理论对照不替代Begovic三速度和Fridsma实验验收。
