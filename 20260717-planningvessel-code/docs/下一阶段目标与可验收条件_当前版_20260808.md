# 下一阶段目标与可验收条件（当前版）

日期：2026-08-08

## 1. 当前进展情况

围绕“高速船型运动预报系统总体目标”，当前项目已经完成第一轮可扩展框架建设，并进入线性高速 2.5D 核心模型的硬验证收敛阶段。

已经完成的主要内容如下：

1. 已建立 `planing_seakeeping` Python 包、命令行接口、配置读取、规则波和不规则波、时域响应、频域响应、六自由度统一输出、可视化和报告输出流程。
2. 已形成面向后续扩展的统一架构，包含 `linear_2p5d` 主线、`NonlinearBEM2DtProvider` 生产内核接口、`ReducedOrderPlaningLoadProvider` 简化载荷接口、多体船和水翼模块预留接口。
3. 已可运行示例滑行艇算例，输出不同航速下的规则波、不规则波时间序列、响应幅值算子、汇总表和图表。
4. 已建立验证框架，覆盖数值稳定性、物理趋势、剖面边界元基本正确性、Faltinsen 第 9 章状态检查、Katayama 趋势检查、Fridsma/Katayama/SL-7 待补数据检查、Ma 2005 Wigley III 硬验证。
5. 最新回归测试记录为 `203 passed`，说明现有软件结构和诊断链条在代码层面稳定。

当前最关键的未完成项是：Ma 2005 Wigley III 八个频域水动力系数尚未通过 Gate 1。最新结果中，`A33/B33/A35/B35/A53/B53/A55/B55` 均为 `FAIL`，默认路线仍为 `matched_bie_station_sweep`。这说明目前问题不在程序是否能跑通，而在核心 2.5D 水动力方程链尚未达到可验证可信状态。

## 2. 下一阶段阶段目标

下一阶段目标是：

在保持默认 `matched_bie_station_sweep` 路线不变、不引入经验拟合和事后补偿的前提下，完成 Ma--Duan--Song 型线性高速 2.5D 水动力核心的 Gate 1 硬验证闭环，使 Ma 2005 Wigley III 的八个升沉/纵摇水动力系数全部通过验收；若仍不能全部通过，则必须把剩余误差压缩并定位到明确的公式项、坐标/相位映射项、边界积分项、离散/历史卷积项或缺失参考数据项。

该阶段只解决“线性高速 2.5D 核心是否可信”这一件事。非线性 2D+t、多体船、三体船、水翼船和完整斜浪六自由度模型暂不作为主攻目标，只保留接口和资料整理，不用未经验证的占位模型冒充已完成模型。

## 3. 可验收条件

1. 默认模型路线固定为 `matched_bie_station_sweep`，不得切换到 legacy、reduced-order、经验比例修正或后处理拟合路线。
2. Ma 2005 Wigley III 八个系数 `A33/B33/A35/B35/A53/B53/A55/B55` 全部达到 Gate 1：每一行 `status == PASS`，每一行 `gate_error_ratio <= 1.0`。
3. 所有进入默认模型的公式修改必须能追溯到 Ma--Duan--Song、Faltinsen 或已登记文献中的方程、边界条件、归一化定义、力矩定义或坐标约定。
4. 所有候选修正必须先作为 `diagnostic-only` 输出审计表；只有在八系数同时通过、且有方程来源时，才允许进入默认路径。
5. 固定控制面几何输运、Eq.30 时间压力项、Eq.31 前进速度压力梯度项、Eq.32 Stokes/端部项、`A/B` 拆分、纵摇力矩臂与相位约定必须形成闭合诊断链。
6. 验证命令必须可重复运行，并生成 `ma2005_wigley_iii_coefficients_comparison.csv`、失败/剩余阻塞审计表、候选影响汇总表和 `validation_report.md`。
7. 示例运动预报链必须保持可运行，能生成 `summary.csv`、`rao.csv`、规则波和不规则波时域 CSV、图表与运行报告。
8. 数值与软件回归必须通过：`python -m pytest -q` 全部通过；验证和示例输出不得包含 `NaN`、`Infinity` 或空结果。
9. 若 Gate 1 未能通过，阶段成果仍可验收为“阻塞定位完成”，但必须满足：每个失败系数都有明确失败来源分类、已排除的候选清单、下一步所需数据或理论证据，不得停留在“结果不合理”这类笼统判断。
10. 阶段报告必须同步更新，清楚说明改了什么、为什么改、依据来自哪里、哪些结果改善、哪些仍失败、下一步如何继续。

## 4. 肯定需要的条件

1. 需要高质量 Markdown 或可读文本版文献，尤其是 A1、A3、A4_2、A4_3、A5、A6、A7、B1、B2、C1 和 D2，用于核对公式、符号、表格、试验条件和验证曲线。
2. 需要源头可追溯的 Ma 2005 Wigley III 系数、几何、归一化和频率定义；任何数字化曲线必须记录来源页码、图号、坐标轴和单位。
3. 需要继续补齐 Faltinsen、Fridsma、Katayama 的响应曲线数字化数据，用于后续从“系数验证”推进到“运动响应验证”。
4. SL-7 和 C1 三体船若找不到完整 offsets，可接受公开、可追溯的相近替代船型，但必须明确其替代关系、适用范围和不能验证的项目。
5. 在 Gate 1 通过前，不应把非线性 2D+t、多体干扰或水翼控制作为主验收目标；这些工作只能作为接口、文献、数据和后续架构准备。

## 5. 阶段完成判据

本阶段完成有两种合格出口：

1. 理想出口：Ma 2005 Wigley III 八系数全部 `PASS`，默认线性 2.5D 水动力核心进入可信验证状态。
2. 阻塞出口：八系数尚未全部 `PASS`，但剩余问题已被压缩到明确、可执行、可追溯的缺口清单，并说明需要补充哪一份文献、哪一组 offsets、哪一个公式推导或哪一个实验数据才能继续。
