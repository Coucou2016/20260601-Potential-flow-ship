# 暴露初始化与原自由面边缘处理分离核查

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。**阶段未通过。**

## 目的

上轮有界迁移制造解最大加权误差约1.5%，但同时包含两项近似：新暴露点复制同侧最近状态，以及原自由面上位于旧面元中点覆盖范围之外的点也复制最近状态。本轮用同一解析解、同一四档网格分离这两项，不改变1%制造解误差限，不读取船舶试验响应。

## 四因素对照及数值候选

下表报告最细档（320时间步、横向8倍加密）的全过程最大误差。加权误差是势和自由面升高量按各自解析振幅归一化后的面元长度加权二范数，点误差同样按振幅尺度归一化，避免局部过零造成假大误差。

| 新暴露状态 | 原自由面边缘 | 最大加权误差 | 最大点误差 | 1%全局限值 |
|---|---|---:|---:|---|
| 精确解析值 | 线性外推 | 0.0126% | 0.0107% | 通过 |
| 最近点值 | 最近点保持 | 1.4808% | 5.0323% | 失败 |
| 精确解析值 | 最近点保持 | 0.0337% | 0.1147% | 通过 |
| 最近点值 | 线性外推 | 1.4530% | 4.9622% | 失败 |
| 受限距离线性延拓 | 最近点保持 | 1.3291% | 4.6247% | 失败 |
| 受限距离线性延拓 | 线性外推 | 0.3328% | 1.4888% | 通过但仍有局部精度缺口 |

交叉对照支持：本制造解主要问题在新暴露状态，单独恢复原自由面边缘的线性外推不能消除误差。不过，使用旧边缘数据延拓新暴露状态时，两者会相互影响，所以只在新暴露区线性延拓仍失败。

全线性迁移的最大加权误差从粗档0.8310%降至最细0.3328%，但局部误差约1.5%，在后几档没有明显下降。因此只报告其达到全局误差限，不声称接触物理或局部收敛通过。解析值只用于制造解对照，不能用于真实船体初始化。

## 实际Kang场解检查

将局部延拓及已有全线性迁移分别用于已修正法向的实际匹配域求解，固定无量纲遭遇频率3、321站位、直面元解析积分、控制半径0.9米及原历史设置。三条路线均完成有限解，最大方程残差小于1e-15。

| 迁移策略 | 无量纲总升沉激励幅值 | 相对最近点策略的绕射升沉/纵摇复数变化 | 相对最近点策略的总升沉/纵摇复数变化 |
|---|---:|---|---|
| 最近点保持 | 7.704469 | 基准 | 基准 |
| 仅新暴露线性延拓 | 7.704070 | 0.02446% / 0.03498% | 0.006536% / 0.006777% |
| 全线性迁移 | 7.705156 | 0.20844% / 0.40058% | 0.05569% / 0.07761% |

复数变化包含相位，分母为最近点策略的相应载荷模。实际运行的最大自由面升高量向量范数分别约2.101、2.098、2.644；这是离散向量范数而非单点真实波高，只用于识别本次是否存在数值大幅放大，不是运动适用性指标。

全线性迁移在本次解析面元配置没有重现旧配置下的明显放大。不能据此证明全频段稳定，也不能将旧失败记录删除。需要在多档网格、更多频率及相同输入下验证。

## 结论与下一步

1. 有界迁移确有制造解精度缺口，不能仅凭其非放大性宣布正确。
2. 本轮局部延拓候选仍失败，保留显式实验标签，不进入整船默认。
3. 全线性迁移目前只有单频有限解和全局制造解误差限证据，局部误差及真实接触状态仍未验证，不升级为生产模型。
4. 实际三种迁移的总激励差异小，不能把当前主要参考偏差直接归因于制造解发现的问题。下一步需推进独立复数激励参考、物理约定及全频段验证，避免不断改变迁移策略去追近参考幅值。

阶段合同中的三航速15%/20%、主峰10%、旧线性基础门、Fridsma相位/加速度、时频一致性及全频段三档离散要求全部保留。
