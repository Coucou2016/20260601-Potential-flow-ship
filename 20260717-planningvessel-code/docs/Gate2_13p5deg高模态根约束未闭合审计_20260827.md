## 4. 失败原因判定

本轮不是发散或方程求解失败。三层根失配、条件数和几何有限性均可控，真正未闭合的是细网格绝对运动学积分。由 64 模态扩展至 128 模态后，640/1280 面板 `K`仅降低约 `0.64%/0.81%`，同时根失配明显消耗可行裕量。因此，继续重复同一冻结方向预计会先触发根门槛，而不能把 `K`从约 `1.34e-3` 降至 `1e-3` 以下。

下一次若继续数值延拓，应先检查残差雅可比在根约束零空间内的奇异向量和空间定位，再决定是否扩展至 256 模态或修改形状参数化。不得把重复低收益步进、放宽根门槛或选择单一网格作为通过依据。
