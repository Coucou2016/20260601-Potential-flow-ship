# 浮筒断阶解释与假设参数方案

## 1. 中间间断是否正确

原始NACA-WR-L-722表I（PDF第6页）在179英寸和325英寸位置均分别列出F和A，表示断阶前后两侧。179站龙骨高度由-0.05英寸变成3.70英寸，跳变3.75英寸，即0.09525米；325站由21.09变为24.20英寸，跳变0.078994米。位置分别为首后4.5466米和8.255米。这些是实物底部台阶，不是OCR漏行。

**几何有台阶正确，但实物不是两截悬空的壳体。** 现有图只画型值支撑的底面，不含断阶立面、侧面和甲板；因此图中空隙包含尚未重建的面。不能把当前开口底面称为完整封闭浮筒。后续补面须根据型线核查，不能为视觉连续而跨台阶光顺。补出的连接面也不自动属于实际湿面。

断阶的作用是帮助滑行阶段水流从前体分离，在适当工况下使后体部分离水，减少湿面积和阻力。它不会保证所有速度、姿态下后体均干燥；后体再浸水会改变力和力矩。公开NASA历史技术汇编对此有明确解释：[The Wind and Beyond, Volume III](https://www.nasa.gov/wp-content/uploads/2022/05/the_wind_and_beyond_tagged.pdf)。断阶通气不是空化，不能只在几何上加台阶就认为求解器具备通气模型。

## 3. 可以自行拟定哪些参数

可以建立理论自洽的假设研究机，但必须命名为“EDO真实底面 + 合成机体研究案例”，不使用“真实SB2U-3复现”称谓。这里的合理是惯性/几何/数量级一致，不代表配平、结构、操稳或起降安全已得到证明。

本轮文件：`configs/edo106k_synthetic_aircraft.json`，独立研究配置，尚不由普通run入口执行整机运动。

| 参数 | 假设/派生数值 | 依据与边界 |
| --- | --- | --- |
| 总质量 | 1800 kg | 6部件假设质量之和，不是原飞机实测 |
| 重心 | (4.16444, 0, 1.71000) m | x从浮筒首向后，y向右，z从原表基准向上；不是从水线量取 |
| Ixx / Iyy / Izz | 5018.592 / 7390.400 / 11547.408 kg m² | 均匀等效长方体加平行轴定理；包含各部件相对重心偏移 |
| Ixz=Izx | -185.040 kg m² | 此处表示张量非对角元素，不能与其他文献的惯性积符号混用 |
| 机翼面积/翼展/弦长 | 19.2 m² / 12 m / 1.6 m | 合成矩形翼，展弦比7.5 |

分部件质量：浮筒180、机身600、机翼360、动力260、载荷/燃油240、尾部160 kg。各部件等效尺寸和位置均写入配置，可审计和调整；等效长方体只用于质量分布，不作为外形或水动力网格。

### 计算关系

总质量 M=Σmi；重心 rG=Σ(mi ri)/M。

长方体自身重心惯性为 mi/12 × diag(b²+c², a²+c², a²+b²)，a、b、c为三轴长度。

整机惯性 IG=Σ[Iloc,i + mi((di·di)E−di diᵀ)]，di=ri−rG，E为单位矩阵。这样总质量、重心和惯性来自同一分布，而不是分别猜三个数。程序验证有限性、正定性和主惯性三角不等式。

有限翼升力斜率 a=a0/(1+a0/(πe AR))，a0=2π，AR=b²/S；诱导阻力系数因子k=1/(πe AR)。这是低阶建模假设，适用角度限制为±5°。不能外推失速，也没有地效升力导数。

推力研究律为T=min(Tstatic,ηP/Vair)，零空速取静推力上限。它限制零速奇点和高速功率需求，但未模拟桨叶、转速、桨距或尾流，不是已实现并验证的推进模块。

### 接触水面与坐标不能任意凑数

源几何坐标先转换至以重心为原点的飞机前/右/下坐标：旋转diag(-1,1,-1)，同时平移到重心。再按初始姿态转到统一地固系。平水首次接触可以求竖向平移，使变换后底面最低点恰到z=0；波浪要逐点比较真实位置和相应时刻的波高，不能把浮筒原始基准线当作水线。

瞬时姿态在规定运动试验中是输入，在自由运动中必须是方程解；不能每步重新“拟定”使浮筒保持漂亮的接触。静态浸深需要封闭体积与力矩平衡，目前底面开口，禁止据此宣称浮力配平通过。单主浮筒也缺侧向稳定部件，当前假设只能用于受约束纵向研究，不支持真实横摇稳定判断。

## 4. 实际运行与剩余出口

运行 `python scripts/check_synthetic_aircraft.py`，生成 `outputs/edo106k_synthetic_assumptions/mass_and_sensitivity.json`。已计算总质量系数0.8/1/1.2与载荷前后移动-0.3/0/0.3米组合的9组质量特性。它们是质量参数敏感性，不是运动响应敏感性。

本轮相关59项测试通过，含解析长方体惯性、平行轴结果、整体平移不变性、非法质量拒绝及已有几何/气水载荷/水翼测试。未运行整机起降，未重跑整套回归，未改变任何历史实验验收结论。

下一步顺序：

1. 依据原型线补断阶面及侧面，同时分开真实型值与插值假设；闭合性、法向和体积检查通过后才能做静水配平。
2. 规定姿态/速度求接触线和湿剖面，与手算平水接触及网格加密对照，再接入二维水动力核。
3. 验证积分力、力矩与既有楔形/浮筒公开参考；未经验证不放入自由运动反馈环。
4. 气动、推进、重力和水动力统一坐标接线；先检查无水、无气极限与能量，再做质量/重心/惯性对响应的敏感性。
5. 最后求自由着水和滑跑；地效、水翼控制、多体干扰分别验收，不能用一个“理论合理”的默认系数包替代缺失物理。

本轮补齐的是可复算的参数假设与质量特性链，而不是把缺失的几何、通气、自由面及实验验证假设为已完成。
