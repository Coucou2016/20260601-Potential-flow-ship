证据：`outputs/prescribed_restoring_audit_20260921`，含事前契约、输入和源码哈希、48条检查、三个平均载荷残差。新解析导数的三航速测试及先前耦合分解测试共5项通过。本轮未重跑全套回归；此前829项不能计为本轮新全回归。

## 解析核验的范围

独立写出当前代码公式的链式导数，对比中心差分。仅支持当前采用的湿长类型1、折角湿润、纵倾及升力截断均未激活的内部光滑分支；其他分支明确拒绝，不静默用本公式代替。

令B为船宽、τ为纵倾弧度、z为代码中的重心相对水面高度参数、xG和zG为重心在船体坐标中的纵向及垂向位置。当前几何闭合为：

```text
Lk = xG + zG*cot(tau) - z*csc(tau)
xs = K/tau
lambda = (Lk - xs/2)/B
dLk/dz = -csc(tau)
dLk/dtau = -zG*csc(tau)^2 + z*cos(tau)/sin(tau)^2
dlambda/dz = (dLk/dz)/B
dlambda/dtau = (dLk/dtau + xs/(2*tau))/B
```

Lk是龙骨湿长，xs是龙骨与折角湿长差，λ是无量纲平均湿长，K是固定船宽及斜升角所决定的几何因子。这组关系只检查现有近似几何的导数，不证明它等于真实艇的三维几何。

以当前Savitsky型闭合定义：

```text
CL0 = tau_deg^1.1 * (0.012*sqrt(lambda) + 0.0055*lambda^2.5/FnB^2)
CLbeta = CL0 - 0.0065*beta_deg*CL0^0.6
Fz = (rho*U^2*B^2/2)*CLbeta
lcp = B*lambda*(0.75 - 1/(5.21*FnB^2/lambda^2 + 2.39))
M5 = Fz*sec(tau)*(lcp-xG)
```

CL0和CLbeta分别为零斜升角与实际斜升角的升力系数；斜升角beta和该经验式中的tau_deg以度为单位，而运动微分使用弧度，解析链式求导明确包含180/π的换算。ρ是水密度，U是相对水流速度，FnB是船宽弗劳德数，lcp是距艉的压力中心位置。恢复力为广义净载荷对升沉与纵摇角导数的负值，船重为常量，其导数为零。

三档扰动因子为1e-4、5e-5、1e-5；升沉步长为因子乘船宽，纵摇步长为因子弧度。矩阵先转到[升沉,L×纵摇角]的同量纲坐标，再乘B/船重进行无量纲比较。

## 这项通过不能解决什么

1. 原模型在规定平均姿态下仍有约16.3%、12.4%、7.7%船重的垂向载荷不足。求导一致不会修复平均载荷。
2. 无法证明采用该准静态恢复力与当前频率相关辐射、绕射内核组合后物理一致；这需要逐项理论及独立载荷证据。
3. 不能证明实际艇艏部修形、湿表面和牵引约束已经被表示，也不能据此排除这些因素对低速偏差的影响。

## 本地原文核对

重新阅读 `tmp/begovic_planing_regular_head_waves_2020.pdf`：第3页2.1节说明单斜升角艇艏部经过修形，并把详细几何指向参考文献30；第17页参考文献30为Begovic与Bertorello（2012），《Resistance assessment of warped hull form》，Ocean Engineering 56，28–42。第4页说明该论文数值计算允许升沉和纵摇两个自由度，但这不是原始水池牵引点或约束力矩的完整说明。

因此，不能从该2020论文的“两自由度自由运动”描述推断原试验不存在牵引力矩，也不能在现有模型中随意添加姿态相关补偿。下一步应核对原始几何及试验装置资料；当前仅确认有待核实的几何和约束差异，尚未确定它们分别解释多少误差。
