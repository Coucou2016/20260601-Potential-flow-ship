# 修正法向后控制面半径敏感性

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。**阶段未通过。**

## 目的与合同

在绕射法向错误已修正、整船三速度仍失败的情况下，核查独立Kang船型候选是否主要受人工控制面位置影响。使用船长3米、船宽0.3米、吃水0.1875米的已有参数化几何，船长弗劳德数0.2，无量纲遭遇频率3，321站位、64船体面元、完整历史及直面元解析积分。求解不读取参考响应。

| 项目 | 基准 | 扩大区域 |
|---|---:|---:|
| 控制半径 | 0.9米（3倍船宽） | 1.2米（4倍船宽） |
| 控制面面元 | 96 | 128 |
| 控制面平均弧长间距 | 0.029452米 | 0.029452米 |
| 每侧外自由面面元 | 44 | 62 |
| 外自由面间距 | 0.017045米 | 0.016935米 |

随区域增大同步增加面元，以免把明显变粗的空间离散混入域大小效应。这仍不是严格单变量实验：外自由面节点位置和数量不同；结论限定于近似保持分辨率的两区域比较。内自由面锚点、几何、物理工况、时间步、历史长度和积分设置不变。

## 实际结果

复数相对变化定义为“扩大区域载荷减基准载荷的复数模，除以基准载荷的模”。同时保存绝对差，避免只看幅值掩盖相位差。本次没有据此设置或通过新的验收门。

| 分量 | 升沉力复数变化 | 几何船中纵摇力矩复数变化 |
|---|---:|---:|
| 纯绕射 | 0.8235% | 1.3102% |
| 入射加绕射总激励 | 0.2200% | 0.2538% |

总升沉激励无量纲幅值从7.704469变为7.721328。进一步按固定空间导数作压力恢复后，分别为7.574386与7.591234。候选独立曲线约6.875294，仍未完成正式参考准入，且不提供复数相位。扩大区域没有消除该幅值差异；不能用更接近某条曲线为依据选择半径或压力算法。

扩大区域最大方程相对残差9.39e-16。原压力和积分载荷回放误差为零，相位回放约1.35e-16；这是代数一致性，不是物理验收。

## 结论与限制

本频率、这两个半径下的载荷变化较小，因而当前证据不支持把主要参考偏差单独归因于控制半径不足。不能据此排除其他频率的域依赖、共同的外域历史积分误差，或2.5D近似本身的适用性误差。

自由面新暴露节点的有界迁移仍未获物理验证。下一步应优先核查历史积分精度和接触处理，并完成独立复数参考准入；全交付频段八系数、复杂激励三档离散以及整船原合同仍必须单独完成。当前诊断不代替任何正式验收项。
