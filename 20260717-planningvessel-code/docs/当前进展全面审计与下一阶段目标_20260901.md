## 4. 总体判断与距离

项目已经越过“只有实施方案”的阶段，当前最可靠成果是可运行的软件骨架、线性高速2.5D水动力Gate 1、规则波若干数值一致性子门，以及日益完整的二维非线性诊断链。距离总体目标仍有六个连续验证层需要完成：二维入水物理门、规定横剖面水动力、整船规则波20/20、不规则波纵向统计、斜浪六自由度、多体与水翼扩展。

因此不采用主观完成百分比。准确表述应为：**框架覆盖较广，线性核心局部验证通过；整船纵向响应尚未全通过，非线性、多自由度和多船型生产级验证尚未完成。**

## 5. 下一阶段唯一目标

**保持线性2.5D Gate 1不退化，以冻结且不读取物理参考的数值路径先闭合12.25°，再连续推进并闭合10°、20°和30°二维恒速、无重力楔形入水的数值独立性与独立物理对照；禁止经验倍率、参考反演、选择性删点和事后移动门槛，最终使“二维入水先决门”具有方程、源码、测试、参考、不确定度和机器产物完整证据链，并由`FAIL`转为可一键复现的`PASS`。**

本目标是总体目标中非线性2D+t内核的必要前置条件，不扩张为整船规则波、不规则波或多体船验收。七项硬性条件见当前执行文件，必须全部通过，不能按平均分或多数项通过。

## 6. 完成后的固定顺序

1. Sun--Troesch横剖面规定升沉/纵摇水动力。
2. Begovic/Fridsma整船规则迎浪修正并达到Gate 2 `20/20 PASS`。
3. 不规则波纵向统计响应。
4. 斜浪六自由度响应。
5. 双体/三体干扰与连接载荷。
6. 水翼、附体及真实控制系统。

在二维入水机器验收清单明确为`PASS`之前，后续模块只能继续做准备性工作，不得宣布生产验证完成。
