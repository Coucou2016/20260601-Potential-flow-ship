必须交付：合法检查点链及外推资格审计、三角度二维楔形入水验证、Sun--Troesch 八系数验证、Begovic 三航速运动验证、Fridsma 加速度验证、公式--代码--测试--数据追踪表、与同一输入几何一致的三维船型视图、由计算时序直接驱动的三维升沉--纵摇动态可视化、一键复现命令、机器验收清单和阶段报告。

## 5. 完成判定

仅当八项条件全部通过，且机器清单同时给出 `Gate 1 = PASS`、二维先决门 `PASS`、`Gate 2 = 20/20 PASS`，本阶段才算完成。单个算例改善、代数残差很低、接口完成或回归测试通过，均不能替代独立物理验证。

本阶段只验收**小幅规则迎浪下的升沉、纵摇、响应相位及重心/艏部垂向加速度**；不规则波、其余自由度和其他船型按总体目标保留为后续阶段。
