# Gate 2：30°楔形物理约束多网格闭合与参考差异审计

日期：2026-08-28  
结论：**数值收敛子门 `PASS`；30°物理子门仍为 `FAIL`；二维楔形先决门和 Gate 2 总门状态不变。**

## 1. 审计目的

本审计检查30°恒速楔形入水候选是否同时满足：

1. 参考数据不进入求解；
2. 远端自由面不发生非物理下滑；
3. 运动学积分、根部匹配和三网格结果闭合；
4. 自由面、压力、峰值、峰位和积分力与独立文献相符；
5. 空间、远域和伪时间步结果稳定。

任何一项失败，都不把30°子门判为物理验证通过。

## 2. 方法修正

旧分支只固定远端半径，优化过程中远端高程可沿圆弧滑至负值，虽然运动学积分降低，但自由面变成非物理解。该分支已明确作废。

本轮实施以下修正：

- 固定最后两个远端节点，保持远端位置和正高程；
- 根部浅水射流匹配使用独立内迭代，容差为 `1e-4`；
- 采用80/160/320面板共同目标，所有网格共同改善才接受；
- 新增 `root_cosine_local` 紧支撑余弦基，在实际弧长网格上进行质量矩阵加权正交化；
- 残差支撑区由前10%扩展至前20%，因为残差下降后约14%迁移到第二个弧长分区；
- Sun 2007和Iafrati 2013数据仅在候选解保存后评分，所有求解摘要均为 `reference_used_during_solve=false`。

## 7. 最终判定

30°候选已经完成参考隔离下的数值闭合，空间、远域和时间步均为 `PASS`，自由面、压力、积分力和Iafrati标量均达到门槛。

但Sun 2007数字化压力峰位误差为 `6.1690%`，高于冻结的 `5%`。因此本审计只能给出：

> `30deg_numerical_convergence=PASS`，`30deg_physical_validation=FAIL`。

下一步应先确定峰位验收的参考优先级与不确定度规则，或取得更高精度的原始数值/试验曲线；在此之前不得宣布二维楔形先决门通过。
