## 已确认并修复的缺陷

原始 `pdstrip.f90` 第704—705行明确：`simqcd` 的附加列存储负右端项，求解的是矩阵乘源强加该列等于零。Python曾将该列直接传给 `numpy.linalg.solve`，使源强符号相反。现改为实际右端项 `-i*omega*dy`。这是线性方程接口修正，没有根据计算结果正负进行调整。

原始第619—622行在两个自由面离散结果求和时，将二分之一平均与半剖面镜像倍数2相消。Python外层实际取均值，因此每次半剖面力积分需要先乘2。现已补齐，保留严格模式的带符号原始系数及奇异求解报错。

## 剩余尾部问题已定位

剩余22条负阻尼全部位于纵向坐标约8.27—8.46米的尾部区域，即最后一个断阶之后。对粗纵向网格第40站（8.3185米）再冻结相同五周期作独立诊断，原始Fortran与Python均给出负阻尼。例如1.6秒时约为-737.859 kg/(m·s)，8秒时约为-2386.363 kg/(m·s)，两实现仍数值一致。

这证明在这组几何和离散条件下，剩余负阻尼不是上述移植符号错误继续存在。它尚不能区分几何离散、源点布置、自由面范围和近远场条件哪一项是根因。负阻尼不能截零或取绝对值，候选继续拒绝物理准入。

## 半剖面几何修复与复算

继续检查发现，尾部剖面是平底，多个点具有相同最大深度。旧 `_pdstrip_half_section` 使用 `argmax(depth)` 选取第一个最深点，它实际位于右舷底部；再强制将该点横坐标改为零，导致提取轮廓折返并跨过中线。原始Fortran对照也读取同一错误提取后的几何，所以此前两实现一致仅证明方程移植一致，不能证明输入几何正确。此前“可能为自由面离散”的原因尚属假设，现已取得更具体的几何缺陷证据。

修复后根据实际中线点截取；输入无中线顶点时在线段跨中线处插值，保留轮廓其余点，并拒绝跨中线的异常半剖面。新增平底含中线点/不含中线点测试，检查面积保持和轮廓单向性。没有改动原始浮筒型线、质量、姿态或验收阈值。
