# 隐式变化剖面实际绕射候选核查

## 结论

**已接通实际变化剖面匹配边界元的试验路线，但候选失败，总体阶段未完成。** 本轮不再使用单波数对角映射代替边界元：每站重新组装真实船体、自由面及控制面方程，保留控制面历史，联合求解新自由面状态与边界元未知量。

81 站因超出事先冻结的新露出区域延拓距离限制被拒绝；161 和 321 站完成求解但出现后半船状态异常增长。总升沉激励幅值分别约为 509.50、185.76，不能作为有效预测交付。没有按实验数据调参，也没有放宽限制或删除失效区域。

## 实现范围

使用 Kang 来源明确的解析型线、船长 3 m、船宽 0.3 m、吃水 0.1875 m、船长弗劳德数 0.2。只计算无量纲遭遇频率 3，非完整交付频段。几何中点用于原始纵摇广义力，不冒充已核实的试验重心。

船体 64 面元、固定控制面 96 面元，控制半径 0.9 m。自由面采用固定横向节点，水线以内节点裁去，内外区域每侧分别定义 20、44 个初始面元；实际有效自由面数量随站位变化。每站的矩阵和状态维数同步改变，控制面坐标及历史数组不重置。

入射势和绕射法向边界使用原直接激励约定；新时刻控制面历史与船体边界进入隐式耦合方程。每站在得到新自由面势后，重新组装原匹配方程核对，最大相对残差为 4.65×10⁻¹⁵ 以下。

为隔离改动，压力后处理保留原相位差分路线，没有同时加入曲面移动导数修正。这个保留项本身尚有前序记录的误差风险，不代表压力路线已得到独立验证。

## 新露出区域假设

本次明确选择 `limited_linear_unvalidated`：用同一舷水线附近两个旧自由面点，对势、波高及法向速度作单侧线性延拓。它是假设近水线状态足够光滑的数值闭合，不是已证明的物理接触线模型。

延拓距离以最近两个源点的间距衡量，上限在计算前冻结为 1。超限直接拒绝，不继续复制端点或自动缩放状态。该限制避免任意长距离外推，却不能保证模型正确或稳定。新接口测试只证明仿射场延拓正确、超限拒绝，不证明真实流场适用。

## 运行结果

| 离散 | 结果 | 补充证据 |
|---|---|---|
| 81 站 | 被拒绝 | x≈0.487502 m 处超出延拓距离；已完成 67 站，保存部分站位记录和失败原因 |
| 161 站 | 完成，但数值结果不合格 | 总升沉激励幅值 509.50；82 次新露出点访问，最大距离比 0.954 |
| 321 站 | 完成，但未收敛 | 总升沉激励幅值 185.76；82 次新露出点访问，最大距离比 0.707 |

细化后幅值降低不等于收敛。以 161 站整船复数载荷为分母，两档总升沉和总几何纵摇载荷变化分别约 133.46%、138.90%，相位变化不能被幅值下降掩盖。入射分量变化仅约 0.00383%、0.00860%，因此总差异主要位于绕射计算链。

## 前后半船定位

仅用于诊断，将纵向积分在几何中点分成两部分。正式载荷仍包含全船，没有通过改变积分区域改善分数。表 2 使用各区域 321 站复数载荷的模作为分母，与上一段整船比较分母不同，不直接比较两表百分数。

| 分量 | 前半船变化 | 后半船变化 |
|---|---:|---:|
| 入射升沉 | 0.0073% | 0.0073% |
| 入射几何纵摇 | 0.0084% | 0.0084% |
| 绕射升沉 | 0.808% | 350.70% |
| 绕射几何纵摇 | 1.008% | 351.82% |

船中附近自由面势、波高的离散范数在两档上相近；沿后半船、水线收缩和新区域露出过程，状态范数快速放大。321 站接近艉端时势范数约 3.55×10⁵、波高范数约 1.72×10⁶，显然不能解释为有效的单位波幅线性预测。

上述证据支持将后续诊断集中于新露出状态、迁移后法向速度与新剖面边界元的一致性，以及水线裁切的短面元影响。但这些因素尚未被逐个隔离，不能宣称已经唯一找到根因。

## 下一步

优先隔离水线收缩区的旧法向速度迁移和新边界元约束之间的一致性，再研究有明确假设的新露出状态闭合。所有候选必须事先注明变化项，保留全部结果，不能按整船响应挑选倍率或延拓方法。只有实际变化剖面载荷收敛后，才能继续多频率空间收敛及独立物理验证。

该试验路线没有替换生产默认路线。独立绕射相位、八系数全频段、Begovic 三速度、Fridsma 相位与加速度以及所有旧验收门槛仍未完成。
