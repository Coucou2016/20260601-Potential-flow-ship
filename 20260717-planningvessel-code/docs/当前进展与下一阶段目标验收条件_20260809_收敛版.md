# 当前进展与下一阶段目标验收条件

日期：2026-08-09  
适用范围：高速船型运动预报系统总体目标的下一阶段执行依据

## 1. 总体目标对齐

项目总体目标是：以高速滑行艇为核心，建立完整、可验证、可扩展的高速船型运动预报系统。系统最终应覆盖排水船型、半排水船型、滑行艇、单体船、多体船、三体船，并预留水翼船扩展；理论上以线性高速 2.5D 方法为当前核心，逐步扩展至非线性 2D+t 方法；输入应覆盖船型、质量惯性、航速、波浪、海流、风等参数；输出应覆盖不同航速下的六自由度运动响应和不规则波统计响应；验证上必须形成理论来源、程序实现、实验或文献对照、误差诊断和阶段报告的闭环。

下一阶段工作必须继续服务于这个总体目标，但不应盲目扩大功能范围。当前最关键的问题不是增加更多船型，而是先把线性高速 2.5D 核心水动力链条做实，使后续滑行艇运动预报、多体船扩展和非线性 2D+t 模型都有可信基础。

## 2. 当前进展核对

当前已经完成第一轮可扩展框架建设：

1. 已建立 `planing_seakeeping` Python 包和命令行入口，包含配置读取、船型几何、Savitsky/Faltinsen 稳态滑行平衡、波浪、求解器、六自由度统一输出、可视化和验证模块。
2. 已能读取示例配置并运行滑行艇规则波、不规则波算例，输出 `summary.csv`、`rao.csv`、`timeseries_*.csv`、`figures/*.png` 和 `run_report.md`。
3. 已建立文献与验证资料目录，包括 Faltinsen 第 9 章、Ma 2005、Fridsma、Katayama、Delft 372、ITTC 等资料的基准入口和部分数字化数据。
4. 已加入 Wigley III、SL-7、Fridsma、Katayama、Faltinsen Ch. 9、Delft 372 等验证层级，其中 Delft 372 片体 offsets 已具备重建基础，SL-7 和 C1 三体船真实 offsets 仍属于后续数据缺口。
5. 代码当前能通过 `planing_seakeeping/validation.py` 和 `tests/test_validation.py` 的语法编译；最近新增的 `pitch_m5_forward_speed_scale` 和 `B55` 阻尼来源诊断单元测试通过。

当前已经通过或基本稳定的部分：

| 验证项 | 当前状态 | 说明 |
|---|---:|---|
| numerical_sanity | PASS | 基础矩阵、时间步、谱收敛等数值检查已能运行并通过 |
| physical_trend_sanity | PASS | 波高响应、基本物理趋势等检查已通过 |
| section_bem_numerical_sanity | PASS | 二维截面边界元基础数值检查已通过 |
| 示例运动预报 | 可运行 | 能输出不同航速下规则波和不规则波响应，但仍依赖尚未完全硬验证的 2.5D 水动力链 |

当前最关键的未完成项：

Ma 2005 Wigley III 线性 2.5D 八个核心频域水动力系数尚未通过固定 Gate。当前 `outputs/gate1_linear_2p5d_hard_pass/results/ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 显示八个系数全部为 `FAIL`，因此当前不能宣称完整 2.5D 核心已经可信闭环。

| 系数 | 参考值 | 当前计算值 | 相对误差 | 容差 | 状态 |
|---|---:|---:|---:|---:|---|
| A33 | 1.000 | 10.186 | 9.186 | 0.15 | FAIL |
| B33 | 2.100 | 9.180 | 3.372 | 0.15 | FAIL |

| A55 | 0.063 | 0.160 | 1.537 | 0.15 | FAIL |
| B55 | 0.090 | 1.859 | 19.652 | 0.15 | FAIL |

已知诊断结论：

1. `A33/A53` 主要仍指向时间压力、体势尺度和纵向装配链条问题。
2. `B33/A35/B35` 主要仍指向零 `m3` 分布几何输运、Eq.31/Eq.32 前进速度项和端部项装配问题。
3. `A55/B55` 主要仍指向纵摇行广义力矩、压力梯度、Stokes 项、端部项和相位组合问题。
4. `pitch_m5_forward_speed_scale` 扫描只能改善部分纵摇项，不能闭合 `A55/B55` 成对验证。
5. `B55` 某些反事实分量缩放可以单独接近参考值，但不能同时闭合 `A55/B55`，因此不能作为默认模型修正。

## 3. 下一阶段唯一主目标

下一阶段主目标是：

完成线性高速 2.5D 核心水动力模型的 Gate 1 闭环，使 Ma 2005 Wigley III 八个核心频域水动力系数在固定验证入口下全部通过，并形成可追溯的公式链、诊断链、测试链和报告链。

本阶段只聚焦线性 2.5D 核心可信化。不把 SL-7、C1 三体船、Delft 372、多体船、非线性 2D+t 或水翼船作为主线开发对象；这些内容只允许作为资料整理、接口预留或后续验证层级准备。

## 4. 必须完成的工作

1. 固定 Ma 2005 Wigley III Gate 1 验证入口，保证同一命令、同一参考数据、同一输出目录能够复现实验结果。
2. 修正 `matched_bie_station_sweep` 默认链路中的公式、符号、相位、归一化、站位积分和端部项问题。
3. 分三组闭合八个核心系数：`A33/A53`、`B33/A35/B35`、`A55/B55`。
4. 对每一次默认路径修改给出理论来源和诊断证据，不允许只用经验缩放、符号翻转或后处理拟合通过 Gate。
5. 更新诊断 CSV、验证报告和阶段说明，使失败原因、修正原因、通过原因均可追溯。
6. 通过回归测试，并重新运行示例滑行艇规则波和不规则波运动预报。

## 5. 可验收条件

### 5.1 验证入口

必须提供一个固定、可重复运行的 Gate 1 验证入口。推荐命令为：

```powershell
python -m planing_seakeeping validate --benchmark all --reference-root benchmarks --out outputs\gate1_linear_2p5d_hard_pass
```

如果保留全量 `all` 验证入口导致非本阶段目标的 Fridsma、Katayama 或 SL-7 项仍处于待实现状态，则必须额外提供一个 Ma 2005 Wigley III 专用 Gate 入口，并在报告中明确写出命令、输出文件和判定规则。

### 5.2 八个核心系数全部通过

`outputs/gate1_linear_2p5d_hard_pass/results/ma2005_wigley_iii_coefficients_status_by_coefficient.csv` 必须满足：

1. `A33`、`B33`、`A35`、`B35`、`A53`、`B53`、`A55`、`B55` 全部为 `PASS`。
2. 对角项建议相对误差不超过 15%。
3. 耦合项建议相对误差不超过 30%。
4. 所有计算值不得出现 `NaN`、`Inf`、数值发散或空字段。
5. 通过结果必须来自默认模型路径，而不是诊断候选路径。

### 5.3 公式链可追溯

每个通过的系数必须能够追溯到明确公式链：

1. 截面边界条件。
2. 自由面 marching。
3. 压力公式。
4. 前进速度梯度项。
5. Stokes 或几何输运项。
6. 端部项。
7. 站位积分。
8. 整船矩阵装配。
9. Ma 2005 归一化方式。

报告中必须说明每个修正来自 Ma 2005、Faltinsen 或已登记文献中的哪一类理论依据；若属于程序实现错误修复，也必须说明错误发生在公式、坐标、符号、相位、单位、积分还是归一化环节。

### 5.4 诊断文件完整

至少应保留以下输出：

1. `ma2005_wigley_iii_coefficients_comparison.csv`
2. `ma2005_wigley_iii_coefficients_status_by_coefficient.csv`
3. `ma2005_wigley_iii_coefficients_eq30_component_contribution_audit.csv`
4. `ma2005_wigley_iii_coefficients_*summary.csv`
5. `validation_summary.csv`
6. `validation_status_by_benchmark.csv`
7. `validation_report.md`

对于仍未通过的中间诊断项，必须标注为诊断证据，不得混入默认模型验收结果。

### 5.5 测试通过

必须至少通过：

```powershell
python -m py_compile planing_seakeeping\validation.py tests\test_validation.py
python -m pytest -q
```

如全量测试因外部依赖或长耗时算例不能完成，必须在阶段报告中列明未运行的测试、未运行原因和已完成的替代验证命令。

### 5.6 示例运动预报可复现

1. `summary.csv`

### 5.7 阶段报告更新

必须更新一份阶段报告，至少包含：

1. 当前方法说明。
2. 参考数据来源。
3. 八个核心系数对照表。
4. 修正前后误差对比。
5. 关键诊断图表或 CSV 摘要。
6. 为什么当前结果合理。
7. 仍未解决的边界和后续扩展条件。

## 6. 阶段完成判定

只有当 Ma 2005 Wigley III 八个核心系数全部通过固定 Gate，并且公式链、诊断链、测试链、示例链和报告链均完整时，本阶段才算完成。

如果八个系数仍未全部通过，则本阶段状态为“线性 2.5D 核心水动力尚未闭环”。此时后续工作应继续围绕剩余失败系数做最小诊断和公式级修正，不应转向多体船、三体船、水翼船或强非线性 2D+t 主线开发。

## 7. 下一阶段出口

本阶段通过后，项目进入下一阶段：

线性 2.5D 运动响应验证阶段。

该阶段再重点处理 Faltinsen Ch. 9 响应曲线、Fridsma 规则波和不规则波运动响应、Katayama 跳跃/非跳跃分类、Delft 372 双体船验证入口，以及 SL-7 和 C1 三体船替代或真实几何数据问题。
