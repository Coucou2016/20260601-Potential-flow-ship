# Gate 2：14.0°多网格不等式闭合与空间收敛审计

日期：2026-08-27  
结论状态：**数值门槛与三层空间收敛通过；14.0°冻结为合格数值同伦源；独立物理验证仍为 FAIL；二维先决门和 Gate 2 总状态不变**

## 1. 目的与判定边界

此前14.0°候选虽已表现出稳定的空间趋势，但640面板精确运动学积分为 `1.013996e-3`，高于冻结门槛 `1e-3`，因此不能继续作为13.5°延拓源。本轮把640和1280面板的精确运动学积分同时写入多网格目标，把根部失配写为跨网格不等式约束，并在粗网格根约束轻微超限时执行一次显式可行性修复。

求解过程没有读取自由面、压力、载荷或整船试验参考，`reference_used_during_solve=false`。本审计只判定数值约束闭合、空间稳定和可复现性；由于14.0°仍无冻结权威物理参考，不能据此宣称自由面、压力或载荷获得物理验证。

冻结数值门槛为：640和1280面板精确运动学积分 `K<=1e-3`，320/640/1280面板根部相对失配均 `<=1e-3`，并通过三层同源空间收敛检查。

## 2. 方法增量

1. 在多网格诊断器中加入有界根主动集阻尼 Gauss--Newton 步，对1至6个根约束枚举自由、下界和上界状态，在可行主动集中选择线性化残差最小的步长。
2. 加入逐网格绝对目标上限：已满足门槛的网格不得退化到门槛之外，未满足网格必须单调改善。
3. 允许从已保存的低阶离散余弦变换雅可比前缀扩展更高模态，只重算新增列；源检查点、目标网格、权重、根网格和参考隔离状态必须完全一致。
4. 分离“线性根约束网格”和“非线性验收网格”，使320面板可作为修复约束，同时在320/640/1280三层执行最终硬验收。
5. 加入显式可行性修复模式。该模式只在源状态已有根门槛违规时启用，候选必须修复全部验证网格根约束，并继续满足绝对目标、条件数、位移、偶极系数和曲率限制；它不能用于一般目标退化的豁免。

这些增量只作用于参考隔离的二维数值诊断，不修改生产水动力方程，也不改变任何冻结物理验收阈值。

## 7. 结论

14.0°现已同时满足640和1280面板绝对运动学积分门槛、320/640/1280三层根部失配门槛及三层空间稳定性要求，因此可冻结为**合格数值同伦源**，并可用于13.5°的参考隔离延拓。

该结论不改变更高层级的物理状态：14.0°没有冻结权威物理参考，二维楔形入水先决门仍因10°和30°物理验证缺失而为 `FAIL`，Gate 2仍为 `17/20 PASS`。后续工作的优先级仍是补齐10°、20°、30°二维物理基准和 Begovic/Fridsma 整船独立验证，而不是把14.0°数值通过解释成物理正确。
