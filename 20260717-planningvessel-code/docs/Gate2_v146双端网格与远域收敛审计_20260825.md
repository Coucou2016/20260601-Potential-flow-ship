# Gate 2 v146 双端网格与远域收敛审计

日期：2026-08-25  
状态：**二维楔形入水先决门仍为 FAIL；Gate 2 仍为 17/20 PASS。**

## 1. 本轮问题

`v113` 的 Iafrati 方程（52）运动学积分量为 `K=0.00431682`。其中根部前两面板贡献 `54.18%`，远端八面板贡献 `23.30%`，而去除两端后的中段贡献已经低于总门槛。为判断该平台是否由端点空间离散造成，本轮实现并审计了根部和远端可独立控制的双端网格、远域半径扩展以及时间步收敛。

所有网格参数均为数值分辨率参数；求解和重网格不读取 Zhao--Faltinsen、Iafrati 或其他参考结果。参考数据仍只在计算完成后评分。

## 2. 实现内容

1. `SelfSimilarWedgeConfig` 新增默认关闭的 `double_ended` 网格模式，分别声明根部尺度比、远端尺度比和连续衰减指数；旧配置继续使用原单端几何网格。
2. 所有耦合伪时间重采样入口统一使用同一网格生成器，保证每个 Runge--Kutta 阶段之后仍保持声明的最终节点分布。
3. 检查点重网格支持改变远域半径。新增尾段保持原端点位置和斜率连续，并以指数形式逐渐趋向 Iafrati 方程（51），避免硬投影和强制拼接产生折角。
4. 新增机器审计 `analyze_self_similar_endpoint_convergence.py`，直接读取最终节点并核对实际面板长度分布；配置声明与最终节点不一致的运行不得进入最佳值或验收判断。
5. 网格、远域和时间步比较均在共同伪时间插值后计算，避免把不同演化时刻误当成离散误差。

## 3. 网格持久化缺陷及证据降级

初始实现只在检查点重建时采用双端分布，而耦合伪时间内部的第二个重采样入口仍使用旧几何分布。因而 `v126--v138` 中标记为双端网格的运行，在第一步后已经恢复为旧网格。机器审计通过最终节点发现这一矛盾，并将相关运行列为 `grid_contract_failed_runs`。

这些运行保留为实现缺陷诊断证据，但不得用于空间收敛或物理验收。修复后增加了直接检查最终首端、内部和末端面板长度的回归测试；`v139` 以后才是网格契约成立的双端分支。

## 6. 时间步与远域判定

`v143` 的 `CFL=0.25` 与 `v146` 的 `CFL=0.125` 在共同伪时间 `0.0104649` 处，`K` 分别为 `0.00361660` 和 `0.00361896`，相对差为 `0.065%`，通过 `<=5%` 的时间步变化标准。

等面板密度远域序列 `R=20/24/28` 在共同伪时间比较时，相邻 `K` 变化约为 `24.9%` 和 `62.3%`，均远高于 `5%`。远域扩大后误差上升，而船体压力和参考自由面误差近似不变，表明未松弛尾段和远边界匹配仍是独立问题；本轮不能宣称远域收敛。

## 8. 下一最小闭环

1. 将双端固定分布升级为守恒监视量重分布：联合使用 `S_nu^2 Delta s`、几何曲率和相邻面板增长率，并限制每次节点移动，避免把远端收益转移成中段误差。
2. 对匹配根前两面板输出线性单元端点法向导数，采用单元内解析积分重构方程（52），区分真实运动学误差与中点采样误差。
3. 远域序列必须分别松弛到同一伪时间和同一四步相位，再判断 `R=20/24/28`；未经松弛的渐近尾段不得用于验收。
4. 只有 `K<=0.001`、自由面误差 `<=5%`、压力相关指标继续通过且最后两级网格、远域和时间步变化均 `<=5%`，20 度算例才可转为 PASS。
