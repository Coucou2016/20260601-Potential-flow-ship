# 绕射站位与离散审计

本记录接续《直接激励核验与阶段推进记录》，不改变总体目标或原实验门槛。

## 新证据

### 1. 纵摇力矩参考点变换

对三个速度各取冻结列表的第5个频率，保持船体几何和物理入射波不变，将力矩参考点向艏移动0.1倍船宽。若新参考点处的波相位重新归零，独立力学关系为：

```text
F_new = exp(-i*k*d) * F_old
M_new = exp(-i*k*d) * (M_old - d*F_old)
```

其中F为升沉力复幅值，M为艏抬正向纵摇力矩复幅值，d为向艏参考点位移，k为波数。指数项只改变波浪参考相位；减去dF是力矩平移的几何关系，不依赖某种绕射求解模型。

入射、绕射、合计三个分量，截断前后两种处理，升沉与纵摇两个结果，共36项检查全部通过。绝对容差1e-8，附加相对容差1e-8，求解前冻结。

**这一结果证明指定工况下的力矩搬移和相位适配一致，不证明绕射边界值问题的物理准确性。**

证据：`outputs/excitation_station_balance_20260921_v2/contract.json`、`origin_checks.csv`、`station_loads.csv`、`results.json`。

### 2. 艉部截断对纵摇激励的影响

同一频率处，按原路线的0.5倍船宽艉部硬截断，计算“截断后合计复数载荷的模 / 截断前合计复数载荷的模”：

| 船宽弗劳德数 | 升沉力幅值保留比例 | 纵摇力矩幅值保留比例 |
|---|---:|---:|
| 1.67 | 91.62% | 80.79% |
| 2.26 | 91.16% | 70.53% |
| 2.82 | 82.51% | 42.46% |

这是复数积分后得到的比例，不是逐站幅值求和。该处理对高航速纵摇力矩影响较大，值得作为独立物理核查对象。不能由此推断取消截断一定正确，更不能按实验响应调截断长度。三个速度此处各只有一个频率，不能把表中比例推广为全频段规律。

证据：同目录 `integrated_components.csv`。单位波幅升沉力的单位为N/m，单位波幅纵摇力矩为N；站位密度额外除以纵向米数。

## 三档离散审计的协议修正

采用15/29/57站，船体面元24/36/48，内自由面面元12/18/24，外自由面面元24/36/48。每速度原有8个交付频率全部直接求解，不用响应插值代替本次收敛计算。

首次运行发现内核默认历史缓存40步。在57站细网格中，缓存可能在艉部丢弃早期站位历史；此时网格加密同时改变物理记忆范围，不能视作干净的离散收敛检验。已主动停止该未完成运行，保留部分输出，不计作完成或通过。

修正后的审计把历史长度显式设为64步，覆盖最细网格全部上游站位，辐射和直接激励使用同一组历史设置。默认生产参数仍保留旧值，不无声改写历史结果。历史谱积分点数32、截断波数25和控制域仍固定，因此本轮即使通过，也不能替代它们各自的独立收敛。

对八系数和两个复数激励逐项检查。按船长、船宽、密度和重力构造量纲尺度；无量纲量低于0.02时使用绝对容差0.001，否则采用细两档差异5%。这些新离散判据在本轮求解前冻结，不修改原实验误差门槛。

修正后输出：`outputs/longitudinal_fullband_grid_history64_20260921`。最终状态以该目录完整 `results.json` 为准，部分CSV不得替代完成证据。

本次只有8个交付频率点/航速，覆盖原24工况，不等同于连续频域上的收敛，也不完成主峰密集扫频。通过数只是诊断摘要，正式判据仍要求全部逐项通过。

源文件摘要、完整无量纲数值、逐项差异/容差及分量计数分别保存在 `source_hashes.json`、`dimensionless_coefficients.csv`、`fine_grid_checks.csv`、`component_pass_counts.csv`。此次调用直接在24频率求解，不与前轮插值响应结果混称同一数据集。

软件回归：795项测试、11项子测试通过，保留1247条既有空切片均值警告。随后新增的历史参数传递断言已单独复跑所在18项测试，全部通过；未把软件通过视为物理通过。
