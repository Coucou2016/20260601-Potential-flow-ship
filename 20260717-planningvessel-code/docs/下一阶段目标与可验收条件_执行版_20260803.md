# 下一阶段阶段目标及可验收条件：线性 2.5D 核心硬验证执行版

日期：2026-08-03

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》。

总体目标是建立覆盖排水船型、半排水船型、高速滑行艇、多体船、三体船并可扩展至水翼船的统一运动预报系统。下一阶段不继续扩大功能范围，而是优先把高速单体船线性 2.5D 核心水动力模型做成可信、可验证、可复现的默认基础。

只有线性 2.5D 核心通过硬基准验证后，后续非线性 2D+t、多体船、三体船和水翼扩展才有可靠根基。

## 2. 阶段目标

完成高速单体船线性 2.5D matched-BIE 核心模型的硬验证闭环。

具体目标是：以 Ma 2005 Wigley III 八个升沉/纵摇水动力系数为硬基准，闭合线性 2.5D 方程链、参考数据链、默认代码路径和运动预报输出链，使当前原型从“可运行、可诊断”推进到“可作为后续扩展基础的可信核心求解器”。

本阶段重点通过以下八个系数验证：

| 系数 | 含义 |
|---|---|
| `A33` | 升沉附加质量 |
| `B33` | 升沉阻尼 |
| `A35` | 纵摇对升沉力的附加质量耦合项 |
| `B35` | 纵摇对升沉力的阻尼耦合项 |
| `A53` | 升沉对纵摇力矩的附加质量耦合项 |
| `B53` | 升沉对纵摇力矩的阻尼耦合项 |
| `A55` | 纵摇附加惯量 |
| `B55` | 纵摇阻尼 |

## 3. 必须完成的工作

1. 固定 Ma 2005 Wigley III Gate 1 参考数据，明确每个系数的频率、数值、来源、归一化方式和误差边界。
2. 修正默认 `matched_bie_station_sweep` 路径中的线性 2.5D 方程链，包括时间压力项、前进速度压力梯度项、固定控制面几何输运项、端部项和纵摇力矩装配。
3. 保持示例滑行艇配置可运行，能够输出规则波和不规则波下的六自由度时域响应、响应幅值算子、垂向加速度和统计结果。
4. 保持所有候选模型为 diagnostic-only，未通过硬验证前不得接入默认路径。
5. 更新阶段报告，说明公式来源、代码位置、验证命令、对照结果、剩余风险和下一步工作。

## 4. 本阶段不做的事

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现生产级双体船、三体船共同边界积分模型。
3. 不实现生产级水翼、压浪板和控制系统模型。
4. 不用经验缩放、曲线拟合、最终系数 delta 或按参考值反推来制造通过。
5. 不把 SL-7、C1 三体船或替代几何作为本阶段硬通过依据；它们只作为后续扩展验证数据储备。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 参考数据 | 生成或固定 `wigley_iii_gate1_reference.csv`，每行包含系数名、频率、参考值、来源、单位/归一化方式和说明。 |
| 默认路径 | 验证结果中的八个系数均来自 `matched_bie_station_sweep` 默认路径，不依赖手动候选开关。 |
| 八系数硬通过 | `A33/B33/A35/B35/A53/B53/A55/B55` 在对照表中全部为 `PASS`。 |
| 方程链闭合 | 时间压力尺度、zero-`m3` 固定控制面几何输运、pitch row moment chain 均有审计表，结论为通过或等价闭合。 |
| 候选隔离 | 所有未进入默认路径的候选均标注为 diagnostic-only，并说明未采用原因。 |
| 运动预报 | 示例配置可生成 `summary.csv`、`rao.csv`、各航速时序 CSV、图像和报告。 |
| 六自由度输出 | 时序结果包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave`、`pitch` 和垂向加速度，其他自由度注明对称性假设。 |
| 不规则波 | 固定随机种子下，不规则波时域响应、均方根值、峰值和谱相关结果可复现。 |
| 数值稳定 | 验证结果、运动结果和关键矩阵无 `NaN`、`Inf` 或非物理发散。 |
| 自动测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 阶段报告包含目标、方法、公式来源、代码修改点、验证结果、失败项变化、残余风险和下一阶段建议。 |

## 7. 完成判定

本阶段完成的判定标准是：Ma 2005 Wigley III 八个水动力系数全部通过硬验证，示例运动预报链路稳定可运行，完整测试集通过，且阶段报告能够解释每个关键修正的理论来源和验证证据。

若八个系数未全部通过，本阶段不得标记为完成；只能记录为“已压缩到明确理论或数据缺口”，并列出继续推进所必需的资料、公式或验证对象。
