# Gate 2 v182 喷射根部双节点与速度恢复审计

日期：2026-08-25  
结论：**二维楔形入水先决门仍为 FAIL；Gate 2 仍为 17/20 PASS。**

## 1. 审计问题

`v143` 的连续线性边界元在浅水射流自由面与外自由面交界处形成约 `37.4 deg` 的几何尖角。两侧均为 Dirichlet 边界，势函数连续，但法向不同，因此同一几何节点应允许两个法向导数。共享一个法向导数会把两个物理通量压成同一未知量。

本轮分别回答三个问题：

1. 双节点边界积分方程是否实现正确？
2. 有限网格改善是否能延续到空间极限？
3. 自由面两侧的切向梯度和根部伪速度是否应随双节点同时切换？

参考曲线仍只用于求解完成后的评分，不进入边界方程、时间推进、网格、停止条件或分支选择。

## 2. 实现与独立正确性检查

连续线性边界元新增任意面板内场点影响行。喷射根部共享配点被移除，并在相邻两面板距角点各 `L/3` 处建立两个位移配点；角点两侧分别保留法向导数未知量。该做法与双 Dirichlet 角点的经典双节点/位移配点处理一致：

- [Grilli et al. 1990](https://doi.org/10.1016/0955-7997(90)90004-S)
- [Why use double nodes in BEM?](https://doi.org/10.1016/0955-7997(91)90060-7)
- [Multiple-flux BEM, JCP 2009](https://doi.org/10.1016/j.jcp.2009.04.012)

制造解采用封闭方形域的调和势 `phi=y` 和 `phi=z`。两种势在角点具有解析双值法向通量；新位移行恢复误差约为 `1e-14`，并保持常势恒等式 `H*1=0`。这证明矩阵装配和双通量未知量本身正确，但不证明楔形自由面已物理收敛。

## 3. 冻结几何的共享节点/双节点比较

源检查点均为 `v143`，外自由面 `N=80`、`R=20`，几何、势、根状态和参考隔离完全相同。

| 指标 | 共享节点 | 位移双节点 | 变化 |
| --- | ---: | ---: | ---: |
| 中点 `K` | 0.00361660 | 0.00404102 | 不宜作为验收量 |
| 线性单元精确 `K` | 0.00920229 | 0.00754262 | 改善 18.0% |
| 端点梯度贡献 | 0.00558568 | 0.00350160 | 改善 37.3% |
| 条件数 | 43806.5 | 49018.2 | 增加 11.9% |
| 根部两侧法向导数 | `3.387/3.387` | `2.672/4.636` | 双侧通量被解析 |

双节点在有限网格上确实降低根部端点梯度误差，压力峰值、积分力和偶极系数几乎不变。因此它是有理论依据的离散修正，而不是结果调幅。

## 4. 冻结空间序列

| 外自由面面板数 `N` | 双节点精确 `K` | 相邻变化 | 条件数 |
| ---: | ---: | ---: | ---: |
| 80 | 0.00754262 | - | 4.902e4 |
| 120 | 0.00593907 | 27.0% | 8.77e4 |
| 160 | 0.00540382 | 9.90% | 1.335e5 |
| 240 | 0.00503183 | 7.39% | 2.424e5 |

最后两级变化仍大于 `5%`。仅作诊断的无约束拟合 `K(N)=K_inf+cN^{-p}` 给出 `p≈2.12`、`K_inf≈0.00476`；共享节点序列给出 `p≈1.99`、`K_inf≈0.00471`。两种极限估计相差约 `1%`，却都约为验收阈值 `0.001` 的 4.7 倍。该外推不是验收证据，但说明双节点主要修复有限网格尖角误差，并未消除中段运动学平台。

`N=240` 双节点结果中，根部前 `2` 个面板贡献 `37.85%`，前 `16` 个面板贡献 `59.39%`，去掉两端各 `16` 个面板后的中段仍贡献 `37.07%`。因此后续不能只继续局部加密喷射根部。

## 5. 三种速度恢复模式

双节点边界方程与自由面速度恢复现已完全解耦：

| 模式 | 切向梯度 | 根部伪速度 | 定位 |
| --- | --- | --- | --- |
| `connected_average` | 跨浅水/外自由面连接恢复 | 两侧长度加权平均 | 默认旧基线 |
| `split_average` | 在尖角处分开恢复 | 两侧长度加权平均 | 实验诊断 |
| `split_outer_side` | 在尖角处分开恢复 | 外自由面侧通量 | 实验诊断 |

三组均从同一 `v143` 检查点出发，固定每侧 `256` 个浅水射流边界元并推进四步：

| 模式 | `K` 历史末值 | Zhao 自由面误差 | 压力曲线误差 | 根匹配误差 |
| --- | ---: | ---: | ---: | ---: |
| `connected_average` | 0.00625636 | 11.148% | 2.622% | 1.12% |
| `split_average` | 0.00548119 | 11.148% | 1.618% | 4.28% |
| `split_outer_side` | 0.00715325 | 11.148% | 2.819% | 1.74% |

`split_outer_side` 的 `K` 为 `0.007544 -> 0.008091 -> 0.006292 -> 0.006682 -> 0.007153`，明显非单调，予以拒绝。`split_average` 四步连续下降，故继续到累计 32 步。

## 6. 长时反证

`split_average` 在 32 步末得到：

| 指标 | 数值 | 门槛/判定 |
| --- | ---: | --- |
| 最终精确 `K` | 0.00513885 | `>0.001`，FAIL |
| 最近最低 `K` | 0.00506869 | `>0.001`，FAIL |
| 最近周期相对范围 | 5.00% | 未形成稳定平台 |
| 根匹配误差范围 | 约 0.30%--4.74% | 周期摆动 |
| Zhao 自由面误差 | 11.09% | `>5%`，FAIL |
| 压力曲线误差 | 1.584% | PASS |
| 压力峰值/峰位误差 | 0.096% / 0.643% | PASS |

在与旧 `connected_average` 长算接近的伪时间 `0.0241/0.0246`，两者 `K` 分别约为 `0.005102/0.005110`，差异约 `0.16%`。短时优势最终消失，说明切断切向恢复改善了压力重构，却没有改变运动学长期极限。机器分类仍为 `DESCENDING_NOT_CONVERGED`，物理状态为 `FAIL`。

## 7. 分支判定

1. `displaced_double_node`：保留为显式、未验证的边界积分候选；它有制造解和有限网格改善证据，但空间极限未通过。
2. `connected_average`：继续作为默认回归基线，保证历史行为不被静默改变。
3. `split_average`：保留为压力/运动学分离诊断，不升级为默认或验收分支。
4. `split_outer_side`：四步非单调，拒绝作为推进分支。
5. 所有收敛分析按尖角处理和速度恢复模式分组；不同算法不得伪装成网格相邻层级。

## 8. 下一主线

双节点、局部根部速度和固定边界元拓扑均不能解释约 `K=0.005` 的长期平台。下一步应转向**中段自由面运动学与浅水--外域匹配条件的弱式一致性**：

1. 将精确 `K` 分解为浅水根邻域、匹配过渡区、中段和远域，锁定中段主模态。
2. 对外自由面运动学采用面板积分/弱式残差，而不是对端点残差事后平滑。
3. 检查势的时间/相似导数在浅水域与外域交界处是否满足同一材料导数约定。
4. 只有三角度 `K<=0.001`、自由面误差 `<=5%`、压力和积分力门槛及收敛门全部通过，才可解除二维先决门。
