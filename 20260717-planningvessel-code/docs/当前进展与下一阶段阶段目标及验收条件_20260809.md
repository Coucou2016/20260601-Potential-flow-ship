# 当前进展与下一阶段阶段目标及验收条件

日期：2026-08-09  
对应总体目标：《高速船型运动预报系统总体目标》

## 1. 当前进展

当前项目已经完成第一轮基础建设，具备“可运行、可测试、可诊断、可继续扩展”的研究框架，但尚未完成总体目标中最关键的“完整 2.5D 运动预报模型可验证闭环”。

已完成内容如下：

1. 已建立 `planing_seakeeping` Python 包、命令行接口、配置读取、规则波/不规则波、频域响应、时域响应、六自由度统一输出、图表和报告输出链路。
2. 示例滑行艇算例可运行，可生成 `summary.csv`、`rao.csv`、时域结果、图像和 `run_report.md`。
3. 文献与验证体系已接入 Faltinsen、Ma 2005、Journee、Fridsma、Katayama、Delft 372、ITTC 等来源。
4. `numerical_sanity`、`physical_trend_sanity`、`section_bem_numerical_sanity` 已通过，说明基础矩阵、响应趋势、二维剖面边界元数值链路具备可用性。
5. 已建立大量 Gate 1 诊断输出，能够追踪压力恢复、前进速度项、自由面推进、端部项、纵摇力矩、复数相位和无量纲化等问题来源。
6. 阶段报告、理论公式整理、总体目标文件、下一阶段目标文件和科研报告输出链路已经形成。

当前主要缺口如下：

1. Ma 2005 Wigley III 八个核心水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 仍未通过硬验证。
2. 最新固定 Gate 1 验证中，`ma2005_wigley_iii_coefficients` 仍为 `FAIL`，八个目标系数当前为 `0/8 PASS`。
3. `ma2005_sl7_coefficients` 仍因 SL-7 数字型线/可用参考曲线不足处于待补充状态。
4. Katayama 定性趋势中仍有若干失败项，说明现有线性模型尚不能完整表达跳跃、非线性峰值移动等强非线性现象。
5. 强非线性 2D+t、多体船共同边界积分、三体船干扰、水翼控制模型目前仍属于后续扩展方向，不能视为已完成生产级模型。

阶段定位：

当前系统应定义为“高速船型运动预报研究框架 v1”，而不是“已完成验证的完整运动预报系统”。下一阶段必须继续集中解决线性 2.5D 核心水动力硬验证问题。

## 2. 下一阶段阶段目标

下一阶段目标：

**完成线性高速 2.5D 核心水动力模型 Gate 1 验证闭环，使 `matched_bie_station_sweep` 默认路径从可运行、可诊断推进到可验证、可解释、可复现。**

具体说，就是以 Ma 2005 Wigley III 为硬验证对象，在不使用经验缩放、不按参考值反推、不把诊断候选路径混入默认生产路径的前提下，修复或封口八个核心频域水动力系数：

```text
A33, B33, A35, B35, A53, B53, A55, B55
```

一句话目标：

> 把当前线性 2.5D 主线从“研究诊断框架”推进为“可支撑后续滑行艇、非线性 2D+t、多体船和水翼扩展的可信核心内核”。

## 3. 本阶段工作范围

本阶段必须完成：

1. 固定 Ma 2005 Wigley III 八系数为唯一硬验证对象。
2. 固定 `matched_bie_station_sweep` 为默认生产路径。
3. 审计并修正时间压力项、前进速度压力梯度项、自由面推进、固定控制面边界、船体边界、端部项、纵摇力矩、复数相位和无量纲化链路。
4. 保持示例滑行艇规则波、不规则波、六自由度输出链路可运行。
5. 更新验证 CSV、图表、Markdown 阶段报告和必要的测试用例。

本阶段暂不展开：

1. 不开发生产级强非线性 2D+t 自由面边界元模型。
2. 不开发生产级双体船、三体船共同边界积分模型。
3. 不开发生产级水翼、压浪板和控制器模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过对象。
5. 不用经验拟合或最终系数缩放制造通过结果。

## 4. 完成验收条件

只有同时满足以下条件，才可判定下一阶段“完成”：

| 编号 | 验收项 | 必须满足的条件 |
|---|---|---|
| 1 | 默认路径 | 八个核心系数均由 `provider_route == matched_bie_station_sweep` 或等价默认生产路径直接计算得到。 |
| 2 | 八系数硬通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`。 |
| 3 | 误差门槛 | 八个系数的 `gate_error_ratio <= 1.0`，不得只报告平均误差或局部通过。 |
| 4 | 公式可追溯 | 频率、坐标、符号、边界条件、端部项、力矩臂、相位和无量纲化必须在阶段报告中逐项说明来源。 |
| 5 | 禁止经验污染 | 所有候选缩放、拟合、经验修正必须保持诊断状态；未被理论链路证明前不得进入默认路径。 |
| 6 | 数值稳定 | 验证输出、响应计算和示例运行不得出现未解释的 `NaN`、`Inf`、空表或奇异矩阵错误。 |
| 7 | 示例链路 | `configs/example_planing.yml` 可运行，并生成 CSV、图像和 `run_report.md`。 |
| 8 | 六自由度输出 | 时域输出必须包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 与垂向加速度，其余自由度明确标注假设。 |
| 9 | 不规则波复现 | 固定随机种子下，不规则波时域响应的均方根、峰值和统计输出可复现。 |
| 10 | 自动化测试 | `python -m pytest -q` 全部通过；如未运行完整测试，必须记录原因和补跑计划。 |
| 11 | 阶段报告 | 阶段报告必须包含代码改动、公式依据、验证命令、八系数对照、失败项解释、候选排除和剩余风险。 |

## 5. 封口判定

如果下一阶段仍未达到八系数全部 `PASS`，则不能判定为“完成”，只能判定为“Gate 1 缺口封口”。封口必须同时满足：

1. 明确指出失败来源属于公式实现、参考数据缺失、文献歧义、几何输入不足或数值离散限制中的哪一类。
2. 给出每个失败系数的误差来源拆解，而不是只给最终误差。
3. 所有可疑候选路线均有诊断记录，并明确是否排除。
4. 默认路径未被经验拟合、缩放补偿或参考值反推污染。
5. 下一步需要补充的资料、推导或代码改动明确到文件、公式或模块。

封口状态可以作为后续研究决策依据，但不能作为“线性 2.5D 核心已验证通过”的完成证明。

## 6. 下一阶段完成后的推进方向

只有当 Gate 1 完成验收通过后，才进入下一层扩展：

1. 接入 Fridsma 规则波/不规则波滑行艇运动与加速度对照。
2. 接入 Katayama 非线性跳跃与峰值移动验证。
3. 开始 Sun-Faltinsen 型非线性 2D+t 模型原型。
4. 开始 Delft 372 双体船共同边界积分验证路线。
5. 补充 SL-7、C1 三体船或可替代公开型线数据。
6. 预留水翼、压浪板和控制器接口，但不提前声明完成。
