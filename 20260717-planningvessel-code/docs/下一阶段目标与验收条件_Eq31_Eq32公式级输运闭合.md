# 下一阶段目标与验收条件：Eq.31/Eq.32 公式级输运闭合

日期：2026-08-02

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》，目标不是继续扩大功能范围，而是把线性高速 2.5D 核心从“程序可运行、链路可测试”推进到“关键公式可解释、核心算例可验证”。

上一阶段已经完成配置读取、运动预报链路、结果输出、可视化、测试体系和 Ma 2005 Wigley III 系数验证框架；但当前 Ma 2005 八个水动力系数只有 `B53` 通过硬门槛，`A33、B33、A35、B35、A53、A55、B55` 仍未通过。因此下一阶段的核心任务必须集中在 2.5D 公式级闭合，而不是进入非线性 2D+t、多体船或水翼扩展。

## 2. 阶段目标

建立并验证 Ma-Duan-Song 型线性高速 2.5D 求解器的公式级输运闭合诊断，使 `Eq.31/Eq.32` 中站位输运、法向变化、边界项、端部项和整船装配之间的关系可追溯、可量化、可复现；在此基础上推动 Wigley III 八个水动力系数达到可验收精度，或给出明确的剩余误差来源排序。

更具体地说，本阶段要把上一阶段发现的 `m3 = 0` 但 `d(N3 ds)/dx` 非零现象，从“系数层修正候选”推进为“公式层输运恒等式候选”。只有当公式来源、离散项、符号、单位和整船装配全部闭合后，才允许进入默认求解路径。

## 3. 工作范围

1. 实现 `Eq.31/Eq.32` 公式级输运诊断，分解站位间法向变化、面元长度变化、力臂变化、端部项、边界代理项、内域分布项和剩余项。
2. 对 `B33、A35、B35` 建立零 `m_i` 行的公式级闭合表，判断上一阶段 `add_full_zero_m3_transport` 候选为何只改善但不能完全通过。
3. 对 `A33、A53` 建立时间压力项、自由面势、船体势和前进速度梯度项来源诊断。
4. 对 `A55、B55` 建立纵摇行的 `N5/m5`、力臂、端部矩、压力矩和整船装配诊断。
5. 输出所有候选公式对 Ma 2005 八个系数的影响表，但在八个系数全部满足硬门槛前，候选公式不得污染默认生产路径。
6. 保留现有运动预报演示链路，作为程序完整性验证；但在 Gate 1 未通过前，不把运动响应结果宣传为已验证物理预报。

## 4. 暂不纳入本阶段

1. 不实现生产级非线性 2D+t 自由面边界元求解器。
2. 不实现双体船、三体船完整共同边界积分和湿甲板拍击。
3. 不实现水翼控制系统和水翼-船体耦合。
4. 不通过经验比例系数、人工拟合因子或只在最终系数上加差值来通过验证。

## 8. 合格结果定义

本阶段有两种合格结局。

第一种是理想结局：Ma 2005 Wigley III 八个水动力系数全部通过硬门槛，公式级诊断无未解释主导残差，候选公式进入默认 `matched_bie` 路径。

第二种是阶段封口结局：八个系数尚未全部通过，但每个失败项都有明确误差来源排序、方程位置、影响幅度和下一步数据需求；所有不可靠候选保持诊断状态，默认运动预报链路不被经验修正污染。该结局仍可验收，因为它把问题从“结果不合理”推进为“具体公式项和离散项待解决”。
