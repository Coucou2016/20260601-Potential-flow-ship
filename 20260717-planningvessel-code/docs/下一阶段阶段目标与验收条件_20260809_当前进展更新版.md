## 2. 下一阶段阶段目标

完成线性高速 2.5D 核心水动力模型的 Gate 1 验证闭环。

具体目标是：在不进行经验拟合、不按参考结果反推系数、不污染默认生产路径的前提下，修复或封口 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 算例中的八个核心频域水动力系数计算链，使 `A33/B33/A35/B35/A53/B53/A55/B55` 达到可验证、可解释、可复现的状态。

优先目标：八个系数全部通过 Gate 1。  
最低可接受目标：若阶段内不能全部通过，则每个失败系数必须被封口到明确的理论、数据、几何、频率、坐标、归一化、自由面、压力恢复、端部项或力矩装配缺口，并给出证据文件和下一步所需条件。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线，推进为“可硬验证、可解释、可作为后续非线性和多船型扩展基础”的核心模型。

## 3. 本阶段范围

纳入本阶段：

1. Ma 2005 Wigley III 八系数硬验证。
2. Journee 1992 同频复数力辅助验证。
3. `matched_bie_station_sweep` 默认路径修复。
4. A33/A53 的体势、时间压力和频率响应链检查。
5. B33/B35/B53/B55 的前进速度梯度、端部项、阻尼和相位链检查。
6. A35/A55 的纵摇力矩、力臂、坐标原点和装配链检查。
7. 示例滑行艇 RAO、规则波、不规则波、六自由度输出链保持可运行。
8. 自动化测试、验证输出和阶段报告同步更新。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元模型。
2. 不开发生产级双体船、三体船共同边界积分模型。
3. 不开发生产级水翼、压浪板和控制器模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过对象。
5. 不用经验倍率、最终系数拟合或参考曲线反推制造通过结果。

## 4. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数必须由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| Gate 1 通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 失败封口 | 若未全部通过，每个失败系数必须有明确缺口分类、审计表、证据文件、不能通过的原因和下一步所需资料或推导条件。 |
| 候选隔离 | 未通过八系数硬门槛的候选路线必须保持 `candidate_default_gate_eligible=false`，不得进入默认结果。 |
| 参考闭环 | Ma 2005 / Journee 1992 的频率、单位、坐标、符号、无量纲化、数字化来源和取舍理由必须写入阶段报告。 |
| 公式链审计 | 时间压力、前进速度压力梯度、固定控制面输运、端部项、纵摇力矩和归一化链必须有独立审计输出。 |
| 数值质量 | 验证输出、矩阵、响应幅值算子、时域响应和统计结果不得出现 `NaN`、`Inf`、空表或无法解释异常值。 |
| 运动链保持 | `configs/example_planing.yml` 必须可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时域结果必须包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度必须标注模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波响应的均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过；若未完整运行，必须记录未运行原因、已运行测试和补跑计划。 |
| 固定命令 | 固定验证命令、示例运行命令和测试命令必须可复现运行，输出路径和关键字段保持稳定。 |
| 阶段报告 | 更新阶段报告，包含公式依据、代码改动、验证命令、八系数对照、失败封口、候选排除、剩余风险和下一步建议。 |
