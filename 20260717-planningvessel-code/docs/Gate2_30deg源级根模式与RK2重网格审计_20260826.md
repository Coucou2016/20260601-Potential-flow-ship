# Gate 2：30° 源级根模式与 RK2 重网格审计

日期：2026-08-26  
结论状态：**二维楔形先决门仍为 FAIL**

## 1. 审计目的

本审计解释 30° 恒速楔形入水为何能开始耦合伪时间推进、又为何尚不能通过 Gate 2 的二维先决门。审计只使用方程、离散解和冻结参考数据进行事后评价；参考曲线未进入求解、停止条件或参数标定。

## 2. 原始方法判读

Iafrati 2013 第 9--10 页式（32）使用完整伪速度梯度 `∇S` 推进自由面；法向分量决定形状收敛，但切向分量仍属于拉格朗日节点运动。第 11 页以自由面和艇体之间的夹角作为主体流--薄射流截断判据，要求截断处保持有限夹角，未规定主体自由面首面板沿艇体切向的投影必须为正。第 12--13 页式（38）至式（46）给出薄射流浅水 marching，并明确第一个 marching 点的全部量来自边界积分表示；空间步长取邻接射流首个自由面面板长度的一半。第 14 页说明浅水区随后纳入边界积分边界，用于重算艇体势和获得平滑压力。

原文没有定义或要求附加边界积分固定点 `F(S_lambda)=S_lambda`。因此：

- 主体流边界积分解给出的根状态是源级生产量；
- 附加固定点只能作为诊断或显式启用的研究选项；
- 当 `root_inner_iterations=0` 时，不得再用附加固定点预测值覆盖源级根状态。

## 4. 当前定量状态

`v353` 最终绝对运动学积分为 `K=0.1364235199`，运动学均方根为 `0.151727456`，边界积分矩阵条件数为 `4.83e4`，射流根 `S_lambda` 相对不匹配为 `1.594%`。对冻结 Zhao 参考，自由面归一化均方根误差为 `19.418%`，压力曲线误差为 `25.163%`；对 Iafrati 表 1 的标量压力峰值误差为 `11.239%`，峰位误差为 `27.048%`。

与 `v333` 相比，`K`、自由面误差、压力误差和压力峰值误差均持续下降，说明修正方向具有一致性；但它们仍高于阶段门限，且尚未完成 30° 的最终网格、时间步和远域收敛审计。因此当前结论只能是“源级算法可持续推进，验证尚未通过”。`v334` 是因工程运行时间过长而人工中断的 100 步批次，没有形成结果，不作为数值失败或验证证据。

三段父子检查点的局部伪时间经过谱系重建后，全状态 Aitken 收敛因子为 `q=0.936939`，高于预先冻结的资格上限 `0.9`；原始外推还会产生约 19 个局部面板的最大节点位移。将外推显式截断到 `4/1/0.5/0.25/0.1` 个面板后，所有候选仍在浅水射流第一步物理解检查中被拒绝。因此该加速路线已被机器否决，候选没有进入生产结果；30° 当前只保留直接二阶 Runge--Kutta 推进。

## 5. 回归与完成边界

源级修正、检查点时间轴修正和低斜升角同伦支持合入后，扩大定向回归为 `82 passed, 0 failed`；最终代码完整软件回归为 `588 passed, 0 failed, 1247 warnings`，耗时 `798.05 s`。警告来自既有验证统计空切片，另有 `pytest-asyncio` 配置弃用提示。软件回归通过不等于物理验证通过。
