# 下一阶段目标与验收条件：2.5D 核心验证闭环

日期：2026-08-03

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》。

当前系统已经完成第一轮“可扩展、可测试、边界清楚”的升级：配置读取、示例运动预报、规则波与不规则波链路、六自由度统一输出、验证输出和诊断表均已建立。但线性高速 2.5D matched-BIE 核心水动力仍未通过 Ma 2005 Wigley III 八个升沉/纵摇水动力系数的 Gate 1 硬验证，因此下一阶段不能急于扩展非线性 2D+t、多体船或水翼生产模型，而应先把核心 2.5D 验证闭环做实。

## 2. 阶段目标

完成高速单体船线性 2.5D 核心水动力求解器的方程级修正与验证闭环，使 Ma 2005 Wigley III 八个频域水动力系数在默认 `matched_bie_station_sweep` 路径下通过 Gate 1；同时保持规则波、不规则波和六自由度运动预报链路稳定可运行。

若八个系数仍不能全部通过，则本阶段必须把剩余失败项明确压缩到可追溯的理论缺口、参考数据缺口或独立剖面验证缺口，并证明所有未通过候选没有进入默认模型。

一句话目标：

> 把当前“能运行、能诊断”的 2.5D 原型推进为“有硬基准、有误差边界、有默认可信路径”的 2.5D 核心模型。

## 3. 本阶段工作范围

1. 固定 Ma-Duan-Song 型线性 2.5D matched-BIE 为本阶段主线，不切换到经验拟合路线。
2. 以 Ma 2005 Wigley III 八个水动力系数作为第一硬基准。
3. 重点闭合三条失败链路：
   - `A33/A53`：body potential 到 Eq.30 时间压力的尺度链路。
   - `B33/A35/B35`：zero-`m3` 行的 Eq.31/Eq.32 几何输运与边界项链路。
   - `A55/B55`：pitch row 中 `N5/m5`、力臂、Stokes body moment、pressure-gradient moment 和 end-contour moment 的一致性链路。
4. 保留并完善独立校核，包括解析算例、二维剖面 radiation pressure、闭合圆柱或可复核开剖面校核。
5. 保持示例滑行艇运动预报链路可运行，输出不同航速下的规则波、不规则波和六自由度时域结果。
6. 形成阶段报告，记录公式来源、代码改动、验证命令、结果表、失败项、排除候选和下一步缺口。

## 4. 暂不纳入本阶段硬验收

1. 不实现生产级强非线性 2D+t 自由面 BEM。
2. 不实现双体船、三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制器生产模型。
4. 不把 SL-7 或 C1 三体船 surrogate geometry 作为硬验收基准。
5. 不使用最终系数比例修正、最小二乘拟合、单项经验 delta 或后处理缩放冒充方程修正。

## 5. 必须具备的条件

| 条件 | 要求 |
|---|---|
| 理论依据 | 默认修正必须能对应到 Ma-Duan-Song/Faltinsen 2.5D 方程中的具体压力项、边界项、输运项或整船装配项。 |
| 参考基准 | Ma 2005 Wigley III 八系数继续作为本阶段硬验收基准。 |
| 数据边界 | SL-7 与 C1 三体船若没有真实 machine-readable offsets，只能作为替代几何或探索算例，不能作为通过/失败的硬判据。 |
| 候选纪律 | 所有未经八系数验证的候选必须标记为 `diagnostic-only` 或 `candidate_default_gate_eligible=false`。 |
| 可复现性 | 固定验收命令、配置文件、输出目录、CSV 表和报告必须可重复生成。 |

## 6. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 验证输出中 `provider_route` 全部为 `matched_bie_station_sweep`。 |
| 八系数硬验证 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部达到 Gate 1；对角项误差不超过 15%，耦合项误差不超过 30%，或验证器给出等价 `PASS`。 |
| 方程级修正 | 进入默认路径的修改必须发生在 body potential、Eq.30 pressure、Eq.31/Eq.32 transport、`N_i/m_i`、end-contour 或整船装配等方程位置。 |
| 时间压力链路 | 输出 `A33/A53` 独立剖面 pressure/radiation 校核表，并说明 matched-BIE 时间压力尺度是否被支持。 |
| 几何输运链路 | 输出 `B33/A35/B35` 的输运闭合表，能够解释 zero-`m3` 行的分布式输运、边界项和端部项。 |
| 纵摇矩链路 | 输出 `A55/B55` 的 pitch row moment chain 表，明确 `N5/m5`、力臂、Stokes body moment、pressure-gradient moment 和 end-contour moment 的关系。 |
| 数值稳定性 | 关键水动力 CSV、矩阵和时序输出无 `NaN/Inf`；质量、附加质量、阻尼和恢复矩阵数值有限。 |
| 运动链路 | `configs/example_planing.yml` 可运行，输出 `summary.csv`、`rao.csv`、各航速时序 CSV、图像和报告。 |
| 六自由度输出 | 所有时序 CSV 包含 `surge/sway/heave/roll/pitch/yaw` 六自由度列；迎浪主验收聚焦 heave、pitch 和垂向加速度，其他自由度必须标注模型假设。 |
| 不规则波 | 示例不规则波时域结果可复现，固定随机种子下 RMS、峰值和谱输入一致。 |
| 回归测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 更新阶段报告，包含目标、方法、命令、八系数对照表、示例结果、未通过项原因、排除候选和后续数据需求。 |

## 9. 合格结果定义

理想合格结果：八个 Ma 2005 Wigley III 水动力系数全部 `PASS`，默认 2.5D 路径可用于后续规则波、不规则波和六自由度运动预报验证。

有限合格结果：八个系数尚未全部 `PASS`，但每个失败项都有明确方程位置、误差来源、排除候选和所需外部数据；此时只能称为“2.5D 核心验证闭环继续推进中”，不得宣称完整总体目标已经完成。

不合格结果：只给出更平滑的运动曲线、只改善单个系数、只使用经验比例修正、无法复现固定命令，或把 surrogate geometry 当作真实验证基准。
