## 2. 阶段目标

**保持线性2.5D Gate 1不退化，以冻结且不读取物理参考的数值路径先闭合12.25°，再连续推进并闭合10°、20°和30°二维恒速、无重力楔形入水的数值独立性与独立物理对照；禁止经验倍率、参考反演、选择性删点和事后移动门槛，最终使“二维入水先决门”具有方程、源码、测试、参考、不确定度和机器产物完整证据链，并由`FAIL`转为可一键复现的`PASS`。**

该目标直接服务于总体目标中的非线性2D+t内核：只有二维自由面、压力和积分载荷可信，后续横剖面水动力、整船升沉--纵摇耦合及规则波响应才具有可验证的物理基础。

## 3. 可验收条件

以下七项必须全部满足，缺一项即不判定本阶段完成。

| 编号 | 验收项 | 必须满足的条件 |
| --- | --- | --- |
| 1 | 方程与参考合同冻结 | 完整记录边界积分、自由面运动学、根状态、压力辅助势和积分载荷的方程、坐标、符号、单位及离散定义。按[二维楔形入水参考合同](./二维楔形入水参考合同_20260901.md)冻结10°、20°、30°各指标的主/辅参考、页码、工况、提取方法、不确定度和`SHA-256`；传播提取不确定度，参考差异超过合成不确定度时标记`REFERENCE_CONFLICT`，解决前不得判`PASS`。 |
| 2 | 12.25°桥接闭合 | 先使320面板正式 `K<=1e-3`、根部相对失配 `<=1e-3`、无 `NaN/Inf`；再完成320/640/1280面板，最后两级 `K` 和积分垂向力变化均 `<=5%`。根位置、偶极系数和载荷必须连续，不得跳支。 |
| 3 | 10°数值门闭合 | 从12.5°检查点按预登记路径、单步 `<=0.25°` 推进；每个桥接角度的320面板必须先满足 `K<=1e-3` 和根部相对失配 `<=1e-3`，方可进入下一角度。10°必须完成320/640/1280面板、至少两档时间步、两档远域和两条冻结初值/同伦路径；最后两级及两路径的自由面、压力、`K` 和积分力差异均 `<=5%`。 |
| 4 | 20°与30°数值复验 | 在当前源码上重新生成20°和30°正式结果；两角度均须满足 `K<=1e-3`、根部相对失配 `<=1e-3`，并通过三网格、至少两档时间步、两档远域和两条冻结路径检查；关键量变化及路径差异均 `<=5%`。 |
| 5 | 三角度独立物理验证 | 10°、20°和30°均使用冻结、未参与求解或标定的参考数据；每个角度满足自由面归一化均方根误差 `<=5%`、压力曲线误差 `<=10%`，压力峰值、无量纲峰位和积分垂向力误差各 `<=5%`。禁止经验倍率、参考曲线反演、选择性删点或事后更改门槛。 |
| 6 | 参考隔离、诊断与重载 | 不挂载参考目录时仍能产生相同求解结果；负向测试证明参考数据不能进入残差、搜索方向、停止条件或参数标定。必须输出条件数、残差分解、根状态、线性/非线性试探、收敛历史和失败原因；冻结浮点状态检查点重载最大绝对误差 `<=1e-12`。 |
| 7 | 一键复现与回归 | 一条冻结命令从洁净输出目录以退出码0完成全部验收，生成输入及环境快照、源码清单与哈希、参考清单与哈希、检查点、CSV/JSON、图表、误差统计、JUnit或等价机器测试报告及阶段报告。当前源码 Gate 1必须保持 `10/10 PASS`，完整 `python -m pytest -q` 必须 `0 failed`，最终机器清单明确输出 `二维入水先决门=PASS`。 |

## 4. 必要交付物

1. 10°、20°和30°三角度冻结输入、参考合同及来源哈希。

5. 一键复现命令、源码/环境快照、机器验收清单和阶段报告。

## 5. 完成判定与后续顺序

七项条件全部通过后，本阶段才算完成。该结论只解除二维入水内核的先决阻塞，不自动增加整船 Gate 2 的通过项。

后续顺序固定为：**Sun--Troesch 横剖面规定升沉/纵摇水动力 -> Begovic/Fridsma 整船规则波响应 -> Gate 2 `20/20 PASS` -> 不规则波纵向统计响应 -> 斜浪六自由度 -> 多体船干扰 -> 水翼及控制系统。**
