## 1. 问题

1. 稳态基流初始化未收敛。
2. 一次谐波拟合受启动瞬态或窗口选择影响。
3. 非定常横剖面载荷及其船长方向力矩积分尚未收敛。

## 6. 当前结论与下一判据

现有证据将问题收缩到非定常载荷的纵向分布和力矩臂，而不是稳态基流、谐波拟合或线性方程残差。逐时刻、逐横剖面的站位载荷检查点已经实现。

源代码与原论文再次逐项对照后发现：Sun 2007 图 7.12 明确要求使用“等间距的地固横剖面”，并以船前进一个固定剖面间距的周期创建新剖面。修正前实现虽然保持每个已创建剖面地固，但会为维持恒定 BEM 交接吃水而改变新剖面的空间位置，因此整个剖面队列并不保持等间距。原论文第 19 页同时明确给出 Wagner 初始化自由面速度势为 `phi=0`，故初始势实现正确，不是误差来源。

求解器现已增加两种显式模式：

- `fixed_earth_grid`：固定地固、等间距，作为论文一致的默认生产模式；
- `constant_draft_event`：保留修正前算法，仅用于 A/B 敏感性诊断。

同一粗网格、同一物理参数、仅改变交接模式的 A/B 检查显示，`A53` 的无量纲值由约 `-0.186` 变为 `-0.905`。粗网格绝对值不能用于物理验证，但这一大幅变化足以证明交叉力矩对剖面位置敏感，交接模式必须纳入正式收敛检查。修正前的 24 面板、64 子步算例运行至约 `5%` 后终止：它属于 `constant_draft_event` 旧模式，继续计算不能形成 `fixed_earth_grid` 的生产验收证据，也不得用修正后的脚本补写成同一输入快照。

后续判据如下：

1. 使用 `fixed_earth_grid` 从低成本网格重新建立时间收敛序列，并用逐站位一次谐波分布定位残余误差来源。
2. 仅当 `A33/A53/B33/B53` 相邻加密变化全部 `<=5%` 时，才进入统一时间步下的 24→28 面板空间检查。
3. 不得以 Richardson 外推、删除频点、改变拟合窗口或调整射流阈值来替代原始网格收敛。
4. 时间与空间轴均通过前，不启动 Begovic 三航速生产矩阵，也不改变 Gate 2 的 `17/20 PASS` 状态。

## 7. 2026-08-17 固定地固网格复算进展

### 7.1 新剖面创建规则审计

固定地固剖面按平均航进距离等间距创建。新剖面在固定时刻的实际浸深足够时，使用该实际浸深的 Wagner 初值；浸深过小或剖面仍露出水面时，保留固定地固坐标并延迟启动。该处理对应 A3 第 7.4 节和 A4_3 的文字说明。

一次诊断曾把所有新剖面强制定位到相同交接吃水。它把创建吃水偏差降至机器精度，但改变了固定地固剖面在强迫运动中的实际浸深，违反原算法，已从代码中撤回。结果保留在 `outputs/sun2007_sigma14_fixed_earth_body12_sub8_heave_v6_event_localized`，只作为排除证据，不是生产候选。

运行诊断现额外输出接触退出、固定剖面延迟创建、激活前过期和结束时待激活计数。创建吃水相对稳态交接值的差异改称“实际浸深偏差”；它是强迫运动下的物理变化，不再误标成固定网格误差。

## 18. 2026-08-23 图 2.6 独立参考冻结与首次二维物理判定
