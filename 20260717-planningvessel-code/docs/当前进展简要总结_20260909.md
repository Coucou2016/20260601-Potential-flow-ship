## 1. 总体判断

项目已经完成了统一软件框架、线性高速2.5D核心链、规则波纵向响应链和较完整的验证基础设施，当前源码回归稳定。现阶段的主要矛盾已经从“功能是否存在”转为“非线性二维入水内核和整船响应能否通过独立物理对照”。

准确结论是：**框架覆盖较广，线性2.5D核心局部验证通过；完整非线性2D+t、整船纵向响应、斜浪六自由度、多体船干扰和水翼控制尚未达到生产级物理验证。**

## 3. 当前正在推进的工作

当前数值工作从12.375°合格检查点向12.3625°推进。正式合格前沿仍为12.375°，其指标为：

- 运动学精确积分目标`K=9.6642994461e-4`，满足`K<=1.0e-3`；
- 根部相对失配`1.0322e-7`，满足`<=1.0e-3`；
- 检查点重构相对误差`8.4134e-17`，满足`<=1.0e-12`；
- 求解中读取物理参考为`false`；
- 12.3875°至12.375°的根厚度、根速度、偶极系数和根位置均连续，无跳支证据。

12.3625°已经完成无参考同伦、既有方向复用、16模态全局同步重线性化、根部余弦局部基诊断和24模态全局同步重线性化。当前最好状态来自：

`outputs/self_similar_wedge_12p3625deg_n320_globaldct24_syncmap_v958`

其结果为：

| 指标 | 当前值 | 门槛 | 判定 |
| --- | ---: | ---: | --- |
| 精确积分目标`K` | `1.0396803095e-3` | `<=1.0e-3` | `FAIL`，高约`3.97%` |
| 根部相对失配 | `7.3278e-7` | `<=1.0e-3` | `PASS` |
| 条件数 | `2.5310661e5` | 相邻连续且比值`<=1.10` | 当前无异常 |
| 接受步数 | `1` | 至少存在合法下降步 | `PASS` |
| 求解中读取参考 | `false` | 必须为`false` | `PASS` |

因此，12.3625°不是失败分支或根部失稳，而是**已接近门槛但形状残差仍略高**。残差定位表明，精确积分中约62%的能量来自单元内左右迹线斜率项，主要集中在根部前10%弧长；后续应扩充形状方向空间或改进离散连续性，不能放宽验收阈值。

## 5. 下一步执行顺序

1. 在不改变`K<=1.0e-3`等冻结门槛的前提下，扩展12.3625°根部及高阶全局形状方向，使该点正式通过并加入连续性机器审计。
2. 以相同参考隔离和连续性规则推进至12.25°，完成320/640/1280面板以及积分垂向力网格独立性。
3. 并行冻结参考提取不确定度和压力积分力派生规则，明确20°参考冲突的处理结论。
4. 按预登记路径推进并闭合10°，随后在当前源码重算20°和30°数值独立性。
5. 对10°、20°和30°执行统一、不可选择参考的物理评分，生成一键机器清单；七项阶段条件全部通过后，二维入水先决门才可由`FAIL`改为`PASS`。
6. 之后依次完成Sun--Troesch横剖面水动力、Begovic/Fridsma整船规则波Gate 2、不规则波、斜浪六自由度、多体船和水翼控制验证。

## 6. 当前结论

本轮取得的实质进展是：线性2.5D核心已经有严格机器验证，非线性二维入水的小斜升角合格分支已从12.5°连续推进到12.375°，候选映射同步和参考隔离问题得到实证处理。当前主要阻塞是12.3625°的`K`仍比硬门槛高约3.97%，以及三角度物理参考合同尚未冻结。

所以，项目不是“尚未开始”，也不是“接近全部完成”；更准确的表述是：**已经完成可靠的软件和线性核心底座，正在攻克决定非线性2D+t可信度的二维入水先决门。**
