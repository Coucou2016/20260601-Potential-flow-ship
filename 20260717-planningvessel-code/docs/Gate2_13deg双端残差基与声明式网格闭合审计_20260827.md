# Gate 2：13.0°双端残差基与声明式网格闭合审计

日期：2026-08-27  
结论状态：**三层绝对数值门槛和空间稳定性通过；13.0°可冻结为数值同伦源；独立物理验证仍为 `FAIL`；二维先决门与 Gate 2 总状态不变。**

## 1. 判定范围

本轮从13.5°已闭合检查点延拓到13.0°，只处理参考隔离的自相似楔形入水数值方程。求解、网格选择和停止判据均未读取自由面、压力、载荷或整船试验参考，输出均保持 `reference_used_during_solve=false`。

冻结数值门槛不变：320、640、1280面板的精确运动学积分 `K`和根部相对失配均须 `<=1e-3`，随后必须通过同源三层空间收敛检查。本审计不提供自由面、压力或载荷物理正确性信用，不能代替10°、20°、30°正式楔形入水验证。

## 2. 残差闭合过程

13.0°初始同伦状态的三层积分约为 `5.90e-3/5.30e-3/5.19e-3`。闭合过程保持三层根约束，并依据残差弧长能量位置切换数值基：

1. 32/64模态全局离散余弦基首先处理自由面中段残差。
2. 三层根约束方向复用后，积分降至 `1.943e-3/1.350e-3/1.255e-3`，但320面板根失配接近硬上限。
3. 重新线性化恢复根余量后，末端15%弧段承担约60%至73%的残差能量，因此改用末端局部基。
4. 16模态末端基将640/1280面板积分降到 `7.31e-4/6.29e-4`；48模态进一步降到 `4.88e-4/3.82e-4`，但320面板仍约 `1.10e-3`。
5. 随后320面板前10%弧段承担约87%的残差能量，而1280面板后10%仍约36.5%。为此新增通用 `dual_endpoint_local` 基，将局部模态分配到自由面两端并统一做弧长质量正交化。新基通过定向测试，但三层等权形状优化仍受320面板离散分辨率限制。

全部基函数优化只修改数值残差空间，不改变控制方程、物理参考或冻结门槛。

## 5. 软件增量与测试

新增 `dual_endpoint_local_nodal_basis`：

- 保留声明数量的全局模态；
- 将剩余模态近似均分到起始端和末端；
- 两端局部帽函数使用相同声明式支撑比例；
- 全部种子函数经连续线性弧长质量矩阵统一正交化；
- Cholesky失败、非有限值或质量正交误差超限时拒绝该基；
- 低模态和多网格命令行均支持 `dual_endpoint_local`；
- 端部局部雅可比仍禁止跨模态数前缀复用。

定向测试新增双端基正交性和两端能量定位检查，结果为 `38 passed, 0 failed`。在 Python 3.14 / NumPy 2.4.4 环境下执行完整 `python -m pytest -q`，结果为 `620 passed, 0 failed, 1247 warnings, 11 subtests passed`，耗时 `221.33 s`。现有警告来自 `tests/test_validation.py` 触发的 NumPy 空切片均值告警，未导致测试失败，但应在后续诊断清理中继续跟踪。软件测试通过不提供物理验证信用。

## 7. 结论与边界

13.0°已同时满足三层绝对运动学积分、三层根失配和同源空间稳定性要求，因此可冻结为**合格数值同伦源**，并可用于12.5°的参考隔离延拓。通过依赖明确声明的双端网格规则，后续角度必须复用并重新审计该网格合同，不能把参数扫描本身当作物理标定。

13.0°没有冻结权威物理参考，故二维楔形入水先决门仍因10°和30°正式物理验证缺失而为 `FAIL`，Gate 2仍为 `17/20 PASS`。本结果不能解释为物理正确，也不增加Gate 2机器验收计数。
