# 下一阶段目标与可验收条件：核心 2.5D 硬验证

日期：2026-08-03

## 1. 阶段定位

本阶段服务于《高速船型运动预报系统总体目标》。

当前系统已经具备配置读取、规则波/不规则波计算、六自由度统一输出、示例运行、诊断表和回归测试能力，但核心线性高速 2.5D 水动力模型尚未通过 Ma 2005 Wigley III 八个升沉/纵摇水动力系数的硬验证。因此下一阶段的重点不是继续扩大功能面，而是先把 2.5D 核心水动力求解器做实、做准、做成可验证的默认路径。

## 2. 阶段目标

完成高速单体船线性 2.5D matched-BIE 核心水动力模型的方程级修正、诊断闭环和硬基准验证，使其成为后续滑行艇运动预报、非线性 2D+t、多体船和水翼扩展的可信基础。

一句话目标：

> 将当前“可运行、可诊断”的 2.5D 原型，推进为“有文献方程依据、有硬基准对照、有明确误差边界、可作为默认模型继续扩展”的核心 2.5D 求解器。

## 3. 必须完成的核心任务

1. 固定 `matched_bie_station_sweep` 为线性 2.5D 主路径，不用经验比例缩放或后处理拟合替代方程修正。
2. 以 Ma 2005 Wigley III 八个频域水动力系数作为本阶段第一硬基准：`A33/B33/A35/B35/A53/B53/A55/B55`。
3. 闭合三条主要误差链路：
   - `A33/A53`：剖面势函数、时间压力、站位装配的尺度链路。
   - `B33/A35/B35`：前进速度项、几何输运项、端部项和交叉耦合链路。
   - `A55/B55`：纵摇法向量、力臂、压力矩、Stokes 项和端部矩链路。
4. 保持示例滑行艇运动预报链路可运行，继续输出不同航速下的规则波、不规则波和六自由度时域响应。
5. 建立阶段报告，记录公式来源、代码修改、验证命令、结果表、未通过项原因和后续数据需求。

## 4. 必须具备的条件

| 条件 | 要求 |
|---|---|
| 理论来源 | 所有进入默认模型的修正必须能追溯到 Ma-Duan-Song、Faltinsen 或等价 2.5D 方程中的具体项。 |
| 基准数据 | Ma 2005 Wigley III 八系数作为硬验收基准；SL-7、C1 三体船和替代几何只作为探索或后续验证，不作为本阶段通过判据。 |
| 输入输出 | 配置文件、基准参数、输出目录、CSV 表、图像和报告必须可重复生成。 |
| 候选约束 | 未通过硬验证的候选模型必须标注为 `diagnostic-only`，不得进入默认路径。 |
| 数值稳定 | 关键矩阵、系数、时序结果不得出现 `NaN` 或 `Inf`。 |
| 回归安全 | 新增修正不得破坏现有配置读取、示例运行、可视化和测试集。 |

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 验证输出中的 `provider_route` 全部为 `matched_bie_station_sweep`。 |
| 八系数验证 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部达到 Gate 1；对角项误差不超过 15%，耦合项误差不超过 30%，或验证器输出等价 `PASS`。 |
| 方程级证据 | 每个默认修正均有公式位置、代码位置和验证表支撑，不能只给经验解释。 |
| 压力链路 | 输出 `A33/A53` 的势函数、时间压力和整船积分诊断表，并说明误差来源是否闭合。 |
| 输运链路 | 输出 `B33/A35/B35` 的前进速度输运、边界项和端部项分解表。 |
| 纵摇链路 | 输出 `A55/B55` 的纵摇矩链路表，明确 `N5/m5`、力臂、压力矩和端部矩的一致性。 |
| 运动预报 | `configs/example_planing.yml` 可运行，生成 `summary.csv`、`rao.csv`、各航速时序 CSV、图像和报告。 |
| 六自由度结果 | 所有时序 CSV 包含 `surge/sway/heave/roll/pitch/yaw` 六自由度列；迎浪算例重点验证 `heave`、`pitch` 和垂向加速度，其他自由度标注模型假设。 |
| 不规则波 | 固定随机种子下，不规则波时域响应、均方根值、峰值和谱输入可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过。 |
| 阶段报告 | 生成或更新阶段报告，包含目标、方法、命令、八系数对照、示例结果、失败项解释、排除候选和后续缺口。 |

## 7. 合格判定

理想合格：八个 Ma 2005 Wigley III 水动力系数全部通过 Gate 1，示例运动预报和测试集全部通过，可进入非线性 2D+t、多体船和水翼扩展的下一层工作。

有限合格：八个系数尚未全部通过，但每个失败项均被定位到明确的方程项、数据缺口或独立验证缺口，且所有未通过候选均未进入默认模型。

不合格：只改善曲线外观、只改善单个系数、依赖经验缩放、无法复现固定命令，或把替代几何当成真实硬基准。
