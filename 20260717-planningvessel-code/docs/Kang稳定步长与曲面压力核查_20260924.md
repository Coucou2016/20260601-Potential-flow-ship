# Kang 稳定步长与曲面压力核查

## 目标与边界

本轮继续检查规则迎浪直接激励核，不修改生产模型、试验限值或响应倍率。上一轮在固定边界离散下减半实际推进时间步，消除了异常爆发；这尚不意味着载荷收敛。本轮将站位 161 增至 321、历史步数 256 增至 512，保持三倍船宽控制半径、64 船体面元、128 内自由面面元、192 控制面面元及物理历史时长不变。

仍只检查无量纲遭遇频率 2、3、4。它们不能替代交付全频段、八个水动力系数及完整复数激励的三档验收。几何中点纵摇力矩不冒充已核实参考点的实验力矩。

## 本轮增加的可复算证据

除整船复数力及站位载荷密度外，新算例保存：实际面元中心、法向量、长度、边界元原始势、压力恢复使用的去相位势及纵向导数、面元压力、规定法向速度，以及自由面推进前后的势和波高状态。所有场来自实际求解，不以插值示意场冒充计算结果。

`solved_body_potential` 是局部时间相位下的解，`pressure_body_potential` 是去除该相位后的物理谐波势。两者不能混用。重放程序先核对相位关系、面元压力代数式和整船力积分，任何一项不能重构就拒绝继续比较；非有限场也拒绝通过。

## 曲面坐标转换

重新核对用户提供的 `20260729-文献收集/md/A1.md`：式 4、5 的法向量定义在横剖面轮廓上，不能在没有新推导的情况下擅自加入三维纵向法向项。式 7、8 给出局部时间与相位转换。压力核查使用式 30 第一个等号右侧的量纲一致形式：

$$p=-\rho(i\omega\phi-U\phi_x).$$

这里 p 为单位波面幅值的复数压力，rho 为水密度，omega 为遭遇角频率，U 为航速，phi 为物理谐波势，phi_x 为固定横向位置和水深处的纵向偏导数。式 30 后一个表达式存在此前已记录的记号问题，本轮不据其改写生产公式。

若同一面元索引的中心随站位 x 改变为 y(x)、z(x)，对这些中心上的势值直接差分获得的是移动轨迹导数，而不是固定空间偏导数：

$$D_x\phi=\phi_x+y_x\phi_y+z_x\phi_z.$$

其中 y_x、z_x 表示面元中心随纵向站位移动的斜率；phi_y、phi_z 是势在横剖面内的梯度。两者乘积之和是坐标移动产生的链式项，与改变物理前进速度或拟合试验响应不同。

独立诊断通过轮廓切向势导数和已知法向导数恢复横剖面梯度。两舷分开差分，避免跨越龙骨角点混合切向方向。曲线弧长用面元中心的相邻距离近似，端部使用单边差分，因此它仍有空间离散误差，不是已经验证的保守通量压力算法。

解析制造解为横剖面内满足拉普拉斯方程、随纵向改变相位的二次势。17、33、65 档离散的导数误差按测试要求收敛，最细档相对误差小于 0.1%。直接把移动轨迹导数当作固定空间导数，误差明显更大。该测试只证明坐标转换诊断的数学一致性，不是实际绕射验证。

应用到实际势场时，诊断保留生产程序原有局部相位求导，仅扣除上述链式项；直接对去相位势差分所产生的另一项差异另存为 `phase_differencing_gap`，不将两种变更混为一个修正。所有结果仍为诊断，不接入生产默认路线。

## 本轮计算结果

**本次三个新频率工况已全部计算完成，阶段仍未通过。** 半步长与四分之一步长分别指相对于最初 81 站的推进间隔，而不是任意缩放物理航速。最大矩阵条件数保持约 5.01×10⁷，三个细步长算例线性系统相对残差均小于 9×10⁻¹⁶。

## 下一步

推进误差尚大于或相当于曲面压力转换影响。下一步应继续核查完整耦合推进的离散收敛，不能只增加不重新求解边界元的局部子步，也不能挑选更接近候选参考的后处理路线。达到稳定的势和载荷收敛后，再验证曲面压力转换及独立绕射相位参考，最后回到全频段和三航速整船验收。

## 完成边界

只有独立绕射参考准入、完整频段离散、Begovic 逐航速运动及主峰、Fridsma 相位和加速度、时频一致性、稳定性和全回归全部满足原条件，才能宣布本阶段完成。本轮局部核查不改变这些要求。
