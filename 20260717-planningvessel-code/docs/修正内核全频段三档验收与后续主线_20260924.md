## 下一步目标及出口

**目标：优先完成直接绕射激励和压力/恢复力一致性的独立验证，消除可定位的物理错误，再以原合同复验三航速整船运动。暂不把扩大船型覆盖作为当前主线。**

1. 独立复数激励参考：先冻结几何、航速、波向、幅值归一化、时间相位、力矩参考点和误差限值，再计算。已有Kang幅值图缺相位，Qiu资料为零航速，均不能冒充完整高速复数参考。未取得或未核实的数据继续标注待验证。
2. 压力与力学一致性：用独立制造解核查固定空间压力导数、船体/流体法向、力的投影、纵摇力臂和端部项；长波激励与采用的恢复力必须在同一物理假设下比较。不得用试验响应倍率补偿错误。
3. 每次物理修正后重新冻结源码与工况，重跑本轮240项检查；不得沿用旧版本的通过标签。旧基础门继续10/10且网格变化不超过2%。
4. 整船出口不变：三速度各自升沉、纵摇达到15%/20%；至少4个可解析主峰，覆盖两速度和两种运动，频率误差不超过10%；Fridsma既有运动门、相位15度及重心加速度25%门保留；同核时频幅值5%、相位5度。
5. 同次运行交付真实计算网格、复数分量、时频响应、加速度、逐工况误差及机器验收文件。全回归零失败；未支持自由度、规定姿态和线性稳态重构必须明确标识。任一必要门未过，阶段继续记为未完成。

多体干扰、非线性自由航行、水翼控制及水上飞机起降仍属于总体目标，但本轮证据不支持将它们标为已验证。参数合理假设可以支持演示和敏感性分析，不能替代独立试验验收。
