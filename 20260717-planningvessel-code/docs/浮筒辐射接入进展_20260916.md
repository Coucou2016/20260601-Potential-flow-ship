线性方程残差很小只说明离散方程被解出，不能证明边界条件、符号或压力积分正确。负阻尼需要核查，不能通过取绝对值、截零或调响应倍率宣称解决。附加质量出现负值本身也不是普遍否决条件；本轮另外检查的是总有效质量矩阵。

## 源程序核对

本地源文件：`early_stage_materials/code/potential_flow_seakeeping/pdstrip/pdstrip.f90`。

- 第 64 行定义复附加质量为 `a+d/(i*omega_e)`；因此对正频率，阻尼为复附加质量虚部乘负频率。当前输出转换与该注释一致，不能无依据整体翻转符号。
- 第 531 行为升沉边界右端，第 619 行为积分力到复附加质量转换。当前 Python 路径形式与这两处一致，尚未完成独立逐矩阵数值对照。
- 第 622 行解释两个自由面离散取平均与半剖面镜像倍数相消。当前 Python 路径对两个半剖面结果直接取均值，镜像倍数需要专项核验。即使确认缺少正的倍数，补倍数也不能消除负阻尼，不能将它当成已找到全部根因。
- Python 路径仍是 PDSTRIP-inspired 剖面诊断，不是原始外部程序，也不是已经验收的 Ma 型前进速度 2.5D 内核。

## 下一步明确出口

1. 固定一个解析对称剖面及一个真实湿剖面，与原始 PDSTRIP 在相同水深、频率、面元、近远场分区下逐项对照，核查镜像倍数、边界矩阵、源强及压力积分。禁止依赖最后响应反推修正。
2. 分别加密纵向、剖面和自由面，核查自由面计算域长度；不能只增加面元数量并同时改变多个参数。
3. 原始系数及独立参考核验通过后，再接入频率相关运动方程，检查同一系数的时频一致性。绕射激励仍需独立补齐，不能把当前静水近似称为完整波浪激励。
4. 每次重算使用新的洁净目录；本轮失败证据保留，旧线性门及实验门不改。仅数值通过仍不能代替实际飞机试验验证。
