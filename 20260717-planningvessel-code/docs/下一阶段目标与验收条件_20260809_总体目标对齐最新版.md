# 下一阶段目标与验收条件：线性 2.5D 核心水动力验证封口

日期：2026-08-09

## 1. 总体目标对齐

本阶段服务于《高速船型运动预报系统总体目标》：以高速滑行艇为核心，建立完整、可扩展、可验证的 2.5D 运动预报模型及软件框架，并最终扩展到排水船型、半排水船型、多体船、三体船和水翼船型。

当前不应把主要精力分散到非线性 2D+t、多体干扰或水翼控制的完整实现上。下一阶段必须先把线性高速 2.5D 核心水动力链做成可验证、可复现、可解释的硬基准。

## 2. 当前进展核对

1. 已建立 `planing_seakeeping` Python 包与命令行框架，能够读取船型、质量惯性、航速、波浪、海流、风和仿真参数配置。
2. 已实现规则波、不规则波、频域响应、时域响应、六自由度统一输出、图表和报告生成的基础流程。
3. 已形成文献索引、理论公式整理、总体目标文件、阶段目标文件、科研报告和多轮 Gate 1 诊断报告。
4. 已建立验证体系，包含 Faltinsen 第 9 章、Katayama 趋势、数值稳定性、剖面边界元检查、Ma 2005 Wigley III 系数硬验证等入口。
5. 最新固定验证结果为：`64 PASS / 16 FAIL / 8 NOT_EVALUATED / 109 INFO`。
6. 最新全量回归测试结果为：`223 passed`，说明现有软件框架和测试体系基本稳定。
7. 当前最大缺口是 Ma 2005 Wigley III 八个线性 2.5D 水动力系数仍未通过硬验收：`A33/B33/A35/B35/A53/B53/A55/B55` 均为 `FAIL`。
8. 已排除若干不可靠修正路线，包括单一经验比例缩放、统一实数比例、统一相位旋转和简单同系数频率趋势修正；这些不得作为默认模型补偿。
9. Delft 372 双体船几何已有可重建路径；SL-7 真实数字 offsets 和 C1 三体船主片体/侧片体数字 offsets 仍属于后续验证数据缺口。

## 3. 下一阶段目标

在保持默认路线 `matched_bie_station_sweep` 不变、不得使用经验拟合或事后比例补偿的前提下，完成 Ma--Duan--Song / Faltinsen 型线性高速 2.5D 核心水动力模型的 Gate 1 封口。

具体目标是：使 Ma 2005 Wigley III 的八个升沉/纵摇水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 全部通过可重复硬验证；若基于现有公开资料仍不能全部通过，则必须把剩余误差压缩到明确、可追溯的公式项、坐标项、相位项、边界积分项、压力梯度项、端部项、频率传播项、离散历史卷积项或缺失参考数据项。

## 4. 必须完成的工作

1. 核对 `matched_bie_station_sweep` 中频率、遭遇频率、局部时间、前进速度项和缓存键是否完整进入剖面求解、压力恢复和整船装配。
2. 分别审计 `B33/B35/B53/B55` 的阻尼频率传播链，重点检查压力梯度项、端部项、历史卷积项和局部时间相位项。
3. 分别审计 `A35/A55` 的纵摇力矩链，重点检查力臂、坐标原点、站位权重、首尾端部闭合和复数力矩装配。
4. 保留所有候选路线的诊断性质，只有公式级或实现级证据闭合后，才允许进入默认模型。
5. 更新验证输出、阶段报告和测试用例，使每个通过项和失败项都能追溯到具体文件、命令和数据表。

## 5. 硬验收条件

1. 固定验收命令可以重复运行：

```powershell
python -m planing_seakeeping validate --benchmark all --out outputs\gate1_linear_2p5d_hard_pass\results --reference-root outputs\matched_bie_provider_gate_probe\reference --ma-hydro-model matched_bie_provider --ma-bem-free-surface-panels 4 --ma-bem-body-panels 8
```

2. `ma2005_wigley_iii_coefficients_comparison.csv` 中八个目标系数 `A33/B33/A35/B35/A53/B53/A55/B55` 均满足 `status == PASS`。
3. 八个目标系数均满足 `gate_error_ratio <= 1.0`，不得只靠人工解释绕过自动判据。
4. 默认模型路线必须仍为 `matched_bie_station_sweep` 或其公式级等价实现，不得切换到 reduced-order、legacy、经验缩放或后处理拟合路线。
5. 所有新增修正必须有文献公式、离散推导或代码级错误证据支撑，并写入验证报告。
6. 验收输出目录必须包含 `validation_summary.csv`、`validation_status_by_benchmark.csv`、`ma2005_wigley_iii_coefficients_comparison.csv`、失败/候选审计表和 `validation_report.md`。
7. 全量测试必须通过：

```powershell
python -m pytest -q
```

8. 任何新增或修改的测试必须覆盖对应修正，至少包括频率传播、压力/端部项、纵摇力矩装配或缓存一致性中的相关项。
9. 阶段报告必须明确写出：采用的公式链、修正原因、被排除的候选、误差变化、剩余风险和下一步边界。

## 6. 阻塞验收条件

如果八个目标系数仍不能全部通过，本阶段只能以“阻塞定位完成”作为有限验收，且必须同时满足以下条件：

1. 每个失败系数都有唯一或少量明确的剩余阻塞分类。
2. 每个阻塞分类都对应到具体公式、代码模块、数据表或缺失参考资料。
3. 已明确列出哪些候选修正被排除，以及排除原因。
4. 已说明继续推进所必需的新资料，例如 SL-7 offsets、C1 三体船 offsets、原始试验曲线、论文附录数据或更高精度图表数字化数据。
5. 不得把未通过的 Gate 1 结果包装为“模型已验证”。

## 7. 本阶段暂不验收的内容

1. 非线性 Sun--Faltinsen 2D+t 自由面边界元生产内核。
2. 多体船、三体船片体间完整相互干扰模型。
3. 水翼、压浪板、控制器和舵机动态的完整闭环模型。
4. 斜浪六自由度高精度响应。
5. 基于未知真实型线和未知质量惯性的工程实船定量预报。

这些内容可以继续保留接口、数据准备和文献整理，但不得作为下一阶段核心验收目标。

## 8. 阶段完成后的进入条件

只有当 Ma 2005 Wigley III Gate 1 通过，或剩余阻塞被压缩到明确且无法由现有资料继续解决的数据缺口后，才进入下一阶段。下一阶段可以转向 Fridsma/Katayama 规则波与不规则波运动响应验证，并把已可信的 2.5D 水动力核心接入完整运动预报流程。
