# 下一阶段目标与验收条件：线性 2.5D 核心硬验证闭环

日期：2026-08-09

## 1. 总体目标对齐

本阶段继续服务于《高速船型运动预报系统总体目标》：以高速滑行艇为核心，建立可验证、可扩展的高速船型运动预报模型及软件框架，最终扩展到排水船型、半排水船型、单体、多体、三体和未来水翼船型。

下一阶段不扩大船型范围，不追求新功能堆叠，优先把线性高速 2.5D 核心水动力模型做实。只有该核心模型通过可追溯硬验证，后续规则波、不规则波、六自由度输出、非线性 2D+t、多体船和水翼扩展才有可靠基础。

## 3. 下一阶段阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 硬验证闭环，使 `matched_bie_station_sweep` 路径在 Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 上全部通过，并能够解释每个修正来自哪个方程、哪个坐标约定、哪个边界项或哪个参考数据处理。

若八系数仍无法全部通过，则必须把失败封口到明确、可复查的公式缺口、坐标缺口、归一化缺口、固定控制面缺口、端部项缺口、频率传递缺口或参考数据缺口；不得用经验倍率、最终系数拟合或按参考值反推的方式制造通过。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、可作为后续扩展根基”的核心模型。

## 4. 本阶段工作范围

纳入本阶段：

1. 硬化 Ma 2005 Wigley III / Journee 1992 参考数据，明确频率、单位、坐标、无量纲方式和数字化来源。
2. 闭合 `A33/A53` 的时间压力、体势尺度、局部时间相位、自由面 marching 和归一化链路。
3. 闭合 `B33/A35/B35` 的固定控制面几何输运、zero-`m3` 行、同频 `A/B` 配对和 Eq.31/Eq.32 转换链路。
4. 闭合 `A55/B55` 的纵摇矩、压力梯度矩、Stokes body moment、端部项、力臂原点和参考轴装配链路。
5. 保持示例滑行艇运动预报链路、六自由度输出、不规则波统计和可视化不退化。
6. 更新阶段报告和验证表，使每个结论都有命令、数据文件和代码路径可追溯。

暂不纳入本阶段：

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船、三体船共同边界积分生产模型。
3. 不实现水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件；它们保留为后续二级验证和扩展验证对象。
5. 不使用经验补偿、最终系数修正、曲线拟合或只对单个系数有效的局部补丁。

## 7. 必要条件

本阶段能够做实，至少需要满足以下条件：

1. 参考数据必须可信：Ma 2005 图线、Journee 1992 表格和当前八点开发参考必须完成频率和值的统一审计。
2. 公式链必须可追溯：任何默认修正都必须说明它对应 Ma--Duan--Song / Faltinsen / A1 文献中的哪一项。
3. 误差来源必须可定位：不能只知道“结果不对”，必须能定位到时间压力、固定控制面输运、纵摇矩链或参考数据层。
4. 代码路径必须单一：硬验收只看默认 `matched_bie_station_sweep`，不把 diagnostic-only 候选混入生产结果。
5. 测试必须可复现：固定命令、固定配置、固定随机种子、固定输出目录能够重复生成同类结论。

## 8. 完成判定

本阶段的主验收出口只有一个：

1. Ma 2005 Wigley III 八个核心系数全部 `PASS`。
2. 示例运动预报链路可运行。
3. 自动测试通过。
4. 阶段报告完整更新。

若八系数仍未全部通过，只能判定为“阶段封口进展”，不能判定为“线性 2.5D 核心已验证通过”。封口进展必须同时满足：失败项来源明确、无未解释候选、无未通过候选进入默认路径、下一步所需资料或公式条件清楚。

只有平滑曲线、单个系数改善、局部候选通过、示例程序能画图，均不算完成本阶段目标。
