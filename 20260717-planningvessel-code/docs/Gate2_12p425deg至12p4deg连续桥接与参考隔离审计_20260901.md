审计状态：**12.425°、12.4125°和12.4°的320面板数值桥接点均`PASS`；12.25°及其三网格门仍未完成。**

## 1. 本轮目的

此前12.425°最新正式端点积分为`K=1.0295601614663434e-3`，只比`1e-3`门槛高约2.96%，根相对失配已为`8.38e-8`。本轮保持Iafrati Eq. (52)正式定义、根门槛、条件数门槛和参考隔离不变，重新计算局部Jacobian，并按0.0125°连续步长继续推进。

本轮禁止使用中点积分`3.982e-4`代替正式端点积分，也没有读取自由面、压力或标量物理参考来生成搜索方向、选择候选或判断停止。

## 2. 关键修正

### 2.1 当前点重新线性化

旧v904冻结方向在v916第三步已全部转为上坡。重新使用64模态全局离散余弦基和正式端点残差生成器，在当前12.425°状态计算64坐标子空间Jacobian，使正式`K`从`1.0295601614663434e-3`降至`9.656003028327099e-4`。

该步没有改变验收指标。最终同步重基准后仍满足`K<=1e-3`，根相对失配为`7.56e-12`，条件数为`2.52993e5`。

### 2.2 无参考挂载同伦

`continue_self_similar_wedge_deadrise.py`新增`--skip-reference-metrics`。启用后，脚本写出变角检查点和数值诊断，但不打开任何分布式或标量物理参考文件。负向运行故意传入不存在的`Z:\definitely_missing\*.csv`，12.4125°和12.4°检查点仍以退出码0生成，摘要明确记录：

- `reference_used_during_solve=false`
- `reference_metrics_requested=false`
- 两类后处理指标均为`SKIPPED_BY_REQUEST`

这关闭了同伦脚本对参考目录的非必要后处理依赖，但不等于验收条件6已经整体完成；其他生产入口仍需相同负向测试。

### 2.3 机器连续性审计

新增`scripts/audit_self_similar_bridge_series.py`。该工具重新加载每个正式检查点，验证二进制重构误差、正式`K`、根失配、正根、参考隔离和相邻角度连续性，并冻结检查点及外自由面CSV的SHA-256。
