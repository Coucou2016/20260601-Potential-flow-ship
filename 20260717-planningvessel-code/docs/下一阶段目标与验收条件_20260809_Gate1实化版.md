# 下一阶段目标与验收条件：Gate 1 实化版

日期：2026-08-09

## 1. 总体目标对齐

本阶段服务于《高速船型运动预报系统总体目标》：以高速滑行艇为核心，建立可扩展到排水船、半排水船、多体船、三体船和未来水翼船的统一运动预报系统。

当前阶段不继续扩大功能面，优先把线性高速 2.5D 核心水动力链做实。原因是：六自由度运动响应、不规则波统计、非线性 2D+t、多体船干扰和水翼扩展都依赖可靠的频域水动力系数。如果 2.5D 核心未通过公开算例验证，后续结果只能算演示，不能算可信预报。

## 3. 下一阶段目标

完成线性高速 2.5D 默认求解链的 Gate 1 实化，使 `matched_bie_station_sweep` 在 Ma 2005 Wigley III 八个核心频域水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 上达到可验证、可解释、可复现的状态。

优先目标是八个系数全部通过 Gate 1；若阶段内仍无法全部通过，则必须把剩余失败项封口到明确的理论、数据或实现缺口，并形成下一步所需资料与推导条件清单。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、可作为后续非线性和多船型扩展根基”的核心模型。

## 4. 本阶段工作范围

纳入本阶段：

1. 闭合 Ma 2005 Wigley III / Journee 1992 参考数据链：频率、单位、坐标、符号、无量纲方式、数字化来源和取舍理由。
2. 接入并完成 `body_potential_frequency_entry` 审计：确认频率依赖是在船体边界条件、体势求解、自由面 marching、压力恢复还是整船装配中丢失。
3. 闭合 `A33/A53` 时间压力链：体势尺度、局部时间映射、压力恢复、自由面项和归一化。
4. 闭合 `B33/B35/B53/B55` 阻尼链：前进速度压力梯度、Eq.31/Eq.32 转换、固定控制面几何输运、端部项和同频 A/B 配对。
5. 闭合 `A35/A55` 纵摇耦合链：力臂原点、压力梯度矩、Stokes body moment、端部矩和参考轴约定。
6. 保持示例滑行艇运动链路可运行：六自由度时序、规则波响应、不规则波统计、垂向加速度和图表输出不得退化。
7. 更新阶段报告，使每个结论都能追溯到公式依据、代码路径、验证命令和输出文件。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元。
2. 不开发双体船、三体船共同边界积分生产模型。
3. 不开发水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 设为本阶段硬验收对象。
5. 不用经验补偿、最终系数拟合或按参考曲线反推的方式制造通过。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数均由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| Gate 1 硬通过 | `ma2005_wigley_iii_coefficients_comparison.csv` 中 `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 失败封口 | 若未全部 `PASS`，每个失败系数必须对应明确缺口：理论公式、参考数据、坐标符号、归一化、边界条件、自由面 marching、压力恢复、几何输运、端部项或力矩装配之一。 |
| 参考数据闭环 | Ma 2005 / Journee 1992 的参考值、频率、单位、坐标、符号、无量纲方式和数字化来源写入阶段报告。 |
| 频率入口审计 | 生成并测试 `body_potential_frequency_entry_audit.csv` 与 `body_potential_frequency_entry_summary.csv`，结论必须能说明频率依赖是否在体势求解前后丢失。 |
| 三条主链审计 | `A33/A53` 时间压力链、`B33/B35/B53/B55` 阻尼链、`A35/A55` 纵摇矩链均有独立审计表和结论。 |
| 候选隔离 | 未通过八系数硬门槛的候选必须保持 `candidate_default_gate_eligible=false`，不得污染默认结果。 |
| 数值质量 | 验证输出、矩阵、响应幅值算子、时域响应和统计结果无 `NaN/Inf`、空表或不可解释异常值。 |

| 六自由度输出 | 时序结果包含 `surge/sway/heave/roll/pitch/yaw`；迎浪重点验证 `heave/pitch` 和垂向加速度，其余自由度明确模型假设。 |
| 不规则波复现 | 固定随机种子下，不规则波响应均方根、峰值和统计结果可复现。 |
