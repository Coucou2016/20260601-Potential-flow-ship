# Gate 2 频率相关水动力缺口诊断与实施判据

日期：2026-08-16  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
当前验收口径：[下一阶段阶段目标与验收条件](./下一阶段阶段目标与验收条件_当前执行版.md)

## 1. 当前结论

Gate 1 已冻结为双网格 `10/10 PASS`，Gate 2 正式基线仍为 `17/20 PASS`。剩余失败项是 Begovic 升沉幅值、纵摇幅值和主峰频率；本轮诊断没有修改正式基线，也没有把任何跨工况系数或经验倍率接入生产模型。

独立 OpenPlaning 公式审计表明，当前 Faltinsen 第 9 章附加质量和阻尼实现与开源实现一致，附加质量及阻尼矩阵相对差异约为机器精度，恢复力差异约为 `0.9%--1.3%`。因此，剩余误差不是公式抄写错误，而是简化 Chapter 9 模型缺少目标工况下的频率相关、非互易强迫运动水动力及相容波浪激励。

## 2. 本轮修正与新增证据

1. 修正 matched-BIE 与 Gate 2 之间的纵摇坐标变换，统一采用 `T=diag(1,-1)` 和 `K_response=T*K_kernel*T`。
2. 修正局部波浪法向加速度，将 `omega_0^2` 改为 Faltinsen 式 (9.100)--(9.113) 要求的 `omega_0*omega_e`。
3. 修复 `compute_matched_bie_frequency_correction` 被截面 BEM 函数意外截断的问题，并增加两个入口独立可调用的回归测试。
4. 新增 Sun (2007) 式 (7.42)--(7.45) 动量导数路线，明确区分 `DA/Dt` 的湿深变化率与相对入水速度。
5. 新增 Sun (2007) 式 (7.46)--(7.47) 强迫运动一次谐波系数提取器，可从强迫升沉和强迫纵摇载荷时序组装完整 `2 x 2` 附加质量和阻尼矩阵。
6. 从 A3 PDF 第 153 页、印刷页 141 的图 7.13--7.14 数字化 80 个 Sun/Troesch 数值点，保留像素标定、误差带、工况、归一化和源文件 SHA-256。
7. 已形成地固横剖面队列、自由面推进、人工折角分离、射流切除、压力辅助边值问题、前部相似解和沿船长积分的强迫运动原型；`sigma=1.4` 已完成升沉/纵摇两列时序。
8. Sun 图 7.4 恢复矩阵已可重复数字化；同一时序可在不重跑流场的情况下按可追溯恢复矩阵重识别附加质量。
9. 新增严格矩阵加载接口，可合并升沉列和纵摇列 CSV，检查源哈希、五频率八系数、谐波残差、非互易矩阵顺序及恢复来源，并拒绝零恢复或响应标定结果进入生产响应。

## 3. 关键物理发现

Sun/Troesch 强迫运动基准工况为 `Fn_B=2.5`、斜升角 `20 deg`、纵倾 `4 deg`、平均湿长比 `lambda_w=3`。未作艉部三维修正时：

| 无量纲频率 | `A35/(rho B^4)` | `A53/(rho B^4)` | 说明 |
|---:|---:|---:|---|
| 0.85 | 1.957 | -0.155 | 两个交叉项符号相反，明显非互易 |
| 1.40 | 0.646 | -0.208 | `A35` 随频率显著下降 |
| 1.95 | 0.273 | -0.220 | 高频时差距缩小但仍不相等 |

与此同时，`B33`、`B35`、`B53`、`B55` 在五个频率点上的变化均小于 `0.1` 个无量纲单位。该结果与 A3 正文“除 `A35` 外多数系数近似频率无关”的判断一致，也解释了为什么只替换一个准稳态阻尼公式不能闭合 Gate 2。

A4_3 进一步明确指出：高 Froude 数共振区若使用简化方法得到的过低 `A35`，运动计算可能发散；改用强迫运动数值方法得到的 `A35` 后才收敛。这与当前最高航速 Chapter 9 状态矩阵出现正实部特征值的诊断一致。

## 4. 已排除候选

### 4.1 仅修正 Sun 式 (7.45) 动量导数

将 Chapter 9 阻尼替换为文献一致的 `DA/Dt` 路线后，三个航速的升沉/纵摇幅值仍全部失败；例如 `Fn_B=2.26` 的归一化均方根误差达到 `627%/436%`，主峰误差为 `30.0%/20.8%`。因此，式 (7.45) 的前部近似载荷不能代替完整强迫运动 BEM。

### 4.2 直接移植 Sun/Troesch 单一工况矩阵

将数字化矩阵按船宽量纲缩放到 Begovic 船体，仅作为敏感性诊断。采用带艉部三维修正的完整矩阵时：

| `Fn_B` | 升沉中位误差 / NRMSE | 纵摇中位误差 / NRMSE | 升沉/纵摇主峰误差 |
|---:|---:|---:|---:|
| 1.67 | 48.0% / 41.9% | 34.1% / 26.1% | 26.2% / 0.2% |
| 2.26 | 57.0% / 48.0% | 35.2% / 28.3% | 17.8% / 23.6% |
| 2.82 | 53.6% / 38.0% | 28.0% / 28.4% | 0.07% / 10.9% |

最高航速升沉主峰显著改善，证明频率相关非互易矩阵确实控制共振位置；但跨航速幅值全部失败，证明不同斜升角、湿长、重心和 Froude 数之间不能直接移植系数。该路线只能用于机理判断，不得进入 Gate 2 正式结果。

### 4.3 其他已完成诊断

matched-BIE 的总压力、时间导数、前进速度项、端部项及其组合，经典独立截面 BEM，以及总长、龙骨湿长、平均湿长和舭线湿长相位尺度均未形成三航速同时通过的结果。所有候选保持诊断状态，没有通过试验响应反演或倍率缩放进入默认模型。

## 5. 生产路线

下一步不再继续组合现有矩阵，而是实现“目标艇强迫运动系数预计算器”：

1. 以目标艇实测或求得的稳态纵倾、龙骨湿长和舭线湿长初始化地固横剖面。
2. 在每个目标遭遇频率分别施加强迫升沉和强迫纵摇，不叠加入射波。
3. 用非线性自由面二维边界元法计算各剖面的压力，包含薄射流处理、硬折角分离、自由面重网格和艉部三维修正。
4. 将剖面力沿船长积分为垂向力和纵摇力矩，再由统一的一次谐波提取器得到 `A33,A35,A53,A55` 与 `B33,B35,B53,B55`。
5. 将目标工况矩阵接入线性频域运动方程，并用同一基流上的站位积分入射/绕射激励计算 Begovic 响应。

该路线虽然使用非线性 BEM 预计算系数，但最终 Gate 2 响应仍是小幅线性规则迎浪响应，不扩大本阶段验收边界。

## 6. 准入条件

强迫运动矩阵进入正式 Gate 2 前必须同时满足：

1. 谐波提取合成真值反演误差 `<=1e-10`，载荷稳态段一次谐波拟合残差 NRMSE `<=5%`。
2. Troesch 五频率、八系数数据完整；各系数中位相对误差 `<=10%`、NRMSE `<=15%`，并正确再现 `A35` 频率下降和 `A35 != A53`。
3. 横剖面数、边界面板数和时间步长加密后，各系数变化 `<=5%`；艉部三维修正必须单独报告，不得用响应数据确定修正长度。
4. 所有矩阵明确使用升沉向上、纵摇艏部向上、力矩关于重心的约定，单位和量纲恢复测试全部通过。
5. 目标艇强迫运动计算不得读取 Begovic 响应幅值或相位；试验数据只用于计算完成后的盲对照。
6. 接入后 Gate 1 不回退，Gate 2 的频域--时域、线性、残差、数据追踪和完整回归检查继续通过。
7. 最终 Begovic 与 Fridsma 精度达到当前执行版第 7--8 项，机器验收由 `17/20 PASS` 提升为 `20/20 PASS`。

## 7. 当前完成判定

本轮已完成缺口定位、公式修正、强迫运动识别与矩阵加载接口、独立系数/恢复基准及单频率原型诊断。24 面板、`sigma=1.4` 升沉列在图 7.4 恢复扣除后得到 `A33=1.0161`、`A53=-0.1078`、`B33=2.5350`、`B53=1.4702`；对角项已接近基准，但交叉项和网格收敛尚未过门槛。28 面板原时间步失稳已由隔离诊断定位为时间分辨率问题，16 子步正式复算正在执行。五频率八系数、横剖面/面板/时间步三轴收敛及目标艇矩阵仍未完成，因此 Gate 2 保持原状态。下一项主任务仍是让 `NonlinearBEM2DtProvider` 在“规定运动、无入射波”模式下完整通过 Troesch 准入条件，再用于 Begovic 目标工况。
