# 下一阶段目标与验收条件：总体目标对齐简明版

日期：2026-08-08

## 1. 总体目标锚点

后续所有工作继续围绕《高速船型运动预报系统总体目标》展开：以高速滑行艇为核心，建立可验证、可扩展、可追溯的 2.5D 运动预报模型及软件框架，并逐步扩展到排水船、半排水船、多体船、三体船和未来水翼船。

当前阶段不追求“功能铺得更广”，而追求“核心模型做实”。只有线性高速 2.5D 水动力核心通过可追溯硬验证后，后续非线性 2D+t、多体船、三体船和水翼模块才有可靠根基。

## 2. 当前进展

项目已完成第一轮可扩展、可测试、边界清楚的工程升级：

1. 已建立 `planing_seakeeping` Python 包、命令行入口、配置读取、规则波和不规则波计算、频域响应、时域响应、六自由度统一输出、可视化和报告生成链路。
2. 示例滑行艇算例可运行，能够输出不同航速下的响应幅值算子、时域响应、加速度、汇总表和图像。
3. 已建立文献和验证框架，覆盖 Faltinsen、Ma--Duan--Song、Fridsma、Katayama、Delft 372、SL-7、ITTC 等验证路线。
4. 线性 2.5D 默认主线已固定为 `matched_bie_station_sweep`，并生成大量分量级诊断表。
5. 最新固定验证汇总为 `64 PASS / 16 FAIL / 8 NOT_EVALUATED / 91 INFO`。

但核心验收尚未通过：

1. Ma 2005 Wigley III 八个升沉/纵摇水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 仍全部为 `FAIL`。
2. 失败源已从“结果不合理”压缩到三条主要方程链：`A33/A53` 时间压力与体势尺度链，`B33/A35/B35` 固定控制面几何输运链，`A55/B55` 纵摇矩与端部项链。
3. 目前所有候选修正仍应保持 `diagnostic-only`，不得进入默认生产路径。

## 3. 下一阶段目标

下一阶段目标为：

> 完成线性高速 2.5D 核心水动力模型的 Gate 1 硬验证闭环，使默认 `matched_bie_station_sweep` 路径下 Ma 2005 Wigley III 八个水动力系数全部通过；若仍不能全部通过，则必须把每个失败项封口到明确的公式、坐标、归一化、边界积分、历史卷积、端部项或参考数据缺口。

一句话概括：

> 把当前“可运行、可诊断”的 2.5D 主线推进到“可验证可信”，不靠经验拟合，不靠最终系数补丁。

## 4. 本阶段工作范围

1. 闭合 `A33/A53`：核清时间压力项、体势归一化、自由面局部时间映射和 Ma 2005 无量纲方式。
2. 闭合 `B33/A35/B35`：推导并实现固定控制面下的分布式几何输运项，明确 `Eq.31` 与 `Eq.32` 的等价或差异来源。
3. 闭合 `A55/B55`：统一 `N5/m5`、纵摇力臂、压力梯度矩、Stokes body moment 和端部轮廓项的符号、尺度和装配方式。
4. 固定参考数据链：明确 Ma 2005 Wigley III 八点参考值的图号、频率、归一化和数字化来源。
5. 保持示例运动链路可运行，确保核心修正不破坏配置读取、六自由度输出、规则波、不规则波和可视化。

## 5. 暂不纳入本阶段

1. 不实现生产级强非线性 2D+t 自由面边界元。
2. 不实现双体船、三体船共同边界积分。
3. 不实现水翼、压浪板和控制器耦合生产模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不用经验倍率、曲线拟合、最终系数修补或按参考值反推的方式制造通过。

## 6. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | `ma2005_wigley_iii_coefficients_comparison.csv` 中八个核心系数均使用 `provider_route == matched_bie_station_sweep`。 |
| 八系数硬门槛 | `A33/B33/A35/B35/A53/B53/A55/B55` 全部为 `PASS`，且 `gate_ratio <= 1.0`。 |
| 方程来源 | 所有进入默认路径的修正必须能追溯到 Ma--Duan--Song、Faltinsen 或已登记文献中的方程、边界条件、坐标定义、归一化或力矩定义。 |
| 候选纪律 | 未通过八系数硬门槛的候选全部保持 `diagnostic-only`，并在候选汇总表中说明排除原因。 |
| 三条失败链 | `A33/A53`、`B33/A35/B35`、`A55/B55` 均有单独审计表，说明修正结果、剩余误差和是否进入默认路径。 |
| 参考数据 | 八点参考值的来源、频率、坐标、单位和无量纲方式固定，并写入阶段报告。 |

| 不规则波 | 固定随机种子下，不规则波响应统计可复现，均方根、峰值和谱响应结果可追踪。 |

| 阶段报告 | 更新阶段报告，记录公式依据、代码改动、验证命令、八系数对照、失败项、排除候选和剩余风险。 |

## 8. 阶段完成判定

本阶段有两种合格出口：

1. 理想出口：Ma 2005 Wigley III 八系数全部 `PASS`，默认线性 2.5D 核心进入可验证可信状态，示例运动链路和完整测试通过。
2. 阻塞封口出口：八系数仍未全部 `PASS`，但每个失败项都有明确失败来源、已排除候选、待补公式或待补参考数据清单，且不能再被归为笼统的“模型不合理”。

若只得到平滑曲线、局部改善或单个系数通过，但不能满足上述条件，则不得宣布本阶段完成。
