# 下一阶段阶段目标及可验收条件

日期：2026-08-09

## 1. 总体目标对齐

后续所有工作继续围绕《高速船型运动预报系统总体目标》展开：以高速滑行艇为核心，建立可扩展到排水船型、半排水船型、单体、多体、三体和未来水翼船型的运动预报系统。

当前阶段不再优先扩展功能面，而是先把线性高速 2.5D 核心水动力链做实。只有 2.5D 基础链通过可追溯验证，后续的六自由度运动响应、不规则波统计、非线性 2D+t、多体干扰和水翼控制扩展才有可信地基。

## 2. 当前进展判断

已经完成：

1. 已建立 `planing_seakeeping` Python 包、命令行、配置读取、波浪输入、频域响应、时域响应、六自由度统一输出、可视化和报告输出链路。
2. 已形成 `linear_2p5d`、`nonlinear_2dt`、`multihull`、`hydrofoil` 等扩展入口，但生产级主线仍聚焦线性 2.5D。
3. 已整理并接入 Ma 2005、Faltinsen、Fridsma、Katayama、Delft 372、SL-7 等验证资料和基准数据。
4. 默认线性 2.5D 验证路径已固定为 `matched_bie_station_sweep`，并能输出系数对照、力项分解、站位诊断、候选路线审计和失败原因追踪。
5. 示例滑行艇运动链路已经可运行，能够生成规则波和不规则波下的响应、六自由度时序、加速度、图像和报告。
6. 最新针对性测试已通过；完整回归测试在最新修改后尚未重新跑完，需要作为下一阶段验收项补跑。

尚未完成：

1. Ma 2005 Wigley III 八个核心线性 2.5D 水动力系数 `A33/B33/A35/B35/A53/B53/A55/B55` 当前仍为 `0/8 PASS`。
2. 当前默认结果的主要误差仍集中在压力梯度、row-measure 几何输运、端部轮廓项、纵摇力矩链、频率传递和归一化闭合上。
3. 最新 row-measure 与 end-contour 组合审计表明：row-measure 有物理相关性，但不足以单独通过；当前端部项只明显改善 `B33`，同时会恶化多个纵摇和耦合项，因此不能提升为默认生产路线。
4. SL-7、C1 三体船和 Delft 372 可作为后续验证对象，但不作为本阶段硬通过门槛。
5. 非线性 2D+t、多体船共同边界积分和水翼控制模型仍属于后续扩展，不应在本阶段冒充已验证成果。

## 3. 下一阶段目标

完成线性高速 2.5D 默认 matched-BIE 求解链的 Gate 1 封口。

具体目标是：以 Ma 2005 Wigley III 八个核心水动力系数为硬基准，使 `matched_bie_station_sweep` 达到以下两种结果之一：

1. 硬通过：`A33/B33/A35/B35/A53/B53/A55/B55` 全部达到 `PASS`，且所有进入默认路径的修正均可追溯到明确理论、公式、坐标约定、边界条件或数值离散处理。
2. 封口通过：若八系数不能全部 `PASS`，必须把每个失败项定位到明确、可复核的缺口，并写明下一步必须补充的理论推导、参考数据、几何数据或数值边界条件。

一句话目标：

> 把当前“可运行、可诊断”的线性 2.5D 主线推进到“可验证、可解释、失败源可封口”的核心模型阶段。

## 4. 本阶段工作范围

纳入本阶段：

1. 固定 Ma 2005 Wigley III 和 Journee 1992 参考数据链，包括频率、单位、坐标、归一化、数字化来源和取舍理由。
2. 闭合或封口 `A33/A53` 时间压力链，包括 body potential 尺度、局部时间映射、自由面 marching、压力恢复和归一化。
3. 闭合或封口 `B33/B35/B53/B55` 阻尼链，包括 pressure-gradient、end-term、同频 A/B 配对、频率传递和固定控制面端部处理。
4. 闭合或封口 `A35/A55` 纵摇力矩链，包括 `N5/m5`、力臂原点、压力梯度矩、Stokes body moment、end-contour moment 和参考轴约定。
5. 保持示例滑行艇运动链路可运行，输出六自由度响应、规则波和不规则波时域结果、响应幅值算子、垂向加速度和图表。
6. 更新阶段报告，使结论均能对应到代码路径、验证命令、CSV 输出和文献依据。

不纳入本阶段：

1. 不开发生产级强非线性 2D+t 自由面边界元。
2. 不开发生产级双体船、三体船共同边界积分模型。
3. 不开发生产级水翼、压浪板和控制器耦合模型。
4. 不把 SL-7、C1 三体船或 Delft 372 作为本阶段硬通过条件。
5. 不用经验倍率、最终系数拟合或按参考值反推参数的方式制造通过。

## 5. 可验收条件

| 类别 | 验收条件 |
|---|---|
| 默认路径 | 八个核心系数均由 `provider_route == matched_bie_station_sweep` 计算得到。 |
| 硬通过条件 | `ma2005_wigley_iii_coefficients_comparison.csv` 中八个核心系数全部为 `PASS`，且 `gate_error_ratio <= 1.0`。 |
| 封口条件 | 若未全部 `PASS`，每个失败系数必须对应明确 blocker，并给出 `next_required_evidence`。 |
| 理论可追溯 | 所有进入默认路径的修正必须对应具体公式、边界条件、坐标约定、自由面 marching、压力恢复、几何输运、力矩装配或端部项。 |
| 候选隔离 | 未通过硬门槛的候选路线必须保持 `candidate_default_gate_eligible=false`，不得污染默认结果。 |
| 数据闭环 | Ma 2005 / Journee 1992 的参考值、频率、单位、坐标、归一化、数字化来源和采用理由必须写入阶段报告。 |
| 诊断闭环 | 至少形成 `B33` 端点/半站位/端部项审计，以及纵摇耦合链 `A35/B35/B53/A55/B55` 的力矩源审计。 |
| 数值质量 | 验证输出、矩阵、响应、时序和统计结果不得出现 `NaN/Inf`、空表或不可解释异常值。 |
| 示例链路 | `configs/example_planing.yml` 可运行，并生成 `summary.csv`、`rao.csv`、时域 CSV、图像和 `run_report.md`。 |
| 六自由度输出 | 时序结果包含 `surge/sway/heave/roll/pitch/yaw`；迎浪主验证聚焦 `heave/pitch` 和垂向加速度，其他自由度必须标注模型假设。 |
| 不规则波复现 | 固定随机种子时，不规则波均方根、峰值和统计结果可复现。 |
| 自动测试 | `python -m pytest -q` 全部通过；若未完整运行，必须记录已运行测试、未跑原因和补跑计划。 |
| 阶段报告 | 更新 `docs/线性2p5D_Gate1硬验证通过_阶段报告.md`，包含公式依据、代码改动、验证命令、八系数对照、候选排除、剩余风险和下一步。 |
