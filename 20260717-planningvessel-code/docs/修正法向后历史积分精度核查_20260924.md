# 修正法向后历史积分精度核查

日期：2026-09-24。上位目标：高速船型运动预报系统总体目标。**阶段未通过。**

## 目的与方法

此前两控制半径的复数载荷变化不足以解释主要参考偏差。本轮固定半径0.9米、无量纲遭遇频率3、321站位、64船体面元、96控制面面元、时间步和完整历史，单独将历史核的谱积分点数从64加到128、256。波数上限保持25每米；自由面推进、法向修正和压力路线不变。

历史核是过去控制面势和法向导数对当前解的影响。其波数积分既有有限上限导致的截断误差，也有有限点数导致的求积误差。本轮只检查后者，不把两者混同。

独立数值参考采用原波数坐标中的自适应积分；生产核采用波数平方根坐标上的等距梯形积分。对96面元控制面的6组场点/源点，抽查1、128、512步滞后下的势核和法向导数核，共36项。包含近水面、跨控制面及深部点，不使用实验响应。参考仅检验同一有限积分区间，不是对原理论的独立物理验证。

## 历史核条目核查

| 积分点数 | 势核最大绝对误差 | 法向导数核最大绝对误差 |
|---:|---:|---:|
| 64 | 0.002742 | 0.035015 |
| 128 | 0.000664 | 0.007793 |
| 256 | 0.000164 | 0.001890 |

上述量包含源面元长度，两个核的量纲不同，不能跨列比较大小。各列误差随点数加倍约减至四分之一，符合该光滑有限区间梯形积分的二阶行为。绝对条目误差不能直接换算为整船载荷误差，因此另做实际场解。

## 三档实际场解

| 积分点数 | 无量纲总升沉激励幅值 |
|---:|---:|
| 64 | 7.704469363 |
| 128 | 7.703398185 |
| 256 | 7.703135811 |

| 加密 | 绕射升沉复数变化 | 绕射纵摇复数变化 | 总升沉复数变化 | 总纵摇复数变化 |
|---|---:|---:|---:|---:|
| 64→128 | 0.05701% | 0.07589% | 0.01524% | 0.01469% |
| 128→256 | 0.01396% | 0.01860% | 0.003730% | 0.003601% |

复数变化按两档复数载荷差的模除以细档载荷模计算，兼顾幅值与相位；绝对变化也写入机器结果。这里的纵摇是关于几何船中的激励力矩，并不是实际纵摇运动。三档最大方程残差均小于1e-15。

## 结论与边界

在这个单频候选中，固定波数上限25每米后的求积误差很小，不能解释与候选参考曲线的主要差异。仍不能排除高波数尾部截断、历史时间离散、控制面空间积分、自由面接触处理和2.5D适用性误差。三档谱积分并不等于全交付频段三档站位/面元/历史收敛，不能据此完成原合同。

下一步应单独检查波数尾部截断，并维持足够的谱分辨率。近水面源点和场点的指数深度衰减较弱，应重点检查；本轮不根据参考幅值选择截断值，也不把更接近实验当作积分正确的证明。独立复数激励参考准入及三航速整船门槛仍未完成。
