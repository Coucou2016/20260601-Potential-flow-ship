# Gate 2：12.5°三网格精确残差闭合审计

日期：2026-08-29  
结论：**12.5°数值桥接门 `PASS`；物理验证 `NOT_EVALUATED`；二维入水先决门与整船 Gate 2 仍未通过。**

## 1. 审计对象与边界

12.5°只作为12.75°到10°的同伦桥接点，没有冻结的独立自由面、压力或载荷物理参考。本审计只判断参考隔离求解器能否在320/640/1280三层网格上同时满足正式精确运动学残差、根闭合和最后两级数值收敛，不评价物理精度。

正式指标采用Iafrati式（52）

```text
K = integral(S_nu^2 ds)
  = sum[Delta_s*(r_left^2+r_left*r_right+r_right^2)/3]
```

覆盖完整外自由面，不删除根区、不使用中点替代积分，也不挂载物理参考参与残差、方向、线搜索或停止条件。

## 3. 最后两级收敛

统一相对变化定义为

```text
abs(fine - coarse) / max(abs(fine), 1e-12)
```

640到1280面板的正式`K`变化为`2.1250%`，积分垂向力变化为`0.03969%`，均小于`5%`门槛。积分力比点态残差更稳定，说明网格加密没有造成载荷跳支；`K`在1280面板略高于640面板，但差异落入预登记收敛界，并且三层绝对值均过门。

## 4. 推进路线

320面板从已通过的12.75°检查点按0.25°单步同伦建立。64/128/192模态全局离散余弦方向、精确坐标子空间、根区局部余弦方向和冻结方向复用均使用完整根闭合及正式精确端点积分接受。192模态方向使v873首次越过320绝对门。

640面板采用保守弧长重网格和归一化弧长方向映射。1280面板先从640检查点保守重网格，再用全局方向映射、根区诊断及受限连续复用达到v882。所有候选保留位移、曲率、条件数、根失配和有限性硬约束；没有降低门槛或删除残差分量。

12.5°三网格数值桥接门正式改判为`PASS`。该结论只证明从12.75°继续向10°延拓具备数值基础，不能替代10°、20°和30°的独立自由面、压力峰值/峰位及积分载荷物理对照。
