## 1. 目的与纪律

`v83` 的四步锯齿周期最小值仍缓慢下降，但长时分类为 `INSUFFICIENT_OR_NONMONOTONE`。本轮按相同 `pseudo_cfl=0.25` 连续执行两个预声明的 `100` 步窗口，形成 `v83/v84/v85` 晚期检查点序列。参考曲线只在求解结束后评分，不参与状态推进、外推或停止条件。

## 4. 晚期外推资格

`v83→v84` 与 `v84→v85` 的伪时间间隔分别约为 `0.09842` 和 `0.09798`，间隔比约 `1.0045`，满足等间隔前提。正式矢量 Aitken 候选随后重建完整增广边界积分状态，但候选残差比为 `0.983668`，高于预声明上限 `0.9`，没有实现至少 `10%` 的残差降低，因此机器判定 `REJECTED`。

拒绝后没有写入变换检查点，也没有继续候选状态。CLI 现会为所有资格拒绝写出机器清单，记录三源检查点路径、累计时间、源文件哈希、重建误差、全部资格阈值和拒绝原因。

## 5. 结论

1. 普通推进在 `v83→v85` 期间持续降低残差和压力误差，证明分支仍有数值进展。
2. `v85` 尚未达到运动学长时收敛，自由面 Zhao 门也未通过，因此不能启动正式第三网格和 `10/20/30 deg` 三角度验收。
3. 晚期 Aitken 路线已被机器资格否决，不得用外推候选替代普通分支。
4. 当前正式状态保持：二维压力先决门 `FAIL`，Gate 2 为 `17/20 PASS`。
