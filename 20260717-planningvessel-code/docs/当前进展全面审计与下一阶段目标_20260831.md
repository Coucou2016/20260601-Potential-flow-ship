## 4. 总体判断

项目已经越过“只有方案和占位程序”的阶段，具备了可运行框架、线性2.5D水动力验证和较强的软件回归基础。但距离总体目标仍有明显距离：**目前真正通过独立验证的核心主要是Gate 1和部分纵向线性长波响应；非线性二维入水、整船规则波全门、不规则波、斜浪六自由度、多体干扰和水翼控制尚未形成连续验证链。**

因此，当前进度应描述为“框架基本成形、线性核心局部验证通过、关键物理门仍在攻关”，不宜用一个百分比概括，也不宜把模块存在等同于模型完成。

## 5. 主要风险

1. **数值通过与物理通过混用。** 12.75°和12.5°只通过数值门，不能作为10°、20°、30°物理精度证据。
2. **参考合同不够统一。** 20°等算例的不同文献参考存在超出数字化不确定度的差异，必须预先指定主参考和冲突处理规则。
3. **文档权威入口过多。** 项目中有大量带“当前”“最终”“唯一”字样的历史文件；后续应以总体目标、本审计和现行阶段验收文件为权威入口。
4. **产物与源码绑定不足。** 项目无Git提交标识，部分历史产物未保存完整源码哈希或机器测试报告。
5. **真实产物回归不足。** 现有测试大量覆盖公式和合成门槛，但对v883至v899冻结产物的严格重载和哈希锁定仍需加强。
6. **资料索引不等于证据追踪。** `materials_inventory.csv`可盘点文件，但尚不能替代“公式--页码--数据--代码--测试--结论”的逐项追踪表。
