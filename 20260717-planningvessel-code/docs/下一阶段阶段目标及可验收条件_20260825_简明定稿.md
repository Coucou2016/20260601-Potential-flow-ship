# 下一阶段阶段目标及可验收条件

日期：2026-08-25  
上位目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
阶段名称：**线性高速 2.5D 规则迎浪纵向运动可信基线闭合（Gate 2）**

> 本文件是下一阶段的统一执行与验收口径。只有全部硬条件通过，才能进入不规则波、斜浪六自由度、非线性 2D+t 和多体船扩展。

## 1. 当前基线

- `Gate 1 = PASS`：Ma 2005 线性高速 2.5D 十行水动力基准为 `10/10 PASS`，最大双网格变化为 `1.1465%`。
- `Gate 2 = 17/20 PASS`：Begovic 独立规则波试验的升沉幅值、纵摇幅值和主峰频率尚未通过。
- 二维压力先决门为 `FAIL`：当前 `20 deg` 长期候选的自由面和压力分布归一化均方根误差分别约为 `25.81%` 和 `31.66%`，压力峰值和峰位误差约为 `17.10%` 和 `29.86%`，运动学残差仍约为 `0.254`。
- 耦合末态检查点、恢复路径等价、三档时间步和 `80/120` 两级空间门均为 `PASS`；这些结果只证明数值离散稳定，不代表二维压力物理基准通过。第三网格观测阶仍待完成。
- 最近一次完整软件回归为 `505 passed、0 failed`，已覆盖检查点、完整射流尖端资格、根恢复候选和时间步/网格分析器。

## 2. 阶段目标

**在保持 Gate 1 不退化的前提下，完成二维入水压力、频率相关升沉--纵摇水动力、直接波浪激励、恢复力、耦合运动和垂向加速度的物理与数值闭合；通过 Zhao--Faltinsen、Sun--Troesch、Begovic 和 Fridsma 的分层独立验证，使 Gate 2 从 `17/20 PASS` 达到 `20/20 PASS`，形成不依赖试验反演或经验调幅、可解释、可追溯、可一键复现的线性高速 2.5D 规则迎浪纵向运动预报基线。**

禁止使用试验响应反演、参考值缩放、经验倍率、逐点拟合、选择性删点或事后改变验收区间。

## 3. 可验收条件

以下九项必须全部满足，缺一项即不通过。

| 编号 | 验收项 | 通过条件 |
| --- | --- | --- |
| 1 | Gate 1 不退化 | Ma 2005 十行基准继续 `10/10 PASS`；最后两级网格最大变化 `<=5%`；单位、符号、坐标、矩阵顺序和相位约定可追溯。 |
| 2 | 二维压力先决门 | Zhao--Faltinsen 恒速楔形入水 `10 deg、20 deg、30 deg` 均满足：自由面归一化均方根误差 `<=5%`，压力曲线归一化均方根误差 `<=10%`，压力峰值、峰位及积分垂向力误差各 `<=5%`；最后两级空间和时间离散变化各 `<=5%`。 |
| 3 | 源级水动力闭合 | Sun--Troesch `5` 个频率、`8` 个升沉--纵摇系数全部计算；中位相对误差 `<=10%`，归一化均方根误差 `<=15%`，网格变化及谐波拟合残差各 `<=5%`，耦合项符号和趋势正确。 |
| 4 | 方程与激励闭合 | 完整求解 `[-omega_e^2(M+A)+i*omega_e*B+C]xi=F_exc`；质量、附加质量、阻尼、恢复力和非零直接波浪激励均有理论来源、正确单位及独立测试，不允许由目标响应反演激励。 |
| 5 | 三航速运动验证 | 保留 Begovic `Fn_B=1.67、2.26、2.82` 全部数据；预先声明的线性适用区内，升沉和纵摇中位相对误差各 `<=15%`、归一化均方根误差各 `<=20%`、主峰频率偏差各 `<=10%`、非近零响应相位中位循环误差 `<=15 deg`。范围外数据不得删除，须单列解释。 |
| 6 | 独立加速度验证 | 使用冻结的 Fridsma 1969 数据；重心垂向加速度归一化均方根误差 `<=25%`；同步输出艏部垂向加速度，并明确线性谐波加速度不等同于非线性砰击峰值。 |
| 7 | 数值自洽 | 有效频点复数运动方程相对残差 `<=1e-8`，无 `NaN/Inf`；至少 `3` 个代表频点的频域--时域幅值差 `<=5%`、循环相位差 `<=5 deg`；波幅加倍后的响应幅值比为 `2.00 +/- 5%`。 |
| 8 | 数据与软件可追溯 | 冻结几何、质量惯性、航速、波浪、来源页码、数字化方法、不确定度和源文件 SHA-256；提供公式--代码--测试--验证数据追踪表；检查点直接续算与分段续算等价；定向测试和完整 `python -m pytest -q` 均无失败。 |
| 9 | 一键复现与交付 | 一条固定命令可从空输出目录生成输入快照、水动力和激励矩阵、频域/时域结果、试验误差统计、收敛诊断、二维图、三维船型与动态可视化、阶段报告和机器验收清单；最终明确输出 `Gate 1 = PASS`、`Gate 2 = 20/20 PASS`。 |

## 4. 必要交付物

1. 三角度二维楔形入水基准及空间--时间联合收敛报告。
2. Sun--Troesch 五频率八系数源级验证数据与误差统计。
3. Begovic 三航速升沉、纵摇、相位对照和 Fridsma 垂向加速度对照。
4. 频域--时域一致性、线性缩放、矩阵残差及失败工况诊断。
5. 冻结输入、文献来源、SHA-256 和公式--代码--测试--数据追踪表。
6. 一键复现脚本、机器验收清单、二维图、三维船型、动态可视化和阶段报告。

## 5. 执行顺序与完成判定

1. 利用已验证的检查点续算功能完成两档时间步、两档网格的二维压力收敛；未通过前不启动整船生产验证。
2. 二维压力通过后，完成 Sun--Troesch 五频率八系数源级验证。
3. 源级验证通过后，冻结模型并完成 Begovic、Fridsma 独立整船验证。
4. 最后完成频域--时域一致性、三维可视化、一键复现和完整回归。

只有九项硬条件全部满足且机器验收为 `Gate 2 = 20/20 PASS`，才能宣布本阶段完成。单个算例改善、低代数残差、接口完成或软件测试通过，均不能替代独立物理验证。

本阶段只验收**小幅规则迎浪下的升沉、纵摇、相位和垂向加速度**。通过后依次进入：不规则波纵向统计响应、斜浪六自由度、强非线性 2D+t、多体船干扰和水翼控制。
