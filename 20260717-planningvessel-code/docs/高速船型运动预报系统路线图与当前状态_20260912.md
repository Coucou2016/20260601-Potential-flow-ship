# 高速船型运动预报系统路线图与当前状态

日期：2026-09-12  
总体目标：[高速船型运动预报系统总体目标](./高速船型运动预报系统总体目标.md)  
当前阶段验收口径：[二维恒速楔形入水物理验证闭合](./下一阶段阶段目标及可验收条件.md)

## 1. 一句话总体目标

**以高速滑行艇为核心，建立一套能够读取船型、质量惯性、航速、波浪、海流和风等输入，计算不同航速下规则波与不规则波六自由度运动，并能逐步覆盖排水型、半排水型、滑行艇、单体、多体、三体和水翼船的统一2.5D/2D+t运动预报系统；所有可用结论必须具有理论、代码、数值收敛和独立试验对照证据。**

最终交付不是一个单次算例，而是一个可配置、可扩展、可测试、可复现、可说明适用边界的研究型计算平台。

## 2. 状态用语

| 状态 | 含义 |
| --- | --- |
| 已完成并验证 | 功能、测试、数值独立性和规定参考对照均达到当前冻结门槛。 |
| 已实现但未完全验证 | 已有可运行代码和部分测试，但仍有验收项失败或缺少独立对照。 |
| 原型或接口 | 已有数据结构、简化模型或局部算法，不能作为生产级物理结果。 |
| 尚未实现或缺数据 | 已有目标说明，但关键求解器、真实几何或试验数据尚不存在。 |

| --- | --- | --- | --- |
| 1. 统一框架与资料基础 | 建立配置、几何、环境、单位、结果类型、命令行、报告、测试和文献追踪体系。 | 基本完成，持续维护 | 配置和统一接口可用；14份核心文献及Markdown、理论手册、基准数据和报告链已建立。 |
| 2. 线性高速2.5D水动力 | 实现Ma--Duan--Song型站位求解，装配升沉/纵摇水动力系数并通过Wigley III、SL-7验证。 | 部分完成 | 选定10条Wigley III Gate 1为`10/10 PASS`；完整Wigley III频率/系数集和SL-7仍未闭合，SL-7真实型线缺失。 |

| 6. 双体与三体船 | 实现片体间交叉辐射、交叉绕射、湿甲板冲击、连接载荷和三体干扰。 | 几何与装配准备阶段 | Delft 372片体几何可重建；已有分量载荷装配和完整性检查。真实交叉水动力求解器、三体数字型线及系统验证尚未完成。 |
| 7. 水翼、控制与最终集成 | 加入水翼/压浪板载荷、执行器和控制器，完成多船型统一验收和最终报告。 | 初级原型 | 有小攻角有限翼载荷和Routh--Hurwitz稳定性工具；自由面效应、通气、空化、支柱、真实控制器和整船试验验证未实现。 |

**当前在第3阶段。** 第1阶段可视为框架完成；第2阶段只完成了选定核心Gate，完整线性2.5D仍有Wigley III全量和SL-7缺口；第4阶段已有较完整程序但物理验收未全过；第5至第7阶段不能视为生产完成。

## 4. 各模型模块做什么，以及做到什么程度

| 模块 | 主要作用 | 与其他模块的区别 | 当前状态 |
| --- | --- | --- | --- |
| 配置、几何与环境 | 读取船型、质量、惯性、航速、波浪、海流、风和数值参数。 | 负责输入和约定，不直接求水动力。 | 框架已完成；真实目标艇资料仍待补充。 |
| 静水/滑行平衡与航态判别 | 求纵倾、沉降、湿长和排水/半排水/滑行状态。 | 给动态模型提供平均运行姿态和湿表面。 | Savitsky/Faltinsen降阶实现可用；全过程高精度物理拼接尚未系统验证。 |
| 线性2.5D水动力 | 沿船长把二维横剖面水动力按高速局部时间关系装配成整船附加质量、阻尼和激励。 | 适合小幅运动和频域分析，是当前线性主模型。 | 选定Wigley III Gate通过；完整Ma系数集、SL-7和部分压力/端部项仍未全部验证。 |
| 频域升沉--纵摇响应 | 解复数运动方程，得到响应幅值算子、相位、加速度和主峰。 | 使用线性水动力矩阵，计算快，适合扫航速和频率。 | 数值一致性通过；整船实验Gate为17/20。 |
| 规则波时域 | 把规则波激励和运动方程放到时间域，输出运动与加速度历程。 | 可观察相位和瞬态；小幅时应与频域一致。 | 频域--时域幅相一致性通过；强非线性自由航行尚未闭合。 |
| 不规则波模型 | 用Pierson--Moskowitz或JONSWAP谱生成波浪分量，计算时历、均方根、峰值和谱响应。 | 面向真实海况的随机统计，不是单一周期响应。 | 代码和数值测试已有；Fridsma 1971等独立统计验证未完成。 |
| 非线性2D+t边界元 | 在随船前进的横剖面上计算瞬时自由面、入水、砰击、喷溅、分离、压力和湿长变化。 | 比线性2.5D更适合大幅运动和滑行艇强非线性载荷，计算更复杂。 | 自由面边界元、压力辅助问题、重网格、硬折角分离、移动平面和直接规则波项已有；喷溅切除、自由航行耦合和完整物理验证未完成。 |
| 六自由度统一接口 | 统一输出纵荡、横荡、升沉、横摇、纵摇和艏摇。 | 是状态和结果容器，不代表六个方向都已有可信水动力。 | 接口已完成；当前迎浪可信重点仍是升沉/纵摇，其他四自由度多为零或原型。 |
| 多体船模块 | 汇总各片体载荷，并处理片体间相互作用和连接结构载荷。 | 单体结果简单相加不能替代交叉辐射/绕射。 | 分量装配已实现；真实交叉水动力、湿甲板和连接载荷求解未实现。 |
| 水翼与控制模块 | 计算水翼升阻力、力矩、稳定性和控制器作用。 | 需要附体局部流场和控制系统，不能只依赖裸船2.5D。 | 只有线性有限翼和稳定性原型；完整水翼船模型未实现。 |
| 验证与报告 | 对照文献/试验，检查网格、时间步、公式、参考隔离、误差和回归，并输出CSV、Markdown、HTML/PDF。 | 决定结果是否可信，不产生新的物理载荷。 | 基础设施较完整；最终跨阶段一键验收尚未形成。 |

## 6. 哪些“完全没有设计”

严格来说，**总体目标中的主要方向都已有概念方案、接口或验证路线，没有一个核心方向处于完全没有想法的状态。** 但下列内容尚无可验收的生产实现，实际工作中应视为“尚未完成设计落地”：

1. 任意斜浪下完整、高精度六自由度2.5D/2D+t耦合求解器。
2. 非线性2D+t自由航行整船运动耦合器。
3. 多体船交叉辐射、交叉绕射、湿甲板冲击和连接载荷的统一求解器。
4. 三体船真实几何驱动的干扰和增阻生产模型。
5. 包含自由面、通气、空化、支柱和真实控制器的完整水翼船模型。
6. 覆盖全部阶段、从洁净目录执行的最终一键物理验收程序。

## 7. 最容易记住的项目定位

可以把当前项目理解为：

> **底座已经建成，线性2.5D核心通过了一个严格但有限范围的Gate；现在正在攻克非线性2D+t的二维入水先决门。整船规则波已经能算但还差3项实验验收；不规则波、完整六自由度、多体船和水翼已有不同程度的框架或原型，但尚未形成生产级验证闭环。**

后续固定顺序为：**二维入水先决门 -> 规定横剖面水动力 -> 整船规则迎浪20/20 -> 不规则波统计 -> 斜浪六自由度 -> 双体/三体干扰 -> 水翼及控制 -> 最终统一验收。**
