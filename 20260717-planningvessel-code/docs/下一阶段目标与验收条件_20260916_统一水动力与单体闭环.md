# 下一阶段目标与验收条件：共用水动力核验与单体规则迎浪闭环

日期：2026-09-16  
上位目标：[高速船型运动预报系统总体目标](高速船型运动预报系统总体目标.md)  
既有验收合同：[单体规则迎浪执行卡](下一阶段执行卡_20260915.md)

本文件是下一阶段建议执行范围，尚未完成验收；承接既有单体规则迎浪合同，并增加浮筒剖面辐射专项核验，不倒改历史评分。

## 阶段目标

**围绕高速滑行艇核心，核查并修复水动力内核中的已定位问题，完成频率相关辐射与波浪激励的独立核验；通过统一入口，在冻结的单体高速艇三航速规则迎浪试验上交付可复现、误差达标的升沉、纵摇及加速度预测闭环。EDO 106K 浮筒作为剖面核验补充案例，为后续水上飞机扩展提供可信基础。**

当前已有统一入口、三速度24工况计算及输出；实验幅值仅六项“速度—运动”组合中的三项达标。浮筒候选在1155条剖面记录中出现1133条负阻尼，综合网格检查仅4/10通过；全套软件回归787项通过不能替代上述物理验收。

## 实施顺序

1. 冻结参考与约定，核对剖面法向、镜像倍数、自由面边界、势函数与压力积分，形成有证据的根因诊断。
2. 对辐射、波浪激励、恢复力及艉部项分别核验，按已确认的理论或离散缺陷修正，再做分方向收敛检查。
3. 用同一内核重算三航速、密集峰频及Fridsma适用工况，生成逐项验收与实际来源可视化报告。

## 可验收条件

| 编号 | 验收项 | 具体条件 |
|---|---|---|
| 1 | 输入与参考冻结 | 型线来源与重构假设、质量惯性、平均姿态、牵引/推进力矩、航速、波浪、坐标及单位完整。保留Begovic三航速24工况、21个线性适用点和3个诊断点；新增参考、相位约定、误差定义及近零量绝对容差在修正求解前冻结并记录哈希。 |
| 2 | 剖面专项核验 | 一个解析定义的对称剖面、一个EDO实际湿剖面各覆盖五个冻结频率，与原始PDSTRIP在同水深及离散设置下对照；非近零附加质量与阻尼误差分别≤5%。零航速阻尼在冻结容差内满足被动性；镜像倍数、符号和积分修正有公式/源程序依据。 |
| 3 | 整船水动力与收敛 | 旧Wigley基础门仍为10/10、粗细变化≤2%。交付频段八个附加质量/阻尼系数及复数激励完成三档离散，细两档关键量变化≤5%；纵向、船体剖面、自由面分别加密并检查域长，相对方程残差≤10⁻⁸。近零项用条件1冻结的绝对容差。 |
| 4 | 波浪激励与分量诊断 | 交付长波极限、激励相位和独立参考对照，参考及限值按条件1预先冻结；低速与高速的恢复力、八系数、激励及艉部项形成逐分量诊断。每项修改对应可核查的缺陷证据，不使用实验运动响应拟合倍率。 |
| 5 | 三速度实验幅值 | Begovic每个速度的升沉、纵摇均分别满足：中位相对误差≤15%、归一化均方根误差≤20%。三个诊断点继续展示并说明排除依据；合并指标保留，不能替代逐速度达标。 |
| 6 | 峰频、相位及加速度 | 至少解析4个主峰，覆盖至少2个速度和两种运动，各主峰频率误差≤10%。同一内核下Fridsma既有适用区运动仍满足15%/20%，实验相位中位误差≤15°、重心加速度归一化均方根误差≤25%。 |
| 7 | 接线与时频一致性 | 同一入口使用声明的内核；频域响应、规则波稳态时历及加速度共享同一水动力结果。单频固定矩阵的独立常微分方程积分核对：幅值误差≤5%、相位误差≤5°。仅由复数响应重构的时历须标注“稳态重构”，不计作独立积分验证。 |
| 8 | 完整结果与适用性 | 同次运行输出输入快照、几何与真实计算网格、系数/激励幅相、运动和加速度、逐工况误差、适用性、机器验收及自包含HTML报告。六自由度分别标记求解/约束/未支持；失稳、越界湿长、大幅运动及未支持输入拒绝有效预测。网格重构假设明确，未求得的压力和自由面不得冒充计算场。 |
| 9 | 可复现与防误通过 | 环境及完整依赖锁定，洁净目录重跑可复现，全套回归0失败；求解不读取实验响应，未知状态、缺字段、错误哈希、缺工况及非有限结果均拒绝通过，无静默回退。既有试验作为回归验证集标注，另冻结未参与方法选择的公开工况用于独立复核，复核合同在计算前确定。 |

条件2的5%对照值为拟新增的数值核验条件；原始PDSTRIP对照证明实现一致性，不能代替实验验证。零航速被动性条件不直接套用于全部前进速度系数。

## 必要条件与边界

- 优先使用已有Wigley、Begovic、Fridsma及EDO资料。实验验收案例的质量、惯性、姿态等不可用随意假设替代；研究示例允许理论合理的假设并记录敏感性。
- 可先规定实测平均姿态，以隔离耐波模型误差；自动稳态预测需要另有正确姿态基准与牵引/推进力矩验证。
- 浮筒剖面核验通过，只认证其声明范围内的零航速辐射；它不替代单体高速艇验收，也不认证完整飞机起降。
- 本阶段集中完成单体规则波主线。非线性自由航行、随机波实验统计、斜浪六自由度、多体/三体干扰、水翼控制及飞机变速起降按总体目标后续分阶段验收；SL-7、C1数字型线采集不阻塞当前已有基准。

## 完成出口

**全部条件通过后，交付一个水动力来源可查、三航速实验误差达标、结果可视化且可重复运行的单体高速艇规则迎浪案例包，以及独立核验通过的浮筒剖面辐射案例。未通过的条件保留为失败，不以文件齐全或软件测试通过宣布阶段完成。随后扩展同一已验证内核的不规则波统计；飞机起降沿非线性载荷、自由运动、气动/推进耦合路线逐级推进。**
